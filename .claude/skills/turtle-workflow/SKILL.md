## 一条需求怎么走

```
用户需求 → 方案书 docs/plans/（七节 + 已知风险与未决点；登记 docs/README.md）
        → 用户拍板未决点（拍板当场写进记忆；以后作废 / 修改就在原条目上标）
        → 实现（用户点名参考的美术：先参考研究、用户看过再动手 —— 钩子强制）
        → 相关测试 + 反向验证（故意改坏、确认变红、逐字节还原）
        → python tools/precheck.py → python tools/ship.py <主题>（CI 全绿自动快进 main）
        → 玩家可感知才升版本；周一 21:00–23:00 统一换版
        → 方案书回填「实施回填」、状态改「已完成」（归档）
```
