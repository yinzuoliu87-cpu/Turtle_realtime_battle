## 阶段 0 · 先搞清楚它到底做什么（读代码，不读文案）

**文案会漂，代码不会。** 001 这次就是文案里写着「射程 2000 内最近的敌人」，
而 2000 是个永远不会卡住任何事的门槛（目标是最近的敌人，本来就在跟前）——
读文案会以为这是件远程装备。

要定下来的四件事：

| 项 | 001 的答案 | 从哪读 |
|---|---|---|
| 触发条件 | 每 3 秒（`RUST_IV`），场上有敌人就甩 | `equip_tick_system._tick_rustblade` |
| 目标选择 | `_nearest_enemy` —— **最近**（不是最远、不是穿透） | 同上 |
| 伤害 | `0.6/0.75/1.0×ATK + 40/60/100×暴击率`，物理 | 同上 |
| 结算时机 | **命中才结算**（弹道 `frac>=1.0`），路上不打人 | `battle_ballistics` 的 `flyslash` 分支 |

**这四件事决定特效的"分量"。**
1 费、每 3 秒戳 64 点的小 poke ≠ 5 费全场猛砸 + 8 秒眩晕。
LoL 的可读性原则：排场要和威胁度匹配，否则玩家的注意力被不重要的东西吃掉。

## 阶段 2 · 定五段结构

LoL 的弹道是**五段分离**的，不是"一张图在飞"：

| 段 | 内容 | 帧数 | 锚在哪 | 001 |
|---|---|---|---|---|
| ① 蓄势 | 出手前的预兆 | 3~5 | 携带者身上 | 未做（1 费小 poke 不需要） |
| ② 发射 muzzle | 挥出去那一下 | 5 | **出手点，不跟飞** | ✅ 5 帧 |
| ③ 弹体 travel | 本体 | 2~5 循环 | 弹体 | ✅ 8 方向 × 5 帧 |
| ④ 拖尾 | 残影 | 无素材，纯代码 | 路径上 | ✅ 每 45ms 一个 |
| ⑤ 命中 impact | 炸开 | 6~9 | 命中点 | ✅ 9 帧 |

**不加顿帧、不加屏震。** 项目本来就是这么配的：
`JUICE_HITSTOP_LIGHT := 0.0`「轻击不卡」、`JUICE_SHAKE_LIGHT := 0.0`「普通命中 = 不抖」——
只有暴击/击飞/大招/团灭才有。一秒几十次命中的自走棋加顿帧是灾难。
（顿帧+屏震是动作游戏的做法，LoL 和云顶都没有。）

## 阶段 3 · 素材生成（PixelLab）

### 3.1 风格基准从现有素材取

先渲一张现有干净像素图标/特效的并排图看规格：**64×64 或 32×32、8~32 色、粗黑描边、平涂无渐变**。

★ **`style_image` 可以用，`init_image` 不行。**
前者是学描边/明暗风格，后者是**直接保留输入的像素形状** = 拿别人的素材改色 = 违反
「新内容一律新素材」铁律（用户 2026-08-03 定 · 08-04 重申）。
我 09-06 就用错过一次：拿 `eq084-slash` 当 `init_image` 改色，被当场指出。

### 3.1.5 ★纯换措辞救不了：实测 5 轮全废，救场的是 `style_image`

| 轮 | prompt 方向 | 产物 |
|---|---|---|
| 1~3 | "crescent slash（新月斩击）" | 实心月牙 |
| 4 | "claw-mark" 物理构造 | **爪痕**（我自己写的词，怪不得） |
| 5 | "single-stroke sword arc" | 64/64 香蕉 |
| **6** | 同样的词 **+ `style_image`（学"无黑边+发光衰减"）** | **一次就对** |

⇒ 卡在"看着像实心物体"上时，问题多半在**明暗/描边风格**而不在形状措辞，
换 10 个形容词不如给一张风格参考。（`style_image` 学风格 = 允许；
`init_image` 保留输入像素 = 违反「新内容一律新素材」铁律。）

### 3.2 形状描述要说"物理上是什么"，不要用概念词

**这是我卡了三轮的地方。** 写 "crescent slash（新月斩击）" ⇒ 得到实心月牙，三批全是。
改成描述**物理构造**才对：

> Three separate thin curved claw-mark slashes … each a long thin sliver tapering to a
> sharp point at both ends, **clearly separated from the others by empty transparent space** …
> **NOT a solid filled crescent, NOT a moon shape**

关键词：「分离的」「透明间隙」「不是实心的」。同样的写法在命中星爆上一次就对了
（"shards radiating outward … **with transparent gaps between the shards**"）。

### 3.3 单帧 → 动画

`create_image_pro`（小画布给 64 个候选）出基准帧 → `animate_image` 做动画：

```
弹体   action="the energy strokes stretching forward and rippling as they fly"   frame_count=4 → 返回 5 帧
命中   action="the burst expanding outward and fading, shards flying apart"      frame_count=8 → 返回 9 帧
发射   action="the flash bursting outward from the center then fading away"      frame_count=4 → 返回 5 帧
```

★ `animate_image` 返回 **frame_count + 1** 帧（第 0 帧是输入原帧）。常量要按返回值写，别按请求值。

★ base64 传输会被 MCP 客户端**静默截断**。传参前先量化减色（`quantize(colors=12)` + 保留 alpha），
把 base64 压到 ~1000 字节以内。我踩过两次，报错是 "Could not decode image … TRUNCATED in transit"。

### 3.4 8 方向：只用 90° 旋转 + 镜像

**像素风不许自由旋转** —— 旋转让像素落在非网格位置，边缘出锯齿、飞行中抖动。
所以贴图本身永不转，改成**按角度选帧**。

而 8 个方向从 1 张基准帧推出来：

```python
E  = base
N  = base.transpose(ROTATE_90)
W  = base.transpose(ROTATE_180)
S  = base.transpose(ROTATE_270)
NE = N.transpose(FLIP_LEFT_RIGHT)     # 斜向用相邻正交的镜像
NW = N.transpose(FLIP_LEFT_RIGHT)
SW = W.transpose(FLIP_TOP_BOTTOM)
SE = S.transpose(FLIP_LEFT_RIGHT)
```

**只有 90° 旋转和镜像对像素无损**，45° 旋转会重采样。
表布局：横 8 格 = 方向（E/NE/N/NW/W/SW/S/SE），纵 N 格 = 动画帧。
脚本见 `scratchpad/build_dir8.py`（应移进 `tools/`）。

## 阶段 4 · 装进游戏

```
assets/sprites/vfx/eq001-flyslash-muzzle.png    160×32   (5 帧)
assets/sprites/vfx/eq001-flyslash-dir8.png      256×160  (8 方向 × 5 帧)
assets/sprites/vfx/eq001-flyslash-impact.png    288×32   (9 帧)
```

★★★ **新 png 必须跑一次 Godot 导入**，否则 `load()` 返回 `null`：

```bash
"…/Godot_v4.6.3-stable_win64.exe" --headless --path . --import
```

不导入的表现是 **画面上什么都没有，而错误只在日志里一行 `No loader found for resource`**——
我因此白跑了一轮，还以为是 shader 或代码错。判据：`ls assets/…/xxx.png.import` 存不存在。

三条渲染纪律：

| 纪律 | 为什么 |
|---|---|
| `TEXTURE_FILTER_NEAREST` | `LINEAR` 把像素糊成渐变，而同画面的龟是清晰点阵 ⇒ 一眼看出不是一个游戏 |
| `pixel_size = TARGET_BODY_H / 帧高` | 与龟同口径（0.0625 m/px）。不同口径 = 同画面两种像素尺寸 |
| 不用 `blend_add` | 会洗白，颜色该由美术定 |

## 阶段 5 · 接线

```gdscript
# ③ 弹体: 按角度选帧, 永不旋转
p.hframes = FLYSLASH_DIRS      # 8 方向
p.vframes = FLYSLASH_FRAMES    # 5 帧
p.billboard = BILLBOARD_ENABLED         # 正对相机
# 弹道循环每帧:
var ang := atan2(-screen_delta.y, screen_delta.x)
var di := int(round(ang / (TAU / 8.0))) % 8
sp.frame = 帧号 * 8 + di

# ④ 拖尾: 残影, 不画进贴图
if pr.has("afterimage"):
    每 45ms → 复制当前帧 → 原地 0.20 秒淡出

# ⑤ 命中: 接到弹道结算点
elif pr.get("flyslash", false):
    battle._damage._apply_damage_from(…)
    battle._flyslash_impact(tgt["pos"], pr["col"])   # ← 原来这里只有伤害数字
```
