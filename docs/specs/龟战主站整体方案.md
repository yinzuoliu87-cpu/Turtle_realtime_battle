# 龟战 × 主站 整体方案

版本：2026-11-07　|　本文取代《龟战 × 主站 对接说明》和《主站对审核反馈的回复》，以本文为准。

## 1. 一句话

玩家把主站的龟币存进**金库**，在**主站网页**上挑一个对手发起**偷袭**，双方押同样多的龟币；**小游戏**用双方设好的阵容在服务器上打一场，把胜负告诉主站，**主站**把押注转给赢家。

## 2. 分工

| | 主站（TurtleBet） | 小游戏（App） |
|---|---|---|
| 账号 | 账号主体，确认 App 登录 | 用主站账号登录后才能参与偷袭 |
| 钱 | 金库存取、押注、结算、提现、所有金额展示 | **不出现任何龟币或金额**，只有自己的深海币 |
| 龟 | 玩家拥有哪些龟（开蛋获得） | 只能用玩家拥有的龟 + 自己的限免龟；**等级和升级系统由小游戏做**，等级变化告诉主站 |
| 阵容 | 不管 | 玩家在 App 里设一套**固定阵容**（不随大轮重置） |
| 偷袭 | 推荐对手、发起、锁定押注、结算、记录、消息通知 | 接任务、服务器裁判、回传结果、录像 |
| 录像 | 偷袭记录里放「看录像」链接（电脑上内嵌播放器，手机提示去 App 看） | 提供网页播放器 |
| 后台 | 数值设置、总开关、记录查询、对账 | 自己的开关 |

小游戏自己的周赛、深海币、商店都照常保留，和主站无关。

**两种货币完全分开：**
- **龟币**只在偷袭里输赢。偷袭是唯一和龟币有关的对战。
- **深海币**只在小游戏的其他模式里获得，用来买装备、升级阵容，让偷袭时更强。深海币不能用龟币或真钱买，也不能换成龟币。

**守方可以离线：** 设好固定阵容后，玩家离线也会被偷，由他的固定阵容自动应战，结果出来后主站发消息通知他。

**每周重置：** 装备随小游戏的大轮每周重置，固定阵容上的装备也一起清空；龟的等级一直保留。所以每周开始时大家的阵容都偏弱，靠这一周赚深海币重新买装备变强。重置后固定阵容（龟和站位）照样有效，玩家不用重新设，守方离线也照样能应战。

## 3. 玩家怎么玩

1. **绑定账号：** 玩家在 App 点「用主站账号登录」→ 系统浏览器打开主站确认页 → 登录主站，点「确认登录小游戏」→ 回到 App 就绑好了。
2. **设阵容：** 在 App 里设好固定阵容（3 只龟）。没设的人不能偷袭，也不会被推荐成对手。
3. **存金库：** 在主站把龟币从主钱包存进金库。只有金库里的钱能被偷，主钱包永远安全。
4. **偷袭：** 在主站「龟战」页看到 3 个推荐对手和各自的押注额，挑一个点「偷袭」。
5. **等结果：** 小游戏在服务器上打这一场，一般几分钟出结果。主站发消息通知双方，记录里能看录像。
6. **取出：** 金库取回主钱包要等 60 分钟（期间照样能被偷），之后可以按钱包规则提现。

## 4. 偷袭规则（默认值，主站后台都能改）

| 项目 | 规则 |
|---|---|
| 押注额 | 守方金库 × 10%，最少 10、最多 500，且不超过攻方金库 |
| 押注锁定 | 发起时攻方押 X、守方锁定 X |
| 结果 | 攻方赢：攻方拿回 X 再得守方的 X；守方赢：守方得攻方的 X；作废：各退各的 |
| 抽成 | 平台不抽 |
| 战斗 | 攻方固定阵容 对 守方固定阵容，小游戏服务器裁判，没有平局 |
| 护盾 | 被偷后 8 小时内不会再被偷（复仇除外） |
| 次数 | 每人每天最多被偷 3 次、最多偷 10 次（含复仇）；同一时刻一人只能有一场进行中 |
| 复仇 | 被偷后 24 小时内可以对偷他的人复仇一次，不受护盾和推荐限制 |
| 推荐 | 每次 3 个，按小游戏上报的强弱数字接近的优先；金库低于 100 的不推荐 |
| 防小号 | 注册满 3 天才能参加；同一网络（以后改成同一设备）的号不互相推荐、不能互偷 |
| 金库上限 | 存入后不超过 10000（偷来的不受限） |
| 超时 | 小游戏开始计算后 30 分钟没结果，或建任务后 6 小时还没开始计算，自动作废、各退各的 |
| 开放 | 每天都开放，不跟小游戏的大轮走 |

## 5. 一场偷袭的完整流程

```
玩家(主站网页)        主站                         小游戏服务器
   │ 点「偷袭」 ─────→ │ 检查规则，锁定双方押注
   │                  │ POST gameServerURL 建任务 ─→ │ 10 秒内回 {ok, jobId}，任务排队
   │                  │                              │ 开始计算
   │                  │ ←───────── POST started ──── │
   │                  │                              │ 裁判算完
   │                  │ ←───────── POST settle ───── │ 失败就重试
   │                  │ 转账给赢家，发消息，记录录像
   │ ←── 看到结果 ──── │
```

建任务没回 ok 时，主站立即作废、退回押注，提示玩家稍后再试。

## 6. 接口

签名（两个方向都一样）：

```
Content-Type: application/json
X-Arena-Timestamp: <unix 秒>
X-Arena-Signature: hex( HMAC-SHA256( hookSecret, 时间戳 + "." + 原始请求体 ) )
```

- 时间差超过 5 分钟拒收。密钥内测、正式各一套，主站运营私下交付，不进代码仓库、不进客户端。
- 用户 ID 一律用主站**对外编码 ID**（字符串，例如 `GEACjjPJERy`）。
- 龟一律用主站 `pet_key`，现有 11 只：basic / stone / bamboo / angel / ice / fortune / rainbow / lightning / phoenix / lava / shell，和小游戏的龟 ID 一致。

### 6.1 小游戏调主站（前缀 `/api/arena-hook`）

| 接口 | 请求 | 回复 | 说明 |
|---|---|---|---|
| `POST /player` | `{userId}` | `{ok, turtles: ["basic", …]}` | 玩家拥有的龟，上阵只能用这些 + 限免龟。回复里的 `vault` 忽略 |
| `POST /defense` | `{userId, hasDefense, rating, device}` | `{ok}` | 固定阵容变化时上报。`rating` 是任何能代表强弱的数字，没有就报 0；`device` 是设备号，可选 |
| `POST /pet-level` | `{userId, petKey, level}` | `{ok}` | 龟的等级变化（主站只显示） |
| `POST /started` | `{raidId}` | `{ok}` | 开始计算这场偷袭 |
| `POST /settle` | `{raidId, result, matchId}` | `{ok, status, result}` | `result`：`attacker` / `defender` / `void`（算不出结果）。同一场重复发、结果相同返回成功；结果不同或已作废返回 `ok: false` |
| `POST /unlinked` | `{userId}` | `{ok}` | 玩家在 App 删号，主站解绑并停止推荐；主站账号和金库保留 |

### 6.2 主站调小游戏

| 接口 | 请求 | 回复 |
|---|---|---|
| `POST <gameServerURL>` | `{raidId, attacker, defender, seed, stake, isRevenge, expireAt}` | 10 秒内回 `{ok: true, jobId}` |
| `GET /mainsite/link/info?code=` | 网址带登录码 | `{device}`，确认页显示设备型号 |
| `POST /mainsite/link/confirm` | `{code, user_id}` | `{ok}` |

`stake` 只给小游戏做记录，App 里不显示。`expireAt`（毫秒）之后的结果主站不认。

### 6.3 页面

| 页面 | 提供方 |
|---|---|
| `主站/game/link?code=` | 主站：App 登录确认页 |
| `主站/arena` | 主站：龟战页（金库、推荐对手、偷袭、记录） |
| `小游戏/player?match=` | 小游戏：录像播放器（电脑浏览器） |

## 7. 各自要做的

**主站（已做完，部署在线上，开关关着）**
- 金库存取（取出 60 分钟延迟）、押注锁定、结算、超时作废、护盾、次数限制、复仇、推荐对手
- `player` / `defense` / `settle` 接口、建任务调用、签名
- 龟战页、消息通知、后台「龟币 · 龟战金库」（数值设置、总开关、记录、对账）

**主站（还要改，约 1～2 天）**
- App 登录确认页和 `link/confirm` 回调
- `settle` 增加 `void`；新增 `started`、`pet-level`、`unlinked` 三个接口
- 超时改成从开始计算算起；攻方也用固定阵容（攻方必须设了阵容才能发起）
- `defense` 支持设备号，按设备防互偷
- 偷袭记录加「看录像」，显示龟的等级
- 一套内测环境

**小游戏**
- 登录码、系统浏览器打开确认页、轮询绑定结果，`link/info`、`link/confirm` 两个接口
- 固定阵容的设置、保存、校验，变化时上报 `defense`
- 只允许玩家拥有的龟 + 限免龟上阵；升级系统，等级变化上报 `pet-level`
- 建任务接口：验签、排队、开算时调 `started`、算完调 `settle`（失败重试）
- 录像播放器地址；App 删号时调 `unlinked`
- App 里不出现任何龟币或金额

## 8. 上线步骤

1. 主站开好内测环境，把内测地址和内测密钥交给小游戏；小游戏提供内测的 `gameServerURL` 和播放器地址。
2. 用两三个测试号走一遍：App 登录确认 → 设阵容 → 存金库 → 偷袭 → 开算 → 结果 → 看录像 → 后台对账。
3. 没问题后换正式地址和正式密钥，主站在后台打开「龟战总开关」，网站加「龟战」入口。
