## 1. 量法

- 参考：每 4 帧拼图逐格看，记下每一层（坑 / 光柱 / 爆冠 / 冲击环 / 碎石 / 尘 / 龟裂地面）哪一帧出现、哪一帧消失。
- 素材：`tools/build_basic_slam_vfx.py --preview` 出放大拼图（`落地素材-6套逐帧-放大.png`），逐帧看形状 / 描边 / 色阶。
- 实机：审阅台真场景，Movie Maker 60fps（每帧 = 1/60 秒游戏时间），1:1 裁落点周围逐帧看（`实机-落地逐帧.jpg`）。

## 3. 结论（改了什么）

- 落地分层与先后照瑟提：砸中（闪 + 坑）→ 爆冠 → 细冲击环 + 石块 + 低尘 → 久留的坑。
- 冲击环第二版改细（环带 5 → 2.5 像素）：第一版 12 → 5 像素，在 350 码尺寸下像一整块米白甜甜圈盖住人。
- 不顿帧：用户「顿啥啊」。连通用的重击顿帧（单段 ≥ 60 伤害）这一下也关掉（`_hitstop_mute`）。
- 6 套素材全部过肩摔专用，生成脚本 `tools/build_basic_slam_vfx.py`（确定性，重跑逐字节相同）。

## 4. 没做 / 未决

- 瑟提的光柱我们只做成一颗闪光星，没有竖光柱（小龟这招不是能量系，用户看视频再说）。
