# 039 竹制弓箭 · 逐帧研究（2026-09-13）

台子：`VFXLAB_CASE=p2eq_039`（**本轮新建** —— 之前看着"有台子"其实是 `syn_bow` 弓箭羁绊借它当载体）。
录法：`VFXLAB=1 … --audio-driver Dummy`，**共 16 帧**（4.90–10.00 s，全部逐帧看过）。

## 文案就是规格

> 获得 **6/10/15** 次生长充能；每第 **3** 段普攻消耗 1 次充能：射一发强化竹箭给最近的敌人，
> 造成（25/30/35 + `BAMBOO_ARROW_MAXHP_PCT`(6)% 自身最大生命值）魔法伤害，
> 命中后冒出一颗绿色生命球飞回携带者 —— **落到身上才结算**：
> 回复自身 6% 最大生命值，并使自身最大生命值**永久 +50/70/90**。

## 一、★真缺陷：「落到身上才结算」那一下**一次都不落**

```gdscript
var tw := create_tween()
tw.tween_method(_bamboo_orb_step.bind(...), 0.0, 1.0, 0.65)   # 绿球飞行
tw.tween_callback(func():
    ...
    if on_land.is_valid(): on_land.call())      # ← 回血 + 永久成长在这里
```

tween 走**未钳制的真实 delta，无头下推不动**（§3.5）⇒ 回血与永久 +50/70/90 最大生命**从不发生**。

★★**我上一次全仓扫这条病时说「只剩 4 处」是低估的** —— 那次只搜了 `tween_interval`，
**漏了 `tween_method` 这一族**。重扫（把 `tween_method` / `tween_property` 都算上，再看回调窗口里有没有结算关键词）
得到 39 个候选点，其中真埋着结算的除了已知的几处，还多出 **039 竹叶生命球** 与 **053 散弹枪弹珠伤害**。
两处本轮一起挪到共享原语 `EquipTickSystem.schedule`（抛物线/飞行留在 tween，那是纯观感）。

顺带修一处「同一个数存两份」：落点回血写死 `maxHp * 0.06`，而常量 `BAMBOO_ARROW_MAXHP_PCT` 就在那儿、
文案用的也是它的占位符。已改成读常量。

## 二、★台子第一版拍点押早了

第一版把拍点铺在 1.0~4.6 秒，**实拍整段什么都没有** —— 第 3 段普攻要到 **t≈5.4** 才到。
（这与「采样比效果节拍还粗」是同一类错：拍点不对准，就会把"没拍到"读成"没效果"。）
现在铺 4.90~6.50 每 0.15 秒，把整条链盖满。
