## 可借鉴点（落到 010）

1. **时间分三档**：最亮的刃只亮 0.1 秒 → 拖尾 / 余光 0.2~0.4 秒 → 地上的痕迹 1.2~1.8 秒。亮的东西最短，地上的东西最长。
2. **同一个元素叠两种混合**：亮刃、星光都是「叠加发光 + 普通透明」两层一起出，发光不发虚、底子压得住。
3. **命中 = 三道不同宽度的横斩光条 + 四角星 + 冲击环 + 火花**，全部 0.1~0.25 秒；三道光条宽度 225 / 175 / 140、粗细 40 / 20 / 6，层次靠「同形不同大小」。
4. **地面要有东西**：出刀瞬间地面柔光一闪（0.1~0.2 秒）+ 扇形斩痕留 1.8 秒；直线斩沿路起尘 1.2 秒。
5. **贴图几乎全是灰度**（纺锤、星、环、柔光球、条纹），颜色在引擎里上 ⇒ 010 照此：灰度形状贴图 + 着色器上红色色阶（白热芯 → 粉红 → 深红）。
6. 不照搬：永恩是蓝白灵刃、地上碎石；010 是红色激光 ⇒ 刃是激光束（更硬、更直的光），地上是烧灼的红色熔痕而不是碎石。
