## 三、分层拆解（我们能借的）

| 层 | 原版 | 作用 |
|---|---|---|
| 锁定圈 | 目标脚下橙色椭圆圈，开火前一直在 | 告诉玩家「这只被盯上了」，开火后淡掉 |
| 预警线 | 从天到目标的细橙红光线，**一帧出现整根**，不从上往下长 | 延迟期间的提示；比「光从天上落下来」干脆 |
| 开火爆胀 | 细线在 2–3 格（约 0.1 秒）内胀成很粗的光柱 | 打击感来自「突然变粗变亮」 |
| 光柱本体 | 三层：白芯 / 金黄 / 细橙边；内有红色竖纹流动；粗细呼吸 | 持续期间画面一直在动，不是一张静图 |
| 底部飞溅 | 开火那一下底部向两侧喷白色光丝；持续中偶尔甩细金线 | 落点有冲击 |
| 收尾 | 满亮到最后，一帧消失，留一点烟 | 干脆，不拖 |

## 四、和我上一版的差别（上一版为什么不行）

1. 上一版金光是「从天上慢慢往下长」——原版是**预警线一帧出现、然后爆胀开火**，节奏完全不同。
2. 上一版没有锁定圈、没有爆胀、没有底部飞溅；光柱只有一层，颜色发白发淡，粗细只是轻微呼吸。
3. 上一版死后 0.25 秒慢慢收细——原版一帧消失留烟。
