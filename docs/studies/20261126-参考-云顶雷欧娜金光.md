## 三、分层拆解（我们能借的）

| 层 | 原版 | 作用 |
|---|---|---|
| 锁定圈 | 目标脚下橙色椭圆圈，开火前一直在 | 告诉玩家「这只被盯上了」，开火后淡掉 |
| 预警线 | 从天到目标的细橙红光线，**一帧出现整根**，不从上往下长 | 延迟期间的提示；比「光从天上落下来」干脆 |
| 开火爆胀 | 细线在 2–3 格（约 0.1 秒）内胀成很粗的光柱 | 打击感来自「突然变粗变亮」 |
| 光柱本体 | 三层：白芯 / 金黄 / 细橙边；内有红色竖纹流动；粗细呼吸 | 持续期间画面一直在动，不是一张静图 |
| 底部飞溅 | 开火那一下底部向两侧喷白色光丝；持续中偶尔甩细金线 | 落点有冲击 |
| 收尾 | 满亮到最后，一帧消失，留一点烟 | 干脆，不拖 |

## 四、和我上一版的差别（上一版为什么不行）

1. 上一版金光是「从天上慢慢往下长」——原版是**预警线一帧出现、然后爆胀开火**，节奏完全不同。
2. 上一版没有锁定圈、没有爆胀、没有底部飞溅；光柱只有一层，颜色发白发淡，粗细只是轻微呼吸。
3. 上一版死后 0.25 秒慢慢收细——原版一帧消失留烟。

## 五、我们怎么做（待用户看过再动手）

用户的设计里多了一步原版没有的：**面具先从头上飞上天、朝天射一道光**（用户 11-25 原话），这一步保留在最前面。之后照原版：

| 段 | 时长 | 画面 |
|---|---|---|
| 1 面具升空 | 0–0.30 秒 | 黄金面具从头顶飞上去，朝天射一道细金光（用户设计） |
| 2 锁定 | 0.30–0.85 秒 | 目标脚下出金橙锁定圈；从天到目标**一帧出现**一根细金红预警线（照原版） |
| 3 开火爆胀 | 0.85–1.00 秒 | 预警线 0.1 秒内胀成粗光柱，底部向两侧喷白色光丝（照原版） |
| 4 持续 | 1.00 秒起直到目标死 | 三层光柱（白芯 / 金黄 / 橙边）+ 内部红纹流动 + 粗细呼吸；伤害每涨一秒更粗更亮（用户设计：伤害递增） |
| 5 收尾 | 目标死那一帧 | 光柱一帧消失、留一小团金灰烟；头上飘深海币（照原版收法 + 用户设计的出币） |

素材做法：光柱三层与红纹做成逐帧序列（PixelLab 生成后自己逐帧验收），锁定圈、底部飞溅、收尾烟各一套序列帧；像素风、硬边为主，光可以柔边（CLAUDE.md §10 第 7 条）。
