## ★我自己读错、又用探针纠正过来的一条

逐帧看完我写下「护盾飘字从头到尾没出现」，差点当成缺陷报上去。
探针一打：飘字**建出来了**，位置 `(668.8, 282.9)` 在 1280×720 视口内、`fly.visible=true`，
但 **`_ui_layer.visible=false`** —— VFXLAB 默认把整个 UI 层关掉，`cfg["ui"]=true` 只是把
**建场时已有的** HUD 移到另一层保住，**之后**才挂进 `_ui_layer` 的飘字仍然看不见，
要看得开 `VFXLAB_TEXT=1`（`battle_vfx_lab.gd` 的文件头本来就写着这条）。

⇒ **是我台子没配对，不是产品坏了。** 同一条也解释了 010 那一轮为什么只看见金色粒子、看不见伤害数字。
这正是 memory `fb-clean-vfx-stage-not-squint` 说的「触发条件没配对，就会把『没看见』读成『没做』」。
