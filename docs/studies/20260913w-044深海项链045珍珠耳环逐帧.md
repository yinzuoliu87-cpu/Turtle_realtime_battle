# 044 深海项链 · 逐帧研究（2026-09-13）

台子：`VFXLAB_CASE=p2eq_044` / `p2eq_045`（**两个都是本轮新建**）。
录法：`VFXLAB=1 … --audio-driver Dummy`，044 共 **15 帧**（0.20–6.50 s）、045 共 **16 帧**（0.15–1.65 s），全部逐帧看过。

## 文案就是规格

> 【044】生命首次降至 `LOWHP_GATE`(50)% 以下时，在 `NECKLACE_HOT_SEC`(6) 秒内
> **逐渐**回复 20/40/80% 最大生命（每场一次）。
> 【045】同样的触发线，`EARRING_HOT_SEC`(8) 秒内**逐渐**回复 30/60/100% 最大生命，
> 并向 1/1/2 名随机敌人发火球：8/17/30% 目标最大生命的魔法伤害 + 30/70/150 层灼烧（每场一次）。

## 一、台子怎么配才触发得到

`carrier_hp` 在 `battle_vfx_lab._tune_units()` 里**直接走真实入口** `_eq_check_hp_threshold(u)`，
所以配 `carrier_hp: 0.4` 开场就触发 ⇒ 拍点从 0.2 秒起铺满整个摊付窗口。
`enemy_attacks` 必须**关**：摊付期间再掉血，会把「逐渐回满」读成「没回够」。

## 二、★045 真缺陷：火球的「爆裂环」比火球先到

```gdscript
battle._spawn_fireball(u, o, ...)                              # 抛物线, 飞 0.35~0.7 秒
battle._skill_ring(o["pos"], Color(1.0,0.45,0.12,0.6), 50.0)   # ← 施法那一帧就画在目标脚下
```

实拍 16 帧里看得清清楚楚：**火球还在半空，地上两圈橙环已经先亮起来**。
两条毛病叠在一起 —— ①它是程序生成的圆环（禁区）②时序是错的。

落地的火爆本来就有（`battle_ballistics` 命中分支里的 `_fire_explosion(tgt.pos)`）⇒ 直接删掉这一行。
