## 分析：它靠什么读出「挡住 + 反击」

1. **盾面比人大、朝向明确**：举盾那一帧直接张开一大片半弧，正对敌人方向；一眼看出「正面被挡住了」。我们现在的能量盾是一块立着的竖板，读不出「挡住一个方向」。
2. **盾面是活的**：火舌边缘逐帧跳动，中心同心环一直亮着；不是一张图靠缩放闪。
3. **撑盾期间有攻击节奏**：盾后不停刺出突刺光（≈ 每 0.15–0.2 秒），撑盾不是干等。我们 3 档「举盾期间每 0.5 秒刺周围」正好对得上，可以学这个突刺光的样子。
4. **收尾有一个明确的重击**：收盾 → 后缩蓄势 → 盾击一下大金光 + 尘浪。挡的「格挡」和打的「反击」分成两拍，节奏清楚。

## 可借鉴点（只学方法，不照抄造型）

- 举盾一帧到位，盾面画成**朝敌人方向的半弧**，比本体大。
- 盾面边缘逐帧手画变形，中心一个主题徽记（我们是罗马鹰徽 / 金色，不用潘森的火焰配色）。
- 撑盾时盾后出刺，每刺一道细长突刺光。
- 收尾两拍：收盾后缩 → 一次重击（大亮光 + 尘浪）。
