## 需求原话（四轮）

> ①「燃烧阶段不合适，应该是**有火炎从中间爆开**，有命中特效，**像烟雾那种感觉但是火焰**」
> ②「额，**没用 blender ?** **没符合实际爆炸范围?** **爆炸和命中是一回事吗我问你，为什么用相同特效?**」

> ④「**为什么燃烧爆发的时间要这么久**，特效应该就是**火焰从中间爆开一下子的事**啊」

## 一、③ 之后才去找真参考，量完发现我是**做反了**

参考：OpenGameArt CC0 `explosion1_6.png`（100×100 × 50 帧，BenHickling，**只量不用**）。

三条硬事实，我前面几版全违反：
**A** 开头是**一记纯白闪 + 辐射尖刺**（不是慢慢长大的橙球）；
**B** 半径**先冲后缩**（我是单调增）；
**C** **后 40% 的帧全是烟**（我一帧烟都没有）。
参考全表只有 **8 色**、**44% 的像素亮度 ≤ 40**、亮度是**双峰**（p25=35 / p75=245）硬对比，
而我那几版的板子里**一个烟色都没有** —— 这就是「平」「很差」的根源。

## 二、④ 之后砍时长：结构照抄，**时长砍掉**

上一版把参考那条**电影级 50 帧**整条照搬（含「炸开→收缩→二次点火」），14 帧 / 15fps = **0.93 秒**。
砍掉中间那段回缩与二次点火，只留 **炸开 3 帧 + 散烟 5 帧 = 8 帧 / 22fps = 0.36 秒**。
比例关系（烟占后 60%、亮暗双峰、半径到顶不再扩）照旧。

## 三、为什么这一版不走 Blender（上一版走了）

体积渲染 + 6 色量化出来是**软的一坨**——量过：亮度跨度能拉到 85~125 级，
但形状永远是「球的并集」，给不出白闪 / 辐射尖刺 / 硬边烟团。参考本身就是**手绘像素画**。
（Blender 那条管线没删，`tools/blender_candlefire.py` 做**点燃**那段仍然好用。）

## 五、量出来的两个坑（都记在烘制脚本里）

- 烟色第一版给亮度 **66**，正卡在「暗像素 ≤ 60」判据**上方** ⇒ 纯烟那几帧量出来烟占比恒为 **0%**。
- 火色带第一版写成 `v < 1.0 - dark*0.80` —— dark=1.0 时它**还占着内圈 20%** ⇒ 纯烟帧仍有大片橙。
  改成显式 `fire_end = max(bright, 1-dark)`：烟满了火一点不剩。
- 全身按 hash 抖 ±0.09 ⇒ 一片**椒盐噪点**；像素画的抖动只发生在**色带交界**且用有序图案（Bayer 4×4）。
- 16 根等长等角尖刺 ⇒ 读成**卡通太阳**；改 7 根、角度/长度/宽度都错开。
