## 4. 结论（我们怎么做）

1. **结算屏只展示**：「深海币 +8」放大弹入（1.3 → 1.0），图标同时弹一下；不发飞币（结算屏上没有货币条）。
2. **回主菜单才入账**（照 Royal Match）：货币条先显示旧值 → 菜单落定后中央弹出「+N」和一小堆币，停约 0.5 秒 → 一枚一枚弹起、沿弧线飞向货币条（间隔 0.1 秒、每枚飞约 0.45 秒）→ 每到一枚数字整步跳一次、图标弹一下（1.0 → 1.2 → 1.0）并闪白光。
3. **数字滚动总长固定在 1 秒左右，不随金额拉长**：枚数封顶 10 枚，每枚分摊整数、最后一枚补齐余数（+8 = 8 枚各 +1；+56 = 10 枚 5×9 + 11）。
4. **不挡操作**：真实余额在数据层立即入账，动画只驱动显示值；点任意处让剩下的币瞬间到达、数字跳到终值；离开主菜单时显示值直接跳到真值。
5. **补发卡**：卡片上展示奖励行，点「领取」关卡后照第 2 条飞币（皇室战争「全屏卡 → 点领取 → 喷出」的顺序）。
6. 像素风：飞行中的币用 x 方向离散缩放做翻面（4 档宽度，最近邻），不用平滑旋转。
