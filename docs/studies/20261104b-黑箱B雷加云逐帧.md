## 结论（★标「推断」的是从画面反推，看不到它的工程）

- **雷的原语**：竖直细线（白芯蓝晕，约 2~4 帧）+ 地面同心椭圆环（贴地、按透视压扁，约 6~10 帧淡出）+ 落点白点 / 小水花。落点随机、频率高，靠「多」出气势。
- **云的原语**：一团自发光的柔边椭圆（不受场景光照，阴影里亮度不变）+ 朝向小三角；没有拖尾粒子。
- **融合的做法**（★推断）：外形用「云」（载具 / 移动类），**颜色整套换成「雷」的元素色**，再把「雷」的落点效果挂到云周围、边走边落，落点闪光放大一号。等于「A 的形 + B 的色 + B 的触发效果」三个参数拼出来，没有新画一套。
- **好看靠什么**：元素色统一（一整套蓝）、落点闪光的**大小**区分强弱、高频次；同样没看到镜头抖动和顿帧。
- **对我们的启发**：我们每个元素效果各画各的；它是「元素 = 一套调色板」，任何模板换上这套色就是那个元素。对应 S4 的 A2（参数化特效模板）。
