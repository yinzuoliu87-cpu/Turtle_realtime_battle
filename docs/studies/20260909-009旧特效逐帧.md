## 结论一：旧版好在哪（我把这些全删了）

1. **预警是一片"区域"，不是几条线。** 半透明、脉动、**不遮挡单位**，一眼说清"这一整片要挨打"。
   我换的三条同心弧只给了"边界在哪"，**完全给不出面积感**，而且三条同心弧是标准的**声波图形**。
2. **斩击叠在预警上，预警不消失。** 白光沿着还亮着的黄区中线劈开 —— 读法是
   "**在这片区域里劈了一刀**"。我做成了"预警收掉 → 月牙出现"，因果链被切断了。
3. **白光是热白核 + 黄边**，有温度层次；不是一块纯白。
4. **多层小演出撑节奏**：普攻弹 → 挥砍金弧 → 金色流星 → 大爆星 → 地面金环 → 伤害颗粒 → 受击闪白。
   一次技能周期里这些交替出现，密度很高。这就是"节奏感"的来源。
5. **预警 0.56 秒里脉动两个来回**（alpha 0 → 峰 → 谷 → 峰 → 谷 → 峰），有呼吸感。

## 结论二：旧版真正的毛病（只有这些该改）

1. ★**白光消散时变暗成灰块**（#44-46、#84-86）—— 颜色变暗而不是 alpha 淡出，黑场上读成灰板。
2. 软边 + 没设 NEAREST，128px 拉到 19.2 米 ⇒ 边缘阶梯 + 大块渐变，与 001–008 已重做的硬边像素风不统一。
3. 贴图靠 `rotation.y` 自由旋转（像素风禁忌，只有 90° 无损）。
4. 名实不符：芥末黄 vs「月之刃」（用户 2026-09-09 定的新名）。
5. 图标是一把**直剑**、64×64/43 色/2 半透，不是像素画。

## 结论三：我上一版错在哪

**我把"表面问题"当成"结构问题"，连结构一起换掉了。**
该改的是 1–5（表面：消散方式、硬边、旋转、色相、图标），
而我把 ①区域感 ②叠加关系 ③温度层次 ⑤脉动节奏 全删了，换成一个更"干净"但信息量为零的版本。

⇒ 新版的做法：**保留旧版的结构与节奏**（区域 + 叠加 + 脉动 + 多层小演出），
只把表面换成**硬边像素 + 冷银白**，并把"变灰块"改成真正的 alpha 消散。
