## 方法（只学方法）

1. **同一个锥形网格叠四层**，每层换混合方式和颜色，长短略错开（20 / 25）⇒ 有厚度、有层次。
2. **亮的下面垫一层暗的**（普通混合的深色锥、深色拖尾），亮地面上才压得住；全用叠加发光会被沙地吃掉。我们上一版冲击罩在沙地上发白看不清就是这个原因。
3. 头部再叠**光晕 + 十字星芒**，一直闪（寿命 0.2 秒、每秒 20 颗 ⇒ 每帧都在换）。
4. 两侧**高速滚动的流光拖尾** + 细碎火花 + 星尘粒子，读得出速度。
5. 出手那一下一圈**径向冲击环** + 光晕。
6. 热扭曲面片（我们引擎可用屏幕纹理做，后补）。

## 我们怎么用（造型 / 配色自己的：金橙主色、深褐暗层）

普攻刺到最远那一帧：矛尖起一组冲击罩往前冲 2 米、0.3 秒。
- 罩：同一抛物面网格 4 层（深褐暗层 / 金色主层 / 叠加红橙中层 / 橙色流动填充），长短错开。
- 头：叠加光晕 + 十字星芒（每帧换角度、闪）。
- 流光：外面再套一层细长锥，只画高速往后滚的条纹（相当于 side streaks）。
- 粒子：火花往前迸 + 星尘。
- 出手：矛尖一圈垂直于刺击方向的径向冲击环扩开。
