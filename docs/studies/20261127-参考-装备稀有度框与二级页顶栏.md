## 可借鉴点

1. **稀有度 = 框色 + 形状 + 数字三重标记**（云顶）：框按费用上色，用现成的局内装备费用色（`RealtimeBattle3DScene._equip_cost_color`：1 灰 / 2 绿 / 3 蓝 / 4 紫 / 5 金）；右下角嵌费用数字；高费的框角另加装饰，不只靠颜色。
2. **高稀有度加底光**（背包乱斗）：4、5 费的框里图标身后一团同色柔光，一眼挑得出来。
3. **顶栏 = 一条带框的横幅**：返回键是有底板的按钮（不是一个光秃秃的箭头字符），标题在横幅上，右侧放货币或其他入口；页签放在内容面板上沿。
4. 不照抄：云顶的宝石形状和荒野乱斗的斜切面板是它们自己的造型；我们的框用像素硬边、深紫褐描边（与新羁绊图标一套），顶栏用游戏里现有的木牌 / 海底主题皮。
