## 二、时间结构（30 帧 / 秒）

- 抬锤 0~5 帧（0.2 秒，动作的事，特效不管）。
- **砸地爆闪 1~2 帧**（第 6~7 帧）→ 碎石崩飞 + 烟（第 7~8 帧）。
- **裂缝推进 3 帧 ≈ 0.1 秒**到目标（第 9~11 帧），线头最亮，身后一路冒烟、抛碎石。
- 裂缝身后的烟带橙光 4~5 帧（第 11~15 帧）后变薄下沉。
- **尽头 / 命中炸开**（第 16~18 帧），收尾 4 帧（第 19~22 帧）。
- 从砸地到收干净约 **17 帧 ≈ 0.55 秒**。

## 三、对我们的结论（宝箱主题，普攻每 1.4 秒一次 ⇒ 比技能轻、短）

1. 砸地（我们的帧 0 = 宝箱着地）：一下白金爆闪（叠加发光，0.1 秒）+ 金币宝石往上崩、落地弹跳（代替碎石）+ 一圈沙尘贴地推开。
2. 波头：金色裂光沿地面推进，**时长跟结算排程一致（0.18 秒走完）**，线头白金最亮，身后冷却成金 → 橙 → 焦褐、0.55 秒内吃光（代替岩浆裂缝 + 烟）。
3. 波头经过处：金币从地里蹦出来（代替第 11 帧被抛起的碎石），沿线三处、按波头到达的时刻依次。
4. 命中：波头扫到谁，谁身上金币溅开 + 宝石星闪（代替第 16~18 帧尽头炸开），跟伤害数字同一刻。
5. 整段从砸地到收干净 ≤ 0.6 秒；不留长时间的地面残留（普攻太频繁，会糊满场地）。
