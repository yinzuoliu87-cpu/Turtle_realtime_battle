## 1. 量法

- 参考帧：在落点周围裁一块（Poppy 440×240、Sion 600×500、地裂 600×310），**减掉命中前一帧当背景基线**（Poppy 96、Sion 158、地裂 15），
  `|帧−基线|` 三通道和 > 60 记「差分像素」，其中亮度 > 200 记「亮像素」；主色相 = 差分像素的平均色。
- 素材帧：1:1 逐像素数不透明像素 / 亮像素 / 主色相（饱和度 < 0.08 的灰白不计色相）。
- 量化脚本留在会话 scratchpad（`slam_measure.py` / `slam_study_gen.py`），没进仓库。

## 2. 从参考里量出来的东西（纯靠想给不出的）

1. **命中前没有任何特效。** 三份参考在锤 / 斧 / 巨石触地之前，地上都是干净的 —— 预兆全靠动作（举到最高点）。⇒ 我们不加预兆特效。
2. **闪是一帧跳满，不淡入。** Poppy 亮像素 0 → 1686（102 帧）；二爆 141 → 6616（133 帧）。峰值在命中后第 2~3 帧，**峰后 3 帧掉到 1/3**。
   Sion 更狠：闪只活 1 帧（1/60 秒）就掉到 1/6。⇒ 白核 2 帧满亮、第 3 帧只剩小亮点。
3. **地面冲击环减速外扩、到边就碎。** 地裂演示：环在 23 帧出现，bbox 宽 452 → 514 → 564 → 592（每 2 帧 +62 → +50 → +28，减速），
   6 帧（0.2 秒）到满径，下一拍就碎，尘从**环所在的位置**沿地面滚出。⇒ 冲击环 0.15 秒 out_cubic 扩满、再 3 帧碎掉；尘团放在环的位置。
4. **碎石往上抛。** Poppy 二爆 133~136 帧褐色碎块在白核**上方**；Sion 岩块竖着顶出地面。⇒ 碎石是竖立层、真抛物线（不是贴地横滑）。
5. **余韵是尘 + 火星，不是光慢慢变暗。** Poppy 二爆后橙尘 0.3 秒铺开、金色火星再拖 0.5 秒；地裂演示尘 0.47 秒升到顶、1.2 秒淡尽；
   Sion 尘是暗褐（亮度差只 +4~+12）。⇒ 尘团转暗、上升、**破碎**（不是整体 alpha 淡出 —— 九类毛病①）。
6. **颜色**：Poppy 金（色相 37~41°）、Sion 橙红→暗褐（27~45°）。变脸龟不照抄金色：用锤头符文的绿（色相 ~140°）当「光」，
   锤身那组石灰当碎石，尘用暖灰褐（呼应 Sion 的暗褐尘）。

## 2.1 爆炸（第二轮补，量自 `nzUKC_GKp-Q`）

7. **爆之前先收**：一颗黑点 1 张画（122）。我们不加 —— 预兆已是锤举到最高点，再加黑点会把砸地推迟。
8. **尖刺闪 4 帧（0.13 秒）纯白一帧跳满**（124/126 亮像素 21272），9 根尖刺长短不一 ⇒ 我们第 0~1 帧尖刺闪。
9. **火球一帧换满**（128：面积 96405、亮像素掉到 5464、色相 24° 橙），黄白核 + 橙 + 红 + **褐色外瓣**（不是光晕，是有轮廓的瓣）。
10. **开裂**：白火星从核里飞出、外瓣转红褐（130/132）；**碎成翻卷的红褐块**（134，面积掉到 40%），之后 0.2 秒碎块外飞散尽。
11. 整段（尖刺闪 → 散尽）≈ 0.5 秒。我们 0.75 秒：火球在第 7~10 帧多撑 0.2 秒 —— 用户要的是「砸下去的分量」，火球要看得清；
    颜色贴战士形态：黄白 → 橙 → 红（斗篷红）→ 暗红褐 + 灰烟，外加少量符文绿火星。

迭代中自己否掉的（每一版都看过全部帧）：① 冲击环 5 像素实心白 + 内环 = 靶心；② 七道等长地裂 = 雪花（还是「白色涂鸦」）；
③ 暗缝 + 亮缝两层，几何对不上（同 seed 也不同形）；④ 碎石只在一条线上横滑（重力相对速度太大，峰高 12 像素）；
⑤ 尘团描黑边，读成「一圈石头甜甜圈」；⑥ **实拍才看出来的**：地裂和冲击环原来在同一张 2× 表里，1 像素线在游戏里 = 5 厘米、
带描边 15 厘米，取景 2.4 倍下是一片白色粗折线、伸出 3 米 —— 又成了用户否掉的「白色涂鸦」。⇒ 拆成两张：环留 2×（它要大到判定半径），
地裂改 1×、起始压到薄荷色、不描边、缩到 1.4 米；圈边尘团 1× 时几乎看不见 ⇒ 按 2× 显示。

自审还在的（没改）：护盾罩（通用演出，二轮已退到立绘后面）在砸地后 0.3 秒内仍会在变脸龟身后亮一圈；冲击环是纯白一线，
