## 五、对我们（2.5D 像素小游戏）的可借鉴点

只借结构、节奏、层次，素材我们自己画：

1. **出手要有一拍「蓄 + 闪」**：手上先冒 3~4 帧小火，出手那一帧一团橙光罩住施法者半身（1 帧），火球再从身前长出来。我们龟施法也照这个：先在施法点亮 2~3 帧小火苗，第 4 帧一闪。
2. **火球 = 水滴形，不是圆球**：前端一道黄白月牙最亮（全图最亮的点永远在弹头最前沿），中间橙、往后深红，最外一层品红 / 粉色辉光。飞得越远拖得越长（近 1 → 2.3 安妮高，远到 3 安妮高）—— 我们做成「弹头 + 一条随飞行变长的尾带」，不是一张固定长度的图。
3. **火舌朝后飘**：火球身上的小火舌一律逆着飞行方向，读起来就是「在飞」。像素版可以用 3~4 帧循环的小火舌，按飞行方向转。
4. **尾巴颜色随时间走一条曲线**：刚生出来粉 / 亮 → 变红 → 变暗半透明 → 没。所以同一时刻整条尾巴是「头粉尾红」的渐变（第 39~41 帧）。像素版可以把尾带按距弹头远近分 3~4 档颜色。
5. **头碰到就没了，尾迹还挂 3~5 帧**：命中那一帧弹头直接消失，剩下的红色火丝尾迹原地慢慢暗掉，不跟着收回。
6. **命中分三拍，0.2 秒内打完**：①小爆点（1 帧）→ ②圆光团鼓到约 1 个目标大（2~3 帧）→ ③压扁成横条 / 星芒（2~3 帧）。然后 0.3~0.4 秒余火 + 脚下一片深色烟。命中段长度固定，不随飞行距离变。
7. **余火往上舔、碎片往外蹦、烟贴在脚下**：方向感各不相同，命中才有体积。我们的 2.5D 视角下：火舌竖着往上、黄色碎片按抛物线往外、深色烟是贴地的一块。
8. **颜色只用一条暖色带**：黄白（最亮）→ 橙 → 红 → 深红 / 暗紫（最暗）+ 外圈品红辉光。我们魔法书是「烈焰法典」，可以同一条色带，不必加别的颜色。
