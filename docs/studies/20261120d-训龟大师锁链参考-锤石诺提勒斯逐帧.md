## 二、诺提勒斯 Q（总览，每 1/6 秒一帧）

1.50 秒抡锚出手 → 1.67 ~ 1.83 秒铁锚飞出，身后一根**细的深色铁链**，链节一个个看得见（没有拖影带）→ 2.00 秒钩中，铁链绷直成一条线 → 2.17 秒诺提勒斯被拽过去，落点冒深色烟 → 2.33 秒到位，链子收掉。

## 三、学到的做法（新锁链的设计依据）

1. **甩出去的过程要看得见**：飞行时不是画链节，而是一条从手到钩头的**粗拖影带**（深色芯 + 主题色边光），靠钩头那头最粗最深、靠手那头淡 —— 读成「一个很长的东西正被甩出去」。
2. **钩中那一下是一个「切换」**：目标爆一团亮光，拖影带**同一帧**收成细直的链子。
3. **绷紧的链子要远看也读得出是链子**：细直线 + 一节节亮暗相间（固定大小的链节重复铺，不是一张图拉长）；拽的时候链子缩短、链节间距不变。
4. **拽的手感在两头**：拽的人手往回收、链子那头翘一下；被拽的人一下下往这边挪。
5. 诺提勒斯对照：近处能看清链节、没有拖影带 —— 我们镜头远、链子在屏幕上只有几个像素粗，按锤石的「拖影带 + 亮暗节点」更读得出来。
