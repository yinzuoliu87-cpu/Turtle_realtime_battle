# 援军小将 · 四面合围 · 专用演出素材逐帧（共 60 帧 · 2026-10-29）

> 方案书：`docs/plans/20261029-终极战场援军小将.md`。生成脚本：`tools/build_reserve_vfx.py`（逐像素确定性，重跑逐字节相同）。代码：`scripts/systems/skills/reserve_vfx.gd`（`ReserveVfx`），门禁：`tests/verify_reserve_vfx.gd`。

> ★参考说明（老实写）：这一版**没有**逐帧量外部商业视频；分层顺序沿用本仓已被用户认可的两套——过肩摔落地（`20261024b-过肩摔落地逐帧.md`：闪 → 环 → 碎屑 → 散）与远程小将火箭（蓄力汇聚 → 出膛 → 尾焰）。下面逐帧记录的是**本技能每张素材的每一帧**，放大 6~12 倍、在暗底和沙地底各看一遍。

## 量法

- `python tools/build_reserve_vfx.py --preview <目录>` 出两张接触印相（深灰底 / 沙地底，放大 6 倍）；有方向弹体另按 8 倍、10 倍和 3 倍（接近实机）各看一遍。
- 判断标准：第一帧要「满」；散的时候靠**掉像素**而不是变透明（淡出病）；零半透明；锁定 / 出现印在亮沙地上要有暗边。
- 机器检查（门禁 A 段）：帧数 = 代码时长表、零半透明、每帧非空、相邻帧不重复、一次性素材末帧 ≤ 峰值 35%、锁定箭头在 ±x/±y 轴上、出现印末帧外沿 ≈ 18 像素、有方向弹体白热在 +X 侧。

## 时间轴（实机）

施法 t=0：四个出发点「凝聚」0.20 秒 + 贴地「出现印」0.22 秒；四道气波在目标前后左右 360 码处出现后**原地停 0.5 秒**（弹体照常循环、转向对准目标；用户 10-29「一次出现，然后顿一下…动态个零点五秒左右，再开始移动」），再以 210 码/秒追；目标脚下「锁定」弹出，箭头随气波逼近逐帧收拢，名义合拢 0.5 + 360 / 210 ≈ 2.21 秒那一刻括号收紧，再 0.14 秒散掉（锁定每步跟着目标挪）。飞行全程：有方向弹体（场上 120 码长；用户 10-29「气波太小了，要大一点」由 72 码放大）循环 + 尾焰末端每隔 ≥12 码留一团拖尾。打中：命中爆点 0.245 秒（摆在被打者「气波来的那一侧」16 码、朝镜头 0.3 米，轻震屏）。没打中就消失：原地散去 0.20 秒。
