## 二、「生动」量出来是什么在动（运动热图）

做法：只取**镜头静止**的窗口（整段每 0.1 秒估一次镜头平移，找连续 ≥ 1.5 秒不动的段），逐帧差、阈值 10，算画面中央 60% 里「至少 15% 的帧在变」的面积占比。
★量尺踩过的坑（如实记下）：第一版拿全画面算平移，四周不动的 HUD / 暗角把相关峰钉在 0 ⇒ 镜头明明一直在跟人走，被算成「不动」，整张图都亮（70 ~ 80%，假的）；第二版改中央加窗后补了平移，仍是 90% —— 参考是**真 3D 镜头**，跟人平移时近景远景视差不同，一个整体平移补不平。**结论：镜头在动的段这把尺子不能用，只量静止段。**

## 五、学到的（只学做法，不照搬造型）

**地图（四张都要有）**
1. 场景要一直「呼吸」：每一丛草按风整丛摆（同一阵风有先后）；每个光源都闪（火苗序列帧 + 光晕亮度起伏）；前景有缓慢飘过的粒子（落叶 / 萤火 / 灰烬，按地图主题换）；有自己会动的小东西（蛛网上的蜘蛛、漩涡、光柱）。静止段参考场景本身在动的面积约 4 ~ 15%，我们是 0。
2. 场地是一块有**厚度**的岛：边缘露土层侧面，外面压暗成虚空 —— 场地边界一眼就清楚，场地内亮、饱和。
3. 用**超大尺度的前景 / 远景物件**框住画面（比角色大十几倍、压暗），远处散红灯 / 发光眼 / 蜡烛撑纵深。
4. 地面要有大块的设计（路、深浅区域、水），不是均匀地砖；物件成组摆、每组带一个光源。

**武器挥动（我们的普攻）**
5. 出手前**身体闪白 2 帧**；刀光是**一整块实心形状**（纯白芯 + 一圈主题色描边发光），尺寸是身高的 2 ~ 5 倍，持续约 8 帧（0.27 秒）扫过半圈以上 —— 不是粒子拼出来的。
6. 命中要有「世界的反应」：碎叶 / 草屑 / 血点四散，场上物件被打碎（木箱、土堆）。

**远程投掷（我们的远程普攻 / 技能弹道）**
7. 投射物本体是**轮廓清楚的一个东西**（骷髅头），走**抛物弧线**（先上后下）而不是直线；身后拖**和本体一样宽的实心色带**，4 ~ 5 帧内淡掉。
8. 落点在地上留一团发光的东西（光池 + 往上窜的火舌 + 火星），持续约 0.4 秒，比命中闪光本身更久。

**营地 / 角色多也舒服**（用户说的「第一幕庄园」）
9. 深色底 + 一种高饱和的主色铺满地面（营地是黄色月相砖），所有物件都有粗黑描边、剪影清楚；十几个小角色在走也不乱，因为背景的明度低、角色的明度高。
