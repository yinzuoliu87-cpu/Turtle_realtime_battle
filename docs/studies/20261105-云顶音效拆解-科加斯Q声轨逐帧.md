## 结论一：一个动作拆成几条声音，各对一个时刻（游戏文件里的事件名）

| 动作 | 云顶 / LoL 的事件 | 变体数（科加斯实数） | 我们改前 | 我们改后 |
|---|---|---|---|---|
| 普攻出手 | `BasicAttack_OnCast` / `OnMissileLaunch` | 4 | 无 | `bas_<龟>` 3 个 |
| 普攻命中 | `BasicAttack_OnHit` | 4 | `atk_<龟>` 1 个 | `bah_<龟>` 3 个 |
| 暴击 | `CritAttack_OnCast` / `CritAttack_OnHit`（另一套） | 3~4 | 通用 hit-crit 叠一层 | `crit_<龟>` 2 个 |
| 技能放出 | `Q_OnCast` / `cast1` / `cast2`（科加斯 Q 放出 1 + 蓄力第二段 2） | 1~2 | `cast_<技能>` 1 个 | `sk_<技能>` |
| 技能命中 | `Q_OnHitLocation` / `hit`（每个被打中的人） | 1~3 | 通用 hit-physical | `skh_<技能>` 2 个 |
| 增益开始 / 结束 | `buffactivate` / `OnBuffDeactivate` | 1 | 无 | 放出声 + 演出 |
| 装备 / 护盾 / 治疗 / 阵亡 | 云顶公共包里各自一条 | — | 旧 PoC 通用 | `eq_<编号>` / `g_*` |

## 结论二：声音本身（同一把尺子 `tools/sfx_measure.py` 量，中位数）

| 类别 | 分母 | 时长 秒 | 150 Hz 以下低频占比 | 有声段 RMS dB | 平坦度（噪声型质感） |
|---|---|---|---|---|---|
| Riot 普攻出手 | 660 | 0.67 | 0.12 | −16.3 | 0.15 |
| Riot 普攻命中 | 430 | 0.68 | 0.35 | −13.5 | 0.27 |
| Riot 暴击 | 222 | 0.78 | 0.35 | −14.4 | 0.26 |
| Riot 技能放出 | 626 | 1.49 | 0.41 | −15.2 | 0.11 |
| Riot 技能命中 | 354 | 1.25 | 0.46 | −14.6 | 0.21 |
| **我们改前（154 条）** | 154 | 0.74 | **0.01** | **−18.8** | **0.05** |

改前的三个硬伤：几乎没有低频分量（没有分量感）、有声段稀（RMS 低 4~5 dB）、质感是纯音 / 方波一类（平坦度只有 Riot 的一半以下）——这就是「像素感」。

## 结论三：一个技能的声音怎么跟着特效走（科加斯 Q 声轨，下表）

- 放出那一刻（预警环出现）起一段**低频地鸣**，一直持续到爆点：质心 60~370 Hz，低频占比 0.7~0.97，约 −22~−29 dB。它是「蓄力 / 地下有东西」的声音，不是一声就完。
- 爆点**晚画面约 0.1 秒**到峰值（−19.6 dB），频率一下拉高到 1.2~1.6 kHz、高频占比 0.09~0.11：刺破土的碎裂声，和地鸣是两层。
- 爆点之后碎土 / 余响拖约 1 秒（−23 → −41 dB）才没。
- ⇒ 竹刺阵：`sk_bambooSpikes` = 地鸣蓄力（放出时播），`skh_bambooSpikes` = 竹刺破土碎裂（伤害落下时播）；所有技能都照这个「放出 + 命中」两段拆。
