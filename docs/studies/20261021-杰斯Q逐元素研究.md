# 杰斯锤形态 Q（奥术幸存者皮肤）逐元素研究 —— 变脸龟锤击的参考

- 来源：官方皮肤展示视频 YouTube `TpOlXibVxoY`（60 fps，1280×720），73.625~76.125 秒 = 150 帧，帧号 #0~#149（#k = 第 73.625 + k/60 秒；用户口径「0.25 倍慢放 19~25 秒」= #44~#140）。
- 研究人：主会话 2026-10-21 亲自看；原分辨率裁切每 2 帧一张（#44~#130 共 44 张），关键帧 #68/#72/#77/#80/#84/#88/#96/#108 放大到 440 像素看纹理。
- 用户反馈史：「完全不像」「你只看这个点够么」「你看到他有图形吗」——前五版只拆了阶段、量了总像素，**没看到图案、没看到每个元素各自在变**。本文按**元素**拆，每个元素写：出现/消失帧、位置、形状、图案、颜色、大小、怎么变。

## 元素逐个

### E1 起跳拖尾 + 起跳尘（#44~#56）
- #46~#48：起跳点一团灰白尘（小）。
- #48~#56：从起跳点**斜向上**一道**淡青白、半透明、柔边**的风痕长条，宽约角色身宽 0.6，越往下越淡，随身体上升拉长后淡出（约 0.13 秒）。不是实心块、没有描边。

### E2 锤头光（#44~#62）
- 锤头本身变大、发暖金桃色光，中心一颗**粉色光球**（#58~#62 明显），周围有花瓣状金色饰片。跟着锤走。

### E3 下砸锤迹（#64~#66，约 2~3 帧）
- 一道**很宽的桃白色月牙带**（宽度≈角色身高 0.4），从头顶扫到目标；**带内有粉色涡卷花纹**，不是纯色。边缘柔、带粉色外晕。持续极短，随后在 #68 起变成从画面上方掠过的残迹（#70~#80 仍见一道淡白弧在泡上方，渐淡）。

### E4 命中暗星徽记（#68~#74）★ 图案
- 形状：**深紫黑色的多角星**，8~10 根长短不一的尖刺（不对称），刺尖发紫红光。
- 星体上嵌 **3~4 个淡青色水滴 / 豆形亮斑**，排成一个像符号的图案（像一张抽象的脸 / 徽记）。
- #68：星最大最清楚，周围一圈**放射状模糊线**（冲击感），一根**细红线从天而降**已经出现。
- #70~#72：星略缩、刺尖拉出青白光芒；**背后长出暖黄—橙色的大光团**（不是粉色），从星后往外鼓。
- #74：星溶进白热光团里消失。
- 尺寸：星直径≈目标身高 1.0。

### E5 暖黄爆光 → 晶格能量泡（#70~#80）★ 图案
- #70~#74：暖黄白光团（黄 → 白热），直径≈目标 2 倍，**中心最亮、边缘柔**。
- #76~#80：转为**半透明品红 / 淡紫能量泡**，直径≈目标 2.5~3 倍；
  - **泡内是晶体切面（Voronoi / 碎玻璃格）**：一块块多边形格，格面淡紫、格边深紫，**像碎裂的水晶**；
  - 夹着 3~5 道**青色闪电裂纹**（细、折线、贴着晶格边走）；
  - **边缘一圈最亮**（粉白），外面有柔光晕；
  - 一道**斜向的白色光刃**从泡里刺出（#74~#82 右下方）。
  - 目标在泡里**透得出来**。

### E6 旋涡环 + 粗红光柱 + 白星芒（#82~#88）
- 泡内部格纹被「卷走」成**同心旋转的光弧**（有动态拖影，像在转）。
- **粗红光柱**（#82~#88）从正上方打到目标，宽≈目标 0.3，**内核白、外缘红**，落点处炸开**白色尖刺星芒**（#86~#88，尖刺 8~12 根，细长）。
- 青色碎片（几块晶体碎片）在泡上方飘（#84~#88）。

### E7 细波纹环 + 目标红橙光球（#90~#98）
- 泡只剩**一两圈淡青白色细波纹线**（不规则、像水波，抖动），向外略扩后淡出。
- 目标身上一颗**红橙色光球**（直径≈目标 0.6），#90~#96 明亮，#98 起淡。
- 光柱变细，旁边有一缕**白色螺旋烟丝**往上飘（#90~#94）。

### E8 地面碎晶格印记（#96~#124）★ 图案
- 地面一片**暗紫色碎裂多边形**（和 E5 的晶格同一种格子，压扁贴地），中间有淡粉地光；
- 大小≈泡的直径；**很淡**（地面纹理清楚可见），约 0.43 秒逐渐淡掉，格子从外往里消失。

### E9 目标余火（#104~#124）
- 命中点附近几颗**橙金色晶体火花**（有棱角，不是圆火球），闪烁、慢慢变少。

## 亮度曲线（实测，原速；粉光 = 品红像素数，白热 = 白像素数）
- 白热：#75 峰（18196），#87 第二峰（11296，光柱打中），其余低。
- 粉光：#78 峰（48726），之后约每 0.06 秒减半：#81 32230 → #84 20097 → #87 14033 → #90 8250 → #96 2107 → #108 549。
- 宽度：#75~#90 基本不变（310~360 像素）⇒ **泡一出来就接近全尺寸，变的是亮度和内部图案，不是大小在长**。

## 对变脸龟的翻译（规矩：学手法与结构，配色贴变脸龟战士）
- 品红 / 淡紫 → **红橙 / 暗红**；青色闪电与亮斑 → **符文绿**；深紫星 → **深紫褐星**；暖黄爆光保留暖黄。
- 范围：**伤害范围 200 码另用一道淡细圈标在地上**（判定 = 显示），能量泡本身按参考比例做（≈角色 2.5~3 倍），不撑满范围。
- 所有发光层用**加色混合 + 柔边渐变**，不用硬边不透明色块；图案（星徽、晶格、碎晶地面、锤迹涡纹）是逐帧手绘的新素材。
- 时长与亮度按上面的帧表 / 曲线，不手调。

## 实现对照（第六版·2026-10-21）

代码：`scripts/scenes/battle/two_head_vfx.gd`（锤击段 `leap_step` / `leap_end` / `hammer_slam`，常量 `QK_*`）。结算没动（`two_head_system.gd` 只调这三个入口）。第五版的 7 张 `twohead-slam-*` 全删。

**做法**：每个图案是逐帧画的新素材（PixelLab 特效工作台、免费；Voronoi 晶格由脚本算多边形后交给工作台画），每个发光层是程序柔边渐变贴图（`gen_quake_glow` / `gen_quake_beam` / `gen_quake_range_ring`，挂出处键，逐帧直播的手机按同名同参现生成）。所有节点在 sim 步里建、由一条 sim tween 按**游戏钟**逐步推进帧号 / 亮度 / 宽度（顿帧期间一起停）。

**亮度**：白热曲线 `QK_W`（峰 #75）、粉光曲线 `QK_P`（峰 #78、之后约每 0.06 秒减半）原样抄自上面「亮度曲线（实测）」。粉光是**品红像素数（面积）**不是不透明度，泡体染色层取它的 0.6 次方作 alpha。

**尺寸**：泡本体 200 像素 × 0.025 = 5.0 米 = 变脸龟身高（73 像素 × 0.025 = 1.83 米）的 2.7 倍；判定圈直径 9.6 米，泡不撑满。

**自审时改掉的（同节拍并排看出来的）**：
1. 第一版柔光剖面 (1−d)^1.8 只剩中心一个小亮点，又被暗星盖住 ⇒ #70~#72 看不见爆光。改平顶柔边 + 加一层普通混合实心团。
2. 加色的红橙叠在绿地上加成米白 ⇒ 泡成了一块米白圆盘。改成「普通混合染红橙 + 加色晶面」：泡比周围亮、格边读成深色线、目标透得出来。
3. 锤头光按世界高度放，被镜头俯角压到肩膀上 ⇒ 改走公告板 offset。
4. 光球加色叠在青色龟身上变白 ⇒ 改普通混合定颜色 + 小加色核。

**门禁**：`tests/verify_two_head_anim.gd` F⑥ 改为量第六版：素材图案（暗星 1 块星体 + 3~5 颗亮斑 / 晶格 ≥20 块晶面 + 绿裂纹 + 末段散尽 / 地印 ≥20 块碎格且从外往里碎 / 锤迹 ≥4 个涡卷）、泡尺寸比例、范围细圈半径（量贴图 × 运行期 pixel_size）、时序、亮度曲线峰位与衰减、起跳风痕与锤迹时刻。

**主会话自审后再改（10-21）**：初稿泡体用 0.62 的实心红橙染色，「像一颗橙色陶砖球，目标龟几乎完全被盖住」。改成：晶格素材重画为「格面暗暖粉、格边亮橙细线」（加色下格面只透一层淡暖粉）；泡体改为加色暖粉柔光 + ≤0.18 的淡染色；爆光实体层在 #75 之后快速退掉。门禁新增两条：晶格帧泡内亮像素占 5%~30%；泡段（+0.15~0.5 秒）盖在目标上的普通混合层不透明度 ≤ 0.3。锤迹提前到落地前 0.1 秒、40 fps，扫下的三帧在 1× 也看得清。
