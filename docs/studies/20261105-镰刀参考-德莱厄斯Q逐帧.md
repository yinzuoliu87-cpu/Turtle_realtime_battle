## 素材

Riot 官网英雄页技能演示 `champion-abilities/0122/ability_0122_Q1.webm`（1056×720 / 30 fps，0122 = 德莱厄斯）。

另看了凯隐 W（0141_W1，直线斩：红框预警 0.25 秒 → 亮黄红刀光填满一帧 → 快速淡出）与亚托克斯 Q（0266_Q1）做旁证。
为什么选它：LoL 里最典型的「一把大刃绕自己扫一圈、扫到谁伤到谁」，和孤注一掷（前方 120° 镰刀扇形斩）同一类。

## 结论

- **三段节奏**：蓄力约 0.27 秒（第 0~7 帧，斧子拉到身后、身体扭转）→ 挥斧一整圈约 0.33 秒（第 8~17 帧）→ 刀光与血迹 0.2 秒内收掉。
- **命中很早**：挥出后第 3 帧（0.1 秒）斧子扫到盖伦，盖伦身上一团白光爆闪，是全段最亮的一帧；伤害在这一刻，不是挥完才算。
- **刀光是连续的一片**：斧刃后面拖着几层半透明白色残影，连成一条月牙；外缘有一圈红色弧带，最亮最宽在斧头处，往后变细变淡。不是一张张分开的复制图。
- **命中后有残留**：盖伦脚下溅一摊血迹，0.3 秒淡掉。
- **对孤注一掷的做法**：
  - 伤害时刻不能动（改了就改对局结果），所以没有蓄力段，直接挥：0.11 秒扫完 120°，三次缓出（前一半时间扫过 87% 的角度）；
  - 刀后一条连续月牙（贴地扇环，三条硬边色带：外缘亮边 / 红色主体 / 内缘暗边，不透明度 6 级台阶从尾到头递增，刀头最后一格往白里提），扫完 0.22 秒由尾向头收掉；
  - 刀经过每个被砍中的敌人那一帧，敌人身上一道白色斩弧（0.05 秒满亮再 0.1 秒收）；
  - 原来那张红镰刀保留在刀头，跟着缓出曲线转；
  - 去掉每帧一张的红色复制残影（梳子状）。
- **月牙刀光的素材**：`assets/sprites/vfx/dice-scythe-smear.png`（`tools/assetgen/build_scythe_smear.py` 生成，256 像素一格 × 7 帧，30 fps，重跑逐字节相同）。
  第一版用 ImmediateMesh 每帧现画，直播（S3 逐帧直播）录不进流（CI `verify_stream_coverage_3` 判「新出处」），改成和共享地面环同一条路：逐帧烤好、贴地、pixel_size 恒定只切帧、走游戏时钟。
  7 帧逐帧不透明像素 6168 / 5920 / 3950 / 2190 / 1046 / 392 / 91：第 0 帧刀头已扫过 66%（缓出），第 1 帧扫满，之后尾巴往刀头收、整体淡出，第 7 帧起全空（所以只留 7 帧）。实拍核过方向：刀头那一端和镰刀重合。
