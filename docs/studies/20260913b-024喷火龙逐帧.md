## ★★查出来的真缺陷：整条链都挂在 tween 上，无头下一点伤害都不落

美术本身没问题（真像素龙 + 振翅 + 地火带），**坏的是结算的挂法**：

| 层 | 原来 | 症状 |
|---|---|---|
| 外层 | `_eq_dragon_breath` 用 `tween_interval(0.55)` 延时放龙 | 龙**压根没放出来**（探针打出 `pending=0`） |
| 内层 | `_dragon_unleash` 用 `tween_interval(d)` 逐个投递伤害/治疗 | 就算放出来了也不结算 |

`tween` 走**未钳制的真实 delta**，无头下推不动（CLAUDE.md §3.5，`verify_pirate_hook` 连红三次的同一个根因）。
门禁第 ④ 组「走真入口后敌人确实掉血」**实测 0 伤害**，当场确诊。

**★我第一次只修了内层**，跑完还是 0；探针打出 `pending=0` 才发现外层也在 tween 上。
**一条链要整条查**，修一半等于没修。

现在两层都改成挂进 `DragonSystem._pending`，由 `tick(dt)` 按 `battle._t` 到点结算 ——
与 031 水晶球B 同一条路（「结算走 sim 时钟，不走 tween」）。
修后实测：`_t=7.00` 时队列排空，敌人掉血 **16917**，友军回血 **220**。

## 实战镜头逐帧（1:1 连续录，台子 `p2eq_024`，共 **10** 帧）

录 2.40~4.20 s 每 0.2 s 一帧（前摇 → 放龙 → 飞行 → 地火带）。

| 帧 | 时刻 | 画面 |
|---|---|---|
| 0 | 2.40s | 还没起手：携带者在左，三个假人在右 |
| 1 | 2.60s | **前摇**：召唤点浮出一圈橙色细环，四周七八点火星向内收束 |
| 2 | 2.80s | 火星继续内收，环还在；场上没有别的东西 |
| 3 | 3.00s | 火星收尽，环淡去 —— 前摇最后一刻 |
| 4 | 3.20s | **龙出现**：红翼金身的像素龙从召唤点冒出，脚下一柱火 |
| 5 | 3.40s | 龙开始右飞；身下已铺开第一段地火，最近的假人被火裹住 |
| 6 | 3.60s | 龙飞到队列中段，地火带跟着延长，火苗高低不一（不是等距复制） |
| 7 | 3.80s | 龙过第二个假人，火带更长；龙嘴有喷火 |
| 8 | 4.00s | 龙接近最远的假人，火带几乎贯穿整条直线 |
| 9 | 4.20s | 龙飞出队列之后仍在推进，身后整条地火带还在烧 |

**读得出的是**：**先蓄力再出龙**（不是一下冒出来）、龙**真的从头飞到尾**、
**火带跟着龙走**而不是一次性全亮。

## 门禁与反向验证

`tests/verify_dragon_breath.gd`（**12 条**）量几何、数值、友军那半条，以及**走真入口**。
反向验证五条，**五条全红在各自判据上**：

| 变异 | 红在 |
|---|---|
| M1 前摇退回 tween 投递 | ④ 走真入口后掉血 0 ／ 友军回血 0 |
| M2 掏空 `tick`（接线断掉） | ④ 同上 |
| M3 灼烧层数不吃星级 | ② 50 层 ／ ★1 20 层 |
| M4 友军那半条删掉 | ④ 友军回血 0 |
| M5 判定带 88 → 300 码 | ① 带外不算（挡多了也是错） |

### ★★M5 一开始只红在「分母」那条

因为取样点原来写成 `BREATH_HALF_W + 40`：**拿被测常量去算阈值 = 恒真式**，
带宽一改，样本跟着挪出去，几何那两条照样绿。
改成写死的 44 / 87 / 128 码之后，「带外不算」才真的会红。

## 还没解决的（登记，不假装没有）

- `_dragon_windup` 仍用 `VfxTex._make_fire_glow_tex()` **程序生成的光球**，且没设 `texture_filter`
  （探针实测 Sprite3D 默认是 `LINEAR_WITH_MIPMAPS`）。这一轮**没动** —— 它在实拍里读作「收束的火星」，
  不是被否过的那种「无意义白球」，但仍在欠债台账上。
- 治疗仍画一个 `_skill_ring` 绿环（共 4 处环）。
- 龙的**飞行本身**仍由 tween 驱动（`tween_method` 推插值）—— 那是**纯观感**，
  按 memory「tween 只适合纯观感」是允许的；**结算已经全部离开 tween**。
- 数值 / 文案 / 触发条件**一个字未改**。
