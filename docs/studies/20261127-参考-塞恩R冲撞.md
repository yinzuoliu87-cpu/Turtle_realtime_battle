## 二、总览（10 帧/秒，116 格）

- 0–0.7 秒：塞恩站着。
- 0.8–1.5 秒：起手。身上冒橙色火星，背后冒红色烟气；**冲锋方向那一侧先亮起一团橙光**，越来越大。
- 1.5–8.2 秒：冲锋。整个人裹在一团红橙火球里：**前缘一道弯月形的冲击罩**（最前沿一圈品红亮边，往两侧弯过去包住身体），前脸最亮是橙黄；身体染成红色、半透明；**身后拖出好几道很长的暗红火舌 / 速度线**。镜头一直跟着他。
- 8.3–8.9 秒：撞上目标（见逐帧表）。
- 8.9–11 秒：目标被眩晕（头顶紫色），塞恩收招，地上留一块焦黑。

## 四、分层拆解 → 舞狮对应

舞狮不是火焰角色，配色换成舞狮自己的红金；**只学「每一段要有什么」和节奏，不照抄火球造型**。

| 段 | 塞恩 R（看到的） | 舞狮冲撞（要做的） |
|---|---|---|
| 起手 0.45 秒 | 身上冒火星 + 背后红烟（0.2 秒）→ **冲锋方向前面先亮起一团光**，越来越大（0.4 秒） | 压低扒地（已做）+ 身上冒金红火星；**狮头前方先聚一团金红光**，蓄满正好冲出去 |
| 冲锋中·前方 | **前缘弯月形冲击罩**，前脸最亮，包住身体两侧 | 狮头前面一道**弯月形金红冲击罩**（前缘最亮、往两侧弯过去），跟着跑、朝冲锋方向 |
| 冲锋中·身上 | 身体染红、半透明 | 舞狮身体泛一层金红光（加色） |

| 撞上 0.17–0.33 秒 | **地面一圈冲击环**突然出现、里面铺满光和火星、往外扩 | 目标脚下地面炸开一圈金红冲击波（贴地，画出来的，不是程序圆环） |

## 五、可借鉴点

1. **冲锋要有「前脸」**：特效最亮、最厚的地方在冲锋方向前面，不在身后。身后只是速度线 / 拖尾。
2. **起手先在前面亮**：玩家看到前方亮起来，就知道要往哪个方向冲。
3. **撞击分三拍**：接触点小亮星（0 秒）→ 碎片喷 + 抛起（0.03–0.13 秒）→ 地面冲击环（0.17 秒起），最后变暗收尾。三拍错开，不是一张图同时出现。
4. **收尾变暗而不是直接消失**：亮橙 → 暗红 → 焦黑 → 淡出，总共约 0.6 秒。
