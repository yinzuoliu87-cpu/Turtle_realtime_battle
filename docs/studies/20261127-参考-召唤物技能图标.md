## 3. 分析：共同规律

1. **主体 + 特效占满整格**（70%~95%），四周不留空。
2. **有明确光源**：主体靠光的一侧有一圈亮边（rim light），背光侧压暗；背后有一片光把主体托出来。
3. **一个最亮的焦点**（宝石、矛尖、火光），视线先落那里；常用一个与主色互补的冷色点睛。
4. **动作用大块的特效画出来**：速度线贯穿画面、整条火焰拖尾、放射光，不是几根细线。
5. **材质有细节**：金属上有雕纹、镶嵌、高光块。

## 5. 落到我们这套（规格不变）

硬边像素画、64×64、透明底、深色描边，同现有 `skills/` `passive/` 图标。**不做方形满底背景**（我们的图标都是透明底单物件），参考里「背后整片光」改成主体后面的**硬边光晕 / 光块**（两到三色，不半透明）。

颜色从立绘取：百夫长红 `#840b1f / #a2141e / #c7221c / #ee4931`、钢 `#555e74 / #6a7b8f`、金 `#c1812f / #9a551f`；炮台青 `#1b4644 / #3c8778 / #53ac9b`、灰 `#32323e / #575969`、米白 `#fadfad`。点睛色：百夫长用金白光，炮台用暖橙火光（与青绿互补）。

## 6. 做法（如实）

逐像素按几何判层上色的脚本（`tools/assetgen/summon_icons_1127.py`）出分层 PNG（背后光 / 本体 / 描边 / 前景特效），再由 `tools/assetgen/ase/png_layers_to_ase.lua` 在 Aseprite 里后台拼成分层 `.aseprite`（同 010 激光长刃图标的做法）。不是逐笔手画，也不是 AI 生成。
