## 2. 逐张拆解

| 图 | 画面主体 | 构图 | 动势表达 | 可借鉴 |
|---|---|---|---|---|

| 潘森 E | 盾牌正面 | 正中、对称，占画面 70% | 盾后放射光芒 | 防御类技能：正面盾 + 背光 |

## 3. 共同规律

1. **一张图只说一件事**，主体占画面 60%~80%，不画背景场景。
2. **动作用拖影 / 速度线 / 放射光表达**，不靠多个物件堆叠。
3. **颜色跟角色本体走**（潘森金红、黑默丁格铜蓝），一眼对得上是谁的技能。

## 4. 落到我们这套（硬边像素画、64×64、单物件透明底、深色描边，同现有 `skills/` `passive/` 图标）

| 图标 | 画什么 | 借鉴 |
|---|---|---|
| 突刺（攻击） | 斜向矛尖 + 身后速度线 | 潘森 Q |
| 龟甲阵（技能） | 百夫长红色大盾正面 + 金色翼纹 + 背后放射光 | 潘森 E |
| 军团天降（被动） | 长矛竖直插进地面，落点裂纹 + 冲击环 + 上方下落拖影 | 潘森 R |
| 众矛之力（被动） | 三支长矛扇形交叉 + 一颗星（星级加成） | 身份物件式被动 |
| 炮击（攻击） | 炮弹 + 尾焰 | 黑默丁格 W |
| 护卫（被动） | 青绿盾牌 + 炮台齿轮徽记 | 潘森 E 的盾正面 |
| 火力同调（被动） | 剑与炮管之间一道红色能量线 | 两件物件 + 连接线 |

颜色从立绘取：百夫长红 `#840b1f / #a2141e / #c7221c / #ee4931`、钢 `#555e74 / #6a7b8f`、金 `#c1812f / #9a551f`；炮台青 `#1b4644 / #3c8778 / #53ac9b`、灰 `#32323e / #575969`、米白 `#fadfad`。

## 5. 做法（如实）

逐像素按几何判层上色的脚本（`tools/assetgen/summon_icons_1127.py`）出分层 PNG，再由 `tools/assetgen/ase/png_layers_to_ase.lua` 在 Aseprite 里后台拼成分层 `.aseprite`（同 010 激光长刃图标的做法）。不是逐笔手画，也不是 AI 生成。
