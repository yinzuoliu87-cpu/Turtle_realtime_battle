# 041 退潮浊液 · 逐帧研究（2026-09-13）

台子：`VFXLAB_CASE=p2eq_041`（**本轮新建**）。
录法：`VFXLAB=1 … --audio-driver Dummy`，两簇各 **16 帧**（涨潮 4.90–6.10 s / 退潮 19.70–20.90 s，全部逐帧看过）。

## 文案就是规格

> 登场 `TIDE_DELAY`(5) 秒后涨潮：+250/400/650 最大生命、+10/16/25 攻击力、
> 体积 +`TIDE_SIZE_UP`(30)%、射程 +`TIDE_RANGE_UP`(50) 码，持续 8/11/15 秒；
> 到期**全部还原**（退潮**不致死**，只把生命削到新上限）。

## 一、★台子第一版 `dur` 不够，退潮整段拍不到

★3 的涨潮在 t=5.0、持续 15 秒 ⇒ 退潮在 **t=20.0**。缺省 `dur` 是 14 秒，
**整场只看得到涨潮**。而「到期全部还原且不致死」正是这件的一半。已把 `dur` 提到 23。

## 二、★真缺陷：涨潮/退潮的演出是两圈程序圆环 + 11 颗白球

原 `_ebb_tide_fx`：

```gdscript
_skill_ring(u["pos"], col, 66.0)          # 程序生成的圆环
_splash_ring_bold(u["pos"], col, 120.0)   # 又一圈
var gt := VfxTex._make_fire_glow_tex()    # 11 颗程序光球
    m.texture_filter = BaseMaterial3D.TEXTURE_FILTER_LINEAR   # ← 连像素风都不是
```

实拍读出来就是**两圈模糊的青环罩住龟 + 一团糊的白点四散**。圆环与白球都在禁区里；
更要命的是文案写的「**体积 +30%**」在那团糊里**完全读不出来** —— 而那是这件最核心的观感。

重做成一圈**从脚下窜起来的水柱**（新素材 `tide-swell.png`，12 帧：0~5 涨 / 6~11 退，
同一件效果的两个方向）。烘制脚本 [tools/bake_tide_swell.py](../../tools/bake_tide_swell.py)。
第一版水柱烘成了**一排试管**（把"顶端碎裂"加进了半宽 ⇒ 上粗下细），
改成上细下粗 + 沿高度摆动 + 顶端碎成水花才对。

去掉圆环与白球之后，**体积 +30% 一眼就读得出来**（f0 与 f7 并排一比就是两个大小）。
