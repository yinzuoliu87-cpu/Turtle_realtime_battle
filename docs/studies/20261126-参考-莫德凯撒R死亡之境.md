## 三、分层拆解（千面能借的）

| 层 | 原版 | 千面对应 |
|---|---|---|
| 锁定印记 | 目标身上红色爪痕印记 0.5 秒 | 被拽的人头上先浮出一张紫色面具印记 |
| 抓取 | 鬼火 / 鬼手扑上去裹住 | 携带者面具一亮，一只紫色鬼手伸过去抓住 |
| 消失 | 裹住 → 地面炸一圈 → 一团闪光 | 紫雾裹住 → 地面炸开紫色碎浆 → 一闪消失 |
| 进入领域 | 原地转色 + 圆形边界 | 我们是单独一块场地（用户 11-26 认可「这个地图其实已经挺不错了」）：落在里世界平台上，从裂隙里跌出来 |
| 偷属性中 | 领域里亮青光笼在被拽进去的目标身上（第 16–54 格） | 每秒一股紫色魂流从被偷的人流向携带者 + 头上飘字；携带者身上紫色光环随偷的量变大变浓；被偷的人发暗 |
| 回来 | 化成光柱落回原处 | 紫色光柱落回原位 |
| 回来之后 | 拿属性的人一直留着鬼影 | 携带者的紫色光环留到这一路结束；属性面板写「偷取 +X」 |
| （补）主世界留痕 | 原版是原地领域，不需要 | 两人站过的地方各留一个紫色裂隙印记 + 倒计时圈 |
