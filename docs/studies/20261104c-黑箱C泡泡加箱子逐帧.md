## 素材

预告片：Steam app 4437020 商店页 PV（`hls_264_master.m3u8`，1920×1080 / 30 fps / 97 秒；Demo 5294350 的 PV 时长相同，按同一条处理）。抽帧：`imageio_ffmpeg` 自带 ffmpeg 7.1，`-ss <起点> -frames:v 30`，裁中间 1440×810 再缩到 312×176、每张 5×6 拼 30 帧，左上角印帧号；原片与拼图在本机 `.out/blackbox/`（不进仓库）。

片段：0:50.0 ~ 0:52.0（字幕「BUBBLE + BOX =」；先左右分屏：左「泡泡」、右「箱子」，再合成融合结果）

## 结论（★标「推断」的是从画面反推，看不到它的工程）

- **泡泡是材质，不是贴图**：透明 + 折射 + 菲涅尔白边 + 实时高光，罩住敌人时能看到敌人被折射变形。这是整支预告片里质感最高的一个效果，靠的是**一个好着色器**，不是多画几帧。
- **融合的做法**（★推断）：「泡泡」当外壳 / 载体，「箱子」当内核 / 载荷；泡泡按时间放大（约 12 帧放大 3 倍）并会串出第二个泡泡。同样是「A 的形 + B 的东西装进去 + 尺寸参数」。
- **单技能本身很朴素**：「箱子」单独看只是一个小方块飞出去，没有拖尾、没有爆点 —— 好看的是融合之后的那一层材质。
- **对我们的启发**：我们是 2.5D 像素风（Sprite3D 公告板），**照搬 3D 折射材质不适合**；能学的是「载体模板 + 载荷 + 尺寸曲线」的组合方式，以及「一个高质量着色器复用到所有同类效果」。
