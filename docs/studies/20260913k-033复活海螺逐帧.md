# 033 复活海螺 · 逐帧研究（2026-09-13）

台子：`VFXLAB_CASE=p2eq_033`（**本轮新建 —— 这一件原来没有台子**；
`verify_wormhole_escape` 是星际龟的技能，与它无关）。
录法：`VFXLAB=1 … --position 5000,5000 --audio-driver Dummy`，**共 16 帧**（1.00–18.00 s，全部逐帧看过）。

## 文案就是规格

> **彻底阵亡**（所有复活机会用尽）时，在**原位**变形为一只小虫
> （**100/1500/10000** 生命 · **50/80/200** 攻击力，**无护甲魔抗**，只有星级无等级），
> 自动攻击最近的敌人，攻击速度 `WORM_ASPD`（0.65）/秒，造成 **1×攻击力的物理伤害**；
> 小虫诞生时随机携带 **3 件** 1/2/3 星的 `CONCH_COST_MIN`（4）费或 `CONCH_COST_MAX`（5）费装备。
> **★3**：变虫后每 `WORM_SPLIT_IV`（2.5）秒在空位分裂出一只新小虫（上限 `WORM_CAP`（4）只）。

## 一、结算层：健康；修了一处「同一个数存两份」

变形是同步的（`_spawn_summon`），分裂走 `_tick_unit` 的 `worm_split_t` 每帧累加 ——
都在 sim 时钟上，tween 只用在小虫立绘的出场缩放（纯观感）。

**一处真缺陷**：变形那一行写死 `worm["atk_interval"] = 1.0 / 0.65`，
而常量 `WORM_ASPD` 就在旁边、文案用的也是 `{C:EquipSystem.WORM_ASPD}` 这个占位符，
**而且分裂那条路（`RealtimeBattle3DScene.gd:7242`）读的就是常量** ——
同一个数存两份、两条路各读一份，改常量只有一半跟着变。已改成读常量。

## 二、★★台子第一版配错两处，都被逐帧看出来了

| 配错的 | 后果 |
|---|---|
| 没给 `mortal: true` | `battle_spawn` 给台子的携带者写死 `deathfloor_until = 999999`（**携带者永不死**），而 033 是 on-death 件 ⇒ **永远看不到效果，而且不报错** |
| 没给 `allies` | 携带者一死我方就**全灭** ⇒ 战斗判定结束、`_fight_on` 变假 ⇒ 整组 tick 停摆，<br>实拍 18 秒里**一只虫从头站到尾**，不动也不分裂 |

第二条差点让我去查产品 —— 而门禁直推 sim 明明验出 4 只。
memory `fb-clean-vfx-stage-not-squint`：**别把「我没配对环境」报成「效果有问题」**。

## 三、门禁 22 条

- **①** 三个星级的 血 / 攻 / 双抗 / **原位**。
  ★判据写过一版是错的：我直接断言「血 == 100/1500/10000」，实测 400/2200/10600——
  差额不是 bug，是**那 3 件随机装备加的属性**。判据改成**从产品自己的 `EquipStats.STATS`
  里把这份加成算出来再减掉**，而不是拍脑袋放宽阈值。
- **②** 攻击间隔 == `1 / WORM_ASPD`（守住「读常量不写死」这条）
- **③** 带 3 件、都是 4/5 费、星级跟携带者
- **④** 伤害口径：护甲 500 吃得明显少（是物理）、**魔抗 500 挡不住它**（不是魔法）
- **⑤** 分裂：★3 带标记、差 0.15 秒还不分裂、满 2.5 秒出第二只、**封顶 4 只**、★1 不分裂

★这一节的最后一条**不稳**：同一份代码三次跑出「1 只 / 0 只 / 1 只」——
★1 小虫底子只有 100 血，而产品会随机塞给它 3 件 4/5 费装备，有些组合会让它在 7.5 秒里死掉。
那是**测试不稳不是回归**（memory `fb-make-assertions-rng-insensitive`）。
判据改成量**整段里出现过的最大只数** ⇒ 死不死都不影响结论，连跑四次稳定绿，
而 Y14 变异（1 星也分裂）照样当场红（最多同时 4 只）。

反向验证 5 条变异全部红在各自那条判据上。

## 五、已知缺口（没动，登记在案）

- 小虫脚下的深绿变形环（`_conch_transform`）与各件装备的环，同属 `_skill_ring` 那一族。登记。
- 台子里小虫带的 3 件装备是**随机**的，所以每次录出来的画面不一样 ——
  这是产品行为，不是台子不稳；要复现同一套得先钉 `_battle_rng.seed`（本轮没钉）。
- **数值 / 文案 / 触发条件一个字未改**；只把写死的 `0.65` 换成它自己的常量。
