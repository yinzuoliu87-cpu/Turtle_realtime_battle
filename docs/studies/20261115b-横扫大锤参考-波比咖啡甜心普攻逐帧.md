## 一、展示视频逐帧

来源：SkinSpotlights「Cafe Cuties Poppy Skin Spotlight - Pre-Release - PBE Preview」（YouTube `gRUirEhDtcs`），
每秒 15 帧抽帧（`.out/candy_ref/ba/f_23.png` ~ `f_30.png`，对应视频第 24.97 ~ 25.43 秒；原速镜头）。目标是同一只木桩。共 **8** 帧，逐帧：

| 帧 | 时刻 | 观察 |
|---|---|---|
| 0 | 0.00 秒 | 波比转身、锤子收在身后（前摇）；木桩站着；无特效 |
| 1 | 0.07 秒 | 锤子挥到身侧往前抡；无特效（命中前没有任何预示光） |
| 2 | 0.13 秒 | ★命中：锤头砸进木桩，接触点炸开一朵黄色五瓣花形闪光（软边、中心偏深、外缘橙），约半个木桩高；周围一圈暖橙光 |
| 3 | 0.20 秒 | 花形闪光最大（约一个木桩高），转了约 20°，奶油色、中心橙；花瓣尖上带几缕橙色烟 |
| 4 | 0.27 秒 | 花形闪光消失；木桩身上一圈半透明奶油色圆罩；几根尖细的白黄放射线；桃棕色烟团往右上飘（= 锤子挥过去的方向） |
| 5 | 0.33 秒 | 圆罩变淡；几颗棕色焦糖小碎屑往右上崩出、带几点火星；烟团变淡 |
| 6 | 0.40 秒 | 只剩很淡的圆罩；碎屑飞远变小；几乎干净 |
| 7 | 0.47 秒 | 干净，只剩一点点尘；整段从命中到消失约 0.33 秒 |

## 二、对我们的结论

普攻命中 = 一张招牌闪光（参考是皮肤主题的花形；糖果龟的锤头是薄荷糖 ⇒ **薄荷风车糖闪光**，2 帧：命中 → 转一下散开）0.2 秒
+ 软光晕 + 奶油圆罩 0.22 秒 + 放射白线 0.17 秒 + 顺挥动方向飘的糖粉烟 + 顺挥动方向崩出的糖块碎屑（带重力）。
整段约 0.35~0.5 秒，比糖果锤小一档、没有地面件（普攻不该比技能抢眼）。
