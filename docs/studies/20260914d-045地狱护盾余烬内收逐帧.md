# 045 地狱护盾【持续回复】余烬内收逐帧 — `heal-hot-embers.png`

烘制脚本：`tools/bake_heal_embers.py`
规格：cell 40×40 texel，**共 6 帧**，与 044 同样按 `HHOT_YARDS = 71` 码摆（40 × 1.775 = 71，正好 1:1）、
`HHOT_FPS = 9` ⇒ 0.67 秒一轮。

## 为什么要有这张图

用户 2026-09-14：「045 也需要做个回复 buff 持续特效，你想想怎么办，**不要和之前上一个重复**」。

**先说清背景**：045 那时**已经在放 044 那套气泡了** —— 持续演出接在共享字段 `eq_hot_until` 上，
044 / 045 / 037 三件自动都有。所以这不是"045 缺特效"，是"045 跟 044 撞了"。
做法是保留共享机制、**按持有者换素材**（单件花样是第二层，不是替代品）。

**「不重复」必须能被量出来，不是我说了算** —— 判据落在**运动方向**上：

| | 044 深海项链 | 045 地狱护盾 |
|---|---|---|
| 母题 | 水 | 火 / 吸收 |
| 运动 | 气泡**从下往上升**，到顶破掉 | 余烬**从四周向内收**，沉进身体 |
| 门禁怎么量 | 帧间互相关最佳位移 **dy = −6**（= 烘制脚本的 `STEP = 40/6`） | 火星平均半径 **17.8 → 7.2** |

两者的位移方向正交。判据写在 `tests/verify_heal_hot_readout.gd` 判据④。

## 量出来的三条

- **平均半径**：17.8 → 15.1 → 12.3 → 9.4 → **7.2** → 9.0，**连续四帧递减**。
  烘制脚本里有断言卡住「递减次数 ≥ 帧数−2」，不递减就说明它和 044 的气泡没区别了。
- **峰亮 158 → 226 出现在 f2**：火星进内层才点亮最亮档，这是"越靠近身体越烫"的方向感，
  不是随机闪烁。
- **f5 的最外值跳回 20.2** 是循环闭合的证据（收到底的回到外圈），不是穿帮。

色数 5（含透明），NEAREST。

## 半透明与密度是刻意的

火星体 alpha 170~245、外缘余温 `RING` alpha 168。覆盖只有 4~6%（044 的气泡是 12~19%）——
**余烬本来就比气泡稀**；但第一版只有 8 颗火星、覆盖 2~3%，实拍在黑场里盖到龟身上等于看不见，
所以加到 15 颗并把核心加粗成 2 格（`t > 0.34` 加横向一格、`t > 0.62` 再加纵向一格）。

## 已知取舍

- 外缘那圈余温是**断续的弧**（每 3 个跳一个），不是闭合亮环 —— 闭合亮环是被点名过的禁区形状。
- **没有**把「敌人身上的灼烧飞回来」画进去：文案里没有那条因果，画了就是凭空发明。
  这张图只说一件事 —— 它在持续回血。
