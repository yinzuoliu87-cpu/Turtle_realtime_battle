## §1 当前版本（v0.19.420 起，连接云端）

App 会与 **Supabase**（数据库与账号服务，服务器位于英国伦敦）通信。下面逐条列出会发生什么。

### 1.1 账号

- **默认匿名**：首次启动自动创建一个匿名账号，只有一个随机账号编号，**不需要你提供任何信息**。
- **可选绑定邮箱**：你可以在设置里绑定邮箱，用于**换设备时取回你的账号与游戏存档**（存档见 1.3）。
  绑定后我们会存储你的邮箱地址。
  **不绑定也能完整游玩**；但**不绑定的账号换设备即无法取回**，App 内会提示这一点。
- 绑定与取回都使用一次性验证码（OTP），**我们不存储密码**。
- 验证码邮件由 **Google（Gmail）** 以 turtlesupport32@gmail.com 的名义发出 ——
  因此 Google 会处理收件邮箱地址与邮件内容（只有验证码，不含游戏数据）。

### 1.2 每场对局会上传什么

每场结束后上传一份「阵容快照」，用来给其他玩家当对手。字段以
`scripts/net/backend.gd` 的 `build_ghost_snapshot()` 为准：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| 账号编号 | 随机生成 | 否 |
| `profile.name` | 玩家昵称（你自己取的） | **可能** —— 取决于你自己填什么，请勿填真实姓名 |
| `profile.avatar` | 头像用的龟 id（如 `basic`） | 否 |
| `leaders` / `levels` / `equipped` | 出战 3 龟的 id、等级、装备 id 与星级 | 否 |
| `minions` | 小将的前后排与装备 | 否 |
| `leader_off` / 小将 `off` | 你在背包里摆的开战站位（v0.20.0 起） | 否 |
| `season_level` | 赛季等级（v0.20.0 起，对手按你的等级作战） | 否 |
| `season_total_battles` / `season_wins` / `hearts` / `season_sweeps` | 本赛季场次与战绩 | 否 |
| `chest_*` | 宝箱开箱进度 | 否 |
| 客户端版本号 | 如 `0.19.425` | 否 |

**上传时机**：每场都传（不只是赢的那场）——否则对手池里只剩赢家，匹配会越来越偏强。
**一场都没打就判负的那一局（例如开局后立即退出且补打判负）不传。**

### 1.3 云存档（仅限绑定了邮箱的账号）

- **只有绑定了邮箱的账号才会上传存档。**未绑定的匿名账号，存档只在你自己的设备上。
- **上传什么**：你的游戏进度 —— 龟的等级、装备与背包、深海币、赛季进度（命、胜场、等级）、
  最近 50 场的对局记录、训龟大师的外观与技能等。
- **不上传什么**：音量、全屏、画质等**本机设置**；本机的随机安装标识；登录令牌（见 1.4）。
- **什么时候上传**：游戏每次保存进度后约 20 秒内，以及 App 切到后台时。
- **用途**：只用于你换设备时把进度取回来。我们不用它做分析、画像或广告。
- **保留期**：你的账号存在期间一直保留；删除账号时一并删除（见 1.9）。

### 1.4 保存在你设备本地的登录凭据

为了让你重开 App 后仍保持登录，App 会把**登录续期令牌**（refresh token）保存在
**你设备本地**的存档文件里。它**不会**进入云存档，也不会被发往 Supabase 登录服务以外的任何地方。

### 1.5 对局录像与观赛

正式对局（积分赛、周六闯关、周日决赛）结束后会上传一份**对局录像**，用来让你和其他玩家在别的设备上回看。
录像不是视频，而是「重算这一局所需的输入」，字段以 `scripts/systems/replay/replay_recorder.gd` 为准：

| 内容 | 是否可识别个人 |
|---|---|
| 账号编号、双方阵容快照（同 1.2，含昵称） | 昵称**可能**，取决于你自己填什么 |
| 随机种子、开战时的站位、结果摘要（胜负、步数） | 否 |
| 客户端版本号、系统类型（如 `iOS`） | 否 |

- 周六闯关进行中的对局会实时上传进度，供其他玩家观赛（「直播」），对局结束即停止。
- **谁能看**：已登录的其他玩家可以在赛况板、对阵图、战绩页里观看。
- **保留期**：一个周赛结束后，到**下周二 00:00（UTC）**由服务端定时任务自动删除，最长约 8 天。

### 1.6 服务器裁判（v0.20.1 起）

周六闯关与周日决赛的胜负由服务器计算：服务器用双方已上传的阵容快照与一个随机种子把这一局算出来，
再把结果与录像（见 1.5）写回 Supabase。你不在线时，周日的对局同样会按你锁定的阵容由服务器算完。

- **处理方**：计算服务器由 **Hetzner Online GmbH** 托管，位于**德国**（欧盟）。
  它只从 Supabase 读取计算所需的阵容快照与种子，**不接收**你设备发出的请求，因此也拿不到你的 IP 地址。
- **任务记录**（双方快照、种子、结果）在计算完成 **14 天后**自动删除。
- 不额外收集任何信息：用到的都是 1.2 已经上传的快照。

### 1.6a 每个请求附带的版本号（v0.20.0 起）

App 发给服务器的每个请求都带当前**客户端版本号**（如 `0.20.1`），用于拒绝已停止服务的旧版本。
它不能识别个人。

### 1.7 服务商侧的技术日志

Supabase 作为服务商，会在其访问日志里记录 **IP 地址与时间戳**。
这属于服务商侧的技术日志，用途**仅限于防滥用与故障排查**，我们不用它做画像或广告。
保留期以 Supabase 当时的日志策略为准；我们不会另行导出或长期留存这些日志。

### 1.7a 报错与闪退信息（v0.19.567 起）

游戏出现程序报错，或上一次没有正常退出（闪退）时，App 会上传一条报错记录，用来定位和修复问题。
字段以 `scripts/net/error_reporter.gd` 为准：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| 账号编号 | 随机生成 | 否 |
| 报错原文与代码位置 | 程序文件名、行号、报错文字 | 否 |
| 客户端版本号 / 系统类型 | 如 `0.19.567` / `iOS` | 否 |
| 当时所在界面 | 如 `BracketMap.tscn` | 否 |

- 同一种报错在一次运行里只上传一次，每人每天最多 200 条。
- **不含**存档内容、昵称、邮箱、设备标识。
- 用途仅限修复程序问题；只有开发者能读，其他玩家看不到。
- 保留期：你的账号存在期间；删除账号时一并删除（见 1.9）。

### 1.7b 玩家主动提交的反馈（v0.19.569 起）

只有你在「设置 → 问题反馈」里点「提交」时才会上传，不点不传。
字段以 `scripts/net/feedback_net.gd` 为准：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| 账号编号 | 随机生成 | 否 |
| 问题类型 / 描述文字 | 你选的类型与你写的描述（最多 500 字） | **可能** —— 取决于你自己写什么，请勿填写个人信息 |
| 客户端版本号 / 系统类型 / 系统版本 | 如 `0.19.568` / `iOS` / `17.5` | 否 |
| 设备型号 | 如 `iPhone15,2` | 否 |
| 最近对局编号 | 本机最近 3 场对局录像的随机编号 | 否 |
| 最近报错 | 与 1.7a 同一份报错摘要（本机有才带） | 否 |

- 每人每天最多 20 条。
- **不含**存档内容、邮箱、设备唯一标识。
- 用途仅限修复问题；只有开发者能读，其他玩家看不到。
- 保留期：你的账号存在期间；删除账号时一并删除（见 1.9）。

### 1.7c 举报昵称与黑名单（v0.21.2 起）

在排行榜、周六赛况板、周日对阵图或对局顶栏点其他玩家，可以「举报昵称」或「拉黑」。

**举报**：只有你点「举报昵称」时才会上传一条记录：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| 你的账号编号 | 随机生成 | 否 |
| 被举报玩家的玩家 ID | 屏幕上的 `#XXXXXX`；服务端据此在阵容快照里查到对方的账号编号 | 否 |
| 昵称快照 | 举报时屏幕上显示的对方昵称 | **可能** —— 取决于对方自己填什么 |
| 举报场景 | 排行榜 / 赛况板 / 对阵图 / 对局 | 否 |
| 时间 | 举报时刻 | 否 |

- 同一个人对同一位玩家 24 小时内只记一次；每人每天最多 20 条。
- 只有开发者能读，被举报的玩家与其他玩家都看不到是谁举报的。
- 处理方式：昵称违规的，由开发者重置为默认昵称（对方下次打开游戏时生效）；不违规的标记为已处理。
- 保留期：举报人或被举报人删除账号时一并删除（见 1.9）。

**黑名单**：只保存在你自己的设备上，**不上传**。被拉黑玩家的昵称在你的设备上显示为默认昵称；
可在「设置 → 账号 → 黑名单」里移出。删除账号时一并清除。

### 1.8 **不会**上传的

真实姓名、电话号码、位置、通讯录、照片、设备唯一标识（IDFV / IDFA / IMEI）、广告标识符。
不含广告 SDK、不含第三方分析。

> ⚠ **注意**：邮箱**不在**这一行里 —— 如果你选择绑定邮箱，我们会存储它（见 1.1）。

### 1.9 你的权利

玩家集中在海外（英国 / 欧盟），因此适用 UK GDPR / GDPR。你可以随时：

- **查阅**我们持有的与你账号相关的数据（账号、邮箱、阵容快照、云存档）；
- **导出**它；
- **删除**你的账号与全部相关数据（删除后无法恢复，包括排行榜历史与云存档）。

**删除账号**（v0.21.2 起）：游戏内「设置 → 账号 → 删除账号」，两步确认后立即执行，
匿名账号与绑定邮箱的账号都可以删除。删除的内容：

- 账号本身（含绑定的邮箱）、阵容快照、云存档、排行榜与赛事记录、报错记录、问题反馈、你提交的与针对你的举报；
- 本设备上的存档、本机对局录像与黑名单。

为了不损坏其他玩家的录像与对阵图，**已完成对局的结构**（谁赢、录像本体、对阵图上的位置）会保留，
但其中你的昵称、头像与玩家 ID 会被替换为匿名占位「已注销玩家」，与你的账号编号断开关联。
其他玩家录像本体里记录的对手阵容快照无法逐条改写，它们按 1.5 的保留期（最长约 8 天）自动删除。
已经下载到其他玩家设备上的对手阵容缓存不在我们的服务器上，随对方设备的缓存更新而消失。

**邮件渠道**（查阅、导出，以及无法使用游戏内删除时的备用方式）：发邮件到 **turtlesupport32@gmail.com**，
请在邮件里附上你的玩家 ID（在游戏内「设置 → 账号」可以看到）。我们会在合理时间内处理。

法律依据：账号、对局数据与云存档的处理基于**履行合同**（提供你请求的游戏服务）；
技术日志基于**正当利益**（防滥用与安全）。

### 1.10 未成年人

本应用不面向 13 岁以下儿童，也不会刻意收集其数据。

## §2 给提审的人：App Store 隐私问卷

自 v0.19.420 起**不能**再勾「Data Not Collected（不收集数据）」。应当申报：

| 类别 | 具体 | 用途 | 是否用于追踪 |
|---|---|---|---|
| 标识符 → 用户 ID | 随机账号编号 | App 功能 | 否 |
| 联系信息 → 电子邮件地址 | 仅绑定了邮箱的玩家 | App 功能（账号取回） | 否 |
| 用户内容 → 游戏内容 | 阵容快照；绑定者的云存档 | App 功能 | 否 |
| 诊断 → 崩溃数据 / 其他诊断数据 | 报错原文与代码位置、闪退记录（v0.19.567 起，见 1.7a） | App 功能（修复问题） | 否 |
| 用户内容 → 客户支持 | 玩家主动提交的问题反馈：描述文字、版本、系统、设备型号、最近对局编号与最近报错（见 1.7b） | App 功能（修复问题） | 否 |
| 用户内容 → 其他用户内容 | 玩家主动提交的昵称举报：被举报玩家 ID、昵称快照、举报场景（见 1.7c） | App 功能（内容审核） | 否 |

## §3 历史版本（v0.19.419 及更早，离线）

这些版本**不收集、不上传、不共享任何个人数据**：全部进度只保存在设备上，
后端地址为空、联网层整层停用；对手来自本地生成的 bot 与内置示范阵容。
本机会生成一个随机安装标识（`install_uid`，6 字节随机数），它不是设备唯一标识，且不离开设备。
