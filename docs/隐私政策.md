## 当前版本（离线版）

**本应用不收集、不上传、不共享任何个人数据。**

- 全部游戏进度（阵容、装备、赛季进度、设置）只保存在**你自己的设备上**（Godot 的 `user://` 目录），
  卸载应用即随之删除。
- 应用**不含任何联网代码**。2026-08-20 核实：`scripts/` 与 `autoload/` 下
  `HTTPRequest` / `HTTPClient` / `WebSocket` / `https://` 出现次数均为 **0**。
- 对战中的「对手」来自本地生成的 bot 与内置的示范阵容种子，**不是实时连接到其他玩家**。
- 不含广告 SDK、不含第三方分析、不使用广告标识符（IDFA）。

**在 App Store Connect 的 App 隐私问卷里，本版本应勾选「Data Not Collected（不收集数据）」。**

## 将来接入云端后需要改写（现在还没接）

一旦启用真实后端（见 [docs/plans/20260817-上线与后端.md](plans/20260817-上线与后端.md) U2），
上传的内容**只有下面这些**，必须逐条写进政策，不许用模板糊过去
（字段以 `scripts/net/backend.gd` 的 `build_ghost_snapshot()` 为准）：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| `ghost_id` | 随机生成的快照编号 | 否 |
| `profile.name` | 玩家昵称（游戏内自取） | **可能**，取决于玩家自己填什么 |
| `profile.avatar` | 头像用的龟 id（如 `basic`） | 否 |
| `leaders` / `levels` / `equipped` | 出战 3 龟的 id、等级、装备 id 与星级 | 否 |
| `minions` | 小将的前后排与装备 | 否 |
| `bracket` / `season_total_battles` | 赛季场次档位 | 否 |
| `chest_*` | 宝箱开箱进度（schema 2 起） | 否 |

**不会上传**：真实姓名、邮箱、电话、位置、通讯录、照片、设备唯一标识、广告标识符。

服务端（若选 Supabase）会在访问日志里留下 IP 与时间戳 —— 这属于**服务商侧的技术日志**，
政策里要如实写明保留期限与用途（仅用于防滥用），不能只说"我们不收集"。
