## §1 当前版本（v0.19.418，离线）

**本应用不收集、不上传、不共享任何个人数据。**

- 全部游戏进度（阵容、装备、赛季进度、设置）只保存在**你自己的设备上**（Godot 的 `user://` 目录），
  卸载应用即随之删除。
- 应用**当前不向任何服务器发送数据**：后端地址（`turtle/backend_url`）为空字符串，
  联网层（`scripts/net/remote_pool.gd`）在地址为空时整层停用。
- 对战中的「对手」来自本地生成的 bot 与内置的示范阵容种子，**不是实时连接到其他玩家**。
- 不含广告 SDK、不含第三方分析、不使用广告标识符（IDFA）。
- 应用会在本地生成一个随机安装标识（`install_uid`，6 字节随机数）用于将来的存档归属。
  它**不是**设备唯一标识（不是 IDFV / IDFA / IMEI），反查不到人，且当前不离开设备。

**在 App Store Connect 的 App 隐私问卷里，本版本应勾选「Data Not Collected（不收集数据）」。**

## §2 接入云端之后（D 阶段上线时生效，届时更新本文日期）

云端启用后，App 会与 **Supabase**（数据库与账号服务）通信。下面逐条列出会发生什么。

### 2.1 账号

- **默认匿名**：首次启动自动创建一个匿名账号，只有一个随机账号编号，**不需要你提供任何信息**。
- **可选绑定邮箱**：你可以在设置里绑定邮箱，用于**换设备时取回存档**。绑定后我们会存储你的邮箱地址。
  **不绑定也能完整游玩**；但**不绑定的账号换设备即无法取回**，App 内会提示这一点。
- 绑定使用一次性验证码（OTP）登录，**我们不存储密码**。

### 2.2 每场对局会上传什么

每场结束后上传一份「阵容快照」，字段以 `scripts/net/backend.gd` 的 `build_ghost_snapshot()` 为准：

| 字段 | 内容 | 是否可识别个人 |
|---|---|---|
| 账号编号 | 随机生成 | 否 |
| `profile.name` | 玩家昵称（你自己取的） | **可能** —— 取决于你自己填什么，请勿填真实姓名 |
| `profile.avatar` | 头像用的龟 id（如 `basic`） | 否 |
| `leaders` / `levels` / `equipped` | 出战 3 龟的 id、等级、装备 id 与星级 | 否 |
| `minions` | 小将的前后排与装备 | 否 |
| `season_total_battles` / `season_wins` / `hearts` / `season_sweeps` | 本赛季场次与战绩 | 否 |
| `chest_*` | 宝箱开箱进度 | 否 |
| 客户端版本号 | 如 `0.19.418` | 否 |

**上传时机**：每场都传（不只是赢的那场）——否则对手池里只剩赢家，匹配会越来越偏强。

### 2.3 对局记录与重放

- 为了实现观战与重放，周末赛事的对局会保存：随机种子、双方阵容快照、结果摘要、客户端版本号。
- **保留期：最多到下一个周一，到期由服务端定时任务自动删除。**不依赖人工操作。

### 2.4 掉线代打

周日决赛日若你掉线，系统会用你**最后一次锁定的阵容快照**替你把这一局打完。
这用的是已经上传的快照，不会额外收集任何信息。

### 2.5 服务商侧的技术日志

Supabase 作为服务商，会在其访问日志里记录 **IP 地址与时间戳**。
这属于服务商侧的技术日志，用途**仅限于防滥用与故障排查**，我们不用它做画像或广告。
保留期以 Supabase 当时的日志策略为准；我们不会另行导出或长期留存这些日志。

### 2.6 **不会**上传的

真实姓名、电话号码、位置、通讯录、照片、设备唯一标识（IDFV / IDFA / IMEI）、广告标识符。

> ⚠ **注意**：邮箱**不在**这一行里 —— 如果你选择绑定邮箱，我们会存储它（见 2.1）。
> 本文 2026-08-20 那一版把「邮箱」写进了「不会上传」，那在引入账号绑定后是**错的**，已更正。

### 2.7 你的权利

玩家集中在海外（英国 / 欧盟），因此适用 UK GDPR / GDPR。你可以随时：

- **查阅**我们持有的与你账号相关的数据；
- **导出**它；
- **删除**你的账号与全部相关数据（删除后无法恢复，包括排行榜历史）。

行使方式：发邮件到 **turtlesupport32@gmail.com**，请在邮件里附上你的账号编号
（在游戏内「设置 → 账号」可以看到）。我们会在合理时间内处理。

法律依据：账号与对局数据的处理基于**履行合同**（提供你请求的游戏服务）；
技术日志基于**正当利益**（防滥用与安全）。

### 2.8 未成年人

本应用不面向 13 岁以下儿童，也不会刻意收集其数据。
