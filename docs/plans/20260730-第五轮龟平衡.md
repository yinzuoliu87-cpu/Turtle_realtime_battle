## 2. ★对照环境两处修正（比任何数值都重要）

### 2.1 训龟大师从来没被关掉过

`tests/_duel.gd` 第 20 行写着「固定条件: 无装备 / 赛季 Lv5 / **关训龟大师** / 双方配置完全一致」，

```
[体检] ★训龟大师在场数 = 2  ["left(技=hook 攻=1 血=500)", "right(技=hook 攻=1 血=500)"]
```

它扭曲到什么程度：关掉前后同一组对局（财神·梭哈 vs 幽灵·灵魂风暴）——

| 幽灵剩血 | 1055/1056（**只掉 1 点**） | 601/1056（**掉 43%**） |

**修法**：新增 `RealtimeBattle3DScene.NO_TRAINER`（照 `DEBUG_EDIT` 同款 static var，也认环境变量），

## 4. 各项诊断（为什么是这几处）

### 4.1 忍者·炸弹（#1 · 94.0%）
第四轮削了忍者的暴击（95%→75%），**炸弹反涨 6.0pp 接替成最强技能** —— 印证第四轮
风险清单 §4.2 写的「只削一个技能会被换技能绕过」。
炸弹本体：2.0A = 94 物理 **+ 400 码范围 + 群体破甲 25%/5秒**，收 100 龟能（单体价）。

### 4.2 幽灵·灵魂风暴（#2 · 92.8%）
21 个 80 龟能技能中位胜率 51.8%，它 **92.8%**，比第二名（火炮齐射 81.9%）还高 11pp。
一发 369 点 = 中位敌血 39%，其中 **诅咒占 77%**（6 秒 × 5% 目标最大生命真伤，无视双抗）。
第四轮削登场诅咒只让它掉 2.4pp —— 因为**它自带 6 秒诅咒，不依赖被动**。
本轮直接砍诅咒时长 6→4 秒（一发 369 → 275）。**龟能与本体 2.0A 不动**（用户定）。

### 4.3 普通龟·过肩摔 / 龟派气波（#3 89.2% / #4 88.0%）
第四轮把过肩摔 26%→23% 只降 1.2pp。**根因是「不屈」是【总闸】**——
`battle_damage.gd:72` 注释原话：「造成的任何伤害按目标稀有度增伤（总闸→普攻/技能/真伤/固定伤全覆盖）」，
按 28 龟分布加权 = **常驻 +25.9%，乘在最后**。所以削百分比时它还在放大。
本轮改公式结构（%最大生命 → ATK×最大生命 相乘）+ 气波直接砍系数。**不屈本身不动**（用户定）。

### 4.4 财神（整只 20.1% · 全表垫底）
可视对局实测（关大师后 5 场）：**财神稳定在 33 秒左右死**，死时金币只有 **12~30 枚**。
而攒够 132 枚需要 **72 秒** —— 差 39 秒。所以梭哈**永远在「穷」的状态下放出去**，
平均总伤 294 点（敌人血量的 27%），而这是它一整场唯一的一次大招。

★**第四轮把梭哈 340→210 降价 38%，释放 1.65→1.96 次/场，胜率纹丝不动 9.6%** ——
因为它「一场限用一次」，**释放次数天花板本来就是 1**。降价救不了它。

★另一个关键交互：财神**普攻**是 `1.0×ATK + 2%×ATK×当前金币数`，而**梭哈会清空金币**。
每枚金币「留着」值 0.66 伤害/秒（持续到死），「投掉」旧值只有 17.1 点一次性 ——
**打平点需要剩余 25.7 秒，而它只活 33 秒 → t=7.3 秒之后放梭哈还不如把金币留着普攻。**
改到 0.3+0.3 后每枚 28.4 点，打平点 42.9 秒 > 存活 33 秒 → **任何时候放都划算**，
这一改顺带修掉了这个隐藏的设计缺陷。

### 4.5 双头·融合（#78 · 19.3%）
第四轮加了 +125 生命，**反而跌 4.8pp**。融合是「变肉」的技能，而双头的病是「打不死人」：
锁近战后攻击 60.8 → **42.5（−30%）**，魔法波每段吃的就是这个被砍过的攻击力（每段 34 点）。
本轮降价 125→85：因为**波数是累积的**（4→5→6…），放得越多越强 ——
释放 4.66 → 约 6.9 次，累积段数 22 → **49 段**，总伤 749 → **1666（+122%）**。
**攻击惩罚 −30% 不动**（用户定）；若第五轮仍低，即确认根因在那里。

### 4.6 泡泡·泡泡爆破（#80 · 16.9%）
泡泡值被**三方争抢**：被动每 5 秒抽 20%（10% 回血 + 10% 打人）、爆破每次抽 40%。
模拟一整场：只有被动抽 → 33 秒末存 645；**被动+爆破都抽 → 只剩 236**。
每发平均只有 165 点，而且魔法段吃魔抗、物理段吃护甲。
★**三个技能里唯一吃泡泡值的那个就是最差的那个**（束缚 57.8% / 盾 31.3% 都不吃）。
本轮不改消耗比例，改倍率 + 物理底伤（物理段**不吃泡泡值**，是开局唯一稳定的伤害）。

### 4.7 水晶龟（整只 23.7% · 26/28）
护甲 21 / 魔抗 23 **双双全表第一**，被动还额外 −20% 魔法伤害 —— 属性是全表最好的坦克之一。
★**三个技能里两个「锁龟能」，而那两个正好是最低的两个**：

| | 龟能 | 胜率 | 锁龟能 |
|---|---|---|---|
| 水晶球 | 70 | **44.6%** | 否 |
| 碎晶爆破 | 100 | 15.7% | 是（释放期间） |
| 水晶壁垒 | 80 | **10.8%** | 是（持盾 4 秒全锁 → 一场 16.7 秒不充能 = 战斗时长的 51%） |

另两个问题：碎晶三段共 **59 点**收 100 龟能（全表性价比最差之一）；壁垒的水晶刺**零伤害**。
本轮补伤害（碎晶 ×3.2、水晶刺 0→1.5A、引爆 19%→22%）。
★**锁龟能本轮不动**（用户定）—— 若第五轮仍垫底，即确认根因在那里。

## 5. 已知风险与未决点

**这一节必须存在** —— 不写就等于在宣称"无漏洞"，而那从来不成立。

### 5.1 ★第五轮与前四轮【不可直接比】
对照环境变了两处：**关掉训龟大师** + **小将加强**。
两者都会改变所有 84 个组合的基线，尤其：
- 关大师 → 少了 4 秒眩晕 + 25% 易伤的干扰，**需要站桩输出的龟受益**
- 前排小将有效生命 +20% → **靠快速清小将建立优势的龟吃亏，范围/持续伤害受益**

**第五轮应当作新基线看**，不要拿单只龟的 Δ 直接归因到它自己的改动上。

### 5.2 过肩摔的新公式【吃装备】，无装备测试会高估削弱幅度
`1.0A + 0.2%×ATK×最大生命` 是乘法结构：基础攻击 40 时那项 = 8% 最大生命；
装备把攻击堆到 100 就变成 **20% 最大生命（≈ 回到现在的水平）**。
胜率测试是**无装备**的 → 测出来是完整的 −53%，**实战有装备时削弱幅度小得多**。

### 5.3 财神改了三处，归因会变难
骰子 / 梭哈 / 招财进宝同时改。若财神仍低，无法从胜率表分辨是哪处没起作用。
缓解：三个技能的胜率是**分开统计的**，至少能看出是哪个技能没救起来。

### 5.4 两处「用户选择不动」的根因，若无效即被证实
- **水晶壁垒的锁龟能**（数据信号最强：锁的两个 10.8%/15.7%，不锁的 44.6%）
- **双头近战形态 −30% 攻击惩罚**（第四轮加血无效已经指向它）
本轮都只补了数值。若第五轮它们仍低，**这两条就是下一轮必改的**。

### 5.5 冰霜特效重做没有门禁
五层视觉（领域/预警/坠落/命中/残留）**只能靠肉眼验**，任何自动检查都证明不了"好不好看"。
已 F5 给用户看过。风险：`GPUParticles3D` 在低端机/无头下的行为未验证 ——
但它只在 `battle._world != null` 时建，无头下 `_world` 为空会直接 return，不影响胜率测试。

### 5.6 死字段清理的残余风险
135 种字段按「全项目零引用」判定为死。判据是**带引号的字符串搜索**，
已确认**没有动态拼 key 的读法**（grep 过 `.keys()` / 动态 get）。
清理后核对过：龟数 / 核心属性 / 技能数 / 技能名 / type / brief / detail / energyCost **全部未变**。
若仍有遗漏，表现会是「某个技能的某个效果失效」，由 `run-tests.sh` 的 83 项自证测试兜底。

### 5.7 12 分片的稳定性未验证
前四轮都用 8 分片。本机 i9-14900HX（24 物理核 / 32 逻辑核 / 32GB），12 分片理论上约 1.9 小时。
但 memory `project-machine-bsod-during-tests` 记着**这台机器跑重载 Godot 测试蓝屏过**。
12 分片负载比 8 分片高 50%。**若中途蓝屏，损失约 2 小时**。
