# 竹叶龟【生长】永久生命随一大轮保留 + 系数改按攻击力 18% / 25%

日期：2026-11-19　|　状态：**实施中**

## 1. 需求原文

> 用户 2026-11-19：「然后我还想谈的是关于那个竹叶龟的被动啊，就是永久提升最大生命值这一点。现在呢，我是希望改为随一大轮保留，呃，新的一大轮会重置。也就是说，嗯，就是玩家在一直打下去的时候，这个竹叶龟获得永久生命值会越来越多啊、呃。然后需要更改的是这个加成。就是他这里说很多这种基础攻击力，我看这个描述，其实不应该是基础攻击力，就是攻击力的百分比。然后， 然后是就是一般情况下，也就是没有带足迹的情况下，啊、呃，提升的永久生命值的加成，我希望改为百分之十八的攻击力，明白吧？然后是携带了足迹的情况下，提升的永久生命值，我希望改为是百分之二十五乘攻击力。你看，你明白我的意思吗？」

（语音识别：「足迹」= 技能【竹击】`bambooSmack`。）

拆成三条子需求：

- **R1** 永久提升的最大生命值随**一大轮**保留，新的一大轮清零；一直打下去越来越多。
- **R2** 系数的底数从「基础攻击力」改成「攻击力」。
- **R3** 系数：没带【竹击】18%×攻击力；带了【竹击】25%×攻击力（现为 60% / 105%×基础攻击力）。

## 3. 需求 ↔ 代码的出入

1. 用户说的「永久」现在其实**只管一路**：进终极战场就丢（见 §2）。改成一大轮累积后，一局之内要不要也带进终极战场 ⇒ 未决点 U2。
2. 「基础攻击力」：文案与代码一致（都是 `base_atk`），用户要改成「攻击力」（含装备 / 增益）。取**吸收那一刻**的攻击力 `u["atk"]`（被冰寒等减攻时也按当时的）。
3. 新系数比现在小很多（60% → 18%、105% → 25%，底数还从基础攻击力变成攻击力），**单局**里长得比现在少；靠一大轮累积补回来。

## 4. 方案

4.1 系数（R2 R3）：`GROW_MAXHP_PER_ATK := 0.18`、`GROW_SMACK_MAXHP_PER_ATK := 0.25`；`:6542` 底数 `base_atk` → `atk`；结算抽成 `BambooSystem.grow_absorb(u)`（顺手把主场景那行三元表达式搬出去，CLAUDE.md §6）。文案「基础攻击力」→「攻击力」，并补一句「本大轮内跨场累积，进入新大轮时重置」（同命运之轮的灰字）。

4.2 一大轮累积（R1），照 §2 表逐环：

- `GameState.bamboo_growth_hp`：存 / 读 / 切轮清零 / 测试与清档同命运之轮。
- 登场：竹叶龟（左读存档，右读对手快照）`maxHp += 累积值`、`hp` 同加。
- 一局里每次生长记到 `BambooSystem.grown[side]`；裁判结果单带 `bamboo_new` / `bamboo_new_b`；客户端 `apply_bamboo` 入账。
- 快照带 `bamboo_hp`；裁判按服务器盖章封顶（econ_on 关着 / 机器人池 ⇒ 快照原样，同命运之轮）。
- 录像 STATE_KEYS 加一项。
- 两份正式服迁移（§2 表 ①②）：按 `tools/sb_migrate.py` sandbox → beta → prod，**prod 那一步等用户点头**。

4.3 门禁：新写 `verify_bamboo_growth_season`（系数与底数 / 登场套用左右两方 / 结果单字段 / 入账 / 切轮清零 / 封顶）；跟着变的：规则指纹、文案快照、`verify_season_reset` 一类切轮门禁、录像 STATE_KEYS 扫描门禁。RULES_VER 本周已是 8，不再升。

## 5. 已知风险与未决点

- **U1（未决）计入哪些对局**：建议同命运之轮——积分赛（自己那一方）、周六闯关、周日决赛算；切磋、教程、偷袭不算。
- **U2（未决）一局之内带不带进终极战场**：现在进终极就丢。建议**带**（「永久」同一口径：上路长的到终极还在），实现是幸存名单多记一项。
- **U3（未决）要不要上限**：用户原话「越来越多」⇒ 建议先**不设**。估算：攻击力 50 的竹叶龟一局长 2~4 次 × 9 = 18~36 点；一周 30 局约 500~1000 点（龟本身 878）。只是估算，要看真实对局。
- **U4（未决）039 竹制弓箭**：它的绿球也给「永久」最大生命（`battle_ballistics.gd:407` `bamboo_grow`）。用户只说了被动 ⇒ 建议不动（仍只管这一局）。
- **U5（未决）给玩家看**：建议在竹叶龟被动说明里显示「本大轮已累积 +N 最大生命值」（背包 / 图鉴读存档）。
- **U6（要点头）两份正式服迁移**：周一换版窗口里先装裁判机再迁移（新裁判写 `bamboo_new`，旧裁判不写 ⇒ 回包没这个键 ⇒ 客户端什么都不发，向后兼容）。
- **U7（未决）赶不赶 0.23.5**：周五中午提审。U1~U5 当天定下来就能赶；否则下周。
- 风险：对手快照是旧的（积分赛 B 方），快照之后主人又长的不算——与命运之轮一样，封顶取较小值。
- 风险：同一大轮内换了统领再换回竹叶龟，累积仍在（存档按龟记，不按阵容）。
