## 2. ★共用基建：`SpecialBalance`（主会话负责实现，你直接按接口调）

**为什么要它**：五件装备各需要一条**独立于 `u["shield"]` 的第二条余额** ——
064 幽灵护盾（20 秒线性衰减，**耗尽也算破**）· 068 法力护盾（8 秒衰减，存在时锁充能条）·
070 灰色血条（不衰减，每秒 5% 转回生命）· 071 奶油护盾（**永久不衰减**，破了给 buff + AOE）·
072 终极护盾（永久，破了解除变身）。

普通 `u["shield"]` 归零时**不通知任何人**，所以"破盾回调"必须新建。
**不抽这一层就会写出五套互相不认识的护盾。**

文件：`scripts/systems/equip/special_balance.gd`（`class_name SpecialBalance`）
挂点：`battle._spec`

```gdscript
## 给 u 挂一条特殊余额。同一个 key 再给一次 = 叠加到现有余额上。
## key: 自取的唯一串, 建议用装备 id, 如 "p2eq_064_ghost"
## opts:
##   decay_sec : float = 0.0   # >0 = 在这么多秒内【线性】衰减到 0; 0 = 永不衰减
##   on_break  : Callable      # 余额归零时回调 on_break(u, key, reason)
##                             #   reason = "damage"(被打光) / "decay"(自然衰减完) / "clear"(撤场)
##   order     : int = 0       # 吸收优先级, 数字小的先扛。普通 shield 恒定先于所有特殊余额
grant(u: Dictionary, key: String, amount: float, opts: Dictionary = {}) -> void

## 查余额
val(u: Dictionary, key: String) -> float
has(u: Dictionary, key: String) -> bool

## 手动清掉(触发 on_break 且 reason="clear")
clear(u: Dictionary, key: String) -> void

## 【伤害路径调用】普通盾吸收之后、扣血之前。返回穿透后剩余伤害。
## 主会话已在 _apply_damage / _apply_damage_from 两条路径都接好(§3.3)。
absorb(u: Dictionary, d: float) -> float

## 【每帧】衰减 + 到期判定。主会话已接进 sim 循环。
tick(delta: float) -> void

## 换路/清场
clear_all() -> void
```

**你要做的只有两件**：① 在效果触发时调 `battle._spec.grant(...)`；
② 把破盾后的行为写成 `on_break` 回调。**不要自己实现衰减和吸收。**

## 5. 地雷（CLAUDE.md 的，逐条对照）

1. **§3.3 两条伤害路径**：`_apply_damage`(DoT/真伤) 与 `_apply_damage_from`(普攻/技能)
   **各自扣盾扣血**。你如果要改伤害流程，两条都要改。
2. **§3.4 `_t` 跨路累加永不重置**：066「第 11 秒」、068「第 12 秒」这类**必须自存 t0**，
   直接读 `_t` 会让下路一开场就触发。
3. **§3.2 不拿单位字典当 Dictionary 的键**，比较用 `is_same()`，判存在用 `_arr_has_unit()`。
4. **§3.1 hp 数值已是最终值**，不要再乘 `HP_MULT`。
5. **§3.7 注释绝不插进行中间**；改完 `.gd` 立刻编译验证。
6. **随机必须走已播种的 RNG**（073 藤蔓箭、076 连发弩、092 飞行物选目标都涉及）——
   `rng_discipline` 审计器 + `verify_battle_determinism` 会抓。
7. **额外伤害段一律 `from_equip = true`**，不再回钩 on-hit（防自激）。

## 6. 特效标准

用户 2026-08-05：「**要触手水准，除非你用 pixel 的特效动画能做完美**」「**全部做好高质量特效**」。

⚠ **这批一件参考素材都没有**，所以触手那套的第一条（逐帧量参考做成包络表）**无从下手**。
替代方案照 **怒气冲击波**（`scripts/scenes/battle/shockwave_vfx.gd`）那条路：
**用可验证的物理规律当判据**，而不是"我调得像"。那件用的是 Sedov–Taylor 波前 +
Friedlander 超压（负压相＝余振）+ 位移积分，**手调缓动一条都过不了**。

其余判据全部照做：
- **形态要有物理模型，不是凑形状**
- **状态边界要有门禁自动守**
- **★尺子要匹配被测概念**（触手那次拿"投影臂长"量"拍几次"，全程报 0 而肉眼看到两次）
- **数值断言不许依赖 tween 跑完**（无头 CI 下 tween 推进不稳）
- **做不到的诚实写出来**

**素材**：程序化零素材（`VfxTex` 逐像素现算）**或** PixelLab 新生成 —— 两者都符合
用户的素材铁律（新内容一律新素材）。**绝不许拿别件装备的现成立绘顶替。**
