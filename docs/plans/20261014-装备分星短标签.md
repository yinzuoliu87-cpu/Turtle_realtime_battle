## 出入
- 自动从句子里切「数值部分」不可行：同一句里常有两个效果（电棍「追加伤害并眩晕」），5 件装备两句开头是同一组数，
  按句或按首个数做键都会撞。⇒ 改成「每组分档数一行」，标签手写。

## 方案
- `scripts/gamedata/equip_tier_labels.gd`：每件一组标签，顺序 = 正文分档数出现顺序；`#` 标数值位置，前为标签后为单位。
- `CodexDetail.tier_breakdown_lines` 优先用标签行；条数对不上退回整句显示。
- 标签用词统一：平值「基础伤害」、比例「伤害加成 #×攻击力」、召唤物冠所属（大熊 / 炮台 / 小手枪）、
  分阶段的按阶段（草莓蛋糕 ①②③、手半剑 横斩 / 横波 / 竖斩 / 竖波）；正负号贴在每档数上。
