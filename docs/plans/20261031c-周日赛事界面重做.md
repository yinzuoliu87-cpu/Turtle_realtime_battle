### 2.3 商业游戏调研 —— 共同规律

参考目录 `docs/plans/ref/20261031-周日赛事参考/`：34 张对阵图截图 + `对标笔记.md`（C01~C35）；三路深挖（`节奏与观赛/` `仪式与奖励/` `旅程与引导/`）+ 手游观赛抽帧；百款十批全部收齐（`百款/01~10/笔记.md`，每批 10 款 × 十维度，帧图均为实机 / 官方直播关键帧）。
逐条依据（含出处游戏与帧号）在 **`学到的.md`**，下面每条后面的编号指向那里。只收与我们赛制对得上的（小组每组 4 人单败 → 组冠军进冠军杯单败 · 只看不打 · 轮间 3 分钟备战）；竞猜与观赛奖励按用户决定不收。

**开播节奏**
- G1（★按用户 10-31 原话落地为：小组赛各桶并行、桶内同一轮同时开播；冠军杯赛一场接一场）给观众看、选手不在屏上亲自打的赛事，同一张淘汰图里**一场接一场**；唯一普遍的并行是**不同组之间**各一路，组内依次；淘汰正赛收成全服一路。（T-1、W-1~W-3、5-1；四款手游游戏内观赛一次只播一场）
- G2 对阵图**只填已播完的场**，下一轮对手在备战开始时才揭晓。（W-1、T-2）
- G3 场与场之间不空：底部「下一场 A 对 B · 几点」+ 上一场高光 / 预告。（T-3、W-2、W-4、8-2）
- G4 每轮结束固定两拍：本轮出局名单（名牌打叉）→ 下一轮倒计时 + 揭晓对阵。（5-1、2-5、10-2）
- G5 3 分钟备战屏排满：大倒计时 + 本轮进度 + 下一场谁对谁与一句利害 + 一样在动的东西（选手卡轮播 / 回看上一轮）。（3-4、1-3、W-6、6-1、6-2、2-6）

**开场**
- G6 每场开播前一拍「对手入场」2~6 s：轮次名 + 双方名牌（名字 / 头像 / 头衔 / 来历「A 组冠军」/ 本周战绩）+ 双方锁定阵容并排逐只翻出 + 迷你对阵点亮本场那条线 + 倒数自动开播；异步也照样有这一拍，并如实写「阵容已锁定 · 服务器实时演算」；决赛整套换金。（C-5、1-2、1-14、1-15、4-2、7-8、10-1、10-4、2-4）
- G7 冠军杯第一场前，组冠军依次亮相；上周冠军标「卫冕」。（2-3、1-4、1-14）

**结束与夺冠**
- G8 每场结束分拍，不是一张卡：战场上压短标语 → 双方结果（阵容卡，阵亡划掉、赢家发光、三路比分）→ 我的处境与奖励；看别人约 4 s、自己赢约 7 s、自己输约 6 s，自动前进，点屏只跳到这一拍终态。（C-1、C-8、10-5、6-6）
- G9 对阵图本身是舞台：输的格子盖红叉、光点沿连线走到下一格，之后才弹「你晋级 X 强」。（C-2）
- G10 冠军收盘总流程：「决赛完成 · 揭晓中」停一拍 → 亚军卡 → 冠军仪式（白闪 → 奖杯 → 称号 + 规模「24 人冠军」）→ 夺冠阵容逐只特写 → 「夺冠之路」逐轮回顾 → 对阵图补齐比分 → 名次榜 → 冠军定格卡常驻；组冠军走缩短版。整段不放按钮。（C-3、1-1、2-10、3-2、5-3、6-6、6-7、8-7、10-6、J-8；反面 5-8）
- G11 奖励一件一页、先物件后数字、飞进顶栏才算入账。（C-4、3-11、6-9）
- G12 名次越高越华丽，并变成长期身份：头衔挂名字旁直到下一位冠军、名片奖杯柜、冠军墙（往届对阵图可翻）、收盘滚动全部参赛者名字；参赛人人有纪念。（C-6、3-7、3-8、1-8、2-12、6-8、8-9、J-8）
- G13 「今晚之最」：从模拟记录算 2~3 张（单场最高伤害 / 最快结束 / 最强一只龟），只展示。（2-11）

**叫人与入口**
- G14 赛事当天主菜单最大位置是一张「今天的事」卡，状态随时刻变（倒计时 / 进行中 / 已结束），下挂「小组赛 18:00」「冠军杯 20:00」子卡；按身份给主按钮（晋级者「我的比赛」/ 其他人「观看直播」）；绝不放锁住的按钮。（J-1、2-2、6-3、8-3、1-11、5-5）

- G16 倒计时每一页都看得到（全局决赛日小条）；轮到我时不论在哪页都弹「你的比赛 30 秒后开播」；开播时刻 / 结果走全服跑马灯。（J-2、J-3、8-1）

**出局之后与观战页**
- G18 出局卡：本场结果 + 最终名次 + 奖励 + 输给谁，主按钮只有「继续观看」，留下就自动跟到下一场开播；我们比所有被研究的手游多做这一步（它们多数不给出局者观赛入口）。（5-2、J-5、10-11、2-9、W-8）
