用户 2026-10-31（周六），逐字：

## 6. 验收标准

- 验收清单（定稿后逐条展开为门禁）：
  1. 同一组同一轮的场次**一次只开播一场**，下一场有倒计时；一轮全部播完才开下一轮备战；下一轮对手在备战开始时才揭晓（不剧透）。
  2. 对阵图 / 8 强图 / 结算卡 / 主菜单决赛日逐条满足调研「共同规律」（定稿后列条目）。
  3. P1~P22 每一条各有一条判据。
  4. 两个比例（1560×720 手机 / 960×720 iPad）实拍 + 成品视频（周日从打开游戏到冠军诞生一整段）。
- 怎么证明检查会 FAIL：每条新判据都做一次改坏（关掉对应改动），跑红、逐字节还原（与 1ef9279c 的两条门禁同做法）。
