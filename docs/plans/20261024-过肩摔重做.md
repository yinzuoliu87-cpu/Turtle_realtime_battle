### 2.3 共用件（改之前确认过的）

- `_slam` 是十几个技能共用的「演出中锁定」开关（精英铁锁 / 小将浪板 / 火山 / 大熊 / 赛博…），谁先结束谁就关 ⇒ **不抓已经在别的演出里的目标**，只解自己加的锁。
- 贴地圈：`_skill_ring(pos, col, radius)`（10 帧烤好的像素环，躺平贴地，`radius` 就是外径）——用它画 350 码伤害圈，不再用正对镜头的 `fx-shock-ring`。
- 逐帧直播按「sim 步里建的节点」录（`stream_recorder.gd` 节点层），新特效只要在 sim 步里建就会进流。
- 新代码放 `scripts/systems/skills/basic_slam_system.gd`（CLAUDE.md §5「单龟技能」），主文件只留分派一行。

## 3. 需求 ↔ 代码的出入

- 「跳高的时候稍微往小龟背后动一点」：现在是**敌人被甩到背后、小龟原地小后仰**，没有「整体往后飘」。
- 「加速冲向目标」：现在没有冲刺，150 码内直接把敌人**拽过来**（体检第 9 条：前摇期间换了远处目标会被从任意距离拽过来）。

## 4. 方案

### 4.1 新流程（数值除放技距离外都是我的建议）

| 段 | 做什么 | 数 |
|---|---|---|
| ① 冲刺 | 小龟锁定（`_slam`），**由慢到快**冲向目标的**实时位置**（目标此时还能动） | 起速 350 → 0.25 秒内加到 1300 码/秒；到目标 60 码内 ⇒ 抱；0.9 秒还没追上 ⇒ 作废（不伤害、不眩晕，龟能照常已花） |
| ② 抱起 | 目标锁定，贴到小龟身前、被举起 | 0.14 秒；举到 1.3 米 |
| ③ 跳高 | 两只一起起跳（**真抛物线**：上升慢、下砸快）；目标从小龟身前**越过头顶**甩到背后（过肩），越过头顶后倒过来（`flip_v`）；**整体往小龟背后平移** | 滞空 0.64 秒（升 0.42 + 落 0.22）；小龟最高 3.0 米、目标最高 4.4 米；整体后移 60 码 |
| ④ 落地 | 目标砸在小龟背后；眩晕 + 伤害 + 特效 | 目标落点 = 小龟落点再往后 50 码；眩晕 0.5 秒；伤害公式不变（但过护甲，见 B1） |

### 4.2 九条怎么修

- B1：两处「×最大生命」那段改走 `_phys_after_armor`（与竹刺 10-16 同一个修法）。**不补强度**（用户规矩：不许私补隐藏倍率）。
- B2：**抱不起来的目标**（龙蛋 / 免控 / 免击飞 / 已在别的演出里）⇒ 照样冲过去，小龟**原地单跳砸下**：伤害照算、圆心在目标脚下；眩晕：蛋与免控不晕，免击飞（017）照晕（它只免击飞）——我的建议。
- B3：不碰 `no_move`（锁定只用 `_slam`，演出期间位移与挤开本来就跳过 `_slam` 单位）。
- B4：小龟死了 ⇒ 立即中断：目标放回地面（当前水平位置）、复位贴图与偏移、解锁，**不结算**。
- B5：溅射圆心恒为落点。
- B6：抓之前判目标 `_slam`，在别的演出里 ⇒ 走 B2 的原地砸；锁只解自己加的。
- B7：血条 / 影子 / 核影读 `_slam_voff`（影子随高度缩小变淡）；演出全程连续、无瞬移；顿帧（`_hitstop > 0`）与时停（任一方被定格）期间演出停住。
- B8：特效整套重做（§4.3）。
- B9：权威文档 159~176 改成新流程；新增门禁 `verify_basic_slam` 真调这招。
