### §6 四个最终造物要带【特效元素】（用户 2026-09-02:「应该要有额外特殊的特效」）

五个进化档（木/石/铁/金/钻）是**同一把斧头换材质**；四个最终造物**不是** ——
它们是"造物"，图标上要看得出超出一把普通斧头的东西。

| key | 特效元素（要画进图标的，不只是换色） |
|---|---|
| `undead` 亡灵之斧 | 绿色鬼火 / 骨质柄 / 刃口破损缺口 |
| `seraph` 炽天使 | 光翼或光羽 / 金白高光 / 刃背发光 |
| `holo` 全息斧 | 青蓝半透 / 扫描线 / 边缘辉光 |
| `ember` 余烬 | 暗红熔纹 / 飘散的火星 / 刃口余火 |

#### 怎么量「有没有特效」（判据要能证伪，不能靠"我看着有"）

| 判据 | 怎么量 |
|---|---|
| **有基础斧形之外的元素** | 把该图与 `wood` 的**轮廓**对齐后比较：造物图必须有**落在 wood 轮廓之外**的不透明像素（鬼火/光翼/火星就在那儿）。占比 ≥ 8% |
| **色相显著区别于棕色系** | 五个进化档是棕色系（H≈20~40°）。四个造物必须有**一整簇非棕色相**的像素（绿/金白/青/红），占比 ≥ 12% |
| 仍然一眼是把斧头 | 与 `wood` 轮廓的**交集** ≥ 45%（特效不能盖掉斧头本体） |

★这三条是**互相制衡**的：第一条要"多出东西"、第三条要"别盖住斧头"，只满足一条不算过。
