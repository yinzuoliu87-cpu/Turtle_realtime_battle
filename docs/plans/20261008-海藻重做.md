# 海藻（p2eq_012）重做：魔抗 + 登场魔法护盾 + 周期护盾分星

日期：2026-10-08　|　状态：**实施中**（代码与门禁已落地；版本号 / CHANGELOG / 提交由主会话发版时做；§5 的默认值待用户确认）

## 1. 需求原文

| 时间 | 原话 |
|---|---|
| 10-08 | 海草提供的生命值改为90/180/300，不再提供护甲，改为提供7/16/23魔抗。效果为登场时获得相当于25/40/60%最大生命值的魔法护盾（只能挡魔法伤害）。此外每四秒获得40/60/90+3/4/5.5%最大生命值护盾 |

## 2. 调查结论（2026-10-08 读代码，行号以当天工作区为准）

- 属性事实源 `scripts/gamedata/equip_stats.gd:117`：`hp 40/70/100 · def 5/10/18`；展示镜像 `baseStats1`；生成表 `docs/design/装备逐件审查进度.md`。
- 周期护盾：`scripts/systems/equip/equip_tick_system.gd` `_tick_jelly`，`[40,60,90][si] + maxHp × JELLY_MAXHP_PCT(0.04 单值)`，`COMMON_SHIELD_SEC`（4 秒）。主场景每帧 tick 调它（`RealtimeBattle3DScene.gd` 约 2831 行，只在开战后）。
- 伤害路径：`battle_damage._apply_damage`（DoT，按 `bucket` 判类型，`"mag"` = 魔法）与 `_apply_damage_from`（普攻/技能，`_dtv` = 类型、`raw` = 真伤），都是 `ShieldMath.absorb`（普通盾）→ `battle._spec.absorb`（特殊余额）。
- `SpecialBalance`（`special_balance.gd`）是现成的「独立余额」基建，但它**在普通盾之后**吸、且吸全类型 —— 不合「只挡魔法、先于普通盾」，所以没用它。
- 血条 `scripts/scenes/hp_bar.gd` 已有多段特殊盾色（圣盾 / 壳 / 海胆 / 浮囊 / 法力 / 终极）。
- 状态签名：`info_panel._status_sig_own` 在主文件 `_status_signature` 之上拼本面板自己的项 ⇒ 新 chip 的数进这里，主文件零改动。
- 「登场」时机：单件属性在 `_eq_apply_all_stats` 写，之后羁绊（食物学院等）还会加最大生命 ⇒ 若在属性阶段给盾，算出来的最大生命不是最终值。换路时单位字典整体重建（`equip_stats_apply.gd` `_b4_on_spawn_all` 头注）。

## 3. 需求 ↔ 代码的出入

1. 「登场时」在本项目有三路（上路 / 下路 / 终极），用户没说是否每路都给 ⇒ **默认每路都给**（与其它登场效果一致：换路重建单位、登场钩每路重跑）。
2. 魔法护盾的时长没写 ⇒ **默认不随时间消失，打空为止**。它不经 `_grant_shield`，不在 `shield_duration` 台账口径内（那条规则管的是「通用护盾」）。
3. 魔法护盾的量是否吃「护盾强度」没写 ⇒ **默认吃**（与所有护盾一致；015 反伤削弱生效时也会被削）。
4. 吸收顺序没写 ⇒ **默认魔法伤害先由魔法护盾扛**，打空后剩余部分再走普通护盾 / 特殊余额 / 生命。
5. 原简述漏了「+4% 最大生命」那一半 ⇒ 新简述两段都写全。

## 4. 方案（已实施）

| 处 | 改动 |
|---|---|
| `equip_stats.gd` / `baseStats1` / 审查进度表 | `hp 90/180/300 · mr 7/16/23`，去掉护甲 |
| `scripts/systems/equip/magic_shield.gd`（新·`class_name MagicShield`） | `SEAWEED_MAXHP_PCT = [0.25, 0.40, 0.60]`；`absorb(u, d, is_magic)`；`seaweed_on_spawn(battle, u, si)`（`maxHp × 比例 × BattleDamage.shield_strength`，记进装备统计「护盾」栏） |
| `equip_tick_system._tick_jelly` | 每件海藻在本路第一次 tick 给一次魔法护盾（单位字典上的 `_kelp_ms_<序号>` 标记；换路重建 ⇒ 再给）+ 身上罩六棱护罩（通用原语，染蓝紫）；周期盾改为 `JELLY_SHIELD[si] + maxHp × JELLY_MAXHP_PCT[si]`（`[40,60,90]` / `[0.03,0.04,0.055]`） |
| `battle_damage.gd` 两条伤害路径 | 普通盾之前插 `MagicShield.absorb`：DoT 路 `bucket == "mag"`，技能路 `_dtv == "magic" and not raw` |
| `hp_bar.gd` | 新段 `_magic`（读 `magic_shield`），蓝紫 `#9a8cff / #5b4ad8`，紧接生命之后画（= 它先扛），并进 barMax |
| `info_panel.gd` | 状态签「魔法护盾 N」（新图标）；`_status_sig_own` 加这个数 |
| `data/status.json` | 新增 `magic-shield`「魔法护盾」增益条目（图鉴状态页自动列出） |
| `assets/sprites/status/magic-shield-icon.png` | 新图标（128×128 像素画，蓝紫能量盾形 + 星点 + 符纹，PixelLab pixflux 生成，29 色），已 `--import` |
| `phase2-equipment.json` 文案 | 全部数值走 `{C:}` 占位符（`MagicShield.SEAWEED_MAXHP_PCT` / `EquipTickSystem.JELLY_*`） |
| `tests/verify_tick_equips_exact.gd` | 012 期望从 `90 + 4%` 改成需求字面量 `90 + 5.5%` |

文案（渲染后）：
- 详细：登场时获得自身最大生命值 25/40/60% 的魔法护盾（只吸收魔法伤害）。⏎ 每 4 秒获得（40/60/90+自身最大生命值 3/4/5.5%）点护盾。
- 简述：登场获得自身最大生命值 25/40/60% 的魔法护盾；每 4 秒获得 40/60/90+自身最大生命值 3/4/5.5% 的护盾。（`copy_style_audit`：「X% 生命值」必须写明是谁的）
