## 2. 调查结论

- 战锤的招牌「跃起砸地眩晕」已被 090 镇海杵占用，047 已有一件「战锤」（奇械）⇒ 选长矛。
- 召唤物现成写法：`battle._spawn._spawn_summon`（`battle_spawn.gd:909`），技能 / 龟能自管照 115 暗影忍者（`eq_dagger_batch.gd` `_spawn_ninja` / `_tick_ninjas`）。
- 龟能回复速率 = 现有装备属性键 `_echargePct` → `echarge_perm`（`equip_stats_apply.gd`）。
- 击飞 `battle._damage._knock_up` / 击退 `_knockback`（`battle_damage.gd:803`）；冲锋每步线段碰撞照 130 舞狮。
- 「我方团队生命值低于 60%」= 我方存活统领 + 小将当前生命总和 / 最大生命总和（不含召唤物、龟蛋、训龟大师）—— 我定的口径。

## 3. 需求 ↔ 代码的出入

- 「全场击飞」包括被千面拽进里世界的人吗：不包括（里世界与主世界互不敌对，走 `_is_hostile`）。
- 「每件不同长矛按星级加成」：同名只算一件取最高星，每星 +3%（我补的数）；按我方全阵容名单数（与羁绊件数同口径）。
