## 调查(实测数据, 不是推理)

### 根因

同一个事实在**五层**各写一遍, 而**没有任何一层是从另一层生成的**:

| 层 | 例子 | 谁维护 |
|---|---|---|
| 代码常量/字面量 | `tgt["maxHp"] * 0.22` | 改数值的人 |
| 代码注释 | `## 引爆 22%` | 靠自觉 |
| JSON 结构化字段 | `cd: 6` `energyCost: 100` | 配置的人 |
| 玩家文案 ×3 | brief / desc / detail | 写文案的人 |
| 文档 | docs/design/*.md | 谁想起来谁改 |

改一处不会让其余四处报错 ⇒ **分歧是默认结果, 一致才是意外**。

实测分母(`tools/number_coverage_audit.py`): 玩家文案 576 段 · 数字 2913 个。
其中占位符 456(15.7%) · 有审计器逐个对代码验的 1005(34.5%) · **没人验 1452(49.8%)**。

## 4. 已知风险与未决点

**风险 1 · 「全部转成引用」是按周算的, 今晚做不完。**

两者价值不同: 转引用是**未来不会再错**, 核对是**现在没有错**。先保证后者。

**风险 2 · 自动把字面量转成常量引用不可行(已实测否掉)。**

### 这一路上建立的手法（后来者照做）

1. **顺序**：跑审计器挑最大段 → dump 文案到文件用 Read 看（控制台 GBK，直接 print 中文会崩）

2. **`{C:X%}` 只 ×100 不带 % 号**，文案要写 `{C:X%}%`。
3. **`{N:expr}` 不认代码常量**（只认 `build_vars` 的变量），写错了会**原样吐回、不留花括号**。
4. **存语义值不存实现值**：减速存 20% 不存移速 ×0.8；锥角存全角不存半角 —— 否则文案又得手写一个数。
5. **能推导就推导**：`BARRAGE_LIFE = (跳数−1)×间隔`、`RAMPAGE_HASTE_MULT = 1+比例`。
6. **平衡门禁必然红**（已 8 次）：它们断言的是"源码里含某个字面串"，提常量后当场失败但**需求没变** ⇒

7. **新增 `class_name` 文件后必须跑一次 `--import`**，否则它不在全局类表里，
   **连引用它的那个类**的 `{C:}` 也一起静默失效。

### ★★新门禁 `text_value_golden`：原文快照守不住的那一半（第 65 批后建）
