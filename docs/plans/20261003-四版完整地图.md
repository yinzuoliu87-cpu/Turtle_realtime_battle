## 4. 方案

### 4.1 架构：四版**共存且可切换**
一个常量选主题（`scripts/gamedata/arena_theme.gd`），地形生成器与世界构建都读它。
★不开四个分支：分支没法并排对比，用户也没法挑；而且合并时必然漂。

### 4.5 已知风险与未决点

1. ⚠⚠ **「质量达到咩咩」我不自判。** 能把第 2 节每一行推向它的数值，但好不好看是用户拍板。
   验收时逐项列差距，不说「达标了」。
2. ⚠ **动态只有静态参考**：气泡/灯光的频率·速度·生命周期·衰减曲线，单帧一个都给不出。
   ⇒ 本轮**不凭空造新动态**，只删明显错的（向上飘的气泡、从水面打下来的光柱）。
   要真正重做动态得先拿视频抽帧（上游风险 7）。
3. ⚠ **全新素材走 PixelLab**，已知五坑（参考图 44×44 / 20 色 / 装进游戏必查朝向）⇒ 需迭代，不是一次出活。
4. 🔲 **碎料像谁**仍未定（咩咩 178 件/Mpx vs Botworld 战斗场 0 件）——
   四版可以各带各的密度当作对比项，但最终要用户定。
5. ⚠ **椭圆面积只有矩形的 78.5%**（上游代价）。四版都在这个空间里摆东西，
   周边环往里挤会吃掉活动空间 ⇒ 环要摆在 ARENA **外**的海面/岸上。
