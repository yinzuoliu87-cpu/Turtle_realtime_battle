# 训龟大师不受任何影响（装饰单位）

日期：2026-10-31　|　状态：**实施中**（代码与门禁已写完、本机已验；U1~U5 待用户拍板；sim 结果会变 ⇒ 裁判机要随 0.22.7 一起升）

## 1. 需求原文

用户 2026-10-31，逐字：

> 「训龟大师不应该受到任何影响，就是个装饰的地位，丢点技能」

**以下是我的理解（主会话转述 + 我补的边界），不是用户原话：**

- 它**不受任何外部效果**：不掉血（普攻 / 技能 / 装备 / 羁绊 / DoT / 真伤 / 反伤 / 溅射 / 链式，任何一条伤害路径）、不中任何控制与状态（眩晕 / 减速 / 冻结 / 沉默 / 标记 / 灼烧……）、不被位移（击退 / 击飞 / 拉拽 / 钩锁）、不吃任何增益减益与光环（攻速 / 护盾 / 治疗 / 属性改动 / 羁绊加成）。
- **不被任何技能 / 装备 / 召唤物选作目标**，也不计入「最近的敌人 / 友军 / 范围内单位 / 队伍人数」；不影响胜负判定。
- 它**自己放技能照旧**（「丢点技能」）；它自己的普攻（扔石头）与魔法石叠层保持现状不删。
- 087 盗令潜水钟「偷大师主动技」只是用大师的技能表、不碰大师本人 —— 默认保留（见 §5 U1）。

## 4. 方案（穷举清单）

1. **统一入口**（主文件 §UNTOUCHABLE）：`_is_untouchable` + `_untouch_block` + 账本两个变量。sim 路径只读一个布尔字段，不引入随机 / 浮点，确定性不受影响。
2. **查询层**：`_is_hostile(a, b)` 在 b 是大师时返回 false（只看 b —— 大师自己照样把别人当敌人）；`_enemies_of` / `_allies_of` 显式排；其余选靶函数里散落的 `is_trainer` 全部改成 `battle._is_untouchable(o)`；`SynergySystem.tier_for` 对大师恒 0。
3. **落地层**：§2.2 B 表里 20 个入口开头 `_untouch_block`（`_mitigate_incoming` 留作第二道）；`_sim_step` 不对大师调 `_tick_unit`。
4. **反伤**：§2.2 C 表 5 处按攻击者是不是大师闸住。
5. **各 system 循环**：§2.2 D 表 19 处 + 忍者标记渲染；trainer_system 里自己技能的 3 处排除（怒火药水 / 冰川 / 猎龟令嘲讽）也改走统一入口。
6. **门禁**：新建 `tests/verify_trainer_untouchable`（运行时哨兵，§6）；`verify_trainer` ③、`verify_trainer_target` ②、`verify_untargetable` E、`verify_eq_gadget_batch` ⓪ 按新口径改；`run-tests.sh` 给新门禁登记帧预算。
