## 2. 调查结论

### 2.1 学到的商业通行做法（出处见文末；★ = 一手资料）

| # | 规律 | 出处 |
|---|---|---|
| R1 | **玩法可读性第一**，主题与好看排在后面。「如果什么都重要，就什么都不重要」 | ★Riot 特效师《LoL 飞弹解剖》第 1、2 篇；Riot《LoL 特效风格指南》(2017，原 PDF 已下线，2024 仍在用) |
| R2 | 每个特效回答三问：**这是什么**（每个技能有自己的造型语言，换皮换色也认得出）／**它做什么**（同功能同语言）／**它多重要**（策划给每个技能 1~10 的「视觉重要度」，特效按分做） | ★飞弹解剖第 2 篇 |
| R3 | **主次分层**：主体（命中点、弹头前端）亮度最高、对比最高、饱和最高、细节最多、不透明；辅助（拖尾、余烬、雾）压暗、半透明、模糊，不许抢主体 | ★飞弹解剖第 1 篇；风格指南十条之 1 |
| R4 | **强度按重要度**：伤害越高越大、越亮、越尖、时机越抓眼；普攻 ≠ 技能 ≠ 大招；大招也要收在地面上的玩法范围内 | ★飞弹解剖第 2 篇；风格指南之 2 |
| R5 | **亮度值域**：主体用中间亮度，**最亮的一下只给命中那一瞬**（爆点芯）；避免纯黑纯白 | 风格指南之 3、4 |
| R6 | **时序三段**：短预兆 → **峰值落在寿命前 1/4** → 平滑快速消散；「觉得长，那就是太长了」；先用灰色方块定时间再上细节；攻击类节奏快于心跳，治疗慢于 60 BPM | 风格指南之 9、10；VFX Apprentice《Timing》；GDC《Zip! Thwack! Ping! 特效的动画原则》 |
| R7 | **功能语言统一**：治疗 = 绿、不带威胁感；定身 = 地面环 + 升起的圆柱；击飞 = 强竖向元素；法术护盾 = 往下流的脉冲线 | ★飞弹解剖第 2 篇 |
| R8 | **敌我一眼可辨**：《荒野乱斗》每个特效都要表明阵营（友蓝敌红）；LoL 某些范围圈只给相关的人看，减少噪音 | ★Supercell 特效师 Woo（realtimevfx）；飞弹解剖第 2 篇 |
| R9 | **打击感三件套**：顿帧、**声画一致**、镜头控制影响最大，三者缺一会毁掉打击感（Steam 畅销动作游戏统计）；实践经验：顿帧几帧、攻守双方一起停，致命一击停得更久；闪白 1~2 帧（太长会被读成状态效果）；击退随伤害大小变 | ★arXiv 2208.06155（GEM 2022）；实践博客（数字是经验值） |
| R10 | **像素特效**：3~6 帧，先小后在命中帧猛地张开；刀光是月牙形、只存在 1~2 帧；特效可比角色动作用更高帧率；《荒野乱斗》= 手画平面图层逐帧 + 爆炸分「空中 / 地面」两部分、各随机挑几种云团 | ★Supercell Woo；像素特效教程（经验值） |
| R11 | **不堆叠**：半透明层叠多了会糊成一团、团战里丢轮廓；粒子封顶，用爆发不用常驻发射器；同时死很多个时跳过顿帧 | 风格指南之 7、10；实践博客 |

## 3. 需求 ↔ 代码的出入

- 「视觉比不了云顶」里有一部分是**美术层级**：云顶是 3D 模型 + 粒子 + 灯光，我们是 2.5D 像素小人，调参补不上。我们能控制的是**可读性、主次、强度分级、时序、敌我**这几层（R1~R11），这份方案书只管这几层。
- 我之前说音效「对黑箱逐项达标」「大事件接近云顶」，量的是响度 / 长短 / 疏密，不是好坏；而且「接近云顶」那组数是在 `STRESS=1`（`Engine.time_scale = 5`，`RealtimeBattle3DScene.gd:3207`）的 5 倍速录像上量的，**作废**。特效同理：我能看画面，但单帧不等于动态，好坏要靠用户说的那种审核片来定。

## 5. 已知风险与未决点

- **U1（未决）先做哪个**：我的建议是 **P1 审核片先拍现状**（只录不改，后面每一步都拿它对比），然后 P2 + P3 一起做（分级表定下来，打击感才有依据）。用户 11-04 说审核片「先别做」，所以等用户点头。
- **U2（未决）**P4 的阵营色会不会和技能主题色打架（例：红方的寒冰龟，冰蓝特效 + 红描边）。建议只给**地面范围环描边**上阵营色，特效本体不动。
- **U3（未决）**P3 改顿帧会改对局结果：0.22.8 已经升过 RULES_VER（=3），同一周内改不用再升，但要刷规则指纹和确定性金标，并跑完整门禁。要不要赶在 11-08 的 0.22.8 里，还是放下一版？我的建议：放下一版，0.22.8 只做 P1、P2。
- **U4（未决）**闪白缩短会不会让「被打中」不明显：经验值 1~2 帧来自像素动作游戏博客，不是我们的画面尺寸，必须用审核片让用户看。
- **风险·资料**：Riot 风格指南原 PDF 已下线，十条是第三方转述；帧数类数字多是实践经验值，不是标准。一手资料只有 Riot 特效师长帖、Supercell 特效师帖子、arXiv 论文摘要。
- **风险·我的判断力**：我听不见声音；画面能看但单帧不是动态。所以验收必须靠审核片 + 用户。
- **已堵**：这份方案书阶段不改任何代码（用户「认了才写代码」）。

## 6. 验收标准

| 项 | 怎么验 | 怎么证明检查会 FAIL |
|---|---|---|
| P1 审核片 | 112 段齐、全部正常速度（录制命令不许带 `STRESS`）、每段时间表与片子对得上 | 故意带 `STRESS=1` 录一段 → 检查器按「放技能帧号 / 30 ≈ 片内秒数」对不上而报红 |
