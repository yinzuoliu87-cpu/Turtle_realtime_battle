# 图鉴「龟」栏改「角色」：收全部单位，羁绊 / 装备文案里的召唤物改写法

日期：2026-11-27　|　状态：**草稿**

> 用户 11-27：「对于矛这个羁绊，核心是召唤物并强化技能，所以图鉴里最好龟换成角色，及游戏里的可能出现的单位，这里去描述属性，所以对于羁绊里的召唤去描述可以换种方式。」
> 用户 11-27（确认理解后）：「百夫长没有等级，收所有单位，先理清思路。」

## 2. 调查结论

**现状**：图鉴第一栏「龟」= 28 只龟 + 深海小将 4 种（近战 / 远程 / 精英 / 援军，`scripts/gamedata/minion_codex.gd`）。召唤物一个都不在图鉴里；它们的属性只出现在羁绊 / 装备文案里，例如长矛：「(2) 每件 +5% 龟能回复速率，百夫长 1600 生命值、48 攻击力、45 护甲和魔抗」—— 携带者加成和召唤物属性挤在同一句。

**全仓单位清单**（探针：扫全部 `_spawn_summon(` 调用点 25 处 + 战场单位）：

| 类 | 单位 | 来源 | 属性怎么定 |
|---|---|---|---|
| 龟 | 28 只 | 选龟 | 龟自己的属性表（已有页面） |
| 战场单位 | 近战小将 / 远程小将 / 精英小将 / 援军小将 | 每路补位 / 终极战场 | 按等级（已有页面） |
| 战场单位 | 龟蛋 | 每路一颗 | 按等级 |
| 战场单位 | 训龟大师 | 敌我各一位 | 装饰，免疫一切，不参与战斗 |

| 装备召唤 | 蛋糕礼盒 | 蛋糕礼盒 | 生命 = 携带者最大生命值 20% / 40% / 100%（按星级），攻击 = 携带者攻击力 |
| 装备召唤 | 暗影忍者（含影分身） | 匕首 | 按星级固定值 × 系数（待核系数含义） |

| 羁绊召唤 | 百夫长 | 长矛 | 按羁绊档（2 / 5 / 8 / 10 件）底子 × (1 + 3% × 不同长矛星级合计)；护甲魔抗只按档 |

**四种属性来源**决定了每页的属性怎么写：① 按装备星级固定值 ② 按主人（携带者）属性比例 ③ 按羁绊档（百夫长，没有等级）④ 按阵亡 / 被复制单位的属性比例（亡魂、复制体）。

## 3. 需求 ↔ 代码的出入

- 召唤物属性现在只写在文案里，而且是手写进句子的；做角色页必须读代码常量（同 `minion_codex.gd` 的教训：手抄必漂）。
- 每个召唤调用点已强制带中文名（门禁 `verify_summon_label`），但没有「召唤物 → 图鉴条目」的登记表，新加召唤物不会自动进图鉴。

## 4. 方案（思路）

**一、图鉴第一栏改名「角色」，分组列出**：龟（28）→ 战场单位 → 召唤物（按来源：龟技能 / 装备 / 羁绊）。龟仍排在最前。

**二、每个单位一页，统一结构**：
1. 形象（待机动图）+ 名字 + 来源（哪只龟 / 哪件装备 / 哪个羁绊，点了跳过去）。
2. 定位：近战 / 远程、射程、攻击间隔、移速、存在多久（持续时间 / 死后会不会再召）。
3. 属性表，按来源四种写法：
   - 按星级：★1 / ★2 / ★3 三列；
   - 按主人比例：「生命值 = 主人最大生命值的 X%」；
   - 按羁绊档（百夫长）：(2) / (5) / (8) / (10) 四列，下面一行写「每件不同长矛每颗星使生命值与攻击力 +3%」；
   - 按阵亡 / 被复制单位：「继承阵亡单位最大生命值与攻击力的 X%」，比例按羁绊档列。
4. 技能与行为：普攻、技能、被动，和龟页同一种写法。

**三、羁绊 / 装备文案的新写法**：句子里只写「召唤谁、什么时候、它会做什么、每档多了什么本事」，不写召唤物的生命 / 攻击 / 护甲数字；名字做成可点的链接，点了跳到它的角色页。例：

- 长矛 (2)：每件 +5% 龟能回复速率，召唤百夫长
- 长矛 (5)：每件 +10% 龟能回复速率，百夫长攻击贯穿直线，放下盾时横扫周围敌人
- （数字都在百夫长那一页）

**四、单一数据源**：新建 `scripts/gamedata/summon_codex.gd` 登记表（单位 id、名字、形象、来源、属性来源类型、引用哪个代码常量），角色页只读它；门禁扫全部 `_spawn_summon(` 调用点，每一种都必须在登记表里，漏一个就红。

## 5. 已知风险与未决点

- **U1** 面具复制体：不单列（它就是被偷的那只龟），只在面具羁绊里写「复制体为原版 X% 属性」。我的建议：不单列。
- **U2** 训龟大师：收不收？建议收进「战场单位」，写明「装饰，不参与战斗」。
- **U3** 装备文案（例如炮台「650 / 1400 / 2500 生命值」）也按同一规则删掉召唤物数字、改成链接？建议一起改，否则同一个单位两处数字。
- **U4** 羁绊 / 装备文案里的名字做成可点链接：图鉴里能点，战斗中信息面板 / 商店说明卡里也要能点吗？建议图鉴、商店说明卡都能点；战斗中只显示，不跳转。
- 工作量：约 22 种召唤物各要一页属性和行为说明，每种都要从代码里核数字；动图要能在图鉴里播（有些召唤物现在只有战斗用的贴图）。
- 文案改动会让文案快照 / 数值金标整批变，按 `regen_goldens.py` 一次重算。

## 6. 验收标准

- 图鉴第一栏叫「角色」，能看到全部 28 龟 + 战场单位 + 约 22 种召唤物，分组清楚。
- 每个召唤物一页：来源、定位、属性表（按三种来源之一正确展示）、技能行为；数字全部读代码常量。
- 长矛、灵物、枪、面具羁绊与相关装备文案里不再出现召唤物的生命 / 攻击 / 护甲数字，名字点了能跳到角色页。
- 门禁：每个 `_spawn_summon(` 种类都在登记表里；角色页数字 = 代码常量；文案里不出现召唤物属性数字。
