## 3. 实现位置

| 做什么 | 在哪 |
|---|---|
| 阈值常量 `MS_TIER_1/2/3` + tier 纯函数 `_ms_tier(n)` | `scripts/systems/trainer/trainer_system.gd` |
| 常驻特效建/撤/每帧跟随 `_ms_tick_aura(delta)` | 同上，由 `RealtimeBattle3DScene.gd:2148` 那一串 `_tick_*` 里新增一行调用 |
| 跨阈值迸裂 `_ms_tier_burst(u, tier)` | 同上，在 `_trainer_magicstone_onhit` 加层后判定 |
| 角标环色随 tier | `spell_disc.gd` 的 `set_stacks` 旁加 `set_tier`；`battle_render` 每帧喂 |

**特效节点挂 `battle._world`**（不挂大师 sprite 的子节点）—— 大师 sprite 是 billboard，
`pixel_size`/`scale` 会随动作帧变（`_set_anim_sheet` / `_elite_fix_norm`），挂子节点会被父级缩放带歪。
挂 `_world` + 每帧写 `position` 是本项目跟随类特效的既有做法（`_tame_rune` / `_hunt_sigil` 都是）。

## 4. 已知风险与未决点

**① `axis = AXIS_Y` 和 `rotation.x = -90` 只能给一个** —— 这是**今天刚踩的**（0.17.16）：
两圈"贴地印记"同时写了两个，法线被掰成 `(0,0,-1)`，实际是**竖环**，实测 `|法线·上| = 0.000`。
脚下符文环是同一类东西，**必须只给 `axis = AXIS_Y`**，并把平铺断言写进门禁。

**② 跨路保留让攻速上界抬高。** 叠层是对数收敛的（`Σ 1.5/(1+0.05n)`），一整局（上路+下路+决胜）
连续攻击约 3–4 分钟 → 粗算能到 **150–200 层 = 攻速 ×8.5 ~ ×11**。
配合"普攻附带 2.5% 目标最大生命魔法伤害"，折算约 **每秒 18% 目标最大生命**。
★但这个上界**在改之前的单路里就已经存在**（一路够长就能攒到同样高），跨路保留只是不再回落。
**未决**：要不要给层数设上限（比如 60 层封顶 = ×4）。本方案**不改数值**，只做视觉；等测试反馈。

**③ 特效节点数上限。** tier 3 是 6 颗晶石 + 1 环 = 7 个 Sprite3D 常驻。双方各一个大师 → 14 个。
可接受，但**敌方大师也会有** —— 需要确认对面 AI 大师装的是不是魔法石（`_tr_passive` 各自独立）。
若双方都装，画面上会有两组。**判断：可接受**（本来就该看得见对面在攒层）。

**④ 无头 CI 下不能靠 tween 验数值。** 迸裂/旋转都是纯演出，门禁只数节点与 tier，
不等任何 tween 跑完（CLAUDE.md §3.5）。

**⑤ 未决：层数掉回阈值以下会发生什么？** 目前层数只增不减（没有衰减机制），所以降级路径
理论上跑不到。仍然实现撤场逻辑并测它 —— 因为"换掉被动"和"大师死亡"会走同一条撤场路。

## 5.5 交付后补记（实际踩到的）

**素材：PixelLab 把"空心环"画成了实心暗盘。** 首次生成的 `ms-rune-ring.png` 中心 `alpha = 255`、
亮度 41（暗紫实心），踩在脚下会糊一块暗板 —— 缩略图里那个"暗色中心"看着像透明，**不是**。
换 prompt 重生成后仍是实心，最后按**径向剖面**（`r 0–35` 暗实心 / `r 36–52` 才是真正的符文环带）
自己把内圈镂空，并保留伸进内圈的亮符文（`lum > 78`）。中心区平均 alpha **255 → 0**。
★教训：**生成完必须验真实 alpha**，别看缩略图判断透明度。

**常量名写错：`JUICE_SHAKE_SMALL` 不存在** —— 本项目只有 `LIGHT(0.0) / HEAVY(0.10) / BIG(0.22) / MAX(0.30)`。

**新 PNG 要先跑 `--import`**，否则 `ResourceLoader.exists()` 为 false。
代码里那句 `push_warning("缺素材 … 不复用别的贴图兜底")` 当场就把这事喊出来了 ——
这正是"不静默兜底"的价值：静默换张图的话我会以为已经做完了。

**门禁自己写错了一条**：③ 组我先让它"跨 tier1 后连打 20 下，断言迸裂计数仍是 1"，
但 20 下会让层数到 30、**跨过 tier2 的 25**，放第 2 次是**正确行为**。
改成打到 tier2 前一层为止，再单独加一条"再打 1 下跨进 tier2 → 必须放第 2 次"
（否则第一条可能是"永远不放"的假绿灯）。

**顺带撞到一条旧门禁**：`verify_trainer_skills` 有一条断言"每路清零"，跨路保留一改它就红。
已反过来断言"清零不许回来"。★这是**全套门禁的价值** —— 只跑 `verify_ms_tier_vfx` 是绿的。
