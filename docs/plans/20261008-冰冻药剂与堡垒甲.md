## 2. 调查结论（2026-10-08 读代码）

- 014：每层硬化量写在 `scripts/systems/equip/equip_stats_apply.gd` `_eq_apply_flags` 的 `harden_inc = [2.0, 4.0, 6.0][si]`（与 013 的 `[1, 1.5, 2]` 同一行三元式），叠层在 `equip_system._eq_on_target` 的 013/014 共用分支（两条伤害路径都调）。文案 `+2/4/6` 是手写数字。没有测试钉住 4.0。
- 028：命中结算 `scripts/systems/skills/ice_system.gd` `_ice_bottle_hit`，一行 `_resolve_dmg(u, float([40, 60, 100][si]), t, true)`（`magic=true` ⇒ 吃魔抗）；`tooltip_number_audit.py` 白名单里登记着 `40/60/100`；`tests/verify_ice_vial.gd` ⑤ 按 40:60:100 比例断言。
- 旧名「冰霜冻露瓶」玩家可见处只有 `data/phase2-equipment.json` 的 `name`（商店 / 背包 / 图鉴都读它）；其余是代码注释、门禁打印、审计器注释、`docs/specs` 成员表、生成表 `docs/design/装备逐件审查进度.md`。历史记录（CHANGELOG、`docs/studies`、路线图旧条目、autoplay 日志）不改。

## 3. 需求 ↔ 代码的出入

1. 028「ATK」= 携带者攻击力；「目标 3/5/9% 最大生命值」= 被砸中那个敌人的最大生命值。三段相加后整体按魔法伤害结算（吃魔抗、可暴击，与原来同一入口）。
2. 原文案数值全是手写 ⇒ 改为 `{C:}` 引用代码常量，数值只存一份。
