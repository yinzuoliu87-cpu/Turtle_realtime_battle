**无上限叠加**下，打 N 次普攻后的 `aspd_perm`（基础 1.0）：

⇒ 实施时**必须跑真战斗量实际曲线**，不能拿这张表当结论（§6 验收④）。

（memory `[[fb-verify-magnitude-not-just-correctness]]`：彩虹探针五条全绿仍让胜率 14%→97%；

### §4.1 镇海杵（削弱）

```gdscript

+ const PESTLE_ATK_SCALE := 1.0

// eq_arcane_batch.gd:559
```

**保留**「8 秒是用户要的」那半句）。

### §4.2 鲨肝油（加强）

```gdscript
// eq_potion_batch.gd:98
- u["aspd_perm"] = float(u.get("aspd_perm", 1.0)) + [0.01, 0.02, 0.04][si]
+ u["aspd_perm"] = float(u.get("aspd_perm", 1.0)) + [0.03, 0.05, 0.07][si]
```

**不动**：`LIVER_ENERGY = 5.0` · 无上限 · 换路重置 · 层数徽章读数。

改了代码不改文案就会漂（memory `[[fb-system-coefficient-1-hides-missing-placeholder]]` 同族：

### §4.4 深海气压罐（加强）

★注意这是**上限**不是产出：只有在 12 秒内挨够伤害把条打满的场合才吃得到这 10pp。
⇒ 验收要量「实际触顶率」，不能只断言常量变了（§6 验收⑨）。

### §4.5 病毒箭头（削弱）

```gdscript
// hookbomb_system.gd:81-82

+ const BLAST_FLAT := [120.0, 250.0, 400.0]
```

| 目标 maxHp | ★1 | ★2 | ★3 |
|---|---|---|---|
| 2000 | 600 → 320（**−46.7%**） | 900 → 450（−50.0%） | 1050 → 600（−42.9%） |
| 5000 | 1050 → 620（−41.0%） | 1350 → 750（−44.4%） | 1500 → 900（−40.0%） |
| 12000 | 2100 → 1320（−37.1%） | 2400 → 1450（−39.6%） | 2550 → 1600（−37.3%） |

★★**这两个数是面板值，落地还要吃护甲。** `hookbomb_system.gd:74-78` 记着：
2026-08-29 把这两段从「不吃护甲的定额」改成**真物理**（`_phys_after_armor`），
实测平均护甲倍率 **0.6685**，于是把数 ÷0.6685 ≈ **×1.5 补偿**，让实际到手不变。
⇒ 新值同样会 ×0.6685 左右落地（★2 打 5000 血目标：面板 750 → 实际约 **501**）。
**验收要量目标真掉的血，不是量常量**（§6 验收⑩）。

★那两条 `# ★2026-08-29 ×1.5 补偿(见 BOMB_DPS_PCT 头注)` 的注释**必须改掉** ——
新值不是从任何旧值 ×1.5 来的，留着就是第二条与事实相反的注释（第一条见 §2.2）。
**但 `BOMB_DPS_PCT` 头注本身要保留**：它解释的是「为什么这些数除以 0.6685」，
那个理由**仍然成立**（这两段仍是真物理、仍吃护甲）。
