## 四、护栏（2026-07-19 两条血教训 + 本刀特有）

1. **切函数块遇任何列首注释就停**（旧坑：普通 `#` 说明注释会被吃进上一个函数）。每块恰 1 个 `func`、块间不重叠、**拆完做函数总数对账**（原 N = 主文件 + 新文件）。
2. **新 `class_name` 脚本先跑一次 `--headless --import`** 注册全局类，否则运行期 `Identifier "TimestopSystem" not declared`。
3. 本刀特有：`_ts_active` 是全场"是否时停"总开关，**12 处 query 一个都不能漏**（漏一处 → 该处永远以为没时停 → DoT/渲染在时停里行为错）。用 `grep -n "_ts_active\|_ts_remaining"` 对账清零后才算完。
