## 2. 调查结论（带行号证据）

### 凤凰

- **涅槃是一帧完成的**（`RealtimeBattle3DScene._kill` 内）：血条瞬间跳到 25%、灼烧与治疗削减同帧施加。
- **喷火是纯范围结算**：`phoenix_system._phoenix_flame_channel` 每 **0.5 秒**调一次
  `_phoenix_flame_cone`，对扇形内**全部**敌人打 `0.2×ATK×(1+攻速)` 魔法 + `0.07×ATK` 灼烧。
  ⇒ **一次都不碰 on-hit 钩子**，竹叶/竹弓、金弹、腐蚀这类"命中时触发"的装备在凤凰身上完全不生效。
  ★注意攻速是**乘在伤害里**的，不是乘在频率上——节拍恒为 0.5 秒。
- **三条"复活后残留"疑点**（我列的，逐条查证）：
  | # | 疑点 | 结论 |
  |---|---|---|
  | 1 | 半空阵亡复活后卡在天上？ | **是真的** —— 复活没清 `airborne/vy/vx/vz` |
  | 2 | 带着眩晕复活？ | **是真的** —— 没清 `stun_until` |
  | 3 | 强化涅槃 +20% 攻击会被属性重算冲掉？ | **排除** —— `_recalc_stats` 从 `base_atk` 推导，而全仓只有**无头龟**一处整体覆写 `base_atk`，其余都是 `+=` |

### 熔岩

- 怒气：造成伤害 10% + 承受伤害 10%，满 100 变身 15 秒 ⇒ **门槛 = 累计 1000 点伤害收支**。
- 变身加成**全部按攻击力折算**（40 攻时）：最大生命 +100（819→919，**+12%**）、
  攻击 +8（+20%）、护甲 +8（**+57%**）、魔抗 +8（+50%）。
- 砸地：群体击飞约 0.86 秒 + `1.2×ATK` 魔法 + `0.67×ATK` 层灼烧 + **每命中一人回复其已损生命 8%**。

## 3. 需求 ↔ 代码的出入

1. 用户最初说「每 0.25 秒」，实际**本来就是 0.5 秒一跳**——用户看到事实后改为「那以0.5来吧」。
2. 我第一版把 on-hit 按**技能命中**（`basic=false`）接，用户纠正：「我的意思就是触发**普攻**的 onhit」。
   凤凰的喷火**就是它的普攻**（它没有另外的普攻动作），所以要连「每第 N 次普攻」那类计数器一起推进。
3. 熔岩「查强度」的结论不是"太强/太弱"，而是**收益结构错位**：文案写「最大生命 +250%×攻击力」，
   实际只 +12%；真正的强度在砸地的控场与回复。

---

## 4. 方案

- **涅槃 2.5 秒三拍**：`0~0.6` 灰烬定格 → `0.6~1.9` 聚火升腾 → `1.9~2.5` 破壳展翼；
  **结算落在展翼那一刻**；演出期 `untargetable`；计时走 `_pending_shots`（sim 时钟）不用 tween。
- **喷火 on-hit**：每 0.5 秒一跳时，给**扇形内最近的一个**走 `basic=true` 的 on-hit；
  节拍与伤害都不变；**只给一个**（五个人各触发一次 = 装备特效翻五倍）。
- **熔岩砸地**：伤害 `1.2 → 1.0×ATK`，灼烧 `0.67 → 0.3×ATK` 层，用**本技专用系数**。
