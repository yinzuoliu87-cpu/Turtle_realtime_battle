1. 「哎呦，未晋级的玩家是看不到别人的分组吗？还是什么情况呢？」

## 3. 需求 ↔ 代码的出入

- 「未晋级的玩家是看不到别人的分组吗」：18:00 之后看得到（`finals_week_view` 公开全部组），18:00 **之前**本来就还没有分组 —— 真正缺的是「分组前这一页该给什么」，不是「隐藏了分组」。
- 名单：表上的 RLS 注释写着「『谁报名了』本身就是情报」。这次让观众分组前看到名单，是用户要的观众页内容；18:00 之后名单本来就全公开 ⇒ 只是提前 ≤ 30 分钟，且只下发名字 / ID / 头像 / 闯关战绩，不下发阵容。
- 主会话指出的「主按钮 3 分 0 秒」不动：产品里会走（`finals_left_of` 用时间差）；实拍台里冻住是因为 `_shot_finals_day.gd` 没推对阵图自己的钟（已一并修实拍台）。真正的产品问题是同一个数在倒计时行和主按钮各写一遍、且轮次叫错。

## 4. 方案（已实施，穷举）

**写法规矩**（`scripts/ui/finals_copy.gd` 头注；依据对照表 §8）：一行一件事，不用「·」把状态与说明 / 两件事串成一行（两件事就两行或「标签：值」）；状态签 2~4 字（未开始 / 进行中 / 已结束 / 等待开播 / 备战中…）；时长全决赛日一种写法「54 分 09 秒」「1 小时 05 分 09 秒」「9 秒」；时刻「18:00」；数字与汉字之间留空格（全游戏 144:8 的现行写法，不照对照表第 4 条去掉空格，免得决赛日与别的屏两套）；资格写成条件；旁观视角第三人称；轮次名一套「1/16 决赛 → 1/8 决赛 → 1/4 决赛 → 半决赛 → 决赛」。

## 6. 验收标准

1. **① 赛前页**（`verify_finals_copy` ①）：17:56 没晋级 / 晋级两种人都有 Preseat；倒计时 == `dur(分组 − 此刻)`；前半句「距小组赛开始」；名单「24 人」且 24 行、名字逐个对上；今晚赛程含 18:00 小组赛 / 19:00 冠军杯赛（读常量、设备时区）；「参赛资格：周六闯关赛 4 胜」；晋级的人有「已晋级」、没晋级的没有；屏上不再有「未晋级 …」；名单接口拿不到时页仍在、名单卡写「18:00 公布」；18:20 / 周一 / 周六不出。
