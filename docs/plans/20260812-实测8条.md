## 3. 需求 ↔ 代码的出入

- **第 5 条是口径分歧，不是 bug 的简单修复。** 用户的表述「羁绊效果是 3 个战场共享的」
  ⇒ 战斗侧应改成**按全阵容算**（与商店/背包一致），而不是按每路场上单位算。
  这会**推翻 v0.19.130 的方向**（那次修的是"下路沿用上路的值"，方向上让两路各算各的）。
  正确终点：三路都用同一份（全阵容口径），于是"沿用"与"重算"都不再是问题。
- **第 1 条给的是 5 个数、而档位只有 4 档 + 未激活**，正好一一对应（未激活/2/5/8/10）。
  ⇒ 满值表要从"按档位索引 1~4"改成**按档位索引 0~4**（档 0 单列 200，不再与档 1 同值）。

## 4. 方案（逐条）

1. **法器满值** → `MANA_FULL_BY_TIER := [200, 180, 150, 120, 80]`（下标 = 档位 0~4）。
   `mana_full()` 改成直接按档位取，不再 `clampi(tier-1,…)`。043 的"上限 +50/25/0%"倍率照旧叠在上面。
2. **直升机** → 查 `on_spawn` 链路，补上真正的召唤。
3. **小手枪治疗封顶 1** → 与伤害封顶同一个位置思路：治疗的**共用收口**上加一道带值闸
   （不要在每个治疗源各写一遍）。
4. **开打前不许动手** → 查战斗开始闸，召唤物一并纳入。
5. **羁绊三战场共享** → 战斗侧 `_calc_tiers` 改成读**全阵容装备**（与 `team_p2_equips_for_synergy` 同口径）。
6. **训龟大师只吃 AoE** → 穷举所有"选一个目标"的入口，统一走标准排除；AoE/范围结算不排除。
7. **终极护盾条** → 接进血条的特殊护盾段（与圣盾段同一套）。
8. **定海针** → 落点 = 敌人最密处（250 码内），预警圈画在**落点**且半径 = 真实伤害半径。
