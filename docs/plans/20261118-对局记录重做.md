# 对局记录（战绩）页重做：全赛事、双方装备、时间、新背景

日期：2026-11-18　|　状态：**已完成**

## 1. 需求原文

用户 11-18：「还有一个地方要着重改造的是，就是这个头像这边的对局记录这一块，对局记录现在就只有，嗯，是不是只有积分赛打的呀？常规赛打的，周周日是不是没有啊？然后偷袭的是不是也没有啊？然后这整个展示你也没有展示，啊、呃，时间双方的装备也没有。你可以构思一下怎么搞，然后这个背景也不是很好，嗯，你看看这个整个页面怎么做吧，其实，你就可以初步做一版。」

## 2. 调查结论

- 现在的战绩页 `scripts/scenes/RecordScene.gd`（413 行）只读本机 `GameState.match_history`（`autoload/GameState.gd:1697` `record_match`，最多 50 条）。写入点只有三处：`RealtimeBattle3DScene.gd:7520`（本机打完一局）、`referee_watch.gd:262 / 799`（积分赛 / 周六裁判局结算）。⇒ 换设备就没了；**周日决赛（观战形态）不写；偷袭（服务器自己算，App 不经手）不写**；每行只存三统领 id + 对手名，**没有装备、没有时间显示**。
- 服务器上全都有：`referee_jobs`（正式服 11-18 实查：积分赛 8700 / 闯关赛 437 / 决赛 53 / 偷袭 1 局 status = done）。每行有 `a_account / b_account`、`a_snapshot / b_snapshot`（`leaders`、`equipped {统领: [{id, star}]}`、`minions`、`lane_assign`、`profile {name, tag, avatar}`）、`result`（`winner`、`lane_results {top, bottom}`、`score_code`、`steps`(60 步 = 1 秒)、`match_id`）、`done_at`。表开着 RLS 且没有策略 ⇒ 客户端读不到，要一个 security definer 的 RPC。
- 积分赛的 b 方是别人的快照（对手不在线），不算对手「打过」；闯关赛（在线瑞士轮）、决赛、偷袭两边都是真对局。
- 回放：`ReplayFetcher.open(tree, match_id)` 按 match_id 取 `matches.replay`（积分赛 / 偷袭有；按周清，`server_keeps`）；决赛走 `open_finals(周, 组, 轮, 场)`。
- 装备图标：`data/phase2-equipment.json` 每件的 `img`（`equip/xxx.png`，在 `assets/sprites/` 下）。
- 背景：现在是主菜单平铺图 + 深绿底，用户说不好。现有满屏底图都已被别的页面用着（选龟页木桌、背包船舱、主菜单观众墙），按「素材不复用」不能借。

## 3. 需求 ↔ 代码的出入

- 「是不是只有积分赛」：本机能记到积分赛和周六闯关赛（都经 `referee_watch` 结算），但只限这台设备打的；周日决赛、偷袭确实没有。
- 「时间、双方装备也没有」：属实，本机记录里根本没存。⇒ 数据源换成服务器，不再补本机记录。

## 4. 方案

### 4.1 服务端（迁移 `20261118b_battle_log`）
`my_battle_log(p_limit int = 20, p_before bigint = null) → jsonb`（authenticated，security definer，只读）：
- 取 `referee_jobs` status = done，且「a 方是我」或「b 方是我且种类是 闯关 / 决赛 / 偷袭」，按 job_id 倒序分页（`p_before` = 上一页最后一个 job_id）。
- 每行只回展示要用的字段（不回整份快照）：`id, kind, at(done_at 秒), side, won, lanes {top, bottom: me|foe|null}, secs, match_id, replay(matches 里有录像), finals_key(决赛：周/组/轮/场), raid_role(偷袭：attack / defend)`，双方各 `{name, tag, avatar, leaders, equipped(只留三统领), lane_assign}`。

### 4.2 客户端
- `scripts/net/battle_log_net.gd`：调 RPC、解析（纯函数 `parse`，门禁直接喂）。
- `RecordScene.gd` 重写：
  - 顶栏「战绩」不变；下面一排**分类页签**：全部 / 积分赛 / 闯关赛 / 决赛 / 偷袭（各带场数）；页签下一行本页总览（场次 / 胜 / 负 / 胜率）。
  - 每场一张**对局卡**（参考云顶之弈对局记录：每只单位下面一排装备；皇室战争 Battle Log：双方阵容左右对照 + 右侧观看）：左边一条胜负色带 + 赛事标签（积分赛 / 闯关赛 / 冠军杯·小组赛 / 偷袭·进攻 / 防守）+ 时间（本地时区：今天 19:32 / 周日 20:04 / 11-15）+ 时长；中间我方三统领（头像 + 下面 3 件装备，带星）VS 对方三统领 + 双方名字；每只统领左上角标它在上路 / 下路；右边上下两路的胜负小签 + 「观看」（有录像才出）。
  - 往下滑到底「加载更多」（每次 20 场）。没登录 / 断网 ⇒ 一张提示卡（游戏必须联网，不放本机替代）。
- 背景：第一版先用深色底占位；11-19 PixelLab 额度重置后出一张专属底图（战报 / 档案室意象），不借别的页面的图。
