## 3. 需求 ↔ 代码的出入

| 用户的说法 | 实际 |
|---|---|
| 「周六周日没有选技能的页面」| **周六有**：每局开打前都经过「本大轮统领」页，点统领卡就能换技能。**周日确实没有** —— 决赛不经过选龟页 |
| 「确定阵容」| 现在没有「确定」这一步：0.23.4 是背包一改就自动推。玩家不知道哪一刻的阵容算数，也不知道交没交上去（只在推的那一下弹 3 秒回执）|

## 4. 方案

**核心：复用周六那一页。** 「点确定阵容时跳出来选技能」就是把「本大轮统领」页直接打开 —— 它本来就是「看三只统领 + 每只选一个技能 + 右下一个金色主按钮」，只把「出战」换成「提交阵容」。不另做一个弹窗（两套选技能界面迟早长得不一样）。

### 4.1 玩家看到的

1. **背包页右下角**（羁绊下面那块空地）放金色主按钮，和选龟页「出战」同一种按钮：
   - 没交过 / 背包和上次交的不一样 ⇒「确定阵容」+ 小红点
   - 背包和上次交的一样 ⇒「已确定 ✓」（还能点，进去改技能再交）
   - 只在**周日、我已晋级决赛、我这一组还没打完**时出现；观众、没晋级、组已结束都不显示
2. 点按钮 ⇒ 打开「本大轮统领」页的**决赛模式**：
   - 标题「决赛阵容」；顶部说明一句「确认技能后提交，下一轮按这套阵容出战」
   - 三张统领卡、点卡换技能，和周六完全一样
   - 右下金色按钮「提交阵容」；左上返回 = 不提交，回背包
3. 点「提交阵容」⇒ 立刻交给服务端，回到背包，顶部一条回执：
   - 收下了 ⇒「已提交：第 N 轮起按这套阵容出战」
   - 拒收 ⇒ 说原因：阵容开不了打（缺统领等）/ 本组比赛已结束 / 网络不通（自动重试）
4. **提醒**：每一轮锁定前，背包里有没交的改动 ⇒ 决赛日全局条上提醒一次「阵容有改动还没提交」，点它直接进第 2 步那一页。

### 4.2 规则（要改服务端）

- **只认点过「提交阵容」的那一份**：去掉 0.23.4 的「背包一改就自动推」。没交过 ⇒ 沿用周六晋级那一份（和现在一样）。
- **什么时候交都算，每轮锁定前最后一次为准**：服务端去掉「只在开打后 180 秒内收」。备战窗外交的先存「待生效」，到下一轮锁定时生效；锁定之后才交的，进下一轮。这就是 20261115e §4 那份草案（`finals_entrants` 加 `pending_snapshot` / `pending_at`，`referee_enqueue_finals` 建任务前提上来，小组冠军进冠军杯时同样提）。
- **入座前也能交**（见未决点 U2）：周六晋级之后就能在背包里确定，周日 18:00 入座时直接用确定过的那份。这一条才真正解决 11-15 那次「背包调了、比赛还是周六那套」。
