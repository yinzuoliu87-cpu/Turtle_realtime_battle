### 3.1 跨路保留（3·8·9 共性，**本批最大的坑**）

现状：换路时 `_dl_build_lane_field` **重建单位字典**，`eq_state` 归空 → 层数必然清零。
所以「不清零」不能靠改 tick 逻辑，必须把层数**搬到活过换路的载体上**。

仓库里已有同类先例可抄：魔法石攻速叠层跨路保留（`dual_lane_flow.gd:367`，用户 2026-07-30 拍板），
它把状态放在 `trainer_system` 而不是单位字典上。本批照此办理：

- 载体：`battle` 级 `Dictionary`，key = `龟id + "|" + 装备id`，**新对局**（进入战斗场景时）建空表
- 换路重建单位后，从表里**读回**层数写进新单位
- ★教训对齐 memory `[[fb-write-without-reader-and-fake-gates]]`：
  「生产侧写了、消费侧没读」这一天踩过三次。门禁必须走 `_dl_build_lane_field` 真换一次路，
  并断言 `is_same(旧单位, 新单位) == false`（证明确实换了对象）后再断层数相等 ——
  否则测的是同一个对象，永远绿。

## 4. 已知风险与未决点

**已定（2026-08-01 查代码后落实，不再是未决）：**

- **A｜第 1 条「原样伤害」= 现有爆炸原封不动。**
  用户原话：「原来设计的不是目标真实伤害吗，你去查」——查了，是：
  `boom_pct_true = 8/13/20%`，200 码内**每个敌人各受【其自身】最大生命 8/13/20% 的真实伤害**
  （`RealtimeBattle3DScene.gd:6774`，走 `_apply_damage_from(..., true, true)`）。
  ⇒ 第 1 条只改骷髅的 **血/攻/双抗/受伤恒为1/存活时长**，**爆炸伤害一行都不动**。
  （我一开始把"原样"读成"要新算一个数值"，问了个不该问的问题。）
- **C｜第 11b 条的"温泉蛋也是"= 孵满 3 级时的【全队均摊护盾】。**
  `incub_shield` 300/400/600 按人头均分（`RealtimeBattle3DScene.gd:6342`），
  用的**正是铁壁盾那同一个** `_targeting._allies_no_trainer` —— 已排大师、**没排龟蛋**。
  ⇒ 11b 一句话覆盖两处，与第 3 条**毫不矛盾**：第 3 条的每秒回血只作用于携带者。
  ⇒ 实现：加 `_allies_share_pool(u)`（排 `_isEgg` + `is_trainer`），两处共用。

- **G｜靶向器钩索炸弹的百分比基数 = 【被打目标自己的】最大生命**（用户 2026-08-01 拍板确认）。
  即：每秒 1/2/2% 按宿主自身 maxHp、聚爆 +10% 按被炸目标自身 maxHp。与骷髅爆炸同口径。
  实现已是这样，无需改动；这条从「我替你定的」升级为「已拍板」。
