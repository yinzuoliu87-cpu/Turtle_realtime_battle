# 6 个新羁绊设计稿（匕首 / 魔法书 / 面具 / 筹码 / 炸弹 / 乐器）

日期：2026-11-24　|　状态：**草稿**

## 1. 需求原文

> 用户 2026-11-24：「可以匕首魔法书，（拳套）可以换面具…」「我们来个筹码，然后替换掉这个长矛吧」—— 上级方案书 [20261124d-16羁绊每周轮换.md](20261124d-16羁绊每周轮换.md)：大羁绊 10 → 16，每个 9–10 件，每周纯随机抽 10 个。
>
> 「按武器的类型出…可以看别的游戏里面它会有什么装备…可以去借鉴一下」

| # | 子需求 |
|---|---|
| D1 | 每个新羁绊有一条**它独有**的机制（不和现有 10 个撞） |
| D2 | 三档（3 / 6 / 9 件）加成：一条属性 + 机制逐档变强 |
| D3 | 每个羁绊 10 件装备，费用 1→5 各两件；名字是一看就懂的真实物件（去 AI 味标准，见 20261124c） |

## 2. 调查结论

现有 10 个羁绊**已经占用的属性**（`scripts/gamedata/phase2_types.gd` `TYPES`）：剑 = 攻击力、奇械 = 魔抗、食物 = 最大生命、盾 = 护甲、药水 = 治疗 / 护盾强度 + 最大龟能、枪 = 攻速、弓箭 = 暴击率（不给暴伤）、法器 = 魔法穿透 + 最大龟能、灵物 = 闪避、遗物 = 吸血。
现有机制：剑【剑士】追打、奇械【铸币】、食物【成长】、盾【怒气】冲击波、药水【猎物】、枪【金弹】、弓箭【处决】、法器【法力】主动、灵物【触手】、遗物【生死界】。

代码里**现成支持**、还没被羁绊占的装备属性：`critDmg`（暴击伤害）、`armorPen`（护甲穿透）（`scripts/gamedata/equip_stats.gd`）。其余要的属性（技能伤害、增伤、龟能回复）要在战斗计算里新加；面具的减伤接进现有减伤结算（`battle_damage.gd` 直接伤害与持续伤害同一个 DR，封顶 90%） ⇒ 改对局结果，`RULES_VER` +1。

撞题提醒：现有「双生匕首」在剑羁绊里；变脸龟的主题是换脸；骰子龟、赌神龟「命运之轮」是赌博主题 —— 新装备避开同名 / 同造型。

## 3. 需求 ↔ 代码的出入

- 「双生匕首」名字是匕首却属于剑 ⇒ 建议改成剑 + 匕首双类型（一件同时算两个羁绊，现有装备已有先例，如香火石 = 遗物 + 香火）。—— U3
- 筹码机制带随机输赢 ⇒ 随机一律用对局种子（与现有装备同规矩），服务器重算 / 回放逐位一致。

## 4. 方案

### 匕首 —— 贴身首击
- **属性**：每件 +12% 暴击伤害（弓箭只给暴击率，匕首给暴伤，两者互补不重叠）
- **【刺杀】**：对一个目标的**第一次**攻击额外造成伤害；击杀后瞬移到生命值最低的敌人身后。档位：首击 +40% / +80% / +150%，6 件起击杀瞬移，9 件起瞬移后首击必暴击
| 费 | 装备 | 一句话效果 |
|---|---|---|
| 1 | 折叠小刀 | 首击额外流血 3 秒 |
| 1 | 飞刀 | 每 4 秒向最远的敌人掷出一把飞刀 |
| 2 | 苦无 | 闪避后下一击必暴击 |
| 2 | 蝴蝶刀 | 每第 3 次攻击连刺两下 |
| 3 | 毒牙匕首 | 暴击时施加中毒，可叠加 |
| 3 | 三棱刺 | 攻击无视目标 20/30/45% 护甲 |
| 4 | 弯匕 | 击杀后 2 秒内攻速翻倍 |
| 4 | 仪式匕首 | 每击杀一个敌人永久 +攻击力（本场） |
| 5 | 黑曜石匕首 | 首击变成处决：目标生命低于 25% 直接击杀 |
| 5 | 暗影匕首 | 开场隐身 3 秒，现身第一击 3 倍伤害 |

### 魔法书 —— 普攻里穿插法术

### 面具 —— 戴上换一种打法
- **属性**：每件 +4% 减伤（接现有减伤结算，封顶 90%；用户 11-24：「我们没有韧性…我建议是给减伤吧」）

## 5. 已知风险与未决点

- **U1（要用户定）**：每个羁绊的机制方向对不对（尤其筹码的「输了没有惩罚」、面具的三态轮换、乐器的光环）；装备名字逐个过目。
- **U2（要用户定）**：先做哪两个（P2 第一批）。我建议**筹码 + 炸弹**：筹码是你点名的、图标统一（同一个筹码造型换颜色）出得快；炸弹机制最直观、特效辨识度高。
- **U3（要用户定）**：现有「双生匕首」改成剑 + 匕首双类型吗。
- R-1：魔法书 / 筹码 / 乐器要加 3 个新属性（技能强度 / 增伤 / 龟能回复）；技能强度要在结算处分清「来自技能」的伤害 / 治疗 / 护盾，只给这部分加成，面具的减伤接现有结算；改伤害的两条路径都要改（CLAUDE.md §4.3）。
- R-2：数值全部是方向稿，进实现时按现有装备的强度曲线（`tools/equip_budget_audit.py`）定数。
- R-3：每件都要专属命中 / 技能特效（memory：不要通用命中特效），工作量以特效最大。

## 6. 验收标准

- 每个羁绊 10 件、费用 1→5 各两件；新名字过去 AI 味标准、全表不重名（脚本自查）。
- 每条机制有门禁：数值按公式逐档对账（`verify_synergy_text` / `tooltip_number_audit` 同口径），筹码开奖用对局种子 ⇒ 跨进程同一局结果逐位相同（`verify_rules_fingerprint` 覆盖到新羁绊）。
- 用户看每个羁绊的实战录像认可后才放出。

## 7. 决策记录

- 2026-11-24 起草；等用户定 U1–U3。
- 2026-11-24 用户定属性：「匕首提供暴力（暴击）伤害，魔法书…技能伤害也可以。面具的话，我们没有韧性…我建议是给减伤吧。筹码我们给增伤，乐器我们给归能（龟能）回复」、炸弹护甲穿透 ⇒ 匕首 = 暴击伤害、魔法书 = 技能伤害、面具 = **减伤**（不做韧性）、筹码 = 增伤、炸弹 = 护甲穿透、乐器 = 龟能回复。机制方向 / 名字 / 先做哪两个 / 双生匕首仍待定。
- 2026-11-24 用户：「技能伤害其实有点笼统…有些技能是增加伤害，有些技能是给护盾…最好这一魔法书的效果是写提升技能所造成的伤害、治疗和护盾效果」⇒ 魔法书属性 = **技能强度**（技能造成的伤害、治疗、护盾都加）。
- 2026-11-24 用户：「魔法书来提供增伤，然后筹码…来自羁绊的不会提供属性。因为筹码的设计，我打算做成这种消耗品，也就是说，玩家购买筹码，它会存到于背包里面。筹码类型的装备是没有星级的，就只有一星。然后它放在这一个角色身上面…这件装备就会被携带到这个对局里面。然后一个对局完之后，那这个装备就…损坏了，所以这是个消耗品…消耗装备比普通装备会带来更强的临时增益，就是这个羁绊的…核心所在。」⇒
  - 魔法书属性 = **增伤**（取代上一条的技能强度）。
  - **筹码 = 消耗品羁绊**：羁绊不给属性；筹码只有一星、不参与三合一（同临时等级器 / 小木斧的「不升星」名单）；买入进背包 → 装到龟身上 → 带进下一场正式对局 → 打完（不论输赢）损坏消失；单场增益远强于同费普通装备。
  - 我提的细节（待用户认可）：① 面额越高单场增益越猛；② 羁绊档位 = 同时带的筹码越多效果放大越多（3 / 6 / 9 枚 ×1.2 / ×1.5 / ×2）；③ 消耗记进经济流水（结算时扣，否则手机与服务器重放对不上）；④ 积分赛 / 周六闯关 / 周日决赛消耗，切磋与教程不消耗。原「下注开奖」机制作废。
