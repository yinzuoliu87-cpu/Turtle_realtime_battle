## 方案（不需要拍板的先做）

- **D1** 改共享函数 `const_of`：数组分支逐项乘 100。新门禁把全仓带 `%` 的占位符渲一遍，任何「0.x%」且对应常量是小数比例的当场红。
- **D2** `_grant_shield` 传举盾时长；从 `shield_perm_debt.json` 销账；门禁补「落盾后盾清零、第二次举盾不叠」。
- **D3** 两条伤害路径（`_apply_damage` / `_apply_damage_from`）的额外真伤都记进 `_st_taken`/`_st_dealt`。门禁：金弹一段的账 == 实际掉血；085 转化按实际掉血算。
- **D4** 时停期间持有者自己的十字斩待结算、剑波、后撤要继续推进（与 059「只有携带者能动」一致）；锁定到期改走持有者的推进时间。门禁：持有者时停中放十字斩，2 秒内伤害到账。
- **D5** 附带魔伤挪到命中侧（`_eq_on_hit` 带 basic 标那条）。门禁：远程携带者出手当帧不掉血、弹体命中时掉。
- **D6** 080 台子加 `mortal: true`、低 `carrier_hp`、`allies`。
- **D7** 三件读数进 `equip_readouts.gd`（分母必须是常量：龟能 100、攻击次数 40/30/20 按星、金弹 4/3/2 按星）。
- **D8** `carrier_aps` 改成直接调 `battle.aspd_mult(owner) / atk_interval`；金弹档位表收口成一处。

## 已知风险与未决点

- **D3 动的是共享伤害管线**，两条路径都要改，影响所有带金弹/腐蚀的件与结算面板数字；要跑全套门禁，不只是枪批。
- **D4 与 059 时停交叉**：时停期间 `tick_global` 整块不跑是 v0.19.383 为了「无数东西都要定住」加的门，给持有者开口子不能把别人的也放出来 —— 全域冻结门禁 `verify_timestop_global_freeze` 必须仍然全绿。
- **D1 改共享渲染函数**，会改变所有数组型 `%` 占位符的显示；要先扫出全部受影响的文案逐条对（调查时是 3 处）。

- 真实双路换路流程没端到端跑，「每路重置」靠门禁与代码阅读。
- U1 如果选「加大斩击半径」，演出侧 `BladeEqVfx.SLASH_REACH` 与判定要一起改（twin_radius 那一类）。

  - D4 只推了持有者的结算、滑步、剑波，演出层 `vfx.tick` 没推 —— 时停里刀光是定格的。
