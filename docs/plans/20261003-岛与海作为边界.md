## 2. 调查（2026-10-03 实测）

### 2.0 ★★最根本的一条：整个战场现在是**海底竞技场**，而需求要的是**海上孤岛**

这不是三处小改，是**主题翻转**。证据全在 `battle_world_builder.gd` 自己的注释里：

| 构件 | 代码原文 | 为什么只在水下成立 |
|---|---|---|
| 气泡 `:945` `_build_bubbles` | 「缓缓上升的小圆点, 满场飘 → **深海**有生气」 | 气泡**向上**飘 |
| 氛围粒子 `:714` `_build_tilemap_ambient` | 「冰蓝→白·**缓上飘**·ADD 发光」 | 同上 |
| 辉光 `:848` | 「**水下场景的标配** —— 亮青的水与岸线泡沫会向周围渗出光晕」 | bloom 是按亮青水调的 |
| 远景三层 `:646` | 「渐变**水幕** / 远**礁**剪影 / **水面光柱**」 | 光柱**从水面往下**打 |
| 中景 `:658` `MID_OBJS` 13 件 | 「中距离地标」 | 看素材身份（待逐件核） |
| 装饰 `:956-961` | `deco_kelp` / `deco_coral_pink` / `deco_coral_orange` | 海草珊瑚 |

★**而地面早在之前就被改成草/土/沙了** ⇒ 场景已经骑在两个主题中间。
⇒ 用户「拍板根本不像游戏」的真因在这里，比 §2.3「装饰是一张写死的坐标表」**更根本**：
那只是构成方式的问题，这是**同一个画面里两个互相否定的世界设定**。

### 2.0.1 咩咩参考的真实分母（回答用户「参考了多少？有10个场景吗」）

出处 `ref/20261002-咩咩启示录地图参考.md` §0.2：

★★**但它们全是静态截图** —— 这是本轮新增需求的硬缺口，见 §4.3 风险 7。

### 2.1 现在这张图跟需求**正好是反的**

玩家看到的地形由 `data/maps/arena.json` 驱动（`RealtimeBattle3DScene.gd:1005`
`_load_tilemap()`；`battle_world_builder.gd:182` 里那段程序化生成**只是 json 缺失时的兜底**）。

实测 58×34 = 1972 格：

| | ARENA 内（779 格） | ARENA 外（1193 格） |
|---|---|---|
| 草地 | 235（30.2%） | **485（40.7%）** ← 陆地在战斗区**外面** |
| **水** | **240（30.8%）** ← 水在战斗区**里面** | 177（14.8%） |
| 石台 | 245（31.5%） | 10（0.8%） |
| 沙 | 59（7.6%） | 0 |
| void | 0 | 521（43.7%） |

⇒ 画面读成「一大片陆地中间有个湖，边界两侧都是陆地」。
**边界读不出来的真因：它两边是同一种东西。**

### 2.2 边界带跟的是**错的那条界**

`verify_edge_wall.gd:78-90` 独立重算的口径是 **非void ↔ void** 的相邻段数，
产品侧同口径 ⇒ 那道 31px 竖面画在「所有非虚空物的外沿」。

按本需求（内陆 → 外海 → 虚空），它会落在**海的外缘**，
而要玩家读懂边界，竖面必须在**陆地跌入海水**的位置。
⇒ **这是需求变了，不是判据错了**：产品与判据的口径要一起改成 **陆 ↔ 非陆**，并反向验证。

### 2.3 可见余量（决定「海围一圈」看不看得见）

ARENA = `Rect2(70, 110, 1596, 728)`，投到 1280×720：
上边 y=205 / 下边 y=596 / 左 x=11~179 / 右 x=1101~1269。

⇒ **ARENA 自己整个在画面内，但外面几乎没有余量**：
海在**上（205px）下（124px）很明显，左右几乎看不到**。

## 4. 方案

### 4.1 三刀（顺序定死 A→B→C，装饰物最后 —— 用户 2026-10-02 的排序）

| # | 改什么 | 怎么验 |
|---|---|---|
| **A** | **`arena.json` 翻过来**：ARENA 内零水（水→草/沙/石）；ARENA 外一圈海（草→水），海之外仍是 void | 判据直接数 json 的格子，不靠眼睛 |
| **B** | **边界带口径改成「陆↔非陆」**，竖面落在海岸线上；标定高度 `WALL_H_EXPECT` **一个字不动** | `verify_edge_wall` 的重算口径同步改 + 反向验证 |
| **C** | 区内装饰换**陆地系 + 成组**；珊瑚海草**整套删掉**（见下）；挡路障碍换石块 | Clark-Evans R / 件数 / 类别数 由判据现算 |
| **D** | **气泡 / 灯光 / 背景按「孤岛」重做**（用户 2026-10-03 点名）：气泡不再向上飘、水面光柱撤掉、水幕背景换天/海平线、bloom 按新主题重调、中景 13 件逐件核身份 | 每类各一条判据 + 实拍；动态部分要**视频参考**（风险 7） |

★★C 的措辞 2026-10-03 收紧了：原来写「珊瑚海草只留在水里」，但既然主题从水下翻成孤岛，
**水面之下根本不再是镜头所在的世界** ⇒ 珊瑚海草**整套从场景里删掉**，不是搬去 ARENA 外。

★A 不碰 `ARENA` 常量、不碰相机 ⇒ **玩法空间与像素尺寸零变化**。

### 4.3 已知风险与未决点

1. ⚠ **9-18 那条「边界要有能看见的竖面」是用户要过的**（P1-5，照 TFT 实测标定：
   竖面 ÷ 角色屏幕高 = 0.81 ⇒ 31px ⇒ 世界高 1.11 米）。本次**不是撤掉它**，
   是把它从岛外沿**搬到海岸线**。标定值不动。
   ⇒ 任何「把墙删掉」的做法都先过这条（memory `fb-pin-user-words-dont-drift`）。

2. ⚠ **区内不再有水 ⇒ 少了全场唯一的亮色面积**（实测 水 98 vs 淤泥 32）。
   2026-07-31 把水赶出战斗区的理由是「深色龟压在最亮处最难读」—— 这条现在更彻底地满足了，
   但**画面会不会变单调没实拍过**。A 做完先拍，再决定要不要在区内补亮色（石台/沙/光斑）。

3. 🔲 **左右两侧的海几乎看不见**（§2.3）。要「海围一圈」都可见，只有两条路：
   ① ARENA 横向收窄约 15%（少活动空间）② 相机拉远（像素变小，而 2026-07-05 用户刚要求放大 1.4×）。
   **我的建议：先不动，A 做完实拍再定。** 这条要用户拍板。

4. ✅ **已拍定（2026-10-03）：不复用，全部新做。** 用户原话「**不要复用，从新做**」。
   ⇒ 库里那些 `deco_boulder` / `deco_grasstuft` / `deco_rubble` / `prop_barrel` /
   `mid_stone_column` / `brazier` **一件都不用**；铁律 `fb-no-asset-reuse-unless-told` 继续生效。
   ⚠ 代价要摊开：C + D 的素材量不小（装饰 + 障碍 + 背景 + 中景），这是**本方案工期的大头**。

5. 🔲 **碎料层留多少**仍未定，但分母变了。用户 2026-10-03「**别管brotato的**」
   ⇒ Brotato（296 件/Mpx）**出局**，只在咩咩（178 件/Mpx·人工计数）与 Botworld（战斗场 **0 件**）之间选。
   ★★**连带后果**：2026-09-20 加的那 820 件碎料，当时的依据原话是「参考 296 件/Mpx、覆盖 2.20%，我们 0 件」
   —— **那个依据现在被作废了** ⇒ 这 820 件不是"已经做好的"，是**要重新定的**。
   （memory `fb-my-goal-can-be-wrong-not-just-my-code`：实现方案书目标前先复查它的依据。）

6. ⚠ **`arena.json` 有备份 `arena.json.bak-tile48`**（2026-07-21）。改之前另存一份当轮备份，
   但**不要**靠 `git checkout` 回滚（memory `fb-never-git-checkout-to-cleanup`）。

7. ⚠⚠ **手上 33 张咩咩参考全是静态截图，量不出 D 刀要的东西。**
   气泡与灯光是**动态**的：发射频率、上升速度、生命周期、闪烁节奏、衰减曲线 ——
   这几维**单帧一个都给不出**。本仓自己的铁律也说得很清楚：
   `fb-pixel-1to1-video-reference`（像素级 1:1 视频参考是标准）、
   `fb-single-frame-is-not-the-work`（单帧量不出全作）、
   `fb-match-reference-by-measured-curve`（手调缓动补不出真曲线）。
   ⇒ **D 刀动手前必须先拿到视频并抽帧成表**，产出 `ref/20261003-咩咩动态参考.md`。
   ⚠ 这是**新的取材任务**，不是"顺手就做"。静态的那部分（背景构成/色阶/海平线）27 张够用。

8. 🔲 **背景具体换成什么没定**。「不是水幕」是确定的，但换成天空 + 海平线、还是远岛剪影、
   还是像咩咩那样**外面直接是虚空**，三种读法完全不同，而咩咩的地牢恰恰是**第三种**
   （上游报告：地块直接断进虚空，过渡中位 2px，崖面刻意留空）。
   ⇒ 这条等 D 的视频/静态参考研究完再提案，**我不先挑**。
