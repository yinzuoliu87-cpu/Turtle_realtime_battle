- 「5费镇海杵提供的魔法穿透改为13/21/40」
- 2026-10-23「改完这一批，出个新包下载到我手机上」

## 2. 调查（改之前的现状，代码实查）

- 026：`equip_system.gd::_eq_chain_lightning` 写死 `[4, 5, 6]` 跳、`[40, 60, 90]` 魔法伤害，不吃攻击力。
- 086：`eq_gadget_batch.gd` 终极射线每条写死 `[200, 350, 1000]`。
- 073：`eq_bow_batch.gd` 藤蔓箭 = 攻击力 × `[0.20, 0.30, 0.45]`；暴击攻速 `[0.20, 0.25, 0.30]`，`VINE_ASPD_SEC = 2.0`。
- 090：`EquipStats.STATS` 法穿 18/42/110。

## 3. 需求 ↔ 代码的出入

- 026 / 086 / 073 原来没有「基础 + 攻击力系数」这种形态，要新加攻击力那一半（按出手那一刻的攻击力）。
- 「0.1ATK」「0.5ATK」按 10% / 50% 攻击力实现。

## 4. 方案

- 数值抽成常量：`EquipSystem.CHAIN_HOPS / CHAIN_DMG / CHAIN_ATK_COEF`、`EqGadgetBatch.SEXT_RAY_DMG / SEXT_RAY_ATK_COEF`、`EqBowBatch.VINE_FLAT / VINE_ATK / VINE_ASPD`（`VINE_ASPD_SEC` 改 3.0）。
- 文案（`phase2-equipment.json`）攻击力系数与秒数走 `{C:}` 占位符；`baseStats1` 镜像与装备评审表同步。

## 5. 已知风险与未决点

1. ⚠ 雷电法杖 3★ 15 跳、敌人不足时会重复命中同一目标（规则本来就允许「可重复命中同一目标」），单体伤害上限明显变高。
2. ⚠ 六分仪 3★ 从 1000 降到 500 + 50% 攻击力：攻击力低于 1000 时比原来弱。
3. ⚠ 跨平台确定性金标 ③（满装备场景）随数值变化重生；其余 14 个场景不变。
