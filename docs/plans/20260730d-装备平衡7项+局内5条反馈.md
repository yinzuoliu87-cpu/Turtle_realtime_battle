## 1. 需求1 — 装备平衡 7 项

`atk_interval` **2.0 → 1.4286**（=1/0.7）。★文案里若写了"每 2 秒一击"要同步。

### 1-3 复活海螺**加强**
- 小虫 `hp` **100 / 1500 / 10000**、`atk` **50 / 80 / 200**

### 1-4 荆棘海胆**加强 + 效果重做**

- **新效果**：携带者每反伤 **300 / 270 / 230** 点伤害 →
  ① 给自己 **50 / 70 / 200** 护盾
  ② **强化下一次普攻**，命中施加 **30 / 50 / 90 层流血**

### 1-5 玩偶小熊的大熊**加强**
`hp` **1600 / 3000 / 15000**、**+70 点双抗**（护甲与魔抗各 70）。★攻击力用户没提 → **不动**。

### 1-6 飞镖**加新效果**

- 每次释放还使自己获得 **5 / 7 / 10 点魔抗穿透**

## 2. 需求2 — 局内 5 条反馈

### 2-a 手机上**投降键压在血条上**
PK 条占 y `16..42`、副条 `46..55`；右上按钮是**写死坐标**（`Vector2(1088, 12)` 这类），
没走 `SafeArea.margins()`。手机安全区 + 不同宽高比下会与 PK 条重叠。
→ **右上按钮改走 SafeArea + 让位给 PK 条**（PK 条居中、按钮贴右上角且 y 下移到 PK 条之下或缩小）。

### 2-b 灵体小龟形象
改用**小龟统领的形象**加一点灵体感（幽蓝 + 半透明 + 轮廓辉光）。
★**不是复用**：这是"同一只龟的灵体态"，是设定要求；但要**新出一张图**而不是直接 modulate 现有立绘。

### 2-c ★PK 条会莫名增减
根因见 §0。三个跳变源：**驯服归顺搬边**、**口哨临时血抬分子**、**驯服重生回血**。

> ⚠ **未决（要你选）**：
> - **A. 归顺时把该单位的 maxHp 一并从敌方基线搬到我方基线** → 比例连续、不跳（我倾向这个）
> - **B. 归顺单位不计入任何一方**（中立）
> - **C. 保持现状，但加 0.3 秒过渡**让它"流过去"而不是瞬跳
>
> 临时血那条我建议：**把 +700 也加进基线**（否则条会超 100% 被截断）。

### 2-d 驯服跨战场 + 血条颜色
幸存名单**按 `_eff_side` 分组**、spec **有**拷 `tamed_side` —— 看起来是对的，
但**我还没端到端验过**（今天两次栽在"读代码以为对"上）。
→ **必须写一条走真实换路的门禁**：驯服一只 → 结束本路 → 进决胜 → 验它①在我方②血条是我方色③2%/秒掉血继续。

### 2-e ★魔法石继承（已确诊没生效）
`_spawn_trainers()` 每路重建大师 → 层数天然归零。
→ **把 `_ms_stacks` 按 side 持久化**（存 `GameState` 或 battle 层的跨路容器），
`_spawn_trainers()` 建完后**回填**。敌方大师同理。

## 4. 已知风险与未决点

**① `50 / 100 / 25` 疑似笔误**（深海堡垒甲三星回复低于二星）。**阻塞 1-2 的实现**，需你确认。

**② PK 条跳变的处理方式要你选**（§2-c 的 A/B/C）。不选的话我按 A 做，并在实现里留开关。

**③ 1-7 信号放大器是本批最大的一件。** 它有：层数系统 + 阈值触发 + **角度递增的弧形波弹道** + 眩晕 + 穿透。
弧形波要新写一套弹道（现有的是直线/抛物），且"90° 张角发射"的语义有歧义 ——
是**一次发射张角 90° 的扇形波**，还是**沿 90° 方向发一道弧**？我按**扇形张角**理解，
角度递增 = 扇形越来越大，到 360° 就是整圈。**若理解错，这一项要返工**。

**④ 1-3「5 费或 4 费装备」需要装备费用表。** 若 `EquipStats` 里没有"费用"字段，
得先确认费用是从哪来的（商店价？稀有度？）——**这是实现前置**。

**⑤ 1-4 的"每反伤 N 点"是累计计数器**，跨路要不要清零？（与魔法石叠层同类问题）
未说明 → 我按**跨路保留**做（与刚拍板的魔法石一致），但这是我的推断。

**⑥ 2-b 灵体小龟用"小龟统领形象"** —— 需确认小龟统领的立绘文件名/是否有多方向帧。
若它是龟统领本体立绘，直接拿来改色**算不算复用**？我的判断：**要新出一张**（用它做参考重画），
不直接引用原文件。

**⑦ 本批改动会让第六轮胜率数据失效。** 7 件装备里 6 件改了数值/机制，
平衡数据要**重新跑一轮**才有意义。

**⑧ arch_budget 台账 8600 行**：1-7 那套弧形波若写进主文件会撞线，
**必须新开 `scripts/systems/equip/` 或塞进现有装备系统文件**。
