# 选龟页整页重做（照背包页那一套）

日期：2026-10-30　|　状态：**已完成**（未发版，随下一版）

## 1. 需求原文

- 用户 10-30：「然后是选归界面，找找看有有什么问题，去修一下。比如说那些按钮，那个 SSS 到底需要这种什么正方形框吗？那很明显不需要啊。那别人的游戏是用什么框表示这种 SS 和这个过滤的呢？」
- 用户 10-30（看了第一版方向稿）：「你自己说呢？定蓝三个键不动，你来说说看，这是什么东西？」
- 用户 10-30：「你在说什么呢？整个背景图，每个方正条条框框的地方，你都没有注意吗？」
- 用户 10-30：「你先做好，给我看成品啊。你得全部做好给我看成品啊！你现在给我谈谈什么呢？」
- 用户 10-30：「你这还是一股浏览器的感觉啊，压根没有游戏的感觉。我说我都不知道怎么做，人家商业游戏做出来感觉完全不一样。」
- 用户 10-30（重做进行中）：「能参考一下其他游戏的吗」「这种选角色的」「右侧4个属性感觉不用显示，或者不能去这么显示吧」
- 用户 10-30：「我感觉是第一次选龟和锁定后的选龟页不能一样啊，锁定后的就不用去显示其他龟和稀有度了啊」

## 2. 调查结论

- 背景 `assets/sprites/bg/select-bg.png` 是给旧回合制版式画的：6 卡槽 + 绿 / 蓝「前排 / 后排」横幅、龟池大凹槽、右栏上下两格、绿牌、两块小木托。界面一层层贴在上面，按同一坐标逐块对照（`C:\tmp\ts_bg\背景框对照-选龟页.png`）8 块里 6 块对不上：网格伸出凹槽左沿约 45px、顶栏扁平方块盖住木托、技能那行掉出右栏下格、属性数字贴死右框、阵容区盖了一块金边托盘 + 3 张橙边卡（第三种画风）。
- 顶栏三键用的 `TopBar.apply_chip_skin` 扁平矩形皮全仓只有选龟页在用（别的页走 `TopBar.new`，背包页是「←」+ 像素木牌）。
- 筛选条：7 个 81×81 冷蓝方框。同类界面参考约 110 张（`C:\tmp\ts_ref\参考对照.png`）没有一家把稀有度字母放进一个个方框当按钮；横屏顶部多是文字页签（Shadow Fight Arena / 明日方舟）。
- iPad 4:3：内容带宽正好等于屏宽（`_stage_scale` 的 fit_w 卡死），右栏框边和「攻击力 40」被屏幕切半。
- 背包页（用户认可过的那一套）：大卡 = `unit-card.png` 金饰框 + 全身立绘 + 稀有度色横幅 + 下沿木托；顶栏 ← + 木牌；说明卡底板 `insp-card`。

## 3. 需求 ↔ 代码的出入

- 「找找问题修一下」实际是整页的画法问题，不是几个按钮：背景版式过时 + 四五种画风的框叠在一起。
- `TeamSelectScene.gd` 整份在积分赛逐字节守卫（`verify_gauntlet_online_queue` R 段）里；这次是用户点名要改这一页，只改画法 / 版式，选人、存档、出战进匹配的流程不动 ⇒ 守卫给这个文件单独换基线（见 §4.8）。

## 4. 方案

1. **背景**：`tools/build_select_bg.py` 用原图自己一段干净桌板把烤死的面板铺回桌面（错位铺、补板缝、边缘羽化），只留四周道具和左上羊皮纸；源图存 `tools/art_src/select-bg-src.png`（`.gdignore`）。
2. **单位卡画法抽成共用**：`scripts/util/unit_card_art.gd`（窗口底 / 全身立绘 / 框 / 稀有度横幅 / 卡外金边）；背包页三个函数改调它，选龟页也调它 —— 两页的龟卡从同一处画出来。
3. **统领位**：三格 = 背包同款大卡；下沿木托放被动 + 选中技能两枚图标；空位 = 背包占位统领同样子（「?」+「统领N」）；选中 / 待填 = 卡外金边。去掉金边托盘。
4. **龟池**：同款小卡（9 列）、左上稀有度字母（与页签同字同色）、右上实战等级、已上阵压暗 +「已上阵」、正在看的那只卡外金边；稀有度筛选 = 一行文字页签（选中提亮 + 下划线，点击范围仍 81px）；底部渐隐（滚到底收起）。
5. **右栏**：说明卡底板 `insp-card` 一整块；立绘放大；技能格 = 不透明深底 + 直角色边（选中金 / 固有绿 / 普通铜）；删掉重复的「选择 · 技能名」那行；四项属性数字换成一行定位词「近战 · 坦克」（见 §5 R4）。参考里最像我们的两款：Shadow Fight Arena（3 人队、已选上排 + 候选网格、数值点 DETAILS 才看）、明日方舟（技能 3 选 1、选中的技能图标挂在编队卡上 = 我们统领大卡下沿木托）。
6. **顶栏**：「←」（零盒子，与其余各页同一枚）+ 像素标题字；撤下 / 沿用上次 = 背包页木牌（看得见的高度 = 设计区，点击范围仍 81）；不能点整块压暗。出战 = 像素金键。提示条 = 深底黄铜边的签，居中压在统领卡下沿。
7. **锁定后**（本大轮统领已定）：不建龟池和页签；三张统领卡放大（308×404）占那一片；页名「本大轮统领」；撤下 / 沿用上次不显示；常驻提示签「本大轮阵容已锁定 · 点统领卡查看详情、更换技能」；正在看的那张统领卡外金边。
8. **守卫**：`verify_gauntlet_online_queue` R 段支持按文件基线（`spec["base"]`），只把 `TeamSelectScene.gd` 钉到这次提交，其余文件仍比 84d2d853。
