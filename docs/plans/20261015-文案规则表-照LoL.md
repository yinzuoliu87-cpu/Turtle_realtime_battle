## 方案（规则）

### R1 句式
| # | 规则 | LoL 实测 |
|---|---|---|
| 1.1 | 第一句以龟名开头，直接写动作 | 643 / 865 以英雄名开头 |
| 1.2 | 不写只重复技能名的开头（「小龟施展过肩摔：」） | 腕豪 R：「瑟提擒住……猛摔到地上，对……造成」 |
| 1.3 | 同一技能有被动 + 主动时，用「被动：」「主动：」分段，被动在前 | Passive: 94 · Active: 73 |
| 1.4 | 一个效果按自身属性 + 按目标属性两段算时，用「外加」连接 | 腕豪 R「造成 X 外加 Y% 被擒英雄的额外生命值的物理伤害」 |

### R2 数值
| # | 规则 | LoL 实测 |
|---|---|---|
| 2.1 | 按自身属性算的量：写「结果 =（基础值 + 系数）」 | 腕豪 R「206 = (200 +120% bonus AD)」、索拉卡 W「95 = (90 +50%) Health」 |
| 2.2 | 按目标属性算的量：只写百分比（算不出结果） | 腕豪 R「40% of the grabbed enemy's bonus Health」 |
| 2.3 | 属性加成（+X% 护甲）、门槛（低于 X%）只写百分比 | 同上类 |
| 2.4 | 系数一律写百分比，不写「X 倍」「×」 | 中文语料「倍攻击力」0 次 |
| 2.5 | 不写范围码数（射程增减、按距离加伤这类「范围本身就是效果」除外） | 正文写范围数值 25 / 865；「命中第一个敌人」类 45 个写码数 0 个 |

### R3 颜色（★ 推翻 10-13 的「其他数字一律白」）
| # | 规则 | LoL 实测（颜色标签次数） |
|---|---|---|
| 3.1 | 伤害：从数值到「物理 / 魔法 / 真实伤害」整段上该伤害色 | magicDamage 597 · physicalDamage 338 · trueDamage 37，标签包住「# max Health magic damage」整段 |
| 3.2 | 回复：从数值到「生命值」整段上回复色 | healing 148，「95 = (90 +50%) Health」整段绿 |
| 3.3 | 护盾：从数值到「护盾」整段上护盾色 | shield 85，「# Shield」 |
| 3.4 | 移动速度 / 攻击速度加成：数值连属性名一起上色 | speed 157 · attackSpeed 91，「#% Move Speed」 |
| 3.5 | 控制效果词（眩晕 / 击飞 / 减速 / 嘲讽 / 冰寒…）上控制色，后面的时长不上色 | status 539；「Slowing them by 99% for 1 second」只有 Slowing 上色 |
| 3.6 | 公式括号里的系数按它自己的属性色（攻击力 / 法强 / 生命值各自的颜色），不跟整段 | 索拉卡 W「+50%」是法强紫、外面是回复绿 |

### R4 灰字（Shift 下方那一行）
| # | 规则 | LoL 实测 |
|---|---|---|
| 4.1 | 只放：对小将 / 龟蛋 / 召唤物的不同数值、上限、与其他效果的交互、使用限制 | 灰字分类：对小兵野怪 131 · 上限 110 · 交互 75 · 时长细节 69 |
| 4.2 | 不放：关键词释义（放状态页）、实现细节、自身是否会被打断、冷却 / 龟能何时开始 | 「冷却在 X 后才开始」0 · 「对真实伤害无效」0 |

### R5 不写的东西
- 演出过程（生命球飞回、举拳蓄力这类没有效果的动作）。
- 开发用语：霸体、结算、实时、判定、智能冲刺。
- 重复被动里已经写过的话。

### R6 用词（我们自己的定稿，不改）
- 属性名：治疗削减、护盾削减、反伤、增伤、减伤、暴击率、生命偷取、攻击速度、移动速度、魔抗。
- 禁用：改为、等同于、结算、实时、每点、普攻、获得 +X、汉字之间的空格。

## 已知风险与未决点
- R3 改动面大：所有回复、护盾、移速 / 攻速加成的颜色都会变，图鉴、选龟页、战斗面板三处都受影响。
- R3.6 需要改 html_to_bbcode「最外层颜色胜出」的规则：括号里的系数要保留自己的颜色。
- 未决：装备文案的分档数值（「70/100/150%」）在 LoL 没有直接对应，暂按同一套颜色规则处理。
- 未决：LoL 中文客户端的「=」写法没有实截（手上只有外服英文截图），中文排版用「206 =（200 + 120% 攻击力）」。
