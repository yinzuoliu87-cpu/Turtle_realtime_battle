## 需求① 图鉴·装备"框框颜色"是不是有问题？

### 现状（读码）
- 装备数据 `data/phase2-equipment.json` **只有 `cost`（1~5），根本没有 `rarity`/品质/档位字段**（逐件确认 `rarity=None`）。字段仅 `id/name/cost/baseStats1/shopAvailable/emoji/effectDesc1/effectDesc3/img`。
- 图鉴装备列表 [`list_builder.gd:_add_equip_rows`](../../scripts/scenes/codex/list_builder.gd)：按**费用分组**，每行**描边色 = `COST_COLOR[cost]`**（组标题也是这个色）→ 同一费用组里所有装备**边框同色**。
- `CodexScene.gd` 里 **`const P2EQ_RARITY_COLOR` 定义了但从没被用**（死代码）；注释写"行描边用稀有度色(P2EQ_RARITY_COLOR)"——**与代码不符**（实际用 cost）。而且 `COST_COLOR` 与 `P2EQ_RARITY_COLOR` **是同一套配色**（cost1~5 ↔ 普通→传说：灰/蓝/绿/紫/黄），所以 cost 描边"看着像按品质"。
- **跨界面不一致嫌疑**：调试场加装备卡 `_edit_rarity_color(eq)` 用的是**另一套色**（`#5aa9ff` 蓝 / `#5fd08a` 绿 / `#9aa4ad` 灰），和图鉴的 `COST_COLOR` 不是一套。

### 候选问题（要测试人确认是哪个）
1. **框色都太像/发糊看不清**（描边 alpha 0.7 + 灰/蓝/绿三色偏近）。
2. **同费用组边框全同色**——测试人以为"没体现品质/像 bug"（其实装备没品质概念，边框只重复了费用）。
3. **某件装备颜色明显错**（cost 与预期不符的个例）。
4. **和别处（调试场/战斗装备卡）颜色对不上**（上面那套 vs `_edit_rarity_color`）。

### 方案（按不同确认走）
- 若"太像/糊"→ 提描边饱和度/alpha、拉开相近色。
- 若"同色单调"→ 装备无品质，边框可**去掉/弱化**（只留费用组标题分色），或引入真·品质概念（要策划定，改数据，工作量大）。
- 若"跨界面不一致"→ **统一成一套色**（推荐：全项目装备色都走 `COST_COLOR`，删 `_edit_rarity_color` 自造色 + 删死的 `P2EQ_RARITY_COLOR` + 修那条假注释）。
- **无论哪种，先清死代码/假注释**（`P2EQ_RARITY_COLOR` 未用 + "用稀有度色"注释与实现不符）——这条无争议、可先做。

## 需求② 调试场在手机上怎么选择乌龟？

### 现状（读码）
- 选龟已不是弹窗，是**底部常驻笔刷栏** [`battle_hud.gd:_build_brush_bar`](../../scripts/scenes/battle/battle_hud.gd)：`左队/右队` 按钮 + 一条**横向可滚 `ScrollContainer`**（`SCROLL_MODE_AUTO`），里面 28 龟 + 浪板/火箭/精英小将 + 大师，每格 54×54。
- 触屏横滑**已适配过**（2026-07-22 注释：BaseButton 只吃 mouse button，touch drag 透传给 ScrollContainer）。
- 栏子 `PRESET_BOTTOM_WIDE` + `offset_top=-94` → **贴屏幕最底、94px 高**，**没有 SafeArea 下内边距**。

### 候选问题（要测试人确认）
1. **压根找不到/看不见**（栏子被底部手势条/圆角/挖孔挡住，因为没 SafeArea 下边距）。
2. **看得见但不知道能横滑**（28 个太多、一屏放不下，没有"还有更多"的提示）。
3. **横滑滑不动**（触屏透传在某些机型失效）。

### 方案
- **加 SafeArea 下内边距**（栏子上移到安全区内，不被 home 条挡）——**无争议、可先做**。
- **加"可横滑"提示**：栏子两端渐隐/箭头，或首次进场轻抖一下暗示可滑。
- 若某机型滑不动 → 复核触屏透传（要机型/录屏）。
