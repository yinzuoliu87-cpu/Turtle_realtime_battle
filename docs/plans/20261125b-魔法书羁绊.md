# 魔法书羁绊（第三批新羁绊）

日期：2026-11-25　|　状态：**草稿**

## 1. 需求原文

> 用户 2026-11-25（匕首批 9 条全部过审后）：「这些这些也不需要我看了…继续任务吧。我们还有四个羁绊没做出来吧？」
> 用户 2026-11-24：「魔法书…咒语书、魔法书，也是一个类别」「魔法书来提供增伤」

上级：[20261124d-16羁绊每周轮换.md](20261124d-16羁绊每周轮换.md)、[20261124e-6个新羁绊设计稿.md](20261124e-6个新羁绊设计稿.md)（魔法书 = 增伤）。
剩下 4 个（魔法书 / 面具 / 筹码 / 乐器）里**先做魔法书是我的建议**，不是用户原话 —— U0。理由：属性（增伤）单位身上已有现成字段 `damage_amp`；机制只动战斗内，不碰经济（筹码要动背包 / 消耗 / 经济流水 / 服务器重放，放后面单独做）。

## 2. 调查结论

- **增伤**：单位字段 `damage_amp` 已在抗性结算里生效（物理 / 魔法 / 持续伤害都乘，`battle_damage.gd` 的 `_magic_after_mr` 与持续伤害段、主场景 `_resolve_dmg`；信号放大器 038 / FPGA 板 / 若干技能临时加它）。装备属性表（`scripts/gamedata/equip_stats.gd`）**还没有**增伤这个键 ⇒ 新加 `dmgAmp`，在 `equip_stats_apply.gd` 加到 `damage_amp` 上（同 `critDmg` 的接法）。
- **法器羁绊**（现有）= 法术穿透 + 最大龟能，装备是法杖 / 符咒一类、「攒满放大招」。魔法书要区分开：**技能放得越多越强**（翻书 = 念咒），装备效果多挂在「释放技能时」与「普攻节奏里冒小法术」。
- 「龟释放技能」现成钩子：装备系统 `_eq_on_cast(u, tgt)`（释放技能时对携带者调，`equip_system.gd:2330`）；全队计数照导弹 / 刺杀的写法放羁绊系统里。
- 羁绊没有攻击力来源 ⇒ 羁绊伤害写「固定值 + 目标最大生命值 %」（11-24 导弹那次的教训）。
- 现有装备名 116 件已查：下面 10 个名字无重名；避开了雷鸣贝壳 / 雷电法杖 / 寒冰法杖 / 符咒 / 魔法胸甲 / 骨哨（亡灵骷髅）/ 星星龟彗星这些已有机制。

## 3. 需求 ↔ 代码的出入

- 增伤属性要新加装备属性键 `dmgAmp`（改对局结果 ⇒ `RULES_VER` 上线那版 +1，同匕首）。
- 【飞弹】要在「任意单位释放技能」处拿到这次消耗的龟能：龟本体走 `_cast_skill`，召唤物各有自己的技能入口（暗影忍者 / 炮筒 / 武士刀小将 / 援军小将…）⇒ 统一加一个「释放技能」广播（单位 + 消耗龟能），羁绊系统订阅；训龟大师不广播。

## 4. 方案

### 4.1 羁绊：魔法书（3 / 6 / 10 件三档，同炸弹 / 匕首）

- **属性**：每件魔法书为携带者提供**增伤 +3% / +6% / +10%**（1 / 2 / 3 档）。增伤作用于携带者造成的全部伤害（普攻 / 技能 / 装备 / 持续伤害），与其它增伤来源相加。
- **【飞弹】**（全队，**11-25 用户定**）：**我方任意单位（包括召唤物）每释放一次技能，召唤一批魔法飞弹**；**飞弹数量 = 这次技能消耗的龟能 ÷ N**（N 按档位变）；**每枚飞向一名随机敌人，造成（固定值 + 目标最大生命值 %）魔法伤害**。

| 档 | 件数（不同魔法书，按 id 去重） | N（每多少龟能一枚） | 每枚伤害 |
|---|---|---|---|
| 1 | 3 | 20 | 20 + 目标最大生命值 1% |
| 2 | 6 | 15 | 35 + 目标最大生命值 1.5% |
| 3 | 10（集齐） | 10 | 60 + 目标最大生命值 2.5% |

（N 和伤害数是我补的，待看。例：放一个 100 龟能的技能 ⇒ 1 档 5 枚 / 2 档 6 枚 / 3 档 10 枚；暗影忍者影袭 60 龟能 ⇒ 3 / 4 / 6 枚。）

我按的口径（待确认）：
- 数量向下取整、至少 1 枚；技能没有龟能消耗（被动触发）不算。
- 「单位」= 我方龟、小将、召唤物（暗影忍者 / 炮筒 / 武士刀小将等有技能的）；训龟大师不算（装饰，免疫一切）。
- 每枚随机挑一个敌人（龟蛋除外，用对局种子），可以重复挑同一个；飞弹按速度飞（900 码/秒），追着目标飞到才结算，目标半路死了就落空。
- 一路里不封顶，每路照常。
