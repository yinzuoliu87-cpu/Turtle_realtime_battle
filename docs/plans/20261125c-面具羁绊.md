## 2. 调查结论

- 每路开打的判定照匕首【刺杀】的写法：`battle._sd_t0` 换值 = 新的一路（`dagger_synergy_system.gd`）。
- 生成单位走 `battle._spawn._make_unit`（`battle_spawn.gd:335`），装备属性逐件应用新增 `EquipStatsApply.apply_unit`。
- 敌我判定全工程只有 `_is_hostile` 一个入口（`RealtimeBattle3DScene.gd` §HOSTILE），里世界隔离挂在这里。
- 「夹回岛上」统一走 `ArenaShape.clamp_in`（十几处调用），里世界那块地在这一个入口换边界。
- 物理护盾照 012 海藻魔法护盾的写法（`magic_shield.gd`），两条伤害路径都接（CLAUDE.md §4.3）。
