## 2. 调查结论（截至 11-22 晚）

**A · 刷新卡死**
- 正式服只读：LouisT01（`b250de29…`）本周流水停在第 310 条 19:03:17（`econ_ops` max seq = 310），之后手机上买装备 / 买经验都没传上去；服务器那份 fp 深海币 = 2，手机上 17 ⇒ 后面的收入也没传。
- 买装备 / 买经验是本机即时记账（`EconLedger.do`），刷新要向服务器要种子（`EconNet.seeded`，`scripts/net/econ_net.gd:129`）。`seeded` 先问 `busy`，忙就当场回 `busy`；旧版 `ShopScene._on_refresh` 不提示（89b6bd67 前 `ShopScene.gd:1507-1515`）。
- `busy` 只有提交的回调能解开（`econ_net.gd` `seeded` / `pump` / `adopt_async`）；回调靠请求节点进树后看门狗 Timer（`supabase.gd:2680-2686`，15 秒）兜底。节点没进树 ⇒ 永远不回 ⇒ 每 20 秒的 `pump` 也因 busy 跳过 ⇒ 与「能买、能升级、刷新没反应、服务器 19:03 后一条都没有」全对上。
- 同一时段 LouisT01 / alex1997 在对阵图都报了引擎错误 `Condition "!is_inside_tree()" is true. Returning: false @ can_process`。探针 `tests/probes/_probe_can_process_err` 试过 9 种写法，只有直接对树外节点调 `can_process()` 能打出这一条；仓库代码没有直接调用 ⇒ 来源未定。

## 4. 方案

**A 轮空后卡死**
1. 用 `_finals_day_fixture` 造「我在冠军杯第 1 轮轮空」，开记账开关 + 假服务器，走真主菜单 → 对阵图 → 轮空晋级 → 回主菜单 → 商店，全程记 `EconNet.busy` / 每一趟提交的发出与回调、对阵图上的引擎报错（Logger 带调用栈）。
2. 找到没回来的那一趟 ⇒ 修根因 + 门禁（轮空路径走完 busy 必须解开、商店刷新成交）。

**B2 周日局内过场 = 桌面地图为底 + 对阵卡融进去（11-22 设计，按用户 U2）**
- 周日现在的三处另一套：开场 `finals_vs_intro`（静态海报式 VS 卡）、换路 `finals_watch_hud` 平面「战果」横幅、收尾 `finals_end_beats`；平时那套 `lane_map_intro`（桌面地图 → PK 屏 `_build_vs` → 地图战果打叉）周日没用上。
- 开场约 6 秒：桌面地图亮起 + 桌沿金边 / 四角火盆（决赛日标识）→ 顶上缎带从中间展开「冠军杯赛 · 半决赛 · 第 1 场」→ 双方名牌左右冲入砸在桌边（头像 / 名字 / 「B 组冠军」/ 闯关战绩 / 卫冕）+ 震屏尘土 → 中间龟甲 VS 盾徽从天砸下 + 冲击波 → 三只统领棋子依次跳上各自的路 → 接平时：镜头推进上路 → PK 屏开打。
- 每路打完：用平时的桌面地图战果（输的路打叉）+ 周日桌边记分牌金字翻牌 1:0；去掉平面「战果」横幅。
- 收尾：保留周日卡（本轮奖励 / 名次 / 观看下一场），加动画：名牌滑入 → 比分从 0 跳到终值 → 「胜 / 惜败」印章砸下 → 奖励逐项弹出；修「惜败」出场那一下的半透明穿帮。
- 美术迭代按规矩本机做、录视频给用户看，点头后才提交 / 预检 / CI。

**B 全流程走查**（用夹具 + 真场景，一屏一屏录，问题记清单）
1. 周日主菜单：决赛日卡、倒计时、我这一路、开播横幅、观看按钮。
2. 小组赛：对阵图、开播倒计时、我的比赛（跟播）、别人的比赛（观战）、结果翻面、组冠军。
3. 冠军杯：8 签、轮空、每轮开播、半决赛、决赛、夺冠演出、冠军墙。
4. 局内：开场 / 换路 / 结算各段过场，和积分赛、周六闯关赛逐段对照（B2）。
5. 中途进直播（B1）：开播 1 分钟后进 ⇒ 现在看到什么。
6. 每个按钮：返回、观看、补看、冠军墙、分享 / 战绩……逐个点。
产出：问题清单（截图 / 视频 + 现在 vs 应该）+ 优化建议 ⇒ 用户拍板后实施。
