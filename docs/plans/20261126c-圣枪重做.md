## 3. 需求 ↔ 代码的出入

- 「任意护盾」在代码里是三个字段（`shield` / `magic_shield` / `phys_shield`），只接 `_grant_shield` 会漏魔法 / 物理护盾 ⇒ 三处都接。吸血溢出转盾不走 `_grant_shield`，也接。
- 温泉蛋按自己存的基准重写攻击间隔：圣枪等级若各算各的，两件同带会互相覆盖攻速 ⇒ 两者共用「本单位临时等级总数」算攻速。

## 4. 方案

- 效果一（每一路一次）：首次生命 < 50% ⇒ 圣枪护盾 40% / 60% / 100% 最大生命值（不衰减、路末清；走 `_grant_shield` 永久盾，所以也会存进储能条）+ 护甲魔抗 +30 / +50 / +100（buff 到路末）。
- 效果二：储能 `eq_state[ck]["store"]`，上限 100% 最大生命；每件各自存（同一件带多件各自独立）。每 12 秒开始引导，每 0.25 秒耗 500 / 400 / 300 出一个光球，不够就结束；引导期间照常行动（用户没说要定身，默认不定身）。光球从场上（友方统领 + 小将含自己，敌方全部可选中单位）等概率随机挑一个，按速度 900 飞，碰到才结算。
  - 友方：临时等级 +1（+5% 基础攻 / 双抗 / 最大生命，攻速 +2%，与温泉蛋同规则共用计数）+ 回复 150 / 250 / 400。
  - 敌方：魔法伤害 150 / 250 / 500 + 携带者护盾 60 / 100 / 200（存回储能条）。
- 基础属性改坦克：生命 200 / 450 / 2500，护甲 15 / 30 / 120，魔抗 15 / 30 / 120（对齐 5 费坦克 106）。
- 文案、档位标签、信息面板「储能 N / 上限」、头顶徽章；特效（光球、引导、圣枪护盾、友方 / 敌方命中）另走美术流程（§10），用户点头前不推。

穷举改点：`eq_spear_batch.gd`（常量、on_damaged 半血、tick_unit 引导、光球飞行、_live_mirror）；`battle_damage.gd _grant_shield` + 吸血溢出；`magic_shield.gd`；`eq_mask_batch.gd` 物理护盾；`equip_tick_system.gd` 温泉蛋攻速共用计数；`RealtimeBattle3DScene.gd` 显示等级；`equip_stats.gd`；`equip_tier_labels.gd`；`data/phase2-equipment.json` + 审查表；`locale/en.po`；测试 `verify_spear_items.gd` 146 段重写。`RULES_VER` 本周已升过。
