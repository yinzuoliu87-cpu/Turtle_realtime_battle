日期：2026-11-24　|　状态：**已拍板**

## 2. 调查结论

**现状（实测）**
- 大羁绊 10 个：剑 / 盾 / 枪 / 弓箭 / 法器 / 灵物 / 奇械 / 食物 / 遗物 / 药水，每个 9–10 件，共 93 件；另有小木斧（斧头）、香火石（遗物 / 香火）各 1 件（`Phase2Types.types_of` 逐件数，2026-11-24）。
- 羁绊档位与加成：`scripts/gamedata/phase2_types.gd` `TYPES`（多数 3 / 6 / 9 件三档，奇械 2 / 5 / 8 / 10 四档）+ `TIER_DESCS` 文案。
- 商店可刷 95 件，费用分布 1 费 23 / 2 费 20 / 3 费 20 / 4 费 19 / 5 费 13（`data/phase2-equipment.json` `shopAvailable = 1`）。
- **每周 16 抽 10、每个 9–10 件 ⇒ 当周池约 95 件，和今天整个商店的件数一样** —— 商店密度、三合一难度基本不变，这是这个设计成立的关键。
- 经济每周归零：`scripts/referee/econ_replay.gd` `week_start` 把背包 / 身上 / 卡池 / 货架等全部重置为新号状态 ⇒ **不存在「上周买的装备这周不在池里」的跨周问题**。
- 现成的「每周全服同一份、纯函数」先例：`scripts/gamedata/weekly_free.gd`（FNV-1a 排序，种子 = 账号 + 周锚点，客户端 / 裁判同一个函数，有独立 Python 金标门禁 `verify_weekly_free`）。本周羁绊照抄这一套，种子只用周锚点（全服同一份）。
- 服务器记账重放永远用装着的最新版本（`server/referee/referee_poller.py` `econ_project`），掷货在 GDScript 里 ⇒ 轮换规则只要是周锚点的纯函数，客户端与服务器重放天然一致；不需要 SQL 版本。

**参考（别的游戏怎么按类型分装备）**
- 《土豆兄弟》（Brotato）：每把武器属于一到多个类别（锋刃、钝器、元素、枪械、重型、支援、精准、中世纪、医疗、徒手……），同类凑得越多、类别加成越高（到第 6 件为止）—— 与我们「按类型出羁绊」最像。来源：[Brotato Wiki · Weapon class](https://brotato.wiki.spellsandguns.com/Weapon_class)。
- 云顶之弈：按「职业 / 羁绊」凑人口；每个赛季轮换一批羁绊（与本方案「每周轮换」同思路，只是周期更长）。
- 《杀戮尖塔》《哈迪斯》：武器 / 遗物各有鲜明玩法，一件看图就懂干什么 —— 新装备起名、出图按上一份方案书（20261124c）的去 AI 味标准。

## 3. 需求 ↔ 代码的出入

- 现有 10 个羁绊里，**弓箭靠暴击、法器靠法力满了放主动** —— 新羁绊「匕首」「魔法书」要刻意和它们拉开玩法，否则就是换皮（见 §5 R-2）。
- 种子快照是一次性预生成的，里面混着全部羁绊的装备；本周轮换以后，垫底的种子对手可能带着「这周商店买不到」的装备（见 U3）。
- 「每周抽 10」要等 16 个都做完才有意义；做完之前的过渡期怎么处理（见 U4）。

## 4. 方案

### 4.1 新羁绊候选（用户从中定 6 个，可另加）

按「武器 / 物品类型」，每个都要和现有 10 个玩法拉开：

| 候选 | 一句话玩法 | 和现有羁绊的区别 | 参考 |
|---|---|---|---|
| **匕首** | 刺客：首击 / 背刺加伤、闪避后反击、击杀后瞬移到下一个目标 | 弓箭是远程暴击处决；匕首是贴身首击 + 闪避 | 云顶刺客、Brotato 锋刃 |
| **魔法书** | 每打 N 下翻一页，按页施放不同法术（火 / 冰 / 雷轮流） | 法器是法力满了放一个大招；魔法书是普攻节奏里穿插小法术 | 《魔法工艺》Noita、杀戮尖塔能力牌 |
| **拳套 / 爪** | 徒手连打：攻击越快叠层越多，满层打出一记重拳 | 枪也加攻速，但枪是远程金弹；拳套是近战连段 | Brotato 徒手 |
| **长矛 / 戟** | 长柄：攻击距离远、穿透一排，第一下必定击退 | 剑是加攻击力 + 回响；长矛是射程与穿透 | Brotato 中世纪、各类 RPG 长柄 |
| **炸弹 / 投掷** | 定时投出炸弹，延时爆炸、范围伤害、可连锁 | 药水的毒瓶 / 燃烧瓶是单件效果；炸弹羁绊整类围绕范围与引爆 | Brotato 爆炸 |
| **乐器** | 演奏给全队上光环：鼓 = 攻速、号角 = 护盾、琴 = 回血，节拍越久越强 | 食物也是全队加成，但食物是开局给血；乐器是持续光环 | Brotato 支援 |
| 锤 / 重武器 | 慢而重：每下眩晕、破甲 | 与长矛二选一（都是近战重击路线） | Brotato 钝器 / 重型 |
| 鞭 / 锁链 | 拉拽与控制：把后排拉到前面 | 训龟大师已有钩锁，注意别撞 | 恶魔城 |
| 陷阱 | 在地上布置，敌人踩中触发 | 地面类效果目前很少 | 塔防类 |
| 面具 | 戴上变身：换一套属性与普攻 | 变脸龟已有「变身」主题，注意别撞 | 塞尔达·姆吉拉的假面 |

**我的建议 6 个**：匕首、魔法书、拳套、长矛、炸弹、乐器 —— 六种打法互不重叠（贴身首击 / 普攻穿插法术 / 近战连段 / 射程穿透 / 范围爆炸 / 全队光环），也都能一眼看图认出类型。

每个羁绊：档位照现有惯例 3 / 6 / 9 件三档（或奇械那样四档），每档一条属性 + 一条机制；9–10 件装备，费用分布照现有比例（每羁绊约 1 费 2–3 件、2 费 2 件、3 费 2 件、4 费 2 件、5 费 1–2 件）。

### 4.2 每周轮换机制

- **本周羁绊** = `WeeklySynergy.of_week(周锚点)`：16 个大羁绊名按 FNV-1a(「周锚点|羁绊名」) 排序取前 10（与 `WeeklyFree` 同一套写法，纯函数、不读钟不读档、不用引擎随机）；独立 Python 实现算金标做门禁。全服同一份。
- **所有随机产出装备的地方**（§2 表）一律经一个过滤函数 `WeeklySynergy.in_pool(装备id, 周)`：属于本周 10 个羁绊之一，或者是非大羁绊的特殊件（小木斧、香火石）⇒ 可以出；否则不出。
- **多羁绊装备**（一件同时属于两个类型）：只要有一个类型在本周池里就可以出（U2 可改）。
- **界面**：商店顶部一排「本周羁绊」10 个小图标；图鉴里不在本周的羁绊 / 装备标灰「本周不出」；背包羁绊面板只列本周 10 个。
- **服务器**：不用改 SQL（掷货与重放都在 GDScript）；对手池（种子 / 机器人）按 U3 处理。
- **规则版本**：上线那一版 `RULES_VER` +1（商店出货变了 ⇒ 对局结果分布变了）。

### 4.3 分期

| 期 | 内容 | 上线后玩家看到什么 |
|---|---|---|
| P0 | 本方案书拍板：定 6 个新羁绊、轮换规则（U1–U4） | 无 |
| P1 | 轮换机制 + 界面 + 全部出处过滤，开关默认关（16 个凑齐前不打开） | 无（机制先进代码、门禁守住） |
| P2–P4 | 每期做 2 个新羁绊（约 20 件）：效果代码 → 特效 → 图标 → 文案 / 英文 → 音效 → 平衡测试 → 用户看录像认可 | 新装备进商店（轮换开前 = 全部羁绊都出，商店变大） |
| P5 | 16 个齐了，打开轮换开关（用户 11-24：做好一批随周一换版上一批） | 每周商店只出 10 个羁绊 |

（P2–P4 期间商店会从 95 件涨到最多约 155 件，三合一会变难；要不要等 16 个齐了再一起放出，见 U4。）

## 5. 已知风险与未决点

- **U1（要用户定）**：6 个新羁绊选哪几个（§4.1 候选，我建议匕首 / 魔法书 / 拳套 / 长矛 / 炸弹 / 乐器），每个羁绊的核心玩法一句话。
- **U2（要用户定）**：轮换规则 —— 纯随机抽 10；还是加约束（例：同一个羁绊不连续 3 周缺席 / 相邻两周至少换掉 3 个 / 新羁绊上线那周必出）。
- **U3（要用户定）**：种子快照、兜底机器人带了「本周池外」的装备怎么办 —— (a) 对手可以带（它们是别的周的阵容，合理）；(b) 只挑装备全在本周池里的种子；(c) 按本周池重新生成。我倾向 (b)：玩家看到的对手装备都是这周自己也买得到的。
- **U4（要用户定）**：上线节奏 —— 16 个齐了一次性放出并开轮换；还是做好一批放一批（商店先变大）。我倾向**做好的先藏着，16 个齐了一起放**（商店大小不中途变、三合一难度不中途变）。
- R-1 工作量：60 件新装备，每件效果代码 + 特效 + 图标 + 文案 + 英文 + 音效 + 门禁 + 平衡，按以往速度每期（2 个羁绊、约 20 件）要一到两周；全部约 1–2 个月。
- R-2 换皮风险：匕首 vs 弓箭（暴击）、魔法书 vs 法器（法术）、乐器 vs 食物（全队加成）玩法相近，设计时每个羁绊先写「它独有的那一条机制」再出装备。
- R-3 平衡：每周池组合不同（C(16,10) = 8008 种），要有「随机抽 N 周池、各跑一批模拟局」的强度检查，避免某些周某羁绊一家独大。
- R-4 一致性：每个随机出装备的地方漏一处过滤，就会出现「这周不出的装备」；门禁要静态扫全部 `phase2_equipment` 遍历点 + 运行时抽样。
- R-5 图鉴 / 教程：教程固定给的装备必须是不受轮换影响的（或教程时视为全池），否则教程某周会卡住。

## 6. 验收标准

- 轮换：同一周锚点在客户端、裁判重放、Python 金标三处算出同一份 10 个；连续 104 周每周恰好 10 个、都在 16 个之内（分母打印）。**先证明会 FAIL**：把排序键改成不含周锚点 ⇒ 每周都一样 ⇒ 门禁红。
- 过滤：每周掷货 1000 次、糖果罐 / 宝箱 / 对局随机给装备各 200 次，出现的装备 100% 在本周池（或特殊件）；故意绕过一处过滤 ⇒ 红。
- 静态扫描：所有遍历 `DataRegistry.phase2_equipment` 且会产出装备的地方都经过 `in_pool`（白名单登记理由）。
- 每个新羁绊：9–10 件、费用分布在规定范围、档位文案与数值对账（现有 `verify_synergy_text` / `tooltip_number_audit` 覆盖）、图标过 `icon_art_audit`、用户看录像认可。
- 界面：商店「本周羁绊」、图鉴「本周不出」两比例实拍。

## 7. 决策记录

- 2026-11-24 起草；等用户定 U1–U4。
- 2026-11-24 用户拍板（原话：「可以匕首魔法书，全套长矛炸弹乐器，嗯，全套可以换面具啊…轮换的话…纯随机就好了。垫底的种子对手，如果带着本周商店购不到装备…你得想办法处理一下…上线节奏一样是…下周换版的时候上就可以了」；「全套」= 语音的「拳套」，「沉睡机」= 「纯随机」）：
  - **U1** 6 个新羁绊 = **匕首、魔法书、面具、长矛、炸弹、乐器**（面具顶替拳套）。
  - **U2** 轮换 = **纯随机**每周 16 抽 10，不加约束。
  - **U3** 交我处理 ⇒ 挑种子对手时**只挑装备全在本周池里的种子**；一份都没有 ⇒ 退到兜底机器人，机器人装备也只从本周池抽（玩家在对手身上看到的装备这周自己都买得到）。
  - **U4** 照平常节奏：做好一批、随周一换版上一批（不等 16 个齐）；16 个齐了再打开轮换开关。过渡期商店比现在大（我已向用户说明影响）。

- 2026-11-24 用户：「（筹码）就可以嘛。我们来个筹码，然后替换掉这个长矛吧，把长矛给替换掉了。」⇒ **最终 6 个新羁绊 = 匕首、魔法书、面具、筹码、炸弹、乐器**（筹码替换长矛），共 16 个。
