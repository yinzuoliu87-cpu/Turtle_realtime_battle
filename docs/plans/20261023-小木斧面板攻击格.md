# 局内小木斧面板补「攻击」格

日期：2026-10-23　|　状态：已完成

> **v0.21.10**（2026-10-23）带上本方案全部改动；推 tag 走 TestFlight。

## 1. 需求原文

- 用户 2026-10-23（附局内截图：点开小木斧的信息面板，只有「技能 / 被动」两格）「这里为什么没有写攻击」
- 2026-10-23「攒到下一批」→ 同日「出个包，然后给我下testflight测试的邀请连接」

## 2. 调查（改之前的现状，代码实查）

- 龟的「攻击」格取自资料表技能池第 0 条（`info_panel._skill_bar_entries`）；斧头召唤物不在龟资料表里，走单独的 `_axe_entries`（2026-10-22 做的），只有 主动 / 窃取护盾 / 当前形态 三格，漏了攻击。
- 斧头普攻：`RealtimeBattle3DScene._basic_attack` 里斧头没有专属分支 ⇒ 走 `DEFAULT_BASIC`（`BasicConsts.DEFAULT_BASIC_COEF` = 1.0 倍攻击力物理伤害）。
- 用户原话 `docs/plans/20260831-用户原话-小木斧.txt` 第 8 行「近战，普攻造成1ATK，攻速为0.8每秒」—— 与代码一致。
- 面板内容宽 300 = 3 格（`SLOT` 88 × 3 + `SLOT_GAP` 18 × 2）。

## 3. 需求 ↔ 代码的出入

- 没有出入：普攻机制本来就在，只是面板没写。
- 直接加第 4 格会把面板撑出屏幕右边（实拍铁斧：第 4 格与最右一列属性被裁掉）。

## 4. 方案

- `_axe_entries` 补「攻击」：「{斧头名}攻击当前目标，造成 (100% 攻击力) 物理伤害。」走 `SkillText.live_formula_bb` 按斧头攻击力写结果 + 拆解行，系数取 `BasicConsts.DEFAULT_BASIC_COEF`。
- 与龟同为 3 格「被动 / 攻击 / 技能」：窃取护盾与已解锁各档的被动合进一格（进化后以斧头名为题，第一句是窃取护盾，下面「【石斧】：…」逐档）。

## 5. 已知风险与未决点

1. 被动合并后，进化到最终造物时那一格文字较长（窃取 + 5 档 + 造物），靠卡片滚动；没有逐档拆格。
2. 窃取那一句不加「【窃取护盾】」小标题：关键词上色会在「护盾」前插图标，标题变成「【窃取〇护盾】」。

## 6. 验收清单

- [x] 技能行 3 格、行宽 ≤ 面板内容宽 300（`verify_axe_info_panel`）
- [x] 攻击格数字 = 斧头攻击力 × `DEFAULT_BASIC_COEF`，铁斧 / 小木斧两种名字（`verify_axe_info_panel`；变异：不出攻击格 ⇒ 4 条红）
- [x] 被动格先窃取后逐档、小木斧没有形态行（`verify_axe_info_panel`）
- [x] 战斗界面字面量不带全角括号（`verify_hud_gamefeel` ②；CI 分片 3 抓到后改半角，换算后玩家看到的不变）
- 另：实拍人工看过（`tests/_shot_axe_battle.tscn`，1560×720；不是门禁，不打勾）
