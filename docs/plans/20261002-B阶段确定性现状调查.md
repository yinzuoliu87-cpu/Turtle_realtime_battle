**「38/38 全走 `_reg_tween()`」是本节最重要的一个数**，因为：

```gdscript
# RealtimeBattle3DScene.gd:2389
func _reg_tween() -> Tween:
    var t := create_tween()
    if _deterministic: t.pause()        # det 模式不让 SceneTree 按真实 delta 推它
    _sim_tweens.append(t)

# RealtimeBattle3DScene.gd:2373 / 从 :2311 的 _sim_step 末尾调
func _step_sim_tweens(dt: float) -> void:
    if not _deterministic: return
    if not _timestop._ts_active.is_empty(): return
    for tw in _sim_tweens.duplicate():
        if tw != null and tw.is_valid(): tw.custom_step(dt)
```

⇒ **det 模式下这 38 处的结算时刻全部落在 sim 步上，一处都不在渲染帧上**。
方案书 §8.2 那一刀（一处收口覆盖 515 个注册点）是真的，而且守得住：
`tools/tween_freeze_audit.py` 是台账式棘轮（当前 5 文件 / 17 条豁免，全是 UI / 飘字 / 时停自己的演出），
谁再写一处裸 `create_tween()` 就得去白名单里登记 ⇒ 顺带把「以后不会有人在裸 tween 里结算」这件事挡住了
（方案书 §8.5 第 3 条写「没有门禁守住」—— 那一条**也过期了**，只是守它的门禁名字叫 tween_freeze，理由写的是时停）。

**所以 B3 剩下的不是确定性，是三件别的**：① 非 det（玩家实际打的那一局）仍挂渲染帧；
② 无头 CI 下 tween 链推进不稳这一类（CLAUDE.md §3.5 海盗钩索）仍然存在；
③ `custom_step(SIM_DT)` 会把 `tween_method` 的回调频率从「渲染帧」降到「sim 步」——
star_system 那条 1.16 秒的波，det 下跑 ~70 次 / 144fps 交互下跑 ~167 次。
命中有 `hitset` 去重所以**次数不变**，但**命中时刻会差半步**。这是 B-R2 的真实形状。

#### ★★这里有一条被所有四份门禁同时漏掉的东西

```
det 模式：          _process → _sim_step(SIM_DT) 一次，_frame_sim_dt = SIM_DT   （恒 1 步/帧）
交互模式：          _advance_sim_accum(rd) → while _sim_accum >= SIM_DT and steps < 8
                    _frame_sim_dt = steps * SIM_DT                              （0~8 步/帧）
```

- `verify_determinism_b` / `_cross` / `_battle_determinism`：**全部 det** ⇒ 永远 1 步/帧。
- `verify_interactive_determinism`：主体不 pump 帧；它唯一 pump 帧的地方
  （`_measure_wait`，`tests/verify_interactive_determinism.gd:82`）喂的是 `_advance_sim_accum(1.0/60.0)`
  —— **也是恰 1 步/帧**。

⇒ **全仓没有任何一条判据跑过「一帧跑 2 个以上 sim 步、同时有协程在推进」。**
而那正是 B2 / B4 全部 14 处协程 + `_wait_sim` 的 25 个调用点所在的那条路。
这跟 memory `fb-headless-one-step-per-frame-hides-frame-keyed-bugs` 是同一个坑，
只不过这次藏住的不是「按帧号去重」，是「按渲染帧累加 `_frame_sim_dt`」。

顺带一条交互模式自己的事实：`steps < 8` 封顶 ⇒ 大 hitch 时**余量被丢掉**（`_sim_accum` 留着但那一帧只跑 8 步），
所以交互模式连「总 sim 时间 == Σ钳制 delta」都不严格成立。这不影响 det 回放，但影响「玩家那一局能否复算」。

        if depth>0:
