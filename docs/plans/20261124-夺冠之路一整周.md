# 夺冠之路列冠军一整周（积分赛 → 周六闯关赛 → 周日小组赛 → 冠军杯，每场比分）

日期：2026-11-24　|　状态：**实施中**

## 1. 需求原文

> 用户 2026-11-24（看完冠军揭晓成片、我提议删掉「夺冠之路」那一拍之后）：「嗯，我说夺冠之路需要，但是夺冠之路，夺冠，这夺冠之路，你展示这些，不是人家打的积分赛那十六场啊，然后决那个瑞士轮那几场，然后决赛这几场，呃，这个什么小组赛几场，冠军几场。那比分你都不展都不去展示吗？难道？」

拆成：

| # | 子需求 |
|---|---|
| R1 | 夺冠之路保留（不删这一拍） |
| R2 | 列冠军这一周**全部**比赛：积分赛（16 场）、周六闯关赛（瑞士轮）、周日小组赛、冠军杯 |
| R3 | 每场都有比分 |

## 2. 调查结论

- 现在的夺冠之路只列冠军杯几轮：`ChampionData.path_of`（`scripts/scenes/bracket/champion_data.gd:234`）只读对阵表 `view.cup`；收盘演出 path 拍 `champion_show.gd` `_build_path`、定格卡里那段小字都吃它。组冠军版（`group_show`）同理只有小组那几轮。
- 一整周的对局全在服务器 `referee_jobs`（裁判局，四种 kind：ranked / gauntlet / finals / raid），每行 `result.lane_results` = {top, bottom, final?: left|right}、`result.winner` = a|b。正式服只读实测（11-24）上周冠杯冠军：ranked 16 场（12 胜，全在 a 方）、gauntlet 6 场（4 胜）、finals 5 场（5 胜：小组 2 + 冠军杯 3），`season_week` 都是同一个周锚点。
- 客户端现有读法只有 `my_battle_log`（迁移 20261118b）：只回**自己**的对局。看冠军收盘的大多是别人 ⇒ 要一个按「这一周 + 这个人」取的只读接口。
- 比分：按路数现成可算 —— 胜方赢的路数 : 败方赢的路数（final 也算一路）。与 `phase2_duallane.score_code` 的四种码一一对得上：{top,bottom 同一方} = 2:0；1-1 + final = 2:1；只记一路（上路碎蛋）= 1:0；1-1 后碎蛋 = 1:1。

## 3. 需求 ↔ 代码的出入

- 「积分赛那十六场」：积分赛只算冠军自己出手的（a 方）；别人拿他快照打的 b 方那些不是他打的（与 `my_battle_log` 同一口径）。
- 冠军杯轮空那一轮没有对局 ⇒ 写「轮空」，不编比分、不盖「胜」。

## 4. 方案

| 层 | 做什么 |
|---|---|
| 迁移 `20261124_finals_week_journey` | `finals_week_journey(p_week, p_account)` 只读：只对**这一周决赛日的参赛者**（`finals_entrants`）开放；回 `{ok, rows:[{id, kind, at, won, lanes{top,bottom,final: me|foe|null}, finals{bucket,round,match}, foe{name, avatar, leaders}}]}`，按 job_id 正序，最多 80 行；ranked 只取 a 方，gauntlet / finals 两方都取；authenticated 才能调 |
| `scripts/net/journey_net.gd`（新） | 发请求 + 纯函数 `parse` / `score_of(lanes)` / `stages(rows)`（按 kind 分四段，每段胜负数） |
| `ChampionShow` | 开演就去取（冠军 acc 从对阵表 `accs` 拿）；path 拍改成**四栏**：积分赛 / 闯关赛 / 小组赛 / 冠军杯，栏头写「12 胜 4 负」，每场一行「对 名字  2:1」胜金负灰；回包没到 / 失败 ⇒ 只出冠军杯那一栏（与现在相同）；轮空行写「轮空」不盖章 |
| 定格卡 | 「夺冠之路」那段改成四行：每段一句「积分赛 12 胜 4 负」…冠军杯逐轮 |
| 组冠军版 | 同一套，到小组赛为止 |
| 时长 | path 拍按栏数定长；`CUP_RANGE` / `GROUP_RANGE` 上限各放宽 3 秒 |
