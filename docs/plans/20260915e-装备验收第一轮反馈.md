## 调查

- **068 激光源**：`eq_potion_batch.gd` 的 `beam_org` 只在开火那一刻写一次；`mana_beam_vfx.gd` 的束身 / 枪口 / 飘带节点也钉在开火坐标。转向、照到谁、伤害扫掠三处都读 `beam_org` ⇒ 携带者走开后，画面和伤害都还从原地射出。
- **068 特殊护盾条**：`hp_bar.gd` 里五种特殊盾（圣盾 / 壳盾 / 海胆 / 法力 / 终极）与普通盾一样 alpha 0.6 平铺在 5 像素高的条里，叠在暗红槽上发灰。五种共用同一个画法。
- **064 盾不跟随**：`spirit_eq_vfx.gd` 的 `float_bladder` 在开盾那一刻的坐标建球，`_apply_bladder` 只改尺寸和透明度，不改位置。
- **080**：坠机冲刺 `CRASH_SPD` 900 码/秒；坠机爆炸与地毯轰炸共用 `GunEqVfx.blast`，11 帧 0.55 秒。
- **078**：`tick_unit` 到点就朝最近的敌人开火，不看距离；右管电击弹因此能隔半个战场打人。
- **062 台子**：普通龟闪避率为 0，台子没配闪避 ⇒ 24 秒一次都没触发强化普攻（台子配置问题，不是效果问题）。
- **071 台子**：焦点点位把携带者压在左侧队伍面板下面。

## 出入

- 068「特殊护盾条」：改的是五种特殊盾共用的画法，不是只改法力盾一种 —— 只改一种，另外四种同样看不清。
- 078 的开火距离取左管锥形射程同一个数（400 码），没有另立第二个数；用户没指定数值。

## 方案

1. 068：`_eq_beam_step` 每步把 `beam_org` 刷成携带者当前位置；新增 `mana_beam_vfx.set_origin` 平移束身 / 枪口 / 飘带。
2. 血条：新增 `_seg_special`，五种特殊盾段满不透明 + 上下各一道提亮边。
3. 080：`CRASH_SPD` 900 → 450；`blast` 加时长参数，只有坠机那一炸传 0.55 × 1.4 = 0.77 秒。
4. 078：计时攒满后若最近敌人在 `EEL_FIRE_RANGE`（= `EEL_CONE_RANGE` 400）外，停在满格等；进范围立刻开这一发。文案补「400 码内有敌人才开火」。
5. 074 改名【魔法胸甲】+ 图标按 `tools/icon_art_audit.py` 四条走 PixelLab pro 32×32（与 044 同一条路线）；082 改名【护心甲】。
6. 台子：062 补 `dodge`；新增 `carrier_sway` 配置与 `p2eq_068_move` case 录跟随效果。
7. 数值除用户点名的 080 冲刺速度外一个都不改。
