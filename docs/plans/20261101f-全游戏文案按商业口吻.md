## 3. 需求 ↔ 代码的出入

- 「全游戏」≠ 全部字面量：技能 / 装备 / 羁绊说明 1000+ 条走 LoL 体例（copy_lol_style_lint / tooltip_number_audit 守），羁绊档位说明里的「·」是分条符（`synergy_view.gd:45` 按「 · 」拆成一条一行显示），本轮不动。
- 主会话列的「主菜单「生命已耗尽 · 下周二可参加」」是**赛程卡锁**那一行，不在主菜单首屏上（首屏同状态显示的是左栏「已出局」），一并改。
- 选龟页「本大轮阵容已锁定 · …」改两行会碰到 `verify_gauntlet_online_queue` R 段（「积分赛走的 72 个函数逐字节不动」）：其中 `_build_locked_hint` / `_lockout_toast` 只管画字，不在选人 / 存档 / 出战进匹配流程上 ⇒ 从那张表拿掉这两个（基线 1f8baa93 不动，摘要按同一口径现算 72 → 70），见 R3。
- 排行榜「（暂无其他玩家 · 对战后更新）」：`verify_pool_truth` ④ 要求四档四句话、「对战后更新」只在问到了那一档 —— 这是有意的承诺，只去「·」，留承诺（「（暂无其他玩家，对战后更新）」）。

## 4. 方案（已实施，穷举）

**写法**（与 20261101e 同一套）：一行一件事 —— 第二件换行、写成整句或「标签：值」；状态签 2~4 字；弹窗 / 提示完整句；网络失败一种说法「无法连接服务器。请检查网络连接后重试。」；载入只写「正在载入…」/「载入中」；不口语、不教程腔；并列名词之间的「·」保留并登记理由。数字与汉字之间留空格（与 20261101e R4 一致）。
