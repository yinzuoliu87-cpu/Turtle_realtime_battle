# 时间穿越测试 —— 测赛程不用等日子

日期：2026-10-04　|　状态：**实施中**（代码+门禁已落地，未发版本：版本号/tag 由主会话统一处理）

> 路线图 §四「目标·基础设施」第 3 条。本篇只做**客户端**那一半；内测服手动触发 finals_seat / finals_advance 属于同一条目标的另一半，见 §5 R1。

## 1. 需求原文

用户 2026-10-04：

> 「由于现在我们规定好了每周的哪些天是哪些比赛，那测试的话我们只能等到对应日期，还是我们有什么更好的办法」

派活要求（逐条）：只在开发包生效 / 环境变量 `TURTLE_FAKE_NOW`（ISO 或 `sat 15:00` 简写）/ 「假起点 + 真实流逝」不是冻住 / 设置或调试里有只在开发包出现的入口（周一~周日 + 时刻 +「恢复真实时间」）/ 正式包绝不生效且门禁要证明 / 穿越时主菜单角落显示「测试时间 周六 15:00」/ 写清服务端那一半测不了、在正式服用假时间会写真数据。

## 2. 调查结论

**唯一时钟缝**：`scripts/gamedata/phase2_config.gd` 的 `now_utc()`（2026-09-27 开的，原来只认门禁用的 `now_override_ts`，冻住式）。

**全仓直接读系统钟的地方**（`scripts/` + `autoload/`，2026-10-04 grep `get_unix_time_from_system`）逐个判了「影不影响赛程」：

| 位置 | 用途 | 影响赛程？ | 处理 |
|---|---|---|---|
| `MatchmakingScene.gd:120` `_now_mm` | **周六走闯关赛匹配还是按场次匹配** | **是** —— 穿越到周六时主菜单说闯关赛、这里照真实星期几分流 | 改走 `now_utc()` |
| `GameState.gd` `ensure_season()` / `is_season_expired()` / `start_new_season()` ×2 | 周锚点（滚轮 / 新赛季起点） | **是** —— 跨周穿越时相位说下周、周锚点还停在本周 | 改走 `_P2.now_utc()` |
| `supabase.gd` ×4 | 令牌过期 | 否（必须是真时间，否则令牌判错） | 不动 |
| `backend.gd:1241` / `ghost_uploader.gd` / `replay_uploader.gd` ×2 | 上传给服务器的时间戳 / 重试退避 | 否；**而且不该假**（会往服务器写假时刻） | 不动 |
| `RealtimeBattle3DScene.gd:7679` + `RecordScene.gd:525` | 战绩「几分钟前」（同一对真时钟相减） | 否 | 不动 |
| `GameState.gd:1445` | 存档备份文件名 | 否 | 不动 |

其余赛程相关的读法（主菜单 `_now_ts()`、对阵图 `_clock()`、选龟封盘、`settle_*`、`autopilot_finals`、`RecordScene` 重放窗口、`backend` 快照新鲜度）**早就**走 `now_utc()`（2026-09-28/29 两轮收口），这次不用动。

**「这是不是正式包」的现成判据**：`OS.is_debug_build()`（release 导出模板下为 false）+ `SHIP` 环境变量强制按正式包语义 —— `RealtimeBattle3DScene._review_demo()` 与设置页调试场入口用的就是这一套。iOS 测试包是 `--export-debug`（`ios-build.yml:66`）⇒ 测试者手上的包**是开发包**，入口会出现，这正是要的。

## 3. 需求 ↔ 代码的出入

| 需求说法 | 事实 |
|---|---|
| 「设置/调试里加入口」 | 设置页调试场入口的 gate 是 `OS.is_debug_build() or DEVTOOLS` —— **`DEVTOOLS` 在 release 包里也能打开**。时间穿越**不复用 DEVTOOLS**（改时钟比进调试场危险：会让客户端往服务器报假周号），只认 `is_debug_build() and not SHIP` |
| 「主菜单角落显示『测试时间 周六 15:00』」 | 赛程全程按 **UTC**（E2 拍板），简写 `sat 15:00` 也是 UTC ⇒ 角标写成「测试时间 周六 15:00 **UTC**」，免得测试者按本地时间理解差一小时 |
| 「主菜单周条高亮周六」 | 周条走 `_now_ts()` → `now_utc()`，接上缝就自动跟，不用改周条代码 |
| 手机上设环境变量 | iPhone 没有环境变量 ⇒ 环境变量只是桌面入口，**手机靠设置页那一屏** |

## 4. 方案（实际落地）

| 文件 | 改动 |
|---|---|
| `scripts/gamedata/phase2_config.gd` | `now_utc()` 优先级：`now_override_ts`（门禁冻住）> 穿越偏移 > 真实钟。新增 `TRAVEL_ENV` / `travel_offset_sec` / `time_travel_allowed()` / `travel_active()` / `parse_fake_now()` / `travel_to()` / `travel_to_weekday()` / `travel_reset()` / `travel_label()` / `travel_badge_text()` / `WEEKDAY_CN`。存的是**偏移**（假 − 真）⇒ 时间照常往前走。环境变量**只在第一次读时钟时读一次**；「恢复真实时间」后不会再冒回来。**每次读时钟都判一次** `time_travel_allowed()`（不是只在设偏移时判）|
| `scripts/scenes/MatchmakingScene.gd` | 分流那一行改走 `now_utc()` |
| `autoload/GameState.gd` | 滚轮/新赛季四处改走 `now_utc()` |
| `scripts/scenes/MainMenuScene.gd` | `_travel_badge()`：穿越时版本号上方挂一行橙字（节点名 `DevClockBadge`）；没穿越一个节点都不建。`_WD_CN` 改引用 `phase2_config.WEEKDAY_CN`（同一份星期名） |
| `scripts/scenes/SettingsScene.gd` | 「测试时间」按钮与调试场**并排一行**（不加竖向高度——加一行会把重置键推下去，账号行四行时撞底部提示）；gate = `time_travel_allowed()` |
| `scripts/scenes/settings/time_travel_panel.gd`（新） | 弹层：周一~周日七个键 / ±1 时 ±5 分 / 「穿越到这一刻」「恢复真实时间」「关闭」。逻辑一行不在这里，全调 `phase2_config` |
| `tests/verify_time_travel.gd`（新） | 门禁，见 §6 |

### 怎么用

```bash
# 桌面（编辑器 / debug 包）：简写 = 本周那天的 UTC 时刻；也可写完整 ISO
TURTLE_FAKE_NOW="sat 15:00" <godot> --path .
TURTLE_FAKE_NOW="2026-10-11T08:05Z" <godot> --path .
```

手机（iOS 测试包）：主菜单 → 设置 → 「测试时间」→ 选星期几和时刻 →「穿越到这一刻」→ 返回主菜单（角标出现、赛程条「今」移到那一天）。用完点「恢复真实时间」。偏移**只活在本次运行里**，杀进程重开即回到真实时间。

## 5. 已知风险与未决点

### ⚠⚠ 警告：不要在正式服上用假时间打周六 / 周日

**客户端穿越不会骗过服务器，但会让客户端往服务器写真数据。** 正式服上穿越到周六打闯关赛 = 往生产的快照池里传一份带闯关标签的真快照（`gl_w/gl_l`）；穿越到周日点决赛报名 = 往生产 `finals_*` 表里写真报名行（`p_week` 用的是客户端算的周锚点——跨周穿越时**连周号都是假的**）。这些行别的真玩家看得到、会被 `finals_seat` 当真分组。
⇒ **测周末赛程只连内测服**（路线图 §四 基础设施第 1 条：内测服/正式服分开）。在那之前，用穿越测周六/周日时**关掉后端**（`TURTLE_BACKEND=" " TURTLE_SUPABASE=" "`），只测客户端那一半。

### 客户端穿越能测什么 / 不能测什么

| 能测（纯客户端） | 不能测（服务端照真实时间走） |
|---|---|
| 周几分流：主菜单赛程条「今」、收盘块文案、能不能开打（封盘闸 `can_start_match_utc`） | 决赛**分组**（`finals_seat`，pg_cron 周日 08:00 UTC） |
| 匹配走闯关赛那条还是按场次那条（`MatchmakingScene` 分流） | 决赛**轮次推进**（`finals_advance`，pg_cron 周日每分钟） |
| 闯关/决赛界面、对阵图 `_clock()`、结算口径（`settle_kind` / 配额 / 晋级补算） | 决赛 3 分钟购物倒计时 —— 走的是**服务端钟** `srv_now`（`supabase.gd:1955`），客户端穿越改不了它 |
| 倒计时（周五/周六 23:00 收盘）照真实流逝往下走 | 服务端按 `date_trunc('week', now())` 算的周号、重放到期清理 |
| 跨周：滚轮 / 新赛季（见 R2） | 别人的快照新鲜度（服务端写入时间是真的） |

服务端那一半要在**内测服上手动触发** `finals_seat` / `finals_advance`（用假周号），是路线图同一条目标的另一半，本篇没做。

| # | 风险 / 未决点 | 状态 |
|---|---|---|
| R1 | 服务端赛程（分组/推进/srv_now）测不了，见上表 | **未决**（等内测服） |
