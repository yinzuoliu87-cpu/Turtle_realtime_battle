## 2. 调查结论

- **导出预设**在：`export_presets.cfg:46-87`（preset.1「Android」）—— 只出 arm64-v8a、非 gradle、`permissions/internet=true`、`version/code=12`、`package/unique_name="com.turtlebattle.realtime"`。
- **签名是调试证书**：`export_presets.cfg:75-77` 指 `AppData/Roaming/Godot/keystores/debug.keystore`（androiddebugkey / android）。调试证书谁都能复现，不能拿来对外发；而安卓「覆盖安装更新」要求新旧包同一张证书 ⇒ **第一次对外发就必须是正式证书**，之后换不了。
- **最后一次出包** 09-29：`build/android/斗龟场-v0.19.472-wip.apk`（199 MB）。之后没出过；`.github/workflows/` 里只有 `testflight.yml` 出 iOS，没有安卓。
- 渲染 `gl_compatibility`（`project.godot:70-71`），ETC2/ASTC 已开（`project.godot:72`；没开时无头导出报空白错误，见 `docs/实时版APK打包.md` §三）。
- 应用名：`project.godot:17` `config/name="斗龟场 实时版"`；iOS 上架名是「斗龟场」。
- **强更挡墙的安卓链接是假的**：`scripts/scenes/version_wall.gd:36` `STORE_URL_ANDROID` = Google Play 详情页，而应用不在 Play ⇒ 安卓玩家撞墙会打开一个不存在的页面。
  顺带：`version_wall.gd:34` `TESTFLIGHT_JOIN_CODE` 是空的 ⇒ iOS 撞墙去的是 TestFlight 首页，不是公开链接 `join/tx8zK2Gu`（`ios_store_url()` `version_wall.gd:56-62` 两个都空就退回首页）。
- **账号不依赖平台**：匿名号 + 邮箱验证码补绑 / 换设备（`scripts/net/supabase.gd:858-862`）；主站绑定开系统浏览器（`scripts/net/mainsite_link.gd:492-497` `OS.shell_open`）+ 轮询结果 ⇒ 安卓走同一套。
- **安卓返回键**：`project.godot` 没设 `application/config/quit_on_go_back`、脚本里没处理 `NOTIFICATION_WM_GO_BACK_REQUEST`（全仓 grep 0 处）⇒ 按 Godot 默认，返回键直接退出游戏（**未在真机验**）。
  - Godot 4.6.3 源码（11-18 读 GitHub `4.6.3-stable`）：实体 / 导航栏返回键走 `GodotInputHandler.onKeyDown`（返回 true 吃掉）→ `android_input_handler.cpp:133-139` 发一次 `WINDOW_EVENT_GO_BACK_REQUEST` **再**发一个 `Key::BACK` 按键事件；`Godot.kt:1134-1139` `onBackPressed` → `GodotLib.back()`（`java_godot_lib_jni.cpp:255-262`）只发 `GO_BACK_REQUEST`、没有按键事件。⇒ **唯一两条路都有的信号是 `NOTIFICATION_WM_GO_BACK_REQUEST`**；只把 `Key::BACK` 绑进 `ui_cancel` 会漏掉第二条路。
  - 现有页面的「返回」靠 `ui_cancel`（ESC）：`CodexScene.gd:187`、`FriendsScene.gd:88`、`GauntletBoardScene.gd:105`、`InventoryScene.gd:275`、`RecordScene.gd:82`、`ShopScene.gd:347`、`MainMenuScene.gd:1969`（只关周赛弹窗）、`tutorial_chrome.gd:65`（教程里吞掉）；带「←」字样的脚本 35 个，没接 `ui_cancel` 的要逐个列。
- **发版流水**（CLAUDE.md §3）：推 tag → `testflight.yml` 出 iOS；`tools/deploy.py` 装裁判机 / 陪练号 / 网页播放器（`tools/deploy.py:1-30`）；没有安卓那一步。
- **Google Play**（11-18 网上查，来源是第三方博客，Google 帮助页 answer 14151465 原文未打开核对）：2023-11-13 之后注册的个人开发者账号，每个新应用要 12 人连续封闭测试 14 天才能申请正式上架，加上审核约三周；注册费 25 美元。

## 3. 需求 ↔ 代码的出入

- Tom 问「商店链接还是直接下载包」：安卓**两样都没有**。
- 强更挡墙看上去「支持安卓」，但链接是假的。**如果现在把 0.23.4 的安卓包放出去，下周一换版强更时这批玩家会被关在门外、跳到一个打不开的页面** ⇒ 安卓包只能从**带正确链接的那一版**（下一版）开始放，不能补发 0.23.4。

## 4. 方案

| # | 做什么 | 改哪 |
|---|---|---|
| A1 | **正式签名证书**：`keytool` 生成 RSA 4096、有效期 10000 天；放 `~/.config/turtle/secrets/android/`（不进仓库、不打印）；GitHub Secrets 存一份（base64 + 别名 + 密码）。导出时用环境变量 `GODOT_ANDROID_KEYSTORE_RELEASE_PATH / _USER / _PASSWORD`（Godot 文档：环境变量优先于预设；两个密码须相同）。证书 SHA-256 指纹写进仓库 `tools/android_release.py`，出包后 `apksigner verify --print-certs` 核指纹 —— 用错证书直接红 | 本机 secrets、GitHub Secrets、`tools/android_release.py`（新） |
| A2 | **CI 出包**：新 `android.yml`，推 `v*` tag 时跑（ubuntu）：装 JDK 17 + Android SDK + Godot 4.6.3 + 导出模板 → 核 tag = `config/version` → 写入 `version/code` = 主×1000000 + 次×1000 + 序号（0.23.5 → 23005，单调递增、不依赖 run_number）→ `--export-release "Android"` → 核签名指纹 + `aapt2 dump badging` 核包名 / 版本名 / 版本号 → 传到该 tag 的 GitHub Release（预发布，文件 `turtle-arena-<版本>.apk`） | `.github/workflows/android.yml`（新）、`tools/workflow_lint.py` 照常验 |
| A3 | **下载链接用自家域名**：`https://dl.turtlearena.xyz/android`（Porkbun 加一条 DNS 指裁判机，Caddy 302 跳到当前版本那个 Release 文件）。换版窗口里随 `deploy.py --only android` 换跳转目标并回读。给 Tom 的链接永远不变；200 MB 的下载流量走 GitHub 的 CDN，不挤裁判机（开服公告当天集中下载会挤占直播带宽） | `server/dl/`（Caddy 片段 + 换目标脚本，新）、`tools/deploy.py` 加 `--only android` |
| A4 | **游戏里**：`STORE_URL_ANDROID` 换成 A3 链接；`TESTFLIGHT_JOIN_CODE` 填 `tx8zK2Gu`；应用名改「斗龟场」与 iOS 一致；返回键 = 当前页的「←」，主菜单上按返回键弹「退出游戏？」确认框：关掉 `quit_on_go_back`；GameState 下挂一个常驻节点收 `NOTIFICATION_WM_GO_BACK_REQUEST`（同一帧去重）→ 注入一次 `ui_cancel` ⇒ 现有 ESC 返回全部复用；没接 `ui_cancel` 的页逐个补 | `version_wall.gd`、`project.godot`、各场景返回入口（实施前先 grep 全部「←」按钮穷举） |
| A5 | **走查**（真机优先，没有就用本机安卓模拟器）：安装（未知来源提示）→ 首次介绍 / 教程 → 积分赛一局 → 直播 / 录像 → 邮箱补绑 → 主站绑定（跳浏览器再回来）→ 背包 / 商店 → 切后台回来 → 返回键每页按一遍 → 强更挡墙（内测服抬最低版本）。量帧率 | 截图 / 录屏放 `.out/android/` |
| A6 | **发版流水**：CLAUDE.md §3 加安卓一行；`release.py checklist` 加「安卓包 CI 绿 / 指纹对 / 跳转已换 / 回读 200」 | `CLAUDE.md`、`tools/release.py` |
| A7 | **告诉 Tom**：链接 + 一句安装说明（安卓会提示「未知来源」，允许即可） | Telegram |

**上线时间**：随下一版（按正式开跑规则 = 周一 21:00–23:00 换版窗口）一起放，不补发 0.23.4（§3）。

## 6. 验收标准

| 验什么 | 怎么证明会 FAIL |
|---|---|
| CI 在 `v*` tag 上出正式签名包、核过指纹 / 包名 / 版本号 | 在 `ci/android-*` 分支用调试证书签一次 ⇒ 指纹核对红；改 `config/version` 让它和 tag 不符 ⇒ 红 |
| `version/code` 单调 | 单测 `tools/android_release.py` 自测：0.23.5 → 23005 > 12；0.23.10 > 0.23.9；故意写成拼接字符串 ⇒ 红 |
| `dl.turtlearena.xyz/android` 302 到当前版本 | `deploy.py --only android` 回读 Location 头 = 目标版本文件名；换错版本 ⇒ 回读报不符 |
| 强更挡墙链接 | `verify_min_version_wall` 加断言：`store_url_for("Android")` = 新链接、`ios_store_url()` = `join/tx8zK2Gu`；改回占位 ⇒ 红 |
| 返回键 | 新门禁发 `NOTIFICATION_WM_GO_BACK_REQUEST`：每个有「←」的页回上一页、主菜单弹确认框、进程不退出；删掉处理 ⇒ 红 |
| 走查 A5 | 每步截图 / 录屏，逐项打勾 |
