## 2. 调查结论

- 主站调我们已有一套 HMAC 签名网关：`server/referee/mainsite_gateway.py`（GET 签 `ts + "."`，`mainsite_sign.py`），Caddy 反代 `arena.turtlearena.xyz` / `arena-beta.turtlearena.xyz`。新接口挂这里，主站不用再配鉴权。
- 「日活」库里没有按天的历史：`accounts.last_seen` 全仓没人写（正式服只读实测：11-17 起每天 0）。能按天算的来源（正式服只读，11-16~11-22）：`auth.refresh_tokens` 按 `created_at` 去重、`auth.users.created_at`、`referee_jobs` 两侧账号。
- 陪练号（`bot_accounts`，正式服 296 个）会把数字撑大：不去掉 ≈ 100 / 天，去掉后真人 **4–6 / 天**、新增 0–3 / 天。
- `auth.refresh_tokens` 会随会话清理、`purge_junk_anon_users`（04:30 UTC）删空匿名号 ⇒ 过去的日子事后再算会变少 ⇒ 要在当天结束后尽快固定。
- 每周排行榜 = `week_leaderboard`（要求登录、带 account_id / tag / 称号）⇒ 另写一个服务端版本，排序过滤逐条照抄，只回名次 / 昵称 / 胜场 / 剩余生命 / 总场次。
