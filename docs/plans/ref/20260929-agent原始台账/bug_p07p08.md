## ★「卖出 +0」不是设计，是 floor 把 1 费装备的售价算成了 0
- 复现: 背包屏选中任意 1 费 1★ 装备 → 底部按钮写「卖出 +0」; 真卖也是一分不退
- 根因: `scripts/scenes/inventory/equip_ops.gd _sell_value()` = `int(floor(cost * star * 0.8))`
  ⇒ 1 费 1★ = floor(0.8) = **0**; 2 费 1★ = 1; 3 费 1★ = 2。
  而商店「今日货源」里 1 费的出货率是 33%~48%, 是**最常见的那一档** —— 卖它永远 0 币。
- 我的判断: 真 bug(上一轮那条「卖出 +0」的待查现在可以结案)。
  要么 `maxi(1, ...)` 保底 1 币, 要么把按钮文案改成「丢弃」。
