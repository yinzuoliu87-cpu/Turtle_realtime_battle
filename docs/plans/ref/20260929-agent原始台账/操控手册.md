# 操控窗口的工具(给 agent 用)

## 十个槽位
p01..p10，**十个窗口叠在同一位置**（原生 1280×720，1:1，像素清晰），靠 pid 区分。
pid 表：`/c/tmp/turtle-sim10/pids.txt`（第一列槽位号，第二列 pid）。

## 三个命令(只有这三个)
```bash
bash /c/tmp/op.sh focus <slot>            # 把某个窗口提到最前
bash /c/tmp/op.sh shot  <slot>            # 截图 → C:/tmp/s<slot>.png (1280x720)
bash /c/tmp/op.sh click <slot> <x> <y>    # 在窗口内坐标点一下(坐标就是 1280x720 原生坐标)
```

## ★★三条铁律
1. **鼠标是单一共享资源，锁已经做在 `op.sh` 里** —— 你不用管，但**别绕过 op.sh 自己调 PowerShell**，
   绕过去就会和别的 agent 抢焦点，**静默点进别人的窗口**（十个界面一样，点错了看不出来）。
2. **`click` 抢不到焦点会退出码 2 并打印「抢不到焦点」** —— 看到就**重试**，别当成点成功了。
   ★★**绝对不要 `bash /c/tmp/op.sh click ... >/dev/null`** —— 吞掉输出就看不见这条提示，
   于是「我根本没点出去」会被你当成「点了游戏没反应」，立成一条假 bug。
   （2026-09-29 真事：有 agent 因此差点把「满配额点开始战斗没反应」错立案。）
   要静默就只静默 `shot`，**`click` 的输出必须留着看**。
3. **每次点完要截图确认**。本轮已经栽过三次「以为点了其实被模态弹窗吞了」。
   尤其：**教学弹窗是模态的，没关掉之前点什么都没用**，而且**十个窗口的弹窗步数可能不一样**，
   不许一刀切点 N 下就假定都关了 —— **要截图核实**。
