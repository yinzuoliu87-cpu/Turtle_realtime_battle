## 教学第 2 步让手机玩家「把鼠标停在技能图标上」
- 复现: 新号开局 → 选龟屏 → 教学 2/4
- 证据: C:/tmp/p03_bug_hover_mouse.png
- 原文(data/tutorial-steps.json:19): 「点龟头像能在右侧看它的**属性和技能**。把鼠标停在技能图标上看说明；**数值是彩色的**：红=物理、蓝=魔法、白=真伤。」
- 我的判断: 真 bug。这是手机(iOS)游戏, 触屏没有 hover。同一份 json 的 battle 第 3 步还有「滚轮**缩放**、按住左键**拖动视角**」——也是纯 PC 操作。手机上玩家照着做会找不到入口。

## 【待查】敌方「训龟大师」一场打出 3185 伤害, 我方同一个单位只打出 49 —— 相差 65 倍
- 复现: p04 第 2 场(失败 0:2)结算 → 合计页, 敌方「训龟大师」打出 **3185**、击杀 1; 我方「训龟大师」打出 **49**。前几场两边都是 50~110 的量级。

- ★**后来找到了原因**(scripts/scenes/TrainerConfigScene.gd:12): 7 门里**唯一的被动**「魔法石」写着
  「普攻附带 **2% 目标最大生命** 魔法伤害；每次攻击自身 **+3% 攻速(可叠·不封顶·整局不清零)**」。

  而另外 6 门是纯控制/增益 —— 这是**平衡问题**, 不是 bug。值得记一笔: 我照着「打出伤害」这一个读数选, 结论是「只有一门能选」。
- 顺带(同一处代码): 结算「合计」页用 `(阵营, 名字, 该路内同名第几个)` 归并, 所以合计里会有两行都叫「小将」—— 而 MVP 是按**名字**比的(见上面那条), 两者叠加就是双 MVP。

## ★★匹配屏上「你 ID #503911」—— **两个不同的号显示的是同一个 ID**, 因为它只由「第几大轮」算出来
- 复现: p03 开局匹配屏写「你 ID #503911」; p04(完全独立的另一个存档/另一个窗口)匹配屏**也**写「你 ID #503911」。对手的 ID 各不相同(#755428 / #755325 / #678498)。

## 【不是 bug・我查过了】匹配屏入场瞬间整屏泛红

## ★★排行榜那条: 打满之后从「37 人」涨到「**201 人**」, 而真人仍然只有 **10 个**
- 证据: C:/tmp/p04_bug_leaderboard_201_people.png
- 现象: 顶栏写「本周共 **201** 人上榜」; 前 9 名只有 **5 个不同的名字** ——
  `32c6c`(#1 24胜 / #6 23胜)、`77c58`(#2 / #7)、`bc993`(#3 / #8)、`76726`(#4 / #9)、`26e6d`(#5)。
  **每个人都被他自己的上一场快照顶在后面一格。**
- 量化(直接读 p04 的 `ghost_pool.json`): 真人快照 **224 行 / 去重 10 个人**,
  其中 7 个人各占 **24 行**(= 他们各打了 24 场)。
  224 − 24(我自己的被筛掉) + 1(插进去的"我") = **201**, 与屏幕上那个数**逐位相符**。
- ★后果比我上一轮写的更重: 我(p04)打了 **22 胜**, 却排在 **第 16 名** ——
  挤在我前面的 #6~#9 那四行全是**别人的旧快照**(23 胜那一场时的他们)。
  ⇒ 榜的名次现在同时受「打得好不好」和「**同一个人被算了几遍**」两件事影响。
- 判断: 真 bug(与前面那条同根, 只是规模随场次线性放大: 10 人 × 24 场 = 240 行)。

## 【观察·不确定算不算 bug】打满 24 场之后, 商店锁到周六, 而我手上有 **429 枚币**
- 事实: p03 收官时 `meta_deepsea_coins = 429`(p04 是 242), 而商店从配额打满那一刻就锁了。
- 查过的: 周六是闯关赛(`PHASE_MODE_LIVE[GAUNTLET] = true`), 那天 `phase_uses_ranked_quota()` 为 false
  ⇒ `ranked_quota_full()` 返回 false ⇒ **商店周六会重新开**。所以币不是永久作废。
  但 `start_new_season()`(周一换轮) 里有 `meta_deepsea_coins = 0` ⇒ 周一一定清零。
- 体验上: 屏幕右上角一直亮着「429」, 而**唯一**能花它的地方挂着锁, 要等 **3 天 8 小时**(界面自己写的)。
  界面没有任何一处说「你的币周六才能花 / 周一会清零」。
- 我的判断: 待查(可能是有意的赛程设计)。但「钱一直显示、门一直锁着、到期还清零」这三件事凑在一起,
  玩家很容易理解成 bug。
