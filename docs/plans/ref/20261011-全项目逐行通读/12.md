# 第 12 块 通读笔记（sim 驱动 / 28 龟技能系统 / 训龟大师 / util / server + 3 个 SQL migration）

> 只读审阅。行号均为仓库当前版本。核实手段：读被调用/调用方源码、grep、python 只读对账（未启动 Godot）。
> 共用结论先写在前面，避免每节重复：
> - **A. 伤害类型接线缺口（同一形状，多处）**：护甲/魔抗只在 `_resolve_dmg`（RealtimeBattle3DScene.gd:4184）里计算；`_apply_damage_from` → `_mitigate_incoming`（RealtimeBattle3DScene.gd:4447）**没有护甲公式**（shell_system.gd:627-635 自己的注释也这么说）。因此「`_atk_dmg(...) + int(maxHp*pct)`」里 maxHp 那一段、以及直接传一个定额整数且 raw=false 的「物理/魔法」段，都**不吃护甲/魔抗**。违反 memory「伤害类型是接线不是颜色」。且门禁 `verify_dmg_type_sentinel ①d` 看不见「混合式」——`_atk_dmg` 先把 `_dt_resolved` 置 true，后面加上的裸 maxHp 段被当成已结算。
> - **B. 训龟大师站位**：battle_spawn.gd:567-568 把大师放在 `ARENA.x+40 / 中线-150`，按 ArenaShape 椭圆(N=2, rx=798, ry=364) 计算 t≈1.07>1，即**站在岛外**；而且它在 `_enemies_of` 里（battle_targeting.gd:140-146 只排围栏蛋），所以凡是用 `_enemies_of` 求质心/做位移的技能都会把它算进去。
> - **C. 矩形钳位残留**：ArenaShape 头注说 31 份矩形钳位已收口，本块仍有 headless_system.gd:210、hunter_system.gd:87-94、star_system.gd:252/685-687、cyber_system.gd:167/208 按 `ARENA` 矩形钳/求边界。
