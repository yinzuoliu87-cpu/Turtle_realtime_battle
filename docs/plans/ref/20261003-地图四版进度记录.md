## 对照 20 张真实游玩画面得到的结论（11:03）

★推翻了我之前的两条：
- ~~「战斗区几乎是空的」~~ —— 那是 BOSS 宣传图。**真实房间的地面散着大量小碎件**（骨头/石块/草丛/贝壳），低对比、不挡路。
- ~~「镜头近、角色大」~~ —— 真实游玩镜头很远，角色和我们一样小。

真实房间的共同结构（20 张里几乎张张如此）：
1. **平台是全场最亮的东西**，外围压到近黑
2. **边界 = 平台边缘直接断成一道暗色竖崖**，没有墙
3. **边沿被高大的暗色剪影压住一部分**（海草/树干/废墟），尺寸比角色大好几倍
4. **周边一圈彩色小光点**（Darkwood 红烛、Anchordeep 绿/白光球）
5. **地面有纹理**（水下焦散光纹 / 草地夹泥斑 / 砖纹），且散着低对比碎件
6. **一个区域一个主色**（Anchordeep 青绿、Darkwood 黄绿+红点、教程紫）
7. HUD 只有左上几颗心、右上几个小图标

⚠ 与用户已定需求的冲突，照用户的：咩咩房间多是**方块带缺口**的平台，外面是**虚空**；
  用户定的是**圆岛 + 外面是海**。保留圆岛与海，只把海压暗到接近虚空的明度。
