## 怎么量的

- 每个对象单独打一局短局，全程开录流，挂点与裁判机同形：`pre_step` → `_sim_step` → `post_step`（录流器原样，测试里只用子类在 `_samp` / `_node_new` / `_alarm_node` / `_alarm_hit` / `_ensure` 外面包一层记「是哪个节点」）。
- 场地：调试场建场（与 `DetScenarios` 同一套 `_edit_place_unit` / `_edit_start_battle`），满龟能（技能即就绪、回充 ×4）。左队主角 + 半血队友；右队两只会走会打的普通龟（5000 血）+ 一只远处 40000 血假人。
- 龟局 900 步（15 游戏秒）：第 480 步把主角压到 25% 血，第 700 步处决主角（低血 / 死亡 / 复活类被动有触发口）。每只龟的 3 个可选主动技各跑一局。
- 装备局 1300 步：携带者 `basic` 带这一件 3★，第 720 步压血、第 1000 步处决。羁绊局：左队 4 只把该类型全部商店装备（按 id 去重）分着带，1300 步，不压血不处决。小将三种、训龟大师 6 个主动技各一局。
- **出处** = 节点 `add_child` 时的调用栈（跳过 `tests/` 自己的帧）。门禁的键用「文件:函数」（不含行号，免得别处改动挪了行号就红）；下表「样例」列给带行号的 `文件:行 <- 调用方:行`。
- 四样东西：
  1. **白名单外报警**：录流器在 keyframe / 删节点时全量核对，白名单外的属性变了 ⇒ 手机上那个属性停在建节点时的值。
  2. **占位定义**：录流器发出的资源定义里，手机画不出来的那几种 —— 程序贴图（只有类名 + 宽高）、程序网格（只有类名 + 面数）、其它无路径资源（只有类名）。内联 shader 带源码，**能**画，单列备查。计数是「定义发出次数」（每个 keyframe 段重发一次），同一资源只算一次的数见「不重复资源」。
  3. **第三条钟**：每 60 步让出一个引擎帧（SceneTree tween / Timer 在这里跑），前后比镜像节点的变换 / 显隐 / 颜色 / 帧号 / 贴图 / 网格 / 材质颜色；变了 = 录流器在 sim 步之后采样看不到（晚一拍或永远漏）。另记这一帧里被删掉的镜像节点、往 `_world` 加的节点。`GPUParticles3D.emitting` 不比（引擎粒子自己放完，手机端也自己放）。
  4. **分母**：龟 / 小将 / 大师 = 产品自己写的 `skill_cd` / `_active_cd` 抬头次数（与 `verify_determinism_b` cast_probe 同口径）；小将 = 小将技能文件建过的节点数；装备 = 装备统计 `EquipTally` 的产出（伤害 + 治疗 + 护盾）+ 装备统计上下文里建过的节点数，强证据都为 0 时退一级（单列）；羁绊 = 实际档位 == 顶档。

### 读法与局限（先看这一节再用下面的清单）

- **白名单外报警 7 处、第三条钟 1 处（时停蓄力沙漏，2 个属性）是真漏录**：手机上那个属性会停在建节点时的值，或晚一拍 / 永远补不上。其中时停沙漏与 S0 ④ 的结论一致（`timestop_system.gd` 用 `battle.create_tween()`，不走 `_reg_tween`）。`p2eq_033` 复活海螺和「羁绊:遗物」里也出现时停，是因为 033 变成小虫后随机带 3 件装备、遗物羁绊局带着 059。
- **占位定义 129 处是 S3 的主体**：程序贴图 91 处、程序网格 37 处（`ArrayMesh` 20、`ImmediateMesh` 17）、内联 shader 1 处（带源码，手机能编，不算漏画，只列备查）。「其它无路径资源」0 处。最普遍的三项几乎每局都有：单位外观 `battle_spawn.gd:_make_unit`（程序贴图 + 内联 shader，格式 v2 起单位外观进节点层后出现）、命中星芒 `battle_vfx.gd:_hit_spark`。
- 出处键是「文件:函数」。`_adopt` / `_spawn_node` / `_mk_sprite` 这类**通用挂节点函数**会把多个调用方并成一项，调用方看「样例」列。
- **第三条钟只量到一部分**：扫描关掉了战斗场自己的 `_process`（与 `verify_stream_whitelist_alarm` 同一种驱动），每 60 步让出一个引擎帧。`_process` 里非渲染步的部分（HUD、overlay 等）在裁判机上会跑，这里没量；只比了变换 / 显隐 / 颜色 / 帧号 / 贴图 / 像素尺寸 / 文字 / 网格 / 材质颜色 / 透明度。
- **分母**：200 个对象全部 > 0。其中 6 件装备强证据为 0、用的是次一级证据（见「分母」一节）：013 / 014 / 065 是 `eq_state` 变过（硬化层数、油层），041 是涨潮步数，047 是纯属性，059 是时停步数。这几件「效果代码跑到了」有证据，「有没有画面」没有。
- 没覆盖的：双路换路 / 幕布 / 终局（由 `verify_stream_whitelist_alarm` 的真实快照局覆盖）、龟的星级 / 等级差异、装备 1★ / 2★（只跑 3★）、两件以上装备的组合（只有羁绊局是多件）。
