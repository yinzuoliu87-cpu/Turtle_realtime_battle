# 百款游戏赛事日做法 · 第 7 批：全球收入头部休闲手游（10 款）

调研日期 2026-10-31。只收资料，不改代码。

**方法与可信度说明**
- 主证据是实机录屏抽帧（yt_dlp 只下视频轨，抽帧后视频已删）。**因为只下了视频轨，第 10 维里的「音效」全部未核实**，只记了画面动效。
- 图片都在本目录，文件名 = `游戏-维度-内容.jpg`。表里「图」一栏写的是文件名的前半段，能直接对上。
- 出处里 `视频 mm:ss` 指该视频的时间点；网页出处多为攻略站 / 新闻稿，属二手资料，已在格子里标「据…」。
- 「无」= 该游戏没有这项；「未见」= 我看过的素材里没拍到，不代表游戏里没有；「未核实」= 找过但没找到可靠来源。
- 视频年份不一（最早 2015、最新 2026），已在出处里标上传日期，界面可能已改版。

**本批的大背景（先说结论）**：这 10 款**没有一款**是「全员同一时间上线看直播比赛」的形态，它们的比赛几乎都是**异步**的（各打各的关卡 / 跑酷 / 转盘，分数累积到榜上，到点结算）。唯一的直播型是 Candy Crush All Stars 的**线下电视节目式决赛**。所以本批对《斗龟场》最有用的不是「怎么直播」，而是三件事：**怎么揭晓名次、怎么把结算做成一张统一的卡、怎么让没在线的人回来时补上那一刻**。

## 本批共同规律（可执行条目）

1. **结算卡统一成一个模板**（Royal Match、Toon Blast、Coin Master、Monopoly GO、Township 全是这一型）：顶部活动插画 + 「已结束」小签 → 「名次」和「奖励」两个大块并排 → 名次表**每一行都写着该名次的奖励** → 自己那行高亮 → 一个领取按钮。⇒ 斗龟场小组赛每轮、冠军杯每轮、周六闯关赛结算共用一张卡。
2. **自己那一格永远看得见**：钉在榜底（Coin Master）、高亮（Royal Match / Gardenscapes / Mario Kart Tour）、主页按钮上直接写「第几轮 · 第几名 · 剩多久」（Royal League）。⇒ 斗龟场周日赛况板 / 对阵图里，「我」和「我关注的人」那一格固定高亮、不用滚动找。
3. **分区线画出来并写字**：晋级区金色 / 出局区紫色（Candy All Stars）、「▲升一档 / 降一档▼」（Mario Kart Tour）、顺风区 / 稳步区（Township）、「没贡献不发奖」（Toon Blast）。⇒ 斗龟场闯关赛的「4 胜晋级线」、冠军杯每轮的「晋级 / 淘汰」都在列表里画成带字的线。
4. **揭晓要分拍、要有停顿**：Mario Kart Tour 五拍、Candy All Stars 名次倒着揭 + 总决赛先亮分数不亮名字、Township 先重播再弹晋级。⇒ 斗龟场每轮开奖与冠军揭晓至少拆成「悬念（暗场 / 只亮比分）→ 揭晓名字 → 晋级变化 → 领奖」四拍。
