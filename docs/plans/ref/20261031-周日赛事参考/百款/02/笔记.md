# 百款游戏赛事日做法 · 第 2 批（共 10 批）

2026-10-31 · 只收资料，不改项目代码。

**本批 10 款**：Fortnite、PUBG、PUBG Mobile、Free Fire、Call of Duty、Call of Duty: Mobile、Fall Guys、Stumble Guys、Squad Busters、Zooba。

**为什么收**：《斗龟场》周日决赛日 = 18:00 小组赛（4 人一组单败）→ 20:00 冠军杯（各组冠军 6~8 人单败）；玩家不亲自打，服务器按锁定阵容算好每场再「开播」；轮间 3 分钟备战；没晋级的人也能看。这一批大多是大逃杀 / 派对淘汰游戏，赛制和我们不同，所以只收和我们对得上的环节：赛程怎么摆、怎么叫人、观赛页上有什么、轮间过场、出局后做什么、夺冠和赛后怎么收尾。

**按 10-31 的范围要求处理**：
- 大逃杀同图积分、派对淘汰这类**格式不同**的部分只写一句「格式不同，不适用」。
- **竞猜**我们目前不做：只记「有，略」。
- **观赛奖励**（看满几分钟领奖、观赛里程碑 / 进度条、观赛券、直播开奖）不做：只记「有，略」，不提建议。

**怎么读**：每格结尾的括号是来源——（实拍）= 从录屏里抽帧亲眼看到的；（官方）= 官方页面 / 补丁说明；（媒体）/（搜索摘要）= 二手资料，原页没打开。推出来的写「推测」。所有视频只看了画面，**音效一律没核实**。图都在本目录，文件名「游戏-维度-内容.jpg」；抽完帧的视频已删除。

**最值得《斗龟场》学的一招**：进行中的赛事榜单挂「LIVE」和「最后更新时间」，把**我自己那一行钉在最底下**，再给一个「只看好友」开关和一个「看直播」按钮。我们周日的对阵页可以照做：顶上挂「直播中 · 第 2 轮」，我那一格（哪怕已经出局）始终钉在可见位置并写清「止步小组赛 / 冠军杯 8 强」，「只看好友」一键筛出好友在哪组、赢没赢，旁边一个按钮直接跳到正在开播的那场。

**没找到 / 存疑**：「WATCH LIVE」按钮点进去是游戏内观战还是跳直播，没核实；Epic 帮助页 403，只拿到搜索摘要（回放路径）。书签会不会推送开赛提醒，没找到（搜过 "fortnite tournament bookmark notification"）。FNCS 开场没看。音效没核实。

**给汇总的规律候选**：
1. 赛事入口是「周历 + 当天赛事卡」，每张卡直接写时间段和状态（可报 / 锁住及原因）。
2. 「收藏这一场 / 收藏全部场次」两个按钮，把「叫人」交给玩家自己订。
3. 进行中的榜单：LIVE 标 + 最后更新时间 + 自己钉底 + 只看好友。
4. 决赛收尾顺序：回放决胜时刻 → 举杯 → 冠军数据卡 → 终局名次表。

## 本批共同规律（按我们周日的流程排，每条都能直接落到一个环节）

1. **一张图讲清整天赛制，打到哪亮到哪。** PUBG Mobile 专题页一张图：分组 → 各组前 N 去哪 → 决赛，每段写日期，终点放奖杯，当前段标「Live Now」；CoD 系列赛一开场把 9 张图排成底栏；CoDM 世界赛路线图；Fortnite 周历。
   → 周日赛事页顶部画「18:00 小组赛（4 人一组）→ 各组冠军 → 20:00 冠军杯 → 冠军」，每段写时间，当前段标「直播中」，**我在哪一段高亮**；观赛时角上常驻一条进度（小组赛第 1 轮 · 第 2 轮 · 冠军杯 8 强 · 4 强 · 决赛），打到哪一格亮哪一格。

2. **入口自己会说话，提醒交给玩家自己订。** Stumble Guys 赛事卡顶部状态带（倒计时 / Finished）+ 入口红色「!」；CoDM 入口直接写开放窗口和剩余时间；Free Fire 大厅图标下写剩余天数；Fortnite 「ADD BOOKMARK」和「BOOKMARK ALL SESSIONS」；PUBG Mobile「Subscribe」+「Live Now」。
   → 主菜单周日赛事卡三种状态：「小组赛 2 时 15 分后开播」/「直播中 · 第 2 轮」/「已结束 · 冠军 XXX」；赛事页两个按钮「提醒我小组赛」「提醒我全部场次」。迟到的人进来直接看正在播的那场，前面的场在对阵树上点格子回看。

3. **开场先讲人，再亮阵容。** PGC 开幕先放故事片 + 选手黑白特写采访，再一队一队上台；CDL 每队一支入场短片；Free Fire 开幕各队依次上台，大屏打全队照和队名条。
   → 每场开播前 5~8 秒双方亮相卡：昵称、周六战绩、锁定阵容的龟依次落位；冠军杯第一轮开播前，所有组冠军依次亮相一遍。

4. **每轮一张介绍卡，决赛整套换皮。** Fall Guys 每关一张介绍卡（关名 + 一句话玩法 + 奖牌门槛），同时兼加载画面；决赛那张整张换成橙底皇冠纹；CoDM 每张图开局一张「GAME 2 · 模式」大字卡；Zooba 把每个名次的奖惩直接写在等待画面上。
   → 每轮开播前一张卡：「冠军杯 · 4 强 · A 对 B · 赢的人进决赛」；冠军杯决赛的卡和观赛页整套换成金色，不用读字就知道是决赛。

5. **轮间过场固定几拍，3 分钟不留空。** Fall Guys 轮间约 35~40 秒：「LEVEL OVER!」→ 名牌墙出局者逐个打叉、剩余人数倒数 → 晋级者一起翻绿「N QUALIFIED!」→ 老虎机转出下一关 → 介绍卡；Free Fire 开播前大倒计时 + 积分榜 / 接下来场次轮播 + 花絮；Zooba 等待画面写清利害。
   → 一轮最后一场结束 → 名牌墙（本轮所有参赛者，输家逐个盖叉，约 10 秒）→ 晋级者亮起「4 人晋级冠军杯！」→ 转出下一轮对阵 → 3 分钟备战页：大倒计时 + 对阵进度 + 下一场的利害 + 上一轮高光循环播放。

6. **观赛页：LIVE、我钉住、好友、侧栏。** Fortnite 榜单「LIVE」+「最后更新时间」+ 自己那行钉在底部 + 「只看好友」+「WATCH LIVE」；PUBG Mobile 观赛窗旁侧栏「聊天 / 排名 / 赛程」+ 吉祥物表情贴纸。

   → 从服务器的模拟记录里算「本晚单场最高伤害」「最快结束的一场」「最强一只龟」，冠军之外发 2~3 张个人奖卡；小组赛就出局的人也可能被点名，出局的人才有理由看到最后。
