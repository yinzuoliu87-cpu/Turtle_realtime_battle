# 百款游戏赛事日做法 · 第 3 批（卡牌 / 棋类 / 宝可梦对战）

> 调研日期：2026-10-31。只收资料、不改代码。
> 本批 10 款：Legends of Runeterra、MTG Arena、Gwent、Yu-Gi-Oh! Master Duel、Yu-Gi-Oh! Duel Links、Pokémon TCG Live、Shadowverse（Worlds Beyond）、宝可梦朱紫线上大赛、Chess.com、Lichess。
> 方法：每款找实机录像（YouTube），只在赛事关键节点抽帧亲眼看；规则与数字以官方页 / wiki 为准。图在本目录，文件名「游戏-维度-内容.jpg」。表里「出处」用 [S编号]，每节表下列 URL。「无」= 找过没找到。

**只收和我们赛制对得上的做法。** 我们周日：小组赛每组 4 人单败 → 各组冠军进冠军杯单败；玩家只看不打，服务器按锁定阵容算好再开播；每轮之间 3 分钟备战；没晋级也能看。
本批多数游戏的赛事是**自助排队、打到 N 胜或 N 负**（LoR / MTGA / PTCGL / Master Duel / Duel Links / Shadowverse 的 GP / 宝可梦线上大赛）或**瑞士轮 / 竞技场**（Chess.com / Lichess），赛程本身格式不同、不适用；能借鉴的是**开场、结束仪式、奖励发放、直播包装、轮间空档、观赛入口**这几块。真正和我们一样「8 人单败、观众看、选手本人不在游戏里操作」的只有 **Gwent 世界大师赛**和 **Shadowverse 世界大奖赛决赛日**（均为官方直播）。

## 1. Legends of Runeterra（Runeterra Open / 赛季锦标赛）

图：① `LoR-开场-VS画面双方卡组英雄展示.jpg` ② `LoR-夺冠-GloryAchieved九胜得100奖杯.jpg` ③ `LoR-赛程-32强单败淘汰树(官方宣传片).jpg`（③ 是 2020 官方介绍片动画，不是客户端界面）

| 维度 | 做法 |
|---|---|
| 1 赛程节奏 | 格式不同（Open / Daily Rumble 自助打到 8~9 胜或 3 负），不适用。早期赛季锦标赛决赛为 32 强单败，宣传片里用对阵树、头像沿线推进来表现 ③。[S1][S2] |
| 2 观赛方式 | 客户端无观战；赛季锦标赛靠官方直播。[S3] |
| 3 开场仪式 | **VS 画面**：左右两块竖牌，各放头像、ID、该局卡组的 3 个英雄头像 + 区域徽记，中间金色 VS 被闪电劈开 ①；赛季徽章显示在对局加载画面上。[S1] |
| 4 结束与夺冠 | 单局全屏「VICTORY」；整轮达标后大厅弹「GLORY ACHIEVED!」横幅，顶部「9 WINS」，下方「获得 100 奖杯」，两侧红绸 + 火星，只有一个「继续」②。 |
| 5 奖励 | 每个胜场档都有：0 胜也给称号 + 5 奖杯；称号可升级（6 胜满 10 次由「Contender」升「Rival」）。[S1] |
| 6 叫人 | 无（只有大厅里的开放时段与剩余时间）。 |
| 7 出局之后 | 无观赛相关内容。 |
| 8 社交 | 对局内玩家名旁有表情按钮；首届赛季锦标赛允许看对手卡表。[S4] |
| 9 赛后 | 结算后进「宝库」页领经验；称号、赛季徽章留在资料上。 |
| 10 动效音效 | VS 中线闪电 ①；GLORY ACHIEVED 爆闪 + 飘火星 ②。 |

## 2. Magic: The Gathering Arena（Arena Championship）

图：① `MTGA-结束-VICTORY大字与段位徽章.jpg` ② `MTGA-奖励-逐项奖励弹出金币与经验.jpg`

| 维度 | 做法 |
|---|---|
| 1 赛程节奏 | 资格赛全是自助排队打到 N 胜 / 3 负，格式不同，不适用。唯一对得上的是 Arena Championship 第 2 天：16 强单败（受邀选手，线上）。[S1][S2] |
| 2 观赛方式 | 客户端无观战（开发方称优先级低）；Championship 在 twitch.tv/magic + YouTube 每天 9:00 PT 直播，**每轮积分与全部卡表放在外部 Melee.gg 页**，直播中同步更新。[S2][S3] |
| 3 开场仪式 | 无赛事专属开场。 |
| 4 结束与夺冠 | 单局：大字「VICTORY」压在卡面插画上，下方段位徽章 + 「点击继续」①。冠军仪式只在直播里。 |
| 5 奖励 | **奖励逐项弹出**：「Reward」下金币、经验一项一项亮出，每项停一下再「点击继续」②。Championship 奖金池 25 万美元，前 16 进 Pro Tour。[S1][S2] |
| 6 叫人 | 无。 |
| 7 出局之后 | 格式不同（按战绩发下期资格赛门票），不适用。 |
| 8 社交 | 无赛事相关。 |
| 9 赛后 | 外部 Melee.gg 保留每轮积分与卡表。[S2] |
| 10 动效音效 | 胜利插画 + 锁链光效 + 段位徽章进度条 ①。 |

## 3. Gwent（世界大师赛 World Masters）★格式最接近

图：① `Gwent-观赛-世界大师赛决赛直播画面选手摄像头与局分.jpg` ② `Gwent-夺冠-冠军连线采访双人画面.jpg` ③ `Gwent-赛后-八强单败对阵树全部比分.jpg` ④ `Gwent-奖励-最终名次与奖金榜.jpg` ⑤ `Gwent-结束-胜利皇冠横幅.jpg` ⑥ `Gwent-社交-赛后结算页GG按钮与段位分.jpg`

| 维度 | 做法 |
|---|---|
| 1 赛程节奏 | **8 人单败、分两天**：周六 16:00 CET 八强，周日 16:00 半决赛 + 决赛，Bo5，一场接一场（同一时间只有一场）。资格来自天梯 Pro Rank 与月度资格赛（格式不同，不展开）。2023-12 那届是官方最后一届。[S1][S2] |
| 2 观赛方式 | 官方 Twitch / YouTube 直播。对局画面：左右各一个选手摄像头 + 红 / 蓝方名字条 + 大局比分「2 : 2」，左侧「FINAL」阶段标签 ①；换牌阶段叠字「红方还剩 1 次换牌」「蓝方正在决定」。 |
| 3 开场仪式 | 没截到专门开场；对局画面常驻阶段标签 + 双方名字条 + 局分 ①。 |
| 4 结束与夺冠 | 决赛结束三连：**主持人与冠军连线双人画面**（大师赛 Logo 居中）② → **全屏八强对阵树补齐全部比分** ③ → **「奖金与最终名次」榜**（1~8 名国旗、ID、奖金）④。游戏内单局用皇冠盾形「VICTORY」⑤。 |
| 5 奖励 | 8 人全部有奖金，冠军 18,200 美元 ④；天梯赛季末前列拿称号等外观。[S1] |
| 6 叫人 | 无（游戏内）；赛程按固定时刻公布。[S2] |
| 7 出局之后 | 观众看满 4 小时掉称号「Beholder」、满 8 小时掉卡背（两天累计，必须看官方频道）。另有赛前竞猜活动（我们不做，不展开）。[S2] |
| 8 社交 | 单局结算页底部「GG」按钮，可直接给对手发 GG ⑥。 |
| 9 赛后 | 直播收尾即对阵树全比分 ③ + 名次奖金榜 ④ + 感谢观看卡。 |
| 10 动效音效 | 直播转场用金色粒子背景；结算页三枚菱形徽章并排滚数 ⑥。 |

出处：
[S1] https://masters.playgwent.com/en/official-rules
[S2] https://masters.playgwent.com/divination-challenge/ （含赛程时刻与 Twitch 掉落条件）
[S3] https://www.youtube.com/watch?v=g2atWXjwyPs （官方：Season 5 World Masters 半决赛与决赛直播，2023-12）
实机录像：https://www.youtube.com/watch?v=PhDPL_fkv_0 （RYL YZA，天梯一局，2025-11）

**最值得《斗龟场》学的一招**：**冠军决出后的「三连收尾」：冠军特写 → 全屏对阵树补齐每一场比分 → 全部名次榜**。这正是我们冠军杯结束时缺的一段：先给冠军一个大特写（冠军的龟阵容 + 名字），再把整棵冠军杯对阵树连比分亮一遍，最后出 1~8 名榜。

## 7. Shadowverse: Worlds Beyond（大奖赛 GP / 世界大奖赛 WGP 决赛日）★决赛日格式接近

图：① `Shadowverse-开场-先后手VS画面双方段位与分数.jpg` ② `Shadowverse-夺冠-CONGRATULATIONS皇冠全屏金光.jpg` ③ `Shadowverse-奖励-GP奖励卡套徽章冠军头衔一次领取.jpg` ④ `Shadowverse-赛程-GP决赛阶段A组5胜2负格与锁卡组提示.jpg`

| 维度 | 做法 |

## 本批共同规律（只列和我们赛制对得上的，可执行）

1. **开场 VS 是标准件：名字 + 头像 + 段位 / 分数 + 阵容核心。** LoR（3 个英雄头像）、Master Duel（卡套 + 主卡）、Shadowverse（先后手 + 段位分数）。⇒ 周日每场开播前 2~3 秒 VS 屏，必须摆出双方锁定的龟阵容。
2. **单场结束分两拍：先全屏大字，再明细。** VICTORY / GLORY ACHIEVED / CONGRATULATIONS 先占满屏幕，再进分数 / 奖励（LoR、MTGA、Master Duel、Shadowverse、PTCGL 一致）。⇒ 每场开播到结尾，先给胜者全屏一拍，再回赛况板更新对阵树。
3. **冠军决出后要有「收尾三连」。** Gwent：冠军特写 / 连线 → 全屏对阵树补齐全部比分 → 1~8 名榜；Lichess：三杯领奖台 + 数据卡常驻赛事页。⇒ 小组赛结束（每组冠军）、冠军杯结束（总冠军）各走一遍：冠军特写 → 对阵树全比分 → 名次榜。
4. **冠军奖励当场发完，头衔挂在名字上。** Shadowverse 领奖页一屏发完卡套 / 徽章 / 冠军头衔；Lichess 盾牌奖杯保持到被别人夺走。⇒ 冠军杯冠军头衔挂到名字上直到下周冠军诞生（「卫冕 / 被夺走」本身就是下周看点）。
5. **参与者人人有纪念。** Duel Links 打 1 场就给纪念卡套；宝可梦打满 3 场给参与奖；LoR 0 胜也给称号。⇒ 周日所有晋级者至少拿一个「决赛日参赛」纪念（头像框 / 称号），名次越高越多。
6. **服务器结算的空档要有过场，结果出来要挂横幅。** Duel Links 海马「正在计分请稍候」→ 入口「Results Are In!」；宝可梦大厅写「成绩反映需要一点时间」。⇒ 开播前未算完时写「正在同步」并用龟角色台词过场；整天结束后主菜单赛事入口挂「战果已出」。
7. **轮间 3 分钟按「积分 → 倒计时 + 下一轮对阵 → 开播」排满。** Chess.com 三段式（全屏积分榜 → BACK IN 3:57 + 侧栏积分 + 插播 → 多盘墙）；Lichess「正在配对请准备」横幅。⇒ 倒计时数字要大、居中，期间插播上一轮精彩片段。
8. **一轮多场同时开打时：多场同屏 + 一场主推。** Chess.com 10 盘墙 ↔ 焦点对局（已结束的盘直接叠比分）；Lichess 赛事页右侧直播最高名次那盘；Master Duel DUEL LIVE 挑聚光对局。⇒ 小组赛多组同时开打用「宫格 + 点开放大」，默认主推「我 / 我关注的人」那场，已打完的格子直接叠比分。
9. **直播画面常驻「阶段标签 + 双方名字条 + 比分」。** Gwent 左侧「FINAL」+ 红蓝名字条 + 局分；Chess.com「FINAL ROUND」；Lichess 观看单局时左栏常驻赛事名与剩余时间。⇒ 开播画面角落常驻「小组赛 A 组 · 第 1 轮」「冠军杯 · 决赛」。
10. **赛事专属皮肤让「今天不一样」。** Master Duel 等待页换世界赛主视觉、场地中央印赛事 Logo。⇒ 周日开播的地图 / 背景换决赛日装饰。
11. **观看本身给一点奖励（与竞猜无关）。** Gwent 看满 4 / 8 小时掉称号 / 卡背；Master Duel、Duel Links 每天看一场给宝石。⇒ 没晋级的人看满 N 场周日直播给小奖励，给「来看」一个理由。
12. **赛后留得住，并预告下一期。** Gwent 收尾放全比分对阵树 + 名次榜；Master Duel / Duel Links 结算页有「保存回放」；Chess.com 以「下期 10 月 27 日」预告卡（多时区）收尾。⇒ 周日结束后赛况板保留到周一（已定），补「全部比分对阵树」与「下周六闯关赛开放时间」预告。
13. **「叫人」普遍很弱，是可以超过它们的地方。** 本批只找到 Lichess「开赛时通知你」与 Chess.com 直播倒计时，卡牌类都没有「你的比赛快开始」推送。⇒ 「你的小组赛 5 分钟后开播」推送 + 点进来直接跳到自己那场。
