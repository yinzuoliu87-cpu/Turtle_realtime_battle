★风险：仪式时长要算进「一场接一场」的排期，否则下一场开播时上一场仪式还在放。

## 深挖 · 赛事节奏与观赛方式（Worlds / CS Major / TI / CRL / 金铲铲 / 王者 / 世界杯 · 笔记 节奏与观赛/研究笔记.md）

- 「18:23~20:00 空档」：是否把冠军杯提前 = 改已公布赛程 ⇒ 不由我定，列未决点；默认不动时刻，空档用 5-4 中场报告（各组冠军出炉 + 冠军杯签表）接住。

待核：对局时长上限（代码）；观看人数只有个位数时显示与否（冷清）—— 进方案书未决点。
