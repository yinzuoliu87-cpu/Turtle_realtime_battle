# 周日决赛日 · 玩家旅程与引导 · 商业游戏研究笔记（2026-10-31）

## 用途

同级目录的 `../对标笔记.md` 研究的是对阵图和结算卡长什么样，共 34 张图（A / R / S 三组），整理出标准 C01~C35。

这一份研究的是**一整天的旅程**：
- 赛事日的入口怎么摆；
- 比赛前怎么叫人；
- 出局的人还能做什么；
- 赛事期间的社交；
- 赛后的战报、头衔和下次预告。

对应方案书：`docs/plans/20261031c-周日赛事界面重做.md`。

## 只收和我们赛制对得上的做法

我们的赛制：
- 小组单败，每组 4 人；
- 各组冠军进冠军杯赛，也是单败；
- 玩家只看不打，服务器算好再开播；
- 每两轮之间有 3 分钟备战。

按这个标准，收录的游戏分两类：

| 类别 | 游戏 | 怎么用 |
|---|---|---|
| **对得上，完整展开** | 英雄联盟 Clash | 8 队单败，定点开赛，轮间有锁定 / 侦察阶段 |
| | 8 Ball Pool | 8 人单败 |
| | Head Ball 2 | 16 人单败，轮间 1 分钟准备 |
| | 王者荣耀全国大赛 | 8 人单败，分轮次，定点开赛 |
| | 王者荣耀游戏内 KPL 直播 | 观众看赛事直播 |
| | 英雄联盟手游「争者留其名」 | 观众给淘汰赛里的选手助威 |
| **格式不同，不适用** | 见第二节 | 各用一句话说明为什么不适用，不进结论 |

**竞猜我们目前不做**，只在事实里提一下，不写建议。

**规则补充（FAQ 原文要点）**
- 每天只进一个 8 队对阵表。
- 第一场输了进入 consolation（安慰赛），可以继续打来提高奖励；第二天还能再报名。
- 退出对阵表时，每人按自己的胜负拿一个宝珠或胶囊。
- 夺冠得奖杯：奖杯在客户端主页（Nexus）展示两周，本赛季的奖杯展示在个人资料上。

**观赛奖励在网站上，不在客户端里。**
- 示例任务：在 lolesports.com 看 1 场，得 500 蓝色精萃；看决赛，得赛事宝箱；任务剩 33 天（`LOL-06` ⚠ 网站，V2 0:03）。

## 二、格式不同，不适用（只列结论，帧留在目录里备查）

| 游戏 / 模式 | 赛制 | 为什么不适用 |
|---|---|---|
| 皇室战争：全球锦标赛 / 经典 / 大挑战（`CR-`） | 异步打到 X 败为止，或在截止前刷胜场 | 没有对阵表 |

| Golf Clash 周赛（`GC-`） | 异步按杆数刷分排名 | 没有对阵表 |
| 和平精英全民赛场（`HP-`） | 大逃杀大厅，按名次累积 | 没有对阵表 |
| 云顶之弈 | 客户端里没有锦标赛模式 | 检索英文「TFT Clash / in-client tournament」，结果全是英雄联盟 Clash；赛事观赛奖励走 Twitch / lolesports.com 的掉落：https://teamfighttactics.leagueoflegends.com/en-us/news/esports/tft-dragonlands-championship-qualified-participants-drops-and-more/ |

## 三、商业做法的共同规律（可执行条目，只取赛制对得上的证据）

> 编号 J01~J22，接在对标笔记的 C01~C35 后面用。每条后面括号里是证据帧。

### A 入口与叫人

- **J01 赛事日当天，入口是一张「今天的事」信息卡或主按钮，点得动，状态跟着时刻变。**
  - 王者：主卡写「今天19点开启」（WZ-01）。

### 4.0 前提与现状

**我们的赛制**
- 18:00 小组赛：4 人一组单败，打两轮。
- 20:00 冠军杯赛：6 位组冠军进 8 个签位，有 2 个轮空，打三轮。
