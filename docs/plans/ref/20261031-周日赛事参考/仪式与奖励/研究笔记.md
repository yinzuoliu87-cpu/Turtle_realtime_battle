# 周日决赛日 · 开场仪式 / 结束与夺冠仪式 / 奖励 —— 商业游戏研究笔记（2026-10-31）

用途：给方案书 `docs/plans/20261031c-周日赛事界面重做.md` 的 **C 块（开场与结束仪式）** 和奖励展示定稿。对阵图本身的对标见同级 `../对标笔记.md`（本篇不重复，只在用到时引用它的 R01 / R02 / R03 / R04 / S05 / S06）。

## 怎么做的

- 找实机录屏（YouTube），先 360p 整段 5~10 秒一格粗扫，找到仪式那几秒，再 **0.2~0.5 秒一格逐帧** 抽出来。每一张都用 Read 看过。
- 下文时间轴一律以「仪式开始 = 0.0s」计，括号里是原视频的秒数，方便回去核对。
- **只下了视频轨**，所以「音效时点」是按画面推断的：白闪、盖章、数字落定、金币到位的那一帧。
- 存证在本目录。文件名前缀即游戏：`LoL-` 英雄联盟 Clash，`TFT-` 云顶之弈，`CR-` 皇室战争，`BS-` 荒野乱斗，`HS-` 炉石传说，`GC-` Golf Clash，`HB2-` Head Ball 2，`8BP-` 8 Ball Pool，`SAP-` Super Auto Pets。
  - 「序列」是带时间标签的逐帧联系表。
  - 「关键帧」是单张全帧。
- ⚠ 标注的不是上线版原样画面：
  - `LoL-Clash官方说明⚠`：Riot 官方介绍片。画面是客户端真界面，但剪辑过、队名是示例。
  - `LoL-Clash客户端PBE⚠`：2018 年测试服录屏，队名是占位的 ABC / XYZ。上线后夺冠卡的字改成了「BRACKET WON! / CLASH CHAMPION」，见 `../对标笔记.md` R01。
  - HS 酒馆战棋第 1 名那条视频左侧有第三方记牌器覆盖层。

**领奖链**（测试服 12–37s）—— `LoL-Clash客户端PBE⚠-夺冠后领奖链-胶囊叠加到胜利点数到旗帜-序列0.5s.png`、`LoL-Clash官方说明⚠-胜利点数页-加分与NEXT-关键帧.png`
- 通用版式：一页一件奖励。
  - 顶部标题＋一句副标题，如「VICTORY POINTS / Keep up the great work, you are on the path to greatness!」
  - 中间一条横贯全屏的深色带，物件放在带子正中。
  - 下方是数字，再下面是页码圆点。
  - 底部居中一个「NEXT」，按钮下方有一条细进度条，表示领奖链走到第几页。
- ① 锦标赛胶囊（12.0s 起）：
  - 胶囊外圈是胜场环，「0 WINS→1→2→4 WINS」每胜约 0.5s 跳一格，环跟着填。
  - 15.0s 环满变青。15.5s 青色爆光（升档）。
  - 16.5–17.5s 一个胶囊带火尾**分裂成扇形的 5 个**。
  - 然后停住，等玩家点 NEXT。
- ② 胜利点数（21.0s 起）：
  - 圆环从空转到满，数字 556→776→800 约 1.5s 滚完。
  - 22.5s 右侧虚线圆章「BONUS +00→+21→+24 · Tier III」滚约 1s。
  - 24.5s 环中心变成金色对勾（盖章）。
  - 26.0s 青光爆开，**环变形成一面旗帜**。
- ③ 旗帜「DEMACIAN STANDARD I」（27.0s）→ NEXT → ④「BANNER FRAME UPGRADE」旗框升级（30.5s）→ NEXT → 回到胜利点数，显示下一档进度。
- 规律：
  - 先出物件，再滚数字，最后盖章或变形。
  - 每页 3~6s 的动画，播完停住等 NEXT。
  - 一件奖励一页，不堆在一张卡里。

**头衔 / 荣誉给别人看**
- 官方片 130–133s：3 座奖杯立在台座上，像陈列柜。
- 据 Riot 说明，奖杯和旗帜会挂在个人旗帜上。这一点本次没有逐帧核实。

## 二、商业做法的共同规律（可逐条核对）

### 1. 时长

| 环节 | 实测范围 | 例 |
|---|---|---|
| 开场 VS | 2~5s；加匹配滚轮 6~10s | CR 2s、BS 5s（含 5→1 倒数）、HB2 5s＋开球字 1.25s、8BP 5.5s（含奖池飞入）、HS 3.5s |
| 开打大字 | 0.75~1.25s | BRAWL 0.75s、FIGHT 1s、Match Starts 1.25s |
| 单场结束标语 | 0.8~3.5s | CR MATCH OVER 0.8s、8BP You Win 1.5s、HB2 终场哨 2.5s、BS Match over 3.5s |
| 单场结果页到出按钮 | 2.8~5.25s | CR 2.8s 出 OK、8BP 5.25s 出 Rematch |
| 夺冠主动画 | 8~12s | LoL 12s（白闪在 8.6s）、TFT 8s、HB2 对阵图烟花 3.5s＋弹窗 |
| 每件奖励 | 1.3~3s；稀有约 5s | HS 1.3s、CR 1.5~2s / 传奇 5s、GC 每件约 2~3s（数字滚动 3s） |

### 2. 结束一律分三拍，不是一张卡

1. **标语**：压在战斗画面上的一个短词（MATCH OVER / You Win! / 终场哨 / DEFEAT）。
2. **双方结果**：两边都在画面里。胜方放大、加冕、站着；败方变色或退场（红揉碎 LoL、烧成黑影 BS、灰掉 HS、头像下沉）。**胜负靠图形表达，不靠一行字。**
3. **我的处境 / 奖励**：本场奖励、累计进度（胜场格、败场 ✕）、晋级或出局说明、下一步。

### 3. 对阵图本身是仪式的一部分

单场结束后**回到对阵图**，再在对阵图上做动作：
- 败场：盖大红叉（LoL，0.5s 缩到位）。
- 胜者：连线 / 光点从这一格走到下一格（LoL 金线 1.5s、HB2 光点 2s 到位冒烟）。
- 冠军格：放烟花（HB2）。
- 晋级弹窗**在动画之后**才出（HB2「You have qualified for the quarter-finals!」）。

### 4. 夺冠有固定的情绪曲线

**结果 → 盖章（勾 / 冠） → 蓄力 1.5~2s → 全屏白闪 → 奖杯从光里出来 → 称号文字 → 停 2s 以上**（LoL）。
- 白闪是高潮点，奖杯必须在白闪之后才露面。
- 夺冠页不放按钮，按钮在领奖链里。
- 彩带 / 烟花在夺冠后飘 2~4s：SAP 满屏彩带、HB2 对阵图烟花、BS 收件箱彩带。

### 5. 名次越高越华丽，名次要写成「X / 规模」或「称号」

- HS：第 8 名一个感叹号、破旗；第 1 名三个感叹号、翼＋冠＋剑。
- GC：「YOU FINISHED 1/98」，奖章名「MASTER · WINNER'S MEDAL」。
- LoL：「TOURNAMENT CHAMPION / 16 TEAM BRACKET」——称号下面一行写规模。
- Brawlhalla（R04）：名次直接写成列标题。
- 涨分黄 / 绿字，掉分红字。数字都是滚出来的，不是直接出现。

### 6. 奖励：一件一页，先物件后数字，最后入账

- 一页一件，配标题＋一句副标题＋物件＋数字＋一个主按钮（LoL NEXT、GC 点击、HS 翻牌）。
- 物件先出（掉落、开箱、光柱），**数字后滚**（1~3s）。滚完盖章或变形（LoL 环 → 对勾 → 变旗帜）。
- 有「还剩几件」：GC 卡牌计数 14→1、LoL NEXT 下的进度条＋页码点、CR 顶部图标行打 ✓。
- 稀有度用颜色和时长区分：COMMON 蓝、RARE 橙、EPIC 粉；稀有约多 3 倍时间。
- **货币最后飞进顶部货币栏**（CR、8BP 奖池飞进赢家头像）——这一下才算「入账」。
- 小额每胜奖励**不开独立页面**：BS 直接写在结算页「REWARD FOR WIN #15 · 1500」；CR 写在横幅下的奖励格里。大奖（名次、通关）才开领奖链。
- 奖励提前画出来：BS 奖励路线每胜一格、CR 12 格、HB2 冠军格上立着宝箱、GC 开赛就有奖池。

### 7. 开场 VS 的版式

- 我方左 / 下，对手右 / 上；颜色对立（蓝 / 红）；中间一个 VS 盾或菱形。
- 卡上展示的是**身份**，不是战力：名字、头像 / 皮肤、等级或段位徽章、**玩家自选的称号 / 徽章**（CR 3 枚、BS 称号）。
- 顶部写这是哪一轮（HB2「Qualifications / Final」）。
- 有赌注 / 奖池的，奖池放中间，金币从两边飞进去（8BP）。
- 匹配期用老虎机滚轮制造悬念（8BP 头像、HS 称号），锁定那一下白闪。
- 进场前是倒数（BS 5→1），之后一个开打大字。

### 8. 头衔和奖章怎么给别人看

| 位置 | 例 |
|---|---|
| 别人对战前的 VS 卡 | CR 3 枚徽章、BS 称号 |
| 个人资料页的奖章栏 | GC 左栏竖排历届奖章 |
| 旗帜 / 奖杯陈列 | LoL |
| 晋级 / 资格进收件箱留档 | BS |

### 9. 按钮

- 每屏只有**一个主按钮**：NEXT / CONTINUE / OK / Get Prize / EXIT / PROCEED。位置在底部居中或右下。
- 次按钮（Share / Rematch / 查看对阵图）在动画全部结束后才出（8BP 5.25s）。
- 动画播完才给按钮；之前点屏幕只能跳动画，不能直接跳页。
- 胜利页常见「点任意处继续」（HS Click to continue）。

### 10. 音效时点（按画面推断）

每个「定格」的那一帧都有一下：
- 败方碎裂、红叉 / 对勾砸下、白闪、奖杯定格。
- 数字滚动全程有连续的「嗒嗒」声，落定时一响。
- 金币到达顶栏时一响。
- 倒数每秒一下，开打大字一下重音。

## 三、对我们的建议（周日决赛日）

**前提**（与普通商业锦标赛不同的三点）：
1. 玩家**不亲自打**，是看「开播」。所有人看到的是同一条时间线，所以仪式不能「等玩家点」，要**自动前进**，同时允许点击跳过本地动画。
2. 方案 S 是「一场接一场开播」，所以**每场结束仪式的时长必须写进开播排期**：上一场仪式没播完，下一场不能开。
3. 每轮人人都有 +8 深海币 +2 经验（小额），名次只有头衔（冠军 / 亚军 / 四强 / 组冠军）。

**像素风翻译**：
- 白闪 = 全屏白 2 帧再 4 帧淡出。
- 碎裂 = 头像切 4×4 像素块四散。
- 彩带 = 像素纸屑粒子。
- 光点走连线 = 2×2 发光像素沿折线移动。
- 别照搬 LoL 的 3D 光效，结构和节奏照抄即可。

### 3.1 每场开播前：开场 VS（约 6s，看别人和看自己相同）

| 0.0s | 两条斜带从左右扫入（左 = 上半区 / 我方蓝，右 = 下半区 / 对手红），0.25s 到位 | BS、LoL 箭头合拢 |
| 0.3s | 顶部轮次名：「A 组 · 半决赛」「A 组 · 组决赛」「冠军杯 · 8 强 / 半决赛 / 决赛」；决赛用金字 | HB2 |

- 决赛加 2s：VS 之前先出「冠军杯 · 决赛」全屏标题卡＋奖杯剪影。

### 3.2 每场结束：七种画面

### 3.4 奖励怎么展示与入账

**预告（让玩家开赛前就知道能拿什么）**
- 对阵图每一轮的列标题下写「本轮 +8 深海币 +2 经验」。
- 冠军格写「冠军杯冠军 · 头衔」（BS 奖励路线、HB2 宝箱立在冠军格上）。
- 主菜单决赛日卡也写一行奖励（M 块）。

**每轮奖励（小额 · 自动入账）**
- 不开独立页。写在本场结束的第三拍里，一行：「+8 深海币 +2 经验」。
- 先出图标，数字滚 0.8s，深海币飞进顶部货币栏（约 0.6s），落定时一响。
- 当时不在线的人：下次打开游戏时弹一张**周日战报卡**（LoL R02 当日战绩的样式）：
  - 每一轮一栏：对手、胜负、各路比分、「看回放」入口。
  - 合计「+24 深海币 +6 经验」，加上获得的头衔。
  - 一个主按钮「领取」。点下去才播币飞入顶栏，让入账这一下被看见。

**名次奖励（头衔 / 奖章 · 领奖链）**
- 一件一页：头衔页 → 奖章页 → 合计页。版式照 LoL：标题＋一句副标题＋横贯的深色带＋物件＋数字＋页码点＋底部一个「下一个」。
- 头衔页：缎带从上方落下，0.5s 落地扬尘（GC 宝箱落地），停 2s。
- 奖章页：奖章旋转 0.6s 定格，盖章音。

**兜底**：邮件（或收件箱）只做留档和补发（BS 的用法），不当主路径。

**头衔给别人看（全部只读现有数据，不新增玩法）**
1. 每场开场 VS 卡上的头衔徽章（CR / BS）。
2. 对阵图头像框：历届冠军有金边或小冠。
3. 排行榜和资料页的奖章栏（GC 竖排历届奖章）。
4. 本周冠军墙（方案 A 块）。

### 3.5 要写进方案书「已知风险与未决点」的

- **仪式时长要算进开播排期**（方案 S）：每场至少留「开场 6s＋结束 4~7s」；组决赛后留 10s；冠军杯决赛后留 14s，再加领奖链（冠军本人可点，不占全服时间）。否则会出现「下一场开播时上一场仪式还在放」。
- **观赛中途加入的人**：从当前时间点直接进；已经过去的仪式不补放，只在对阵图上显示终态（红叉、光点已到位）。
- **一人同时是当事人又在看别的组**：只对当事人那场弹 ②③④；其余场一律按 ①。
- **白闪对光敏玩家不友好**：高潮白闪限制在最多 2 帧全白，并跟随系统「减少动态效果」开关降成淡金色。
- **素材量**（PixelLab）：需要的新素材有选手卡框（左 / 右）、VS 盾、轮次名标题卡、组冠军 / 冠军 / 亚军 / 四强四种缎带与奖章、像素彩带粒子、三级领奖台、奖杯一座（冠军杯）、红叉 / 灰叉、金勾 / 冠冕。出图前按 memory 规矩先锁参考、出方向稿。
