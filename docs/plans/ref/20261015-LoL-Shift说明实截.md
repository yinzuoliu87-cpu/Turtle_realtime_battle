### ③ 数值（截图看得到的渲染）

- 默认态：`88 (🔮) magic damage` —— 结论 + 系数来源小图标；按 Shift：`88 = (80 +85%🔮) magic damage` —— **结论在前**，`=` 后括号里是「基础值 + 百分比加成图标」，**不写当前属性值**。
- 随等级成长的写 `22 = (22 - 10⬆)`、`37 = (35 - 95⬆ +20%🔮)`。
- 底部等级表：`Damage [ 40 / 60 / 80 / 100 / 120 ]`，当前档亮白、其余灰；标签是短词（Damage / Cooldown / Duration / Mana Cost / Heal Ratio）。
- 上色：伤害数值连同伤害类型词一起上色；控制词（Charms / Knocks Up / Slows / Stunning）紫；专名（Recast / Essence Theft / Turret / Possess）单独上色；属性词（Health / Armor / Magic Resist / Attack Speed）各自的色。

## 3. 对我们文案的结论

1. **灰字该用**：用来写规则补充（对召唤物 / 小将的特殊数值、上限、交互、优先级），放在正文后、等级表前。**效果本身不放灰字**（被动 / 主动效果是正文）。
2. **多模式 / 多阶段用「短标签：」分段**，比圆点列表常用得多（103 vs 18）。彩虹龟三色 / 四色目前用圆点 —— LoL 两种都有，「短标签:」是主流，后续可统一。
3. **被动在前、主动在后，用「被动：」「主动：」**（已于 10-14 改，提交 23e14ab6）。
4. **公式结论在前、不带当前属性值**（已于 10-14 改：图鉴 / 选龟页「20（50% 攻击力）」）。
