# 斗龟场 全流程与页面(2026-10-21 从代码核对)

出处: `scenes/*.tscn` 15 个场景 + 各场景 `change_scene_to_file` 去向 + `docs/design/实时版-系统机制权威.md` §1~§6 + 周赛制方案书。

## 页面(玩家看得到的 14 个)

| 页面 | 场景 | 干什么 | 从哪进 / 去哪 |
|---|---|---|---|
| 首启 | FirstLaunch | 介绍游戏 → 问要不要教程 → 起名 | 首次打开 → 主菜单 |
| 主菜单 | MainMenu | 开始战斗 / 训龟大师 / 背包 / 商店 / 图鉴 / 排行榜 / 玩家卡→战绩 / 设置 / ?教程 | 各页返回都回这里 |
| 选龟 | TeamSelect | 选 3 只龟 + 每只 3 选 1 技能。**本周第一场打完阵容锁死到下周一**, 之后只能换技能 | 开始战斗 → 匹配 |
| 匹配 | Matchmaking | 找同场次对手(真人快照 / 机器人) | → 战斗 |
| 战斗 | RealtimeBattle3D | 上路战场 + 下路战场, 小将、龟蛋; 1:1 进终极战场; 双方训龟大师在场边放技能 | → 结算 |
| 结算 | (战斗内) | 胜负、深海币、经验、命、本周场次 | → 商店 / 主菜单 |
| 商店 | Shop | 深海币买装备、刷新、锁定、买经验(等级 → 装备格数与出货档) | 主菜单 / 结算 → 背包 |
| 背包 | Inventory | 装备装到龟身上、3 件同名同星自动合成、羁绊、卖出、站位(上/下战场各摆位置) | 主菜单 / 商店 |
| 训龟大师 | TrainerConfig | 选形象 + 1 个技能(被动或主动), 战斗里它在场边放 | 主菜单 |
| 图鉴 | Codex | 龟 / 装备 / 羁绊 / 状态 / 规则 | 主菜单 |
| 排行榜 | Leaderboard | 全名次 | 主菜单 |
| 战绩 | Record | 自己的对局记录 | 主菜单玩家卡 |
| 设置 | Settings | 音量、账号等 | 主菜单 |
| 周六赛况板 | GauntletBoard | 闯关赛所有人战绩与回放 | 周六主菜单 |
| 周日对阵图 | BracketMap | 小组赛 + 冠军杯赛签表、观赛 | 周日主菜单 |

## 两层循环

**一场的循环**: 主菜单 → 选龟(本周首场才真选) → 匹配 → 战斗 → 结算 → 商店(买装备 / 经验) → 背包(装上、合成、站位) → 主菜单 → 下一场。

**一周的循环**: 周一休赛 → 周二~周五积分赛(8 命、24 场配额) → 周六闯关赛(4 胜晋级 / 3 负出局) → 周日决赛日(小组赛 + 冠军杯赛)。周一全部清零: 深海币、等级、阵容、装备。

## 新玩家必须懂的(按第一次遇到的顺序)

1. 选 3 只龟 + 技能 —— 而且**这一选锁一周**
2. 战斗自动打; 两个战场 + 蛋 + 终极战场怎么算赢
3. 结算拿到深海币和经验
4. 商店买装备、买经验升级(等级决定能装几件)
5. 背包把装备装上龟; 3 件合成升星; 羁绊
6. 站位(上 / 下战场)
7. 训龟大师(形象 + 技能)
8. 命和配额; 周末赛事
