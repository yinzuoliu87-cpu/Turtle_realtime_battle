# 第一轮内测玩家反馈汇总

收集起点：2026-10-17。来源：用户转发的玩家反馈。原话逐字保留，分类与备注是我加的。

## 1. Ka Wai & Yisheng（2026-10-17 转发）

### 原话

1. 地图有点大 感觉这个龟跑的有点费劲
2. 游戏前战位设置在底层逻辑和执行细节上需要优化
3. 龟龟图标在画风一致性上需要微调，有些是写实，有些是2D风格
4. 游戏的操作风格与道具装备的流程存在提升空间
5. 游戏角色与道具的数量对内部测试阶段的游戏显得有点多了，我们俩这种傻子有点迷糊
6. 角色与道具，羁绊的介绍有些过于繁琐，依旧我俩没玩明白[捂脸]
7. 部分操作与实际UI上的显示未能完全匹配，有的按钮按不动
8. 新手教程在具体能容上依旧存在较大的丰富空间，我俩看半天还是没玩明白
9. 建议针对低智商人群（我俩）进行优化

第 2 条下方，用户转发时附有「ok收到」。

### 待办

以下都未开工，等用户拍板优先级。

- 第 7 条的按钮要找玩家问清是哪个界面、哪个按钮，最好附截图和版本号。这是唯一一条能直接定位成缺陷的。
- 第 6 条和本周的文案改写有关：本周已删掉关键词释义，文案改成 LoL / 云顶写法，但「繁琐」的感受可能主要来自信息量本身，不是措辞。
- 第 5、8、9 条涉及内测期是否缩减可选龟 / 装备数量，以及教程重做。属于设计决策，由用户定。

## 2. 大陆玩家连不上服务器（2026-10-17 查实，排进下周版本）

现象：玩家看到「账号未连接，请检查网络」。LP（#DFMSKT，Windows 正式包）10-13 之后服务器再没收到它任何请求，本地闯关 4-0 服务器为 0-0；本周 11 个真人号多数只在建号当天有上传。

结论：客户端直连 `supabase.co`，在大陆是否可达看运营商 / 是否挂代理。这是线路问题，不是游戏逻辑。

用户 2026-10-17 原话：「这些排进计划里面吧，这周内测版本不要去动」。

### 下周版本待办
- [ ] 大陆可达的中转：自有域名 + 大陆可稳定访问的服务器（如香港）反向代理到 Supabase，客户端服务器地址指向它；出新包（iOS 需重装）。
- [ ] 客户端在连不上服务器时，主菜单与闯关入口明确提示「成绩不会上传」，不让玩家以为打了算数。
- [ ] 离线期间排队的阵容 / 录像上传有重试上限（`MAX_TRIES`），网络恢复前就可能放弃，需改成按时间而不是按次数放弃。
