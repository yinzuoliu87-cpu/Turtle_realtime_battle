# App 图标参考（2026-10-21 采集）

来源：iTunes Search API（`country=us`），取 `artworkUrl512`，也就是 App Store 美区实际上架的 512×512 图标。
每张都核对过 `trackName` 与开发商，确认是对应游戏本体（排除了 `+` 版和同名山寨）。
原图是 JPG，转存成 PNG。总览图见 `contact_sheet.png`（5 列）。
`00-我们现在.png` 取自 `build/ios/turtle/Images.xcassets/AppIcon.appiconset/Icon-1024.png`，
也就是 `project.godot` 的 `config/icon="res://icon.svg"` 导出到 iOS 后的样子；`export_presets.cfg` 里各平台的 icon 字段都是空的。

## 采集说明

- 用户点名的 17 个游戏都拿到了。"像素风生物/怪兽"补了 Cassette Beasts、Coromon、Brotato 三个。注意：这三个游戏本身是像素画，但**它们的 App 图标都不是像素画**，用的是平滑插画；20 张里只有 Balatro 的 Joker 牌面是像素风。
- Archero 和 Brawl Stars 拿到的是当期活动换皮版（New Skin 字样、节日配色），平时的版本可能不一样。
