## 共同做法

1. **立绘是卡的主体**：竖卡里立绘占卡高 40%～80%（杀戮尖塔 40%、怪物火车 52%、云顶商店卡 80%、Rumble 80%），不少直接铺满全卡（皇室战争、漫威终极逆转、符文之地）。到了棋盘 / 战场上卡会缩成只剩头像 + 两个数字（酒馆战棋、Super Auto Pets）。
2. **边框薄**：框厚每侧 2%～12% 卡宽，多数 ≤8%。像素游戏（Cobalt Core、Slice & Dice）只用 1～2px 细描边。厚框只出现在怪物火车（12%），而且它把升级槽塞进了框里，框不是白占的。
3. **数字钉在角上，而且压出框外一半**：费用左上（炉石、符文之地、杀戮尖塔、怪物火车、漫威、皇室战争、Cobalt Core，7 款都是）；攻击左下、生命右下（炉石、符文之地、怪物火车）；雪居之地是生命左上、攻击右上。
4. **名字是一条横幅，压在立绘下沿上**（炉石、怪物火车、雪居之地、符文之地），或者放在卡顶（杀戮尖塔、Cobalt Core）；很少「立绘下面空一行再写名字」。
5. **稀有度 / 费用档靠颜色或形状，不靠字**：云顶名字条颜色 = 费用、杀戮尖塔缎带颜色 = 稀有度、皇室战争 / Rumble 外框颜色 = 稀有度、符文之地底边宝石形状 = 稀有度、Cobalt Core 卡色 = 所属队员。
6. **养成信息（等级 / 进度 / 持有数）放在卡下沿外面或头顶**，不挤进卡面：皇室战争等级字 + 卡下进度条、Rumble 等级徽章 + 进度条、符文之地卡下三点、SAP 头顶 Lvl 牌。
7. **装备格是等大方格，满格和空格一样大**：云顶一排 3 格、剑与远征 / Hero Wars 2×3。空格分状态画：可装 =「+」（剑与远征，Hero Wars 是格子角上的绿色「+」）、没开放 = 锁、普通空 = 暗凹槽（云顶）/ 灰剪影（循环勇者）/ 虚线框（骰子地下城）/ 主人色描边（Slice & Dice）。
8. **卡面不放长说明**：点开再弹（SAP 旁边弹小卡、小丑牌卡下弹框、雪居之地说明框围在卡四周、云顶开检视面板）。

## 对我们龟卡最值得借的 3 条

1. **木框减薄，把位置还给立绘和名字。** 现在框每侧 39px = 卡宽 20%，参考游戏多在 8% 以内（最厚的怪物火车 12%，而且框里还装着升级槽）。框每侧降到 ≈15px（原生 5px × 3，卡宽 8%）以后，内窗从 114 宽变成 ≈162 宽；立绘区做到卡高 ≥45%（现在 90/252 = 36%），头顶照现在这样破框（雪居之地 12）。**名字改成一条横幅，横跨立绘下沿、压住立绘底部约 1/4**（炉石 05、怪物火车 11、雪居之地 12），不再在立绘下另起一行，这样省出的约 20px 留给装备条。
2. **三格不变（云顶 01 的一排三格、每格 ≈27% 宽，和我们 56px / 29% 几乎一样），但空格要分状态、满格要能看出星级。** 空格：背包里有能装的东西时，格子中间画淡「+」（剑与远征 17；Hero Wars 16 是挂在格子右上角的绿「+」）；全队装备满了画锁（剑与远征 17），不要只靠颜色更暗来区分。满格：**装备星级画在格子左下角**（循环勇者 20 把等级数字放在左下角），用 1～3 个小星点，尺寸 ≈格宽 1/4，不要盖住图标中间。现在卡上的格子只看得出费用色和图标，看不出是几星。
3. **稀有度用颜色，数字只进角落。** 龟有稀有度（C～SSS）但卡上没显示：照杀戮尖塔 10（缎带色）/ 云顶 03（名字条色），**用第 1 条的名字横幅的颜色表示稀有度**，不另加元素。以后要在卡上放数字（等级、费用），照 7 款的惯例**只放左上角，圆形角标压出框外一半，直径 ≈卡宽 1/5**（炉石 05、杀戮尖塔 09、皇室战争 04）；养成进度如果要显示，贴在卡下沿外面（皇室战争 04、Rumble 18），不进卡面。
