## 尺子（怎么判的）

1. 提交层：`git log main..<HEAD>` 与 `git cherry main <HEAD>`。66 个全部为 0。
2. 工作区层：每个 worktree 里 `git status --porcelain -uall`，对每个文件读字节、**CRLF→LF 归一**后分别与「该 worktree 的 HEAD 版」和「main 版」比：
   - 与 HEAD 相同 ⇒ 只是行尾（status 里那 1200~1500 个 `M` 全是这一类，尺子没归一时会被当成「改了一千多个文件」）
   - 与 main 相同 ⇒ 已进 main
   - `.uid` ⇒ 自动生成物，不算
   - 其余才算「真差异」。对真差异再量：worktree 相对其 HEAD **新增的行**里有多少条原样出现在 main 同一文件中。
3. 被 .gitignore 的文件也扫了：A 类里只有 `.godot/` 缓存、`*.translation`、`__pycache__`、`tri_audit_report.txt`、`.gate-fail-*.log`、`.claude/settings.local.json`，全是生成物。
