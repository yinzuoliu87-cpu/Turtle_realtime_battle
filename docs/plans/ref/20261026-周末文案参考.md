## 按时刻摘录

**晋级 / 完成**
- 荒野乱斗：结算大字「已晋级！」，下一句「恭喜！您已获得参加荒野乱斗全球锦标赛下一阶段比赛的资格。……」；弹窗「挑战已完成」，按钮「立即前往」。
- 皇室战争：「已完成挑战！」，结束页标题「挑战结果」，按钮「领取奖励」「领取」。
- 炉石：胜负共用结束页「完成竞技模式比赛」，按钮「完成」。

**把没用上的东西换成奖励**（对应我们的「化成」）
- 荒野乱斗：「您的门票已被兑换为宝石！」按钮「领取」。
- 皇室战争：「溢出的满级卡牌已被移除并转换为其他资源！」
- 「补偿」「补发」只出现在事故与运营公告里（荒野乱斗「我们将为您的账号补偿……」、王者荣耀公告「系统自动补发」）⇒ 正常流程不用。

**出局**
- 荒野乱斗：结果页「挑战结束」；「淘汰出局」只出现在规则说明和预警「再输一场，您就会被淘汰出局。」里。
- 皇室战争：「战败3场，挑战结束！」「本次挑战已结束」。
- 英雄联盟冠军杯赛：「请在下一届冠军杯赛中再接再厉。」

**进度**
- 皇室战争：「胜场：<n1>/<n2>」「当您获胜12场或者战败3场时，本次挑战结束。」
- 荒野乱斗：「获胜<WINS>场即可完成挑战。战败<LOSSES>场，淘汰出局！」
- 炉石：「再赢得{0}场对战」。

**赛季结束登录弹窗**
- 荒野乱斗：标题「排位赛赛季已结束」，按钮「领取」；没参加：「……不过您并未参加本周比赛。参加下周比赛，赢取战队币！」
- 皇室战争：「联赛赛季已重置，您有<num>项奖励等待收集！」
- 云顶之弈：「云顶之弈排位赛赛季已经结束」「你拿到了一个奖励！」

**被拦住**
- 炉石：「本次竞技模式即将结束，当前无法入场。」
- 英雄联盟：「这个战队目前没有参加冠军杯赛的资格。」
- 皇室战争：「锦标赛结果整理中，无法对战。」

**引导观战**
- 荒野乱斗：按钮「观战」；英雄联盟：「观看比赛」「立刻观看」。

## 共同规律（我们照这个写）

1. 标题 4~8 字，只说发生了什么：「已晋级！」「挑战结束」「排位赛赛季已结束」。成功带感叹号，失败不带。
2. 正文 1~2 句：第一句复述结果带数字，第二句说下一步去哪、什么时候。
3. 「恭喜」只在成功时、放正文开头；失败页不写「失败」「出局」，写「到此结束」，给下一次机会在哪。
4. 奖励单独成行，「名称 +数量」，不写计算过程。
5. 按钮两字为主：「领取」「好的」「观战」「立即前往」。
6. 进度：常驻读数用计数式；关键节点用「再胜 N 场」「再负一场」式。
7. 拦截提示是完整句「原因 + 下一次机会」，没有一家用「·」串短语。
8. 人称用「你」（我们现有文案 0 处「您」）。荒野乱斗的「真棒」「别气馁，继续加油」偏口语，不照搬。
