# 进化动画怎么做 · 9 款游戏逐帧实测（2026-10-22）

图在同目录：总览 `0-总览.jpg`，每款一张帧条（`01`～`09`，带 `b` 的是补充特写），出处 `来源.txt`。
全部是 YouTube 实机录像抽帧，没有画、没有生成。

**时长怎么量的**：不是看图估的。每段都在原视频帧率下逐帧算画面亮度和帧差（脚本在 scratchpad，不进仓库），
阶段边界取亮度/帧差突变那一帧；误差 ±1 帧（30 fps 为 ±33 ms，云顶 60 fps 为 ±17 ms）。
表里「视频秒」可以直接拿去视频里核对。凡是取决于玩家什么时候点的，标「本例」。
**声音一律没核实**（没下音轨）。

**我们现状**：小木斧 → 石斧 → 铁斧 → 金斧 → 钻石斧 → 四选一（亡灵之斧 / 炽天使 / 全息斧 / 余烬），进化时**没有任何动画**。
斧头素材是 9 个形态各一套横排 8 帧 × 112 px 的像素帧（`eq096-axe-<形态>-idle.png`），
`axe_art.gd` 里铁斧待机帧斧高只有 **45 px**（`IDLE_BODY_PX`，九把同一个正交镜头、像素比例一致）。会触发进化的地方有 4 处：
① 商店里买到另一把斧头之后、② 赛后结算界面、③ 战斗中击杀攒够（战后才生效）、④ 终极四选一（商店卡片上 4 个按钮）。

## 共同做法

1. **揭晓那一下一定有一下「闪」：9/9。** 吸血鬼橙色爆星、弹壳红色三角、宝可梦全屏白、皇室白卡 + 绿粒子、BALL x PIT 爆光、HoloCure 6 瓣星芒、星露谷十字星、云顶光柱 + 闪白、炉石白闪。
   其中 **6/9 是先变白 / 变亮把「换图」盖住**再换（宝可梦、皇室、云顶、炉石、吸血鬼、BALL x PIT）。
2. **换图本身是 1 帧硬切，不做新旧交叉淡化：6/9**（吸血鬼 63.61、皇室 100.23、HoloCure 44.53、BALL x PIT 6.57、星露谷 8.50、云顶 7.60 都是单帧帧差尖峰）。只有宝可梦用「闪白后分 7 档渐退」慢慢露出新形。
3. **揭晓前先让玩家看见「旧的 / 材料」：7/9**（弹壳、宝可梦、皇室、BALL x PIT、HoloCure、云顶、炉石）。其中 **4/9 把旧的往中心收拢 / 合体**（弹壳材料飞入、BALL x PIT 公转再收缩、HoloCure 两图标靠拢、炉石三张收拢）。不给旧的只有 2 款（吸血鬼只给滚动候选，星露谷直接举新工具）。
4. **蓄力段「越来越快 / 越来越亮」：5/9。** 宝可梦切换间隔 365 → 66 ms；BALL x PIT 闪的间隔 1.20 → 0.77 s 再收缩；吸血鬼背景亮度 6.3 s 线性拉满；皇室卡 950 ms 变白；云顶金光 770 ms 变亮。
5. **揭晓后出名字 / 标题文字：6/9**（吸血鬼、弹壳、宝可梦、皇室、HoloCure、星露谷）。**给「旧 → 新」数值的只有 2/9**（弹壳 3 行、皇室 5 行），而且都排在揭晓之后、一行一行出。**用颜色 / 星标表示新档位：3/9**（弹壳传说红、云顶金 + ★★★、炉石金框）。
6. **结束要玩家点一下：6/9**（吸血鬼、弹壳、宝可梦、皇室、HoloCure、星露谷）；自动结束 3/9（BALL x PIT、云顶、炉石）。
7. **接管画面（切专门场景 / 面板）：6/9**；**原地播、不停游戏：2/9**（云顶、炉石），星露谷原地播但角色定住。
8. **时长两极分化，看发生频率。** 触发 → 揭晓：星露谷 ≈0、炉石 0.47 s、弹壳 0.8 s、云顶 0.9 s、HoloCure 1.33 s、皇室 1.63 s、BALL x PIT 5.2 s、吸血鬼 6.3 s、宝可梦 16.0 s，**中位数 1.33 s**。

## 最值得借的 3 条

**1. 宝可梦的「白剪影新旧交替、越换越快」，压到 1 秒左右，直接用在 45 px 的斧头上。**
我们 9 个形态是同一个正交镜头渲的、像素比例一致（铁斧待机斧高 45 px），但刃形差别很大（木斧 → 钻石斧刃形不同，四个终极造物差得更多），
白剪影一交替，玩家一眼就看出「从 A 变成了 B」。这是样本里**唯一一个只用两张现成帧就讲清楚变化的做法**：旧形 idle 第 0 帧 + 新形 idle 第 0 帧，
涂成纯白就是剪影，不用画新素材；纯白 + 硬切，像素边不会糊。
- 宝可梦原版节奏（`03b` 实测）：每个形态停留 365 → 300 → 266 → 200 → 130 → 100 → 66 ms，6.7 s 里切 59 次，最后闪白 230 ms + 停 500 ms。
- 压缩版建议：旧形变白剪影停 150 ms → 交替，每次停留 180 / 140 / 100 / 70 / 50 / 33 ms，每个间隔各切两次（约 12 次、≈1.1 s）→ 全白 2 帧 → 1 帧硬切成新形彩色帧 + 一圈像素爆点。
  总长 ≈1.3 s，正好是样本中位数。

**2. 按地点分两档：反复发生的地方「原地播、不拦操作、≤ 0.9 s」，一局一次的地方才「接管画面 + 等玩家点」。**
样本里会反复发生的合成全都 ≤ 0.9 s：炉石全程 0.83 s、云顶到闪白 0.9 s（这两个还不暂停）、弹壳到闪光 0.8 s。
接管画面的长动画全是一局一次的大事件：吸血鬼 7.1 s、BALL x PIT 5.2 s、宝可梦 16 s。落到我们 4 处：
- **商店（买到斧头当场升档）**：就在那张卡 / 格子上原地播第 1 条那套，不弹窗、不挡购买和刷新（照云顶 / 炉石）。
  0.9 s 太紧就把交替砍到 6 次（≈0.6 s），加闪一共 ≈0.8 s。
- **结算界面 / 战后补播（战斗中击杀攒的升档）**：给一个小面板，照弹壳 2.2 s 自动段：剪影交替 ≈1 s → 名字 + 一行「旧 ➜ 新」数值（新值绿字，
  照弹壳「Max Level 110 ➜ 120」那行，行间隔 300 ms；**别学皇室每行 0.8 s 滚数字，5 行就是 4 s**）→「点击继续」。
  一场连升两档就排队连播，每档 ≈1.5 s，点一下跳到下一档。
- **终极四选一**：一局只有这一次，值得接管画面 2～3 s：照 HoloCure 1.33 s 合体 + 1 帧闪 + 大字标题（「COLLABORATION!」那种），
  或者照 BALL x PIT 收缩成一个点再爆开（收缩 1.6 s 太长，压到 0.6 s），然后出造物名字 + 一句效果，等玩家点确认。

**3. 揭晓那一下 = 用新档位颜色的闪光盖住的 1 帧硬切，名字 / 数值晚 300 ms 再出。**
6/9 换图是 1 帧硬切，6/9 用白 / 亮光把替换盖住。闪的长度可以很短：云顶闪白峰值约 100 ms、炉石 ≈170 ms、宝可梦 230 ms 拉满再停 500 ms。
颜色照弹壳（传说 = 红）、云顶 / 炉石（金）：我们木 / 石 / 铁 / 金 / 钻石五档本来就是一条颜色阶梯，
闪光和爆点用**新档位的主色**（四个终极造物各用自己调色板 `axe_<形态>` 的主色），玩家不看字也知道升到了哪一档。
像素上照 HoloCure / 星露谷 / 吸血鬼：斧头像素图只平移、硬切，不做平滑缩放和旋转；粒子用 1～2 px 方点（皇室绿色方块粒子、HoloCure 四角星）。
名字和数值在闪之后出：弹壳闪光后 500 ms 出第一行数值，HoloCure 名字跟闪同帧；我们放在闪后 300 ms 左右。

**别学的**：吸血鬼金币数完后 ≈4.85 s 什么都不动、开箱老虎机 6.3 s；皇室属性滚 4 s；宝可梦整段 20 s。放在一局一次的地方可以，放进商店流程会拖住玩家。
