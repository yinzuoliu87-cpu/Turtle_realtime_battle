## 0. 方法（怎么保证没漏）

| 环节 | 做法 | 为什么 |
|---|---|---|
| 抽帧 | `ffmpeg -fps_mode passthrough` | 写 `-r 30` 会重采样：这段是 **29.59 fps / tbr 30**，强制整数会补帧或丢帧 |
| 核对 | 容器 **2480 帧** vs 落盘 **2480 张** | 对不上就是漏了，当场看得见 |
| 定位事件 | **两条基线**：`帧N vs 帧N−1`（抓突变）+ `帧N vs 帧N−15`（抓慢淡入淡出） | 只用第一条会漏掉慢变。实测 22s `d1=0.09 / d15=92.32`、29s `d1=0.50 / d15=111.14` —— **这些秒在单基线下就是"什么都没发生"** |
| 小面积动画 | 整帧平均会把小东西抹平 ⇒ 改用 **8×8 分块取最大块** | 实测 16s：全帧 `0.07`，块级 `3.67`（**52 倍**）。加载屏被单一度量误判成"静止" |
| 方向 | **逆时针 +90** | ⚠ 这段是**竖屏包装的横屏内容**（592×1280 → 1280×592）。我前半程按竖屏算的坐标**全错**，已废弃 |

⚠ **源头天花板**：30fps = 一帧 33ms。真机上 1~2 帧的闪光，这段录像里**可能本来就没有**。
本篇只保证「录像里有的没漏」，不保证「游戏里有的录像里都有」。

## 2. 加载屏（#3，15.2 秒）—— 和我们主菜单同尺寸并排

两张都是 **1280×592**。

| | Botworld | 我们 |
|---|---|---|
| **背景** | **有纵深的场景**：前景枝叶压边 → 自己的角色**背对镜头望向画面** → 远景火山岛/海/云 | **一面平铺的龟头像墙**：无纵深、无地点感；龟被裁在边上、大小不一、部分发灰 |
| **玩家在不在画里** | 在 —— 你在看你自己 | 不在 |
| **加载时说什么** | 顶部深色胶囊 + 青色 ⓘ：**玩法小贴士**（「你可以使用廉勾的终极能力以制造强大的组合攻击」） | 无加载屏 |
| **进度** | 底部细条 + 数字（0%→6?%→89%→97%）+ **齿轮（加载中也能进设置）** | — |
| **角落** | 左下 `fmod` 署名、右下 build id + `v1.36.1`，都很轻 | 右下 `v0.19.476` |

★**最大的差距不是控件，是背景在不在演一个世界。** 它把 15 秒的等待当成一幅画来用。

## 3. 出装屏（#12）—— 和我们背包同尺寸并排

| | Botworld 出装屏 | 我们的背包 |
|---|---|---|
| **这一屏干几件事** | **一件**（当前页签只管「装置」） | **四件**：上下路阵容+装备格 / 羁绊 / 装备背包 / 货币 |
| **已装备格子** | 和背包格子**一样大**（≈96×96 = 屏宽 **7.5%**），单独一区，青色描边 | **40×40 = 3.1%，塞在龟卡片里** |
| **背包格子** | ≈96×96，间隙 ≈30px | 86×72，间隙 ≈10px |
| **名字** | 在格子**外面**，青色，看得清 | 在格子**里面**压着图，≈10px |
| **已装备 vs 拥有** | 一条青色折线**在空间上分开** | 混在两区，且**用不同大小** |
| **页签** | 4 个，当前页签有实心底 | 2 个纯文字，当前态不明显 |

★★**这才是「装备格 21.7pt」的根**：在我们的版式里，**「已装备」不是一个正经的装备格，是龟卡片上的小装饰**。
Botworld 给已装备与拥有的是**同一种格子**，只是分区不同 —— 所以点它、卸它都不别扭。
⇒ 把格子放大到 44pt 在现版式里几何上做不到（右列可用宽 128 ⇒ (128−8)/3 = 40.0 整），
**真正要改的是"一屏只展开一个单位"这件事**，不是把格子硬撑大。

## 4. 战斗（#6）

- **入场那一刻 HUD 几乎是空的**：左上一个小图标、右下一个淡摇杆，别的全没有。
- **「竞技场」是画在世界里的** —— 地上一圈发光的环 + 四个青色入口，不是 UI 覆盖层。
- 战斗中：单位卡贴在**左右两条竖边**（带等级角标），底部中间一个「自动战斗」勾选。
- **暂停层**：手绘发光描边的框（不是矩形面板）+ 猫爪装饰 + 双关标题 **PAWS'D**；
  两颗按钮「放弃战斗」（橄榄色）/「继续」（绿色）—— **安全的那颗是绿的**；
  背景**压暗但仍看得见**自己的队伍与战场。

★结论：**它把状态放进世界，而不是堆进 HUD 边框。**

## 6. ★★ 自我更正（量完之后推翻了上面两条判读）

写完 §2 §3 之后我又量了**持续动画强度**（排除一帧跳变，只看连续帧的变化），结果推翻了两条：

### 更正一：加载屏**不是**「在演一个世界」，它基本静止

| 屏 | 持续变化均值 | 判读 |
|---|---|---|
| 主城 | **4.43** | ★持续在动（可走动的活世界） |
| 世界地图 | **2.29** | ★持续在动 |
| 战斗 | 1.39 | 轻微 |
| 出装/背包 | 0.54 | 轻微（只有左边角色在待机） |
| **标题/加载屏** | **0.11** | **基本静止** |
| 装备详情 | 0.10 | 基本静止 |
| 大格子库 | 0.03 | 基本静止 |

⇒ §2 里我写的「它那一屏在演一个世界」**是错的**。它是**一幅构图很好的静止插画**（有纵深、玩家角色在画里），
但它**不动**。差距在**构图**，不在动效 —— 这两件事我不该混为一谈。

### 更正二：面板**不是**滑进来的，是一帧硬切

我从 0.5 秒一格的印相里读出「侧栏滑入」，那是**采样太稀造成的错觉**（两格之间隔了 15 帧）。
逐列量出来：

```
f1494  只有 3 列与静止基线不同
f1495  918 列不同          ← 一帧之内整屏换掉（≤33ms）
f1495~f1511  左缘从 x=158 微调到 x=148（约 10px / 0.5 秒）
```

f1494 是「机器人军团」页、f1495 是「装置」页 —— **页签切换，中间没有任何过渡帧**。
另外三处多帧事件（f1525 / f1539 / f1814）逐列量下来**同样是一帧跳变**。

### ⇒ 由此得到的真结论

**Botworld 把动画预算全花在「世界」上（主城 / 地图 / 战斗），UI 屏几乎是静止的，转场是硬切。**

这一条直接否掉了我自己前面两个打算做的东西：
1. ~~给装备详情面板做滑入动效~~ —— 它不做转场动画
2. ~~卸下装备后飘一句「卸下了 X · 已放回背包」~~ —— 它没有任何文字横幅（已撤）

★**方法教训**：0.5 秒一格的印相**只能用来导航，不能用来判读动效**。
我拿它读出了一个不存在的滑入动画，还差点照着它去实现。
「一帧帧看」的意思是**逐帧量**，不是「看的图比平时多几张」。

### 顺带量到的 tooltip 形状（f1494）

带**尖角指向源卡片**的气泡，里面是风味文字（「基说它不是最灵活的机器人…」），
**不压暗背景**、不挡操作。这是它展示"这东西是什么"的方式。
