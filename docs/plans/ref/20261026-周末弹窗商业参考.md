## 美术本身学什么（用户「你学习来什么美术」后放大原图重看）

1. **有光源**：画面中心最亮 —— 荒野乱斗领奖是蓝底放射光，皇室开箱是宝箱自身发光。
2. **亮度 / 饱和度分主次**：背景暗、偏灰；主角（宝箱、奖励、立绘）最亮最饱和。
3. **材质与体积**：顶栏、按钮、格子都是上沿高光 + 下沿暗边（凸起、可按）。
4. **粗深色描边统一画风**：物件和字都有描边，字还带落影。
5. **奖励格图标撑满**：图标占格约八成，数量白字黑边压在格子下沿，格框颜色 = 稀有度。
6. **主角破框**：皇室卡牌弹窗里立绘顶出弹窗上沿。

像素画里的做法：放射光用逐帧 + 抖点（不用平滑渐变、不旋转）；高光 / 暗边按 1 像素台阶画；描边统一 1 像素深色。

## 共同构成（我们照这个做）

1. **标题有底板**：缎带或顶栏，字粗、描边。没有一家是「一行字飘在框里」。
2. **一张主视觉**：宝箱 / 金币堆 / 立绘 / 场景模型，占弹窗 30~50% 高度，常常顶出框外；成功时背后发光（放射光、光晕）。
3. **数字单独放大**：「x 85」「+750」「+22」都是整块里最大的字之一，不混在句子里。
4. **奖励 = 格子**：图标占满格子、数量压在格子下沿；多件并排。
5. **文字极少**：0~1 句；规则说明不在这一屏讲。
6. **一颗主按钮**：颜色和其它按钮明显不同（蓝 OK、绿升级、黄继续）。
7. **入场有层次**：框先弹出，主视觉、奖励依次出现（荒野乱斗领奖逐件弹出、皇室开箱逐张翻）。
