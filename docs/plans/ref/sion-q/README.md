# LOL 塞恩（Sion）Q · Decimating Smash — 视觉参考

> 用户 2026-09-03:「给我去搜lol塞恩机甲皮肤的Q，逐帧看」

## 来源

- 视频：`Mecha Zero Sion Skin Spotlight - League of Legends`（YouTube `V4YEUY_yiT0`，227 秒）
- Q 出现在 **115.2~117.5 秒**（屏幕上有 `Decimating Smash` 字样）
- 抽帧：30fps（`ffmpeg -ss 114.8 -t 2.4 -vf fps=30`）

★ **下载要点**（下次别再踩）：
- 必须走代理（`HTTPS_PROXY`），绕过会超时
- 必须强制 **H.264**（`format='best[vcodec^=avc1]'`）—— 默认给 AV1，本机 ffmpeg 解码失败，
  227 秒的片子只抽出 54 帧还不报错
- 找技能段的办法：先 1fps 抽全片，算**相邻帧灰度差**排序，变化最大的时刻就是技能爆发

## ★ 真参考：机甲皮肤的满蓄 Q（`sion.mp4` 1:59~2:02）

用户 2026-09-03：「这是机甲皮肤？？你别撒谎行吗」→「1分59到2分02吧」

原生 **29.97 fps**，108 帧抽在 `C:/tmp/sionref/m2/`。归档 `MECHA-*.png` 九张关键帧 + 一张总览。

| 时间 | 进度 | 画面 |
|---|---|---|
| 119.97s | — | 干净 |
| **120.00s** | 0% | 地上出现一条**细白线** ← 蓄力起点 |
| 120.60s | 31% | 线向外延伸变长，青色，橙黄亮点沿线跑向末端 |
| 121.10s | 57% | 线折返回来合成**封闭长条轮廓**，青色接管 |
| 121.37s | 71% | 区内浮出**淡的六边形网格纹理** |
| 121.70s | 88% | 边线转**黄** |
| 121.90s | 98% | 边线转**橙** |
| **121.94s** | 100% | 边线变**红**，释放 |
| 122.04s | — | 橙白六边形网格大爆发 |

**蓄力 = 120.00 → 121.94 = 1.94 秒**（塞恩 Q 上限 2 秒 ⇒ 这就是满蓄）。

### 边线色相分群计数

判据：青 150~215° / 黄橙 12~70° / 红 <12°∪>340°，亮度>0.42 且饱和>0.34。

```
进度      青占比   黄橙占比
0~46%     16→37%   63→54%    线在延伸，黄橙火花沿线跑
48%       66%      27%       轮廓合拢，青色接管（占比突跳）
48~76%    62→89%   27→6%     纯青
84%       48%      48%       黄橙杀回来
100%      —        —         红群从 ~300 突增到 2199
```

⇒ **参考用【颜色】表达蓄力进度，不是用闪烁频率。**

★量法坑：第一版取「色相的环形向量平均」，在 84~98% 报出 99~123°（黄绿），
而判据明明排除了 70~150° —— 那是**黄群(50°)和青群(180°)平均到中间**的假值。
**双峰分布不能取平均，要分群计数。**

### 地面网格的浓度

对比 119.50s（预警前）与 121.30s（67%）同一块区域：

```
区内  亮度 52.3 → 53.8  = 103%   ← 几乎没变
区内  纹理对比度(标准差) 17.6 → 25.7 = 146%
★分母: 区外同两帧也在变(+4.4/−0.3/+12.6)，所以上面取的是净值
```

⇒ **是往地面「加纹理」，不是「改亮度」。** 纯色填充改亮度但不改对比度，方向从根上就不对。

### 判断场地

黑场地面亮度只有 ~10，同样的叠加算出来是 **364%**，而参考只有 103% —— 会读成"一块板"。
**黑场适合看"特效自己长什么样"，不适合看"特效与地面的关系"。**
台子为此加了 `VFXLAB_REALMAP=1`。
