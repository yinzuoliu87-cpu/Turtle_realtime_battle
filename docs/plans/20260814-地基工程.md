## 2. 调查：地基到底什么状况（全是实测数字）

### 2.1 一个需求炸出四处分歧

用户只提了两条需求（熔岩削弱、星际调整），过程中挖出：

| # | 分歧 | 性质 |
|---|---|---|
| 1 | 熔岩**火山形态的普攻与 A/B 两技**在 `skillPool` 里没有条目 | 玩家看不到；图鉴与战斗内信息栏显示的是远程形态那套 |
| 2 | 星光弹文案写「追加星能 30%」，代码 **12%** | 2026-07-16 削过，文案三个字段都没跟上 |
| 3 | 星波彗星文案写「1.5×ATK 魔法」，代码是**全部星能真伤**（377，无视双抗） | 差 5.6 倍 + 多了穿甲 |
| 4 | 虫洞倍率挂在**跨路累加**的 `battle._t` 上 | 下路开场 10.5×、决胜 24×（CLAUDE.md §3.4 明文警告过的坑） |

**四处里三处是文案与代码不符，一处是接错时钟。** 都不是「难发现的深层 bug」，是**没人对账**。

### 2.2 技能系统的门禁覆盖率

变异探针（先拿已知答案的函数 2/2 校准过）实测：把某个系统的主函数整个换成 `pass`，
跑**全套 200 项门禁**，看红不红。

| 批次 | 结果 |
|---|---|
| 11 个「名字配不到门禁」的系统 | **8 个裸奔**（泡泡/宝箱/钻石/赌神/猎手/**熔岩**/火箭/阴燃），3 个守住 |
| 19 个「名字配得到门禁」的系统 | **没测完**（批次跑到一半被我停掉，因为它和我的门禁运行互相干扰） |

★「名字配得到」不等于有人守：`star_system` 配的是 `verify_equip_star_highlight`
——那是**装备星级高亮**，跟星际龟毫无关系。**文件名匹配不是证明。**

### 2.3 文案对账的真实覆盖面

| 工具 | 管什么 | 状态 |
|---|---|---|
| `pet_number_audit` | 龟技能文案数值 ↔ 代码（**双向**：数值没写错 + 效果没漏写） | ✅ 在门禁里、正常工作，**可对账效果 80 条**、3 条登记为「故意隐藏」 |
| `brief_detail_audit` | brief ↔ detail 数值一致 | ✅ 在门禁里、正常工作 |
| `tooltip_number_audit` | **装备**文案数值 ↔ 代码 | ✅ 在门禁里 |
| `tri_audit` | 龟能消耗 / 图标存在性 / 文档缺不缺小节 / 具名常量 / 击飞系数 | ✅ 但**不管技能数值文案** |

**那 80 条是怎么漏掉上面四处的？** 因为它对的是「文案里写了的数字 ↔ 代码里找得到的数字」，
而 §2.1 的 #1（**代码有技能但 `skillPool` 里根本没条目**）落在它的盲区：没有条目就没有文案，
没有文案就没有数字可对。**它查得出「写错」，查不出「没写」。**

## 4. 方案：三条工作流

### W1｜把「代码有但文案没有」堵死（最高优先）

`pet_number_audit` 现在只能对**已存在的文案条目**。要加一条**反向**检查：

> 扫 `_sk_*` / 形态分派表里**实际会被玩家触发的每一个技能分支**，
> 逐个回查 `pets.json` 有没有对应条目；没有就红。

- 已知会被抓出来的：熔岩火山形态的 **普攻 + A技 + B技**（3 条）
- 预计还会抓出：其他有形态/相位切换的龟（龟壳、宝箱、赛博机甲…）
- **工时估计：半天**（写检查 + 把抓出来的条目补齐 + 反向验证）

### W2｜跑完 30 个技能系统的裸奔普查

- 剩 19 个没测（工具已建并校准：`tools/mutation_probe.py`）
- **必须单独跑**，不能和别的门禁并行——今晚就是因为并行导致误报
- 产出：一份「30 只龟里哪些裸奔」的完整名单 + 按逻辑复杂度排的补门禁优先级
- **工时估计：跑一夜（无人值守）+ 半天整理**

### W3｜按名单补门禁

- 优先补：**逻辑最重 + 最近改过**的（熔岩 ✅ 已补、宝箱 146 行、赌神、猎手）
- 每条按今晚定下的标准：判据量产品自己的账 / 反向验证会红 / 裕度足够 / 缺口显式登记
- **工时估计：每只龟 1~2 小时**，8 只已知裸奔的约 2 天

## 6. 验收标准

1. **W1**：故意把某只龟的一个形态分支从 `pets.json` 删掉 ⇒ 新检查必须红（反向验证）。
2. **W2**：名单里每一条都有「打瘸后全套红/不红」的实测记录，不是推断。
3. **W3**：每条新门禁都反向验证过会红，**且裕度足够**（今晚 031 的 0.14 裕度在 CI 上翻转过）。
4. 全套门禁绿 **且 CI 也绿**（本地绿 ≠ CI 绿）。
5. 收尾 `git status` 干净——**不看测试绿不绿，亲自看 diff**。
