日期：2026-10-22　|　状态：**实施中**

## 2. 调查结论

- 背包页 = `scripts/scenes/InventoryScene.gd`（1742 行）+ 拆出去的 `InvOps`（装 / 卸 / 卖）`InvSynergy`（羁绊列）`InvCandyJar` `InvFormation`。
- 画风：底色 `#0a1622` 纯色（`InventoryScene.gd:197`）；战场带 / 单位卡 / 背包格走 `UISkin.nine("slot-frame.png" / "panel-frame.png")` 深蓝金属框（`:384` `:476`）；顶栏 `TopBar.DEEP`（`:218`）。商店已是像素木质（`ShopScene` 木牌顶栏、`shop-plank.png`、场景底图）⇒ 两页来回切像两个游戏。
- 交互：现在只有点选。点背包格 = 选中（`_on_bench_click` `:1410`），再点单位卡 = 装上（`_dl_click` `:705`）；选中时单位卡边框换绿（`:464`），但贴图框只是 `modulate` 染色，实拍几乎看不出（10-22 截图）。底部操作条 `OP_BAR_H = 132`（`:65`）选中后盖住背包第二排（截图「▼下面还有」）。
- 单位卡里装备格硬上限 40px（`:582-597` 长注释：卡片 244 宽、右列 128 ⇒ 40 是版式上限）⇒ 要放大只能改卡片版式，不是改常量。
- 战场带常驻图例 `LANE_LEGEND_TOP / BOTTOM`（`:403-409`）。
- 拖拽：背包页没有任何 `_get_drag_data`；商店 10-18 做过又撤掉（用户「为什么要拖入宝箱去购买？」，`20261018-商店背包合一.md:165`）—— 撤的是「拖进宝箱才算买」，不是装备拖拽。

## 3. 需求 ↔ 代码的出入

- 「选中后能装的龟高亮」代码里**已有**（绿边），但贴图框 modulate 后肉眼几乎看不出 ⇒ 不是没做，是做了看不见；改成卡片整体抬亮 + 脚下金光 + 不能装的压暗。
- 「龟身上的装备图标太小」：40px 是旧卡片版式的硬上限，不改版式放不大 ⇒ 单位卡改成竖卡（立绘在上、三格在下）。

## 4. 方案

**交互（先做，最影响手感）**
- 背包格 = 卡片：按住拖起 → 卡片跟手（放大 1.12、投影），松手落在单位卡上 = 装上；落在背包区 / 别处 = 放回。点选流程全部保留（点卡 → 点龟），拖拽是快捷方式。
- 单位卡上已装的装备也能拖：拖到另一只单位 = 换人；拖回背包区 = 卸下。
- 拖动中：能接的单位卡抬亮 + 金边，不能接的（满 3 件 / 全队上限 / 占位统领）压暗；松手在不能接的卡上 ⇒ 弹一句原因（「全队装备已满 N/N」「这只龟装满了」）。
- 选中（点一下）：卡片旁出一张小说明卡（同商店说明卡），按钮「详情 / 卖出」；不再用整条底栏，不挡背包格。能装的龟同样抬亮。
- 背包区是滚动列表 ⇒ 竖向滑动 = 滚动、按住后横向 / 斜向移出 = 拖起（阈值判方向），避免滑动列表时误拖。

**画风（跟商店同一套）**
- 顶栏：商店那一套（木牌签、币木牌）—— 方案里点名过、用户「做」。
- 背景：新做一张像素场景（军械库 / 后仓，PixelLab Pro 出图，不拿商店底图顶）。
- 战场两条带 → 木板；单位卡 → 竖卡（立绘大、三格 56px 在下、名字在立绘下沿）；背包格 → 卡片框（费用色宝石 + 星）。框用像素九宫格（脚本画，同 `shop-plank` 的做法，按本页新画）。

**信息**
- 背包格右上角合成进度「2/3」（同名同星已有几件，口径 = `ShopScene._owned_count` 同一套：同 id 同星）；差一件即合成的格子加角标。
- 背包顶上一排排序：默认 / 星级 / 费用 / 羁绊（只改显示顺序，不动存档顺序）。
- 删战场带常驻图例（规则在「?」里）。
- 羁绊行：星星换成「下一档还差 N 件」。
- 版式按屏高铺：iPad 下面那三分之一给背包格子。

**改动面（穷举）**：`InventoryScene.gd`（`_rebuild` / `_build_lineup` / `_dl_unit_box` / `_build_equip_cells` / `_build_bench` / `_item_cell` / `_equip_cell` / `_build_op_bar` / `_build_unit_equip_bar` / 教程锚点 `_tutorial_anchor`）、新 `scripts/scenes/inventory/inv_drag.gd`（拖拽）、`inv_skin.gd`（像素框）、`synergy_panel.gd`（还差 N 件）、新素材 `assets/sprites/inventory/`。门禁跟着改：`verify_inventory_layout` / `verify_inventory_text_fit` / `verify_inventory_name_fit` / `verify_shop_inv_phone` / `verify_ui_consistency` / `verify_ios_ui` / `verify_tutorial_flow_v3`（背包三步）/ `verify_first_tips`（羁绊提示锚点）/ `verify_synergy_display`。

## 6. 验收标准

- 新门禁 `verify_inventory_drag`：真实例化背包页，模拟按下 → 移动 → 松开（`DisplayServer` 级的鼠标事件，不直接调函数）：
