## 1. 技能装配 → 全部五选一（单技能）【设计更正·核心】

### 1.1 错在哪（旧实现 + 旧方案书都错）
- 现 `TrainerConfigScene.gd`：**形象 / 被动 / 主动** 三排单选——等于"配 1 被动 + 1 主动"**两个技能**。
- 旧方案书 §1.2 数据模型 `trainer_passive` + `trainer_active` 两字段，也是这个错。
- **用户真实设计（2026-07-26 复述"之前就说过"）**：`{魔法石(被动), 钩锁, 怒火, 口哨, 冰川}` **五个里只能选 1 个**。选魔法石 = 只有被动、**没有主动 Q**；选某主动 = 有那个 Q、**没有被动**。**一个大师只带一样本事。**

### 1.2 改动
| 处 | 现状 | 改为 |
|---|---|---|
| `GameState` | `trainer_passive` + `trainer_active` 两字段 | **合成一个** `trainer_skill: String`（默认 `"hook"`）。旧两字段迁移/废弃 |
| `TrainerConfigScene` | 三排（形象/被动/主动） | **两排**：形象 + **"技能（五选一）"**；下方说明卡（复用 `SkillText`/LoL 风） |
| 战斗接线 `_make_unit` 大师分支 | 读 `_tr_passive`+`_tr_actives` | 读 `_tr_skill`；**是 `magic_stone` → 挂 on-hit 被动**、**是主动 → 装进法术圆盘** |
| 敌方/快照大师 | 带 passive+active | 带**单个** `trainer_skill` |
| 法术圆盘（选到被动时·2026-07-26 更正） | 旧想法"隐藏圆盘" ❌ | **圆盘不隐藏**：显示**被动图标**（魔法石）+ 圆框**循环特效**（旋转光环/呼吸辉光）表示"被动生效中"；点击无响应（非主动）。（用户明确要"右边也要有图标·加个循环特效表示被动在启用"） |

### 1.3 实施前需核实
- `GameState.save()` 存档字段迁移：老存档带 `trainer_active` 时映射到 `trainer_skill`。
- `_make_unit` 大师分支现初始化了哪些 `_tr_*` 字段（一处改全）。
- 选到被动（无主动）时：法术圆盘 `spell_disc` 要能"无技能"隐藏（`_hook_dramatize`/`_cast_active` 入口需容忍无主动）。

### 3.1 战场瞄准指示器（`_draw_aim_indicator` 现只一条细线·PC 还没有）
现状：`RealtimeBattle3DScene.gd:1722 _draw_aim_indicator` 只在 `_disc_aiming`（手机拖动）时画一条 15px 橙线到射程末端；**PC 按 Q 直接瞬发、无预览**；**无射程圈/落点圈/带宽预览**。

**重做——具体设计（2026-07-26 拍板：地面世界空间·半透明·每帧跟随）：**

**状态机（PC 已定：按住 Q 出指示、松开释放）：**
- 就绪：圆盘显技能图标 + 冷却扫描。
- **按住 Q（PC）/ 按住圆盘（手机）= 进入瞄准态** → 地面出指示器，跟随鼠标/拖动实时更新。
- **松开 = 释放**；拖回圆盘内 / 死区轻点 = **快速施法**（自动瞄最近敌 / 默认朝向）。

**三种技能三种指示器：**
- **钩锁（方向直线）**：大师脚下一条**方向指示带**，长 = 600 码，隐约露出 80 码判定宽，末端箭头；**高亮它会勾到的第一个敌人**（命中预览·复用 `_hook_first_target` 判定）。青色。
- **怒火（点目标）**：大师身周一个 **700 码射程大圈**（最大射程·静态）+ 光标/触点处一个 **300 码落点预览圈**（AOE）；**超 700 夹到大圈边缘**（Wild Rift 口径）。橙色。
- **冰川（方向带）**：从大师沿瞄准方向一个 **500 长 × 90 宽的矩形带**（就是冰会铺的位置·和 `_tick_glaciers` 判定同形）。蓝白色。

**实现规格（2026-07-26 落地·`_draw_aim_indicator` 持久节点系统）：**

| 技能 | 类型 | 指示器 | 宽度/尺寸 | 箭头 | 色 |
|---|---|---|---|---|---|
| 钩锁 hook | 直线方向 | 方向带 + 末端箭头 + 高亮会勾到的敌(红圈) | 带宽 34(视觉·判定 80) · 长 600 | ✓ | 青蓝 |
| 冰川 glacier | 方向带 | 宽方向带(= 冰会铺的范围) + 末端箭头 | 带宽 **90(= 判定)** · 长 500 | ✓ | 蓝白 |
| 怒火 fury | 点目标/投掷 | 射程大圈 + 落点预览圈(超射程夹边缘) | 射程 700 · 落点 **300(= AOE)** | ✗ | 橙 |

- **直线 vs 投掷本质**：直线技玩家定**方向**→"带+箭头"; 投掷技玩家定**落点**→"射程圈+落点圈"。宽度=技能真实判定, 圈=真实射程/AOE。箭头只方向型有。
- **持久节点**(非每帧 spawn 短命 VFX): `_aim_ind` 字典存 band(PlaneMesh 躺平半透)/ring/land/tgt(Sprite3D 用 `VfxTex._make_ring_texture`)/arrow(箭头 mesh)·躺平·`no_depth_test` 恒在最上层; `_aim_band`/`_aim_ring`/`_aim_arrow` 每帧更新, 瞄准结束 `_clear_aim_indicator` 清。
- **件**: `_aim_band`(方向带)、`_aim_ring`(圈)、`_aim_arrow`(末端箭头·ArrayMesh 三角)、`_aim_free`(单键清)、`_clear_aim_indicator`(全清)。

## 4. 四技能逐个重做（现状→差距→按 5 关重做）

### 4.1 钩锁 hook —— 最实，补两个洞 + 拖拽节奏
- **机制**：全对规格（射程600/眩晕4s吃韧性/易伤×1.25/CD20·空放10）。
- **拖拽具体时间轴**（用户 2026-07-26 拍板"每秒70码·共4秒·拖4下"·并要"具体计划"）：
  ```
  t=0.0s  命中：局部顿帧(目标闪白+微缩放) + 钩子扎入 + 眩晕4s开始
  t=0.1s  第1下：0.2s内目标朝大师急滑70码(EASE_OUT"猛一拽") → 停顿
  t=1.1s  第2下：70码
  t=2.1s  第3下：70码
  t=3.1s  第4下：70码   (到大师前24码就停·不重叠)
  t=4.0s  眩晕结束：钩链/钩子消失(可加脱钩回弹)
  0→4s 每帧：重画 大师手↔目标 绷直钩链 + 钩子卡在目标身上(看得见一段段收线)
  ```
  - 常量改：`HOOK_PULL_INTERVAL 0.6→1.0`、`HOOK_TUG_DIST 42→70`、`HOOK_TUG_DUR 0.15→0.2`（`RealtimeBattle3DScene.gd:328-330`）。
- **④/⑤ 补洞**：
  - **命中冲击**：到达不只 `_skill_ring`——钩子**扎入 + 局部顿帧**（目标闪白+微缩放·**不用全局 hitstop**·见 §6 风险）+ 爆点。
  - **拖拽全程钩链**：`_tick_hooks` 期间**每帧重画大师↔目标的绷直钩链**（现在链条只在飞行 0.63s 有、拖拽 4 秒里断了 → "你画这线有啥用"的根）。钩子贴图停在目标身上。
  - **易伤可视化**（§3.2）。
- **① PC 瞄准预览**（§3.1·按住 Q 出方向带 + 高亮预览目标）。
- **门禁**：`verify_hook` 加断言——4 秒内**正好 4 次**位移、每次≈70、总≈280。
