## 4. 方案

- 形象：站立、好做动作的全新财神龟，**152×152**（自做组 136~156 档），右手金剑、腰挂元宝、官帽、红金官袍、龟壳背后嵌金币；脸 / 站姿区别于猎人 / 赌神。PixelLab create_image_pro_flash（6 次）。
- 动作（`animate_image_pixminimax`，首尾钉定稿，8 帧）：待机（循环）/ 走路（循环）/ 攻击（挥金剑，命中帧对 0.267 秒）/ 死亡（只钉首帧）/ 骰子 / 梭哈（蓄力 0.6 秒）/ 招财进宝。
- 打包：新写一个确定性打包脚本 pack_fortune_art（放 tools/assetgen），更新动作表帧数 / 帧率 / 命中帧 / 显示尺寸、立绘、头像、图鉴图。
- 主站：Telegram 交代 Tom（换哪些图、尺寸、文件直接发）。

### 设计原则（11-26 深夜用户认可；取代上面「新加」那一行的官帽官袍）

每个特征都要说得出出处，只有两个来源：①老形象的辨识点（像素墨镜、嵌金币的壳 —— 也对上被动聚宝盆攒金币）；②游戏里实际要做的事（金剑 = 普攻 / 打击；腰间骰子 = 骰子；钱袋 = 梭哈扔金币；近战辅助 = 能挥能扔的正常站姿）。不套题材行头（官帽官袍胡子，用户「财神味道太重了」），不写所有龟共有的（绿皮米黄肚皮厚壳），不凭印象加（大肚腩）。
出图：pixen，88×88 画布（身体约 80 像素高，对齐自做组），原样贴进 152×152 帧、脚底对齐底边，不缩放。

### 特效重做（11-27 用户「所有角色的动画都是没问题的，要改的只有特效」「普攻打中这个刀光肯定是要改的…一二三四都需要改」）

现状问题（演示台录像逐帧看的）：普攻借钻石龟斩弧 `diamond-slash.png` 染金 → 画面发绿，且违反「招牌不复用」；骰子 / 招财进宝共用同一张 `fortune-coin-burst.png` 大爆炸，炸开时把整只龟盖住近 1 秒；梭哈金盾 = 白闪 + 金环 + 随机金块，蓄力时一团白泡把龟盖住；聚宝盆每 3 秒脚下冒两根金柱，走路攻击时不停闪。
共同原则：特效围着龟、不盖住龟（龟身前只留半透明 / 细线，实心大块放身后或头顶）；颜色只用财神金（暗金描边 → 金 → 亮黄 → 白热芯），不用绿；每段专属，金币（方孔铜钱，11-27 新画）是财神龟自己的底层元素，五段里可共用；做法 = Aseprite 后台逐帧画的序列帧 + Godot 着色器 / 网格 + 代码驱动的金币粒子；随机一律走固定算式（不碰对局随机流）。
