# 010 激光长刃：图标与特效整体重做

日期：2026-11-27　|　状态：**实施中**

## 1. 需求原文

> 用户 11-27：「然后装备激光长刃的图标和技能特效都全部再重新做一遍，一样的，你是以特效师的身份去做，所以要尽量完美一点，然后最终给我看成果。」

## 2. 调查结论

- 机制（`equip_system.gd` `_eq_laser_sweep` / `_eq_laser_chop`，文案 `data/phase2-equipment.json` p2eq_010）：每隔一个攻击间隔朝最近的敌人斩出 120° 扇形激光（半径 = 攻击射程，3 星 ×2，近战 +250 码），扇形内每人一次全额伤害、出手同帧结算；只命中 1 人时朝它追加一道直线斩击，波前按 550 码/秒推进、碰到谁谁掉血；按总伤回血。
- 旧画面：扇形是 16 向 × 5 帧的平涂红色扇面（网点渐变），直线斩是 16 向 × 4 帧的波前精灵 + 5 帧落刃；图标是一把 32 像素的粗糙红光剑。
- 门禁 `tests/verify_eq_laser_blade.gd`：一半量旧序列帧的几何（扇形素材半径 = 判定半径等），一半量机制（无预警、波按距离先后打人）。

## 3. 需求 ↔ 代码的出入

- 「重新做一遍」只换画面：出手时机、判定、伤害、波速一行不动 ⇒ 不动 `RULES_VER`。
- 门禁里量旧素材的那半要换成量新网格（扇形网格半径 = 判定半径、张角 = 120°、光带宽 = 判定宽），机制那半原样保留。

## 4. 方案

- **参考先行**：`docs/studies/20261127-参考-永恩斩击特效配方.md` —— 永恩 W（扇形斩）与 Q（直线斩）的发射器配方 36 条、贴图 18 张（CommunityDragon 公开解包，不碰本机 LoL 目录）。学：时间分三档（亮刃 0.1 秒 / 余光 0.2~0.4 秒 / 地上痕迹 1.2~1.8 秒）、同元素叠两种混合、命中三道不同宽度横斩光 + 星 + 环 + 火花、灰度形状贴图 + 引擎上色。
- **分段表**：
  | 段 | 时长 | 内容 | 用什么做 |
  |---|---|---|---|
  | ① 出手 | 0~0.2 秒 | 携带者脚下红光一闪 + 刃根白星 | 贴地柔光 + 星光粒子 |
  | ② 扇形斩 | 0~0.25 秒 | 领先刃约 0.1 秒扫完 120°，后拖月牙余光 + 三道同心速度纹 + 外缘亮线；扫过之处沿弧迸火花 | `laser_fan.gdshader` 扇形网格 + 火花粒子 |
  | ③ 命中 | 刃扫到时 + 0.18 秒 | 三道横斩光（红 / 粉 / 白，一道比一道细）+ 四角星 + 冲击环 + 地面光 + 火花 | 灰度贴图粒子 |
  | ④ 地面熔痕 | 0~1.2 秒 | 刃扫过的地面留焦痕，熔裂纹 0.5 秒内由红热冷下去 | `laser_scorch.gdshader` 贴地扇形 |
  | ⑤ 直线追斩 | 推进全程 + 0.25 秒 | 携带者竖剑光一闪；光带波前按结算速度推进、身后拖光束余光、地上留熔痕；碰到谁谁出 ③；到头后光束从尾往前散 | `laser_beam.gdshader` 光带 + 熔痕 + 波前光粒子 |
- **图标**：64×64（与武士刀 / 激光手枪同规格），科技握柄（枪灰 + 防滑纹 + 红色导能灯）+ 金色十字护手（两端翘鳍、中间红宝石）+ 激光刃（白热芯 → 粉 → 红 → 深红，外圈淡光晕）+ 刃尖十字闪光与火花。逐像素按几何判层上色，分层存 `.aseprite`。
- **代码**：新文件 `scripts/scenes/battle/laser_blade_vfx.gd`（不在主文件），`equip_system` 只换掉画面调用；每帧推进挂在 `battle_render`。网格挂出处键、着色器参数挂 `stream_shader_params` ⇒ 逐帧直播照样看得见。

## 5. 已知风险与未决点

- 旧素材 `eq010-slash / wave / chop.png` 与生成脚本 `gen_laserfan.py` 删掉（新画面不用）。
- 伤害在出手同帧结算，命中特效按刃扫到它的时刻出（最晚约 0.1 秒）—— 画面与掉血数字差不到一刀的时间。

## 6. 验收标准

- 门禁：扇形网格半径 = 判定半径、张角 = 120°；光带宽 = 判定宽；无预警（触发到掉血 ≤ 0.05 秒）；直线波按距离先后打人；直播覆盖照过。
- 在演示台录成片：单人（扇形斩 + 直线追斩）、多人（扇形斩一次扫多人）两段，逐帧自检（命中时刻对上刃扫到的时刻、熔痕不盖在龟身上、光不钻地）。
