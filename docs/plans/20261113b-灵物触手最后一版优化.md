**② 待机（75–81 s，镜头固定）**

2. 卷成钩，钩头朝目标（约 0.3 s）。
3. **整根抡到身后、压得很低**，几乎贴地躺在身后，背鳍朝上，钩头一直卷着（约 0.3 s）。

**④ 拍下特效（39.10–39.35 / 45.15–45.85 s，60fps）**
1. 贴地前 1–2 帧：根部 → 目标几道白紫细**速度线**；目标脚下淡紫**光圈**。
2. 第 1–3 帧：整条路径一条亮紫**刀光**（白芯 + 一侧锯齿 = 背鳍剪影），目标处**白核爆闪** + 淡紫光球罩住目标 —— **此时本体还卷在根部**（特效先到）。
3. 约 +0.1 s：本体才弯下来贴地，刀光融进本体。
4. +0.15–0.43 s：本体贴地发紫光，远端几道粉白**锯齿电弧**在闪。
5. +0.33–0.65 s：本体变暗、从梢端先抬起卷回；沿路径留一条半透明暗紫**残影带**，慢慢褪。
6. 地面裂纹：触手周围地面是龟裂纹（裂缝透暗紫光），拍前拍后都在 —— 单次拍下是否新增裂纹逐帧无法确认；**按用户观察做**：根部常驻一片裂地 + 每次拍下沿路径炸开一串亮紫裂缝、冷却成暗紫后淡掉。

**⑤ 两根拍一个目标（39.2 s）**：两根各自蓄力、几乎同时拍下，两道刀光从不同方向汇到目标，目标处闪光叠加。我们两根根部上下分开（`ROOT_Y_HI / LO`），天然成 V。

## 4. 方案（穷举清单）

**不动**：状态机、各态时长（EMERGE 2.0 / WARN 1.0 / REAR 0.13 / SLAM 0.5 / RECOVER 0.4）、`T_TOUCH`、伤害挂点、预警带（`_telegraph_*`）、命中名单与逐个受击演出、根部位置 / 搬家 ⇒ **不改对局结果，不升 RULES_VER**。
**外形也改**（用户：「这个形象我都给你清清楚楚的展示了，只是去实现这个形象」）：照 §2.1b ② 做 —— 下透上实、螺旋钩头、大锯齿鳍、去掉环节与地洞、根部龟裂地。颜色仍用灵物紫（用户 11-01「你可以是紫色，但别搞猎奇」）。
**PixelLab 不用**：全部程序化（网格 + 着色器）。

1. **待机**（`_phase_at` ST_IDLE + 侧摆 `SWAY_*`）：周期拉长到约 4.5 s，角度 / 卷曲幅度放大到「整根起伏 + 卷钩明显张合」，侧摆加大放慢；三频叠加保留（不精确重复）。
2. **出手**：
   - 预警（ST_WARN）抬起时保留卷钩（卷曲不再松到 50），弧长放大量降下来 ⇒ 不再是直杆，是带钩的后仰弯弧；
   - ST_SLAM：`SLAM_SPEED` 调到约 4（下拍约 5 帧），`SLAM_HOLD = T_TOUCH × (1 − 1/SLAM_SPEED)` ⇒ 贴地仍在 `T_TOUCH`；hold 期间不定格 —— 继续往后压（蓄力加深），避免「定格」那一族。
3. **拍下特效**（`_impact` 前后 + 着色器 `flash`）：
   - 速度线：贴地前 1 帧，根部 → 命中点几道白紫细线；
   - 刀光拖影：贴地那一刻起，沿路径一条贴地偏起的亮紫带（白芯 + 一侧锯齿），约 0.15 s 亮、0.15 s 退；纯函数网格 `gen_tentacle_smear`（逐帧直播按出处键重建，同 `gen_tentacle_warn` 的做法）；
   - 目标爆闪：正对镜头的白核大闪 2 帧 + 淡紫地面光圈约 0.1 s，替换现在的小光斑；
   - 本体贴地发光：`flash` 从「2 帧 0/1」改成包络（2 帧满亮 → 约 0.35 s 衰减到 0），贴地那段整根发紫光。
4. **生成**（ST_EMERGE 2 秒内）：漩涡 → 黑影 → 光柱 → 尖芽竖直长出 → 展开成钩，照 §2.1b ①。
5. **地面裂纹**：根部常驻裂地 + 拍下沿路径裂缝（亮紫 → 暗紫 → 淡掉）。
6. 录像：实验台 `syn_spirit` + 侧视调试场 `demo_tentacle_side`，60fps，逐帧对照 §2.1。

## 8. 实施回填

**实际改了哪些**
- 控制器重写成 `TentacleRig`（一个控制器驱动整根线：俯仰 + 侧偏、欠阻尼弹簧跟随、背侧随身体平行传递），旧链式模拟 `_sim_chain` 与 33 个死常量删掉。
- 出土：对折（`_hairpin`，画面平面倾斜 + 往下段回卷）一直播到 1.18 秒；1.18 / 1.35 / 1.51 三张由离线模拟器 `tools/oneoff/spawn_sim.py` 搜出（根要稳、头匀速）；1.88 的圈保持到待机 75.0 秒那个姿势再交；芽按 LoL 相对待机的比例缩 0.745 倍；光柱淡入、挂录流出处键。
- 待机：`TentacleIdleKeys` A 段 = 中间那根每秒一张手标反推（我们的镜头），B 段补设计；`_prep` 弯折改用拟合原值（原来多绕一圈）。
- 拍下：4 击手标中位姿势（往后抡过头顶 → 刀光时本体卷着 → 晚约 2 帧贴地 → 回弹）；拍下特效 `TentacleSlamFx`（速度线 / 刀光拖影 / 目标爆闪）。
- 收回：刀光后约 0.32 秒就从根部拱起（`P_ARCH`），梢端拖在目标那边，拱高卷钩再回待机。
- 外形：自己设计的深海磷光灵体（`PALETTES.abyss_neon`，着色器 style 1）；着色器改写深度（身后那段不再画到前面）。
- 门禁按用户同意的删改清单：`verify_tentacle_soft` ①②④ 改成只看目标那一侧的落地，`verify_tentacle_vfx` ⑤ 在趴好时量够射程；直播块预算按实测重定（触手热参数涨的）。

**与方案的偏差**
- 用户中途把目标从「一比一照 LoL」改成「要这个质量、不照搬」，并要求以手标为基础；看不见的段（LoL 插进墙里的 1.01–1.51 秒）自己设计。
- 音效排期到路线图 §二·五 #13，没在这一版做。
- 用户 11-14 收尾时决定不再做：往后抡幅度加大、两根触手同时的情况、新外形设为默认（游戏默认仍是 `illaoi` 紫色，新外形只在调试场 `SIDE_PAL` 用）。

**新发现的坑**
- 2D 手标反推 3D 姿势不唯一：同一条线可以是「往身后倒」或「在画面里弯」，要用画面上的长度比例和连续性去约束。
- 半透明不写深度 + 整根一个网格按顺序画 ⇒ 身后那段画在前面，看着像姿势错（先查绘制顺序再动姿势）。
- 浮点末位抖动会让着色器参数每帧都「在变」（半径 float32 末位翻），录流跟着涨。
- 新写的程序贴图必须挂录流出处键，本机预检不选 `verify_stream_parity / coverage`，要自己跑。
