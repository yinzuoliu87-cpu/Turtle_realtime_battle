**共同点（数了出现次数）**：
1. 商店和队伍同一屏：9 / 9 个有商店界面的游戏都是。我们是唯一分两页的。
2. 商店一次 3~5 件：没有一款一行摆 10 件。我们一行 10 件。
3. 刷新 / 锁定紧挨着商店行：7 款。
4. 装备页角色居中、槽围一圈：7 款，其中 3 款直接在角色下面标属性变化（绿箭头）。
5. 说明是选中后弹出的卡，不是常驻大面板：BagMaster、超级自动宠物、金铲铲、云顶、The Bazaar。
6. 「已装备 / 未装备」分开显示：Rumble Bag、Weapon Master。
7. （D 组）买和装是一步：5 款直接「买并装备」，其中 2 款（歧路旅人、火焰纹章）是买的时候选给谁。没有一款要求买完换一页再装。
8. （D 组）选商品时就看到装上去属性变多少：6 款。
9. （D 组）钱不够、装不了，在卡上 / 按钮上直接标，不等点了再报错：歧路旅人「Cannot Equip」、Void Tyrant「Unaffordable」、Card of Darkness「Can't Afford」。

## 出入

- 现状两页来回，参考全部一屏；现状说明是固定大面板，参考全部是弹出小卡。
- 现状商店一行 10 件，参考一行 3~5 件。手机横屏上 10 件一行每张约 100 像素宽。
- 现状装备页没有「这件装上去属性变多少」，参考 3 款在角色下直接标。
- 本方案只改布局与操作，不改商品数量、价格、合成规则与任何数值（10 件怎么摆是布局问题，见未决点 ③）。

## 方案

一屏「备战」，横屏 1280×720 布局（手机按比例缩放，两种比例实拍验收）：

```
┌ ← │ 金币 21 │ Lv8 ━━━━ 62/84 │ 买经验 +4 (4) ───────────── 开始战斗 ┐
│ 出战阵容（上战场 / 下战场，每格：龟 + 3 个装备槽）      │ 羁绊（唯一一份）│
│                                                         │ 灵物 2/5 ◆◇◇◇ │
│                                                         │ 奇械 2/5 ◆◇◇◇ │
├ 备用栏（一行 8 格，多了横向滑）──────────────────────────────────────────┤
├ 商店（两行 × 5 张，价签在卡上）                        │ 刷新 2 │ 锁定 │
└────────────────────────────────────────────────────────────────────────┘
```

点某只龟时（参考 B 组），出战阵容区换成这只龟的装备视图：龟居中，3 个装备槽在两侧，下面是攻击 / 生命 / 双抗，拖着一件装备悬停在槽上时，属性旁显示变化（绿 ↑ / 红 ↓）。再点空白处回到阵容。

1. **买**：把商店卡拖到某只龟的空装备槽 = 买下并装上；拖到备用栏 = 买下放着；点一下商店卡 = 弹出说明小卡，小卡上两个键「购买」「购买并装备」（照 Demon Tides / 歧路旅人）。点「购买并装备」后，阵容里能装的龟高亮，装不了的（槽满）标「已满」，点一只龟即完成（照歧路旅人「选择要装备的角色」）。
1a. **钱不够**：商店卡价签变红、卡变暗（照 Void Tyrant），不等点了才提示。
1b. **属性变化**：选中商店卡时，阵容里每只能装的龟头顶出这件装上后的主要属性差值（绿 ↑），照异度神剑 / FFTA2。
2. **装 / 换 / 卖**：备用栏或龟身上的装备可以拖到别的槽；拖回商店区 = 卖出（小卡上也有「卖出」）。
3. **拖动时**：所有能放的格子高亮，放不了的变暗（照超级自动宠物的箭头）。
4. **说明**：点选任何装备、龟、羁绊 → 旁边弹小卡（沿用 10-06 定的云顶小卡样式），不再占右侧大面板。
5. **羁绊**：只留右侧一份，写法统一成「名称 2/5」加档位格。
6. **统领 / 小将**：龟格角上标「统领」「小将」小签，小将格上的「后排」换成前后排切换图标，第一次点时弹一句说明。
7. **入口**：主菜单「商店」「背包」两个按钮合并为一个「备战」。

## 已知风险与未决点

- 改动面大：Shop.tscn、Inventory.tscn 两个界面合一，涉及的门禁（商店布局、背包、教程流程、羁绊显示等）要逐个跟进；实施前先列全受影响的测试。
- 商店改两行 × 5 后会挤占阵容区高度，两种比例实拍确认龟格和商店卡都够点。
- 参考大多是竖屏手游，我们是横屏；布局照搬不了，学的是「同屏、件数少、刷新挨着、弹卡、属性变化」这几条。横屏同类（Underlords、酒馆战棋、云顶）的商店都是一行在屏幕边缘。
- 国内同类（金铲铲、王者万象棋、多多自走棋）的商店实拍本轮没拿到。
- 触屏拖动要和点选区分（按住拖 / 轻点弹卡），iPhone 上实测。
- 教程要按新流程重写（下一份方案书），在此之前教程后半段与新界面对不上，所以两者同一版发。
- **待用户拍板**：① 一屏方案（推荐）还是保留两页、只在商店里加「直接装上」；② 主菜单入口是否合并为「备战」；③ 商店 10 件怎么摆：两行 × 5（推荐，件数不变）、一行 10 张横向滑、还是减到 5 件（改玩法，要另议数值）。
