## 出入

- 现状两页来回，参考全部一屏；现状说明是固定大面板，参考全部是弹出小卡。
- 本方案只改布局与操作，不改商品数量、价格、合成规则与任何数值。

## 方案

一屏「备战」，横屏 1280×720 布局（手机按比例缩放，两种比例实拍验收）：

```
┌ ← │ 金币 21 │ Lv8 ━━━━ 62/84 │ 买经验 +4 (4) ───────────── 开始战斗 ┐
│ 出战阵容（上战场 / 下战场，每格：龟 + 3 个装备槽）      │ 羁绊（唯一一份）│
│                                                         │ 灵物 2/5 ◆◇◇◇ │
│                                                         │ 奇械 2/5 ◆◇◇◇ │
├ 备用栏（一行 8 格，多了横向滑）──────────────────────────────────────────┤
├ 商店（一行 10 张，价签在卡上）                         │ 刷新 2 │ 锁定 │
└────────────────────────────────────────────────────────────────────────┘
```

1. **买**：把商店卡拖到某只龟的空装备槽 = 买下并装上；拖到备用栏 = 买下放着；点一下商店卡 = 弹出说明小卡，小卡上有「购买」。
2. **装 / 换 / 卖**：备用栏或龟身上的装备可以拖到别的槽；拖回商店区 = 卖出（小卡上也有「卖出」）。
3. **拖动时**：所有能放的格子高亮，放不了的变暗（照超级自动宠物的箭头）。
4. **说明**：点选任何装备、龟、羁绊 → 旁边弹小卡（沿用 10-06 定的云顶小卡样式），不再占右侧大面板。
5. **羁绊**：只留右侧一份，写法统一成「名称 2/5」加档位格。
6. **统领 / 小将**：龟格角上标「统领」「小将」小签，小将格上的「后排」换成前后排切换图标，第一次点时弹一句说明。
7. **入口**：主菜单「商店」「背包」两个按钮合并为一个「备战」。
