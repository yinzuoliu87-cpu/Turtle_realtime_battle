状态: **草稿**（调研已完成 · 方案待用户拍板 R1/R2） · 2026-09-17

---

## 需求原文

用户 2026-09-17，按时间顺序（逐条钉住，不许漂）：

1. 「主页面你也可以看着怎么动，要加什么要减什么你都给我总结建议好」
2. 「龟币是我们主站的货币，需要显示，但最好是换一种显示方法，就像其他游戏里显示金币和钻石这样，空地你自己看怎么处理，调试场可以塞到设置里，正式上线的不会要调试场」
3. **「但这样你不觉得很丑吗，市面上哪里有游戏会这么排版呢，会这么布局吗」** ← 否掉第一版
4. 「你再去参考」+「别，参考点其他游戏吧，多参考点」 ← 否掉"照项目自己那份 PoC 设计文档"
5. 「不要hero区」 ← 否掉"右侧放吉祥物龟"
6. **「想想自己和商业游戏差在哪里，市面上那么多商业游戏，找100个吧，主菜单找好，看看我们可以怎么学习」**

⚠ 否定式指令单独列（最容易丢，memory `fb-pin-user-words-dont-drift`）：
- ❌ 不要三块等高卡并排
- ❌ 不要 hero / 吉祥物区
- ❌ 不要照项目自己的 PoC 设计文档做
- ❌ 正式包不要调试场

## 调查

### 样本与方法

151 款商业游戏主菜单，来源 Game UI Database 的 **Main Menus** 分类（`scrn=901`）。
抓法已记入 memory `ref-game-ui-database-scraping`（WebFetch 403，curl 带 Chrome UA 才通）。
遍历 `plat=0..5 × sort=1..3` 共 18 页，其中 11 页被 429 限流，7 页成功；
去重后 **345 张截图 / 151 个不同游戏**，全部下载后做成 13 张接触印相逐张过目。

★**不是 151 个都可比**。其中绝大多数是单机叙事游戏，主菜单只有 `New Game / Load / Options / Quit`
四个入口、零玩家数据——它们没有本项目要解决的那个问题（一屏里塞下经济 + 赛季 + 六个二级入口还要好看）。
逐张筛出**与本项目同构**的（主菜单上有货币/等级/赛季/进度计数，或 3 个以上并列入口）共 **18 款**，
单独做大格精读。下面的结论全部来自这 18 款，编号可回查。

### 商业游戏主菜单的五条硬规律

**① 中间那块是"场景"，不是"墙纸"。**
Last Flag(57) 是一群角色**坐在沙发上看杂志**，有灯、有植物、有电视机；
You Suck at Parking(143) 是一组**漂浮岛屿**，车停在停车位上；
Zookeeper World(151) 是**公园里两个玩家角色在跟 NPC 说话**；
Wonderbox(127) 是角色**站在传送门前**。
共同点：角色处在一个**有空间关系的环境**里、**在做一件事**。不是正面排开的角色海报。

**② 玩家数据一律"图标+数字"，不给框。**
DRIVE(34) 顶部 `295🪙 6📄 3👤`；Valkyrie Connect(112) 顶条三种货币各带 `+` 号；
Wind Runner(124) 顶条等级+经验条+四种货币；Yooka Impossible Lair(137) 顶部 `1535 / 44 / 36 / 8`。
**18 款里没有一款给货币套按钮材质的框。** 它们全是裸图标 + 数字，紧凑贴在顶边。

**③ 每个入口带"状态副标题"，锁定态直接画出来并写清条件。**
Wind Runner(124) 四个模式按钮下各有一行小字：`Stella - 0%` / `No league – Placement` / `Rank 5 required`。
King of Meat(56) 底部三张模式卡，两张是 `🔒LOCKED! Earn more league trophies to unlock!`——
**把锁的理由印在卡上**，不是灰一下让玩家去猜。

**④ 说明走"底部一条"，不占常驻版面。**
Tetris Ultimate(96) 底部一条随高亮项变化：`60 SECOND SPRINT! For the ultimate in bragging rights…`；
King of Meat(56) 把当前选中模式的完整说明放左栏，选别的就换。
**信息量不小，但只占一条，而且是跟着焦点走的。**

**⑤ 主 CTA 靠"材质/颜色异类"取胜，不靠尺寸。**
DRIVE(34) 的 `START` 是全屏唯一的纯黄实心块；Zookeeper World(151) 的 `▶` 是全屏唯一的高饱和绿；
You Suck at Parking(143) 的 `ONLINE MATCH` 是唯一的橙黄填充块。
它们**不跟别的按钮同材质**——本项目的木框如果主 CTA 和次级键都用，那只剩大小差别，量级拉不开。

## 方案

按性价比排序。①②⑤ 是这一轮该做的，③④⑥ 可以下一轮。

### P0-1　中间改成"场景"，不是群像墙（对应规律①）

现在 `tools/build_menu_crowd_bg.py` 的排布是五层纵深 + 脚底线 + 正面排开 —— 那是"角色海报"的做法。
要改成**一个有空间关系的场景**：

- 参照 Last Flag(57)：角色**围着一件东西**（这里是斗龟场的擂台/看台），有前后遮挡、有朝向差异、有高低坐站
- 龟不再"证件照式"正面站开，改成：擂台上 2~3 只在对峙（大、亮、居中偏右），
  看台上一圈在围观（小、暗、有遮挡），前景边缘压两只出画的大剪影
- 加一层地面/看台的几何 —— ★**必须新生成**（见 R1-a）。`assets/sprites/map/` 里虽然有
  石柱/礁石/海藻/地砖，但那是**战场的**地图件，用户明令不许拿来拼主菜单。

★这一条是**本轮最大的工作量**，也是"像不像游戏"的分水岭。

### P0-2　货币去掉木框（对应规律②）

`_coin_frame()` 现在套 `frame-coin.png`。改成裸图标 + 描边数字，横排贴右上，间距 16。
省下的宽度让给 ❓⚙ 两个磁贴。**木框只留给主 CTA。**

### P0-3　主 CTA 换材质（对应规律⑤）

「开始战斗」不再用 `btn-frame.png`，改成**纯色实心块 + 描边**（取 UIPalette 里的金/橙），
让它成为全屏唯一的高饱和实心。训龟大师保持木框 → 材质差一眼分主次，不靠尺寸。

### P1-4　入口带状态副标题（对应规律③）

- 商店锁：副标题直接写 `本周 24 场已打满` / `0 命已出局` / `本大轮还没打第一场`
  （这三条 `_open_shop()` 里已经有现成的三种原因，A4 那次分好了，直接拿来当副标题）
- 排行榜：副标题写当前名次
- 背包/图鉴：副标题写件数

### P1-5　底部说明条（对应规律④）

赛程条右端现在是"距收盘 X"。扩成：鼠标/焦点在哪个入口，条子左半就解释那个入口。

### P1-6　红点角标

商店有新货、排行榜有新名次、赛程进入封盘窗口 → 对应入口挂红点。

## 已知风险与未决点

- **R1（已拍板 2026-09-17）**：场景 = **擂台 + 看台**。擂台上 2~3 只对峙（大·亮·居中偏右），
  看台一圈围观（小·暗·有遮挡），前景边缘压两只出画的大剪影。
  选它的理由是用户定的方向跟「斗龟场」这个名字与 LOGO 里的竞技场直接对上。
  - ★★**R1-a（用户 2026-09-17 补充：「尽量不要复用好吗」）**：擂台台面 / 台沿 / 石柱 / 看台礁石 /
    前景海藻珊瑚，**一律新生成，不许拿 `assets/sprites/map/` 里的战场地图件来拼**。
    我当时的判断是「画斗龟场就用斗龟场自己的场地件，属于一致性不属于复用」——
    **这个判断被用户否了**。铁律见 memory `fb-no-asset-reuse-unless-told`：
    「新内容一律新素材」，我不该给自己开这个口子。已写好的 `arena_patch.py`（靠 `_load_map()`
    复用 map 件搭擂台）**作废，一行都没落地**。
  - ⬜ **R1-b（未决·下次要问）**：群像里 **28 只龟的立绘本身**算不算复用？
    我的理解是不算——主菜单展示的就是这些龟，用它们自己的立绘是「同一个东西的同一份素材」，
    而不是「拿 A 顶替 B」。但用户刚说了「尽量不要复用」，**这条我不自己拍板**。
- **R2（已拍板 2026-09-17）**：主 CTA **保留木框**，靠**呼吸光晕 + 亮金描边**拉开量级，
  ❌ 不换成纯色实心块 —— 那等于在木质像素风里插一块扁平色块。
  ⚠ 代价要认：静态截图里主次不如换材质明显，**验收必须看动图/连续帧，不能只看一张静图**。
- **R3（已关闭 2026-09-17）**：群像合成脚本原来只在 scratchpad，而 `MainMenuScene._bg()` 的注释
  已经指向 `tools/build_menu_crowd_bg.py`——**注释指着一个不存在的文件**（`plans_lint` 独立抓到了同一条）。
  已真的搬进 `tools/`，并验证搬家前后产出的 PNG **逐字节相同**（598907 字节 / md5 f6912a89…），
  不是"搬的时候顺手改了样子"。加龟/换立绘重跑一次即同步。
  ⚠ 仍欠：这个脚本**没进门禁**，改坏了不会有人报。
- **R4（已知缺口）**：`verify_mainmenu_layout.gd` 现在必然红——它焊死的是旧版式
  （左栏栈 6 个 / 信息板 4 行 / 三卡首尾对齐）。**必须整体换判据，不是放宽。**
  新判据应落在：可点元素触摸线、主 CTA 是全屏最大且材质唯一、货币区不含按钮材质、
  赛程条七格齐全、无控件越界。
- **R5（已知缺口）**：`verify_menu.gd` 已改成扫 SettingsScene（调试场搬家），但**一轮没跑过**。
- **R6（已知缺口）**：`verify_week_season` 的时区层断言（判定层零本地时间 API + 显示层确实换算）只想好没写。
- **R7（口径风险）**：本轮 151 个样本里**只有 18 个与本项目同构**，样本量不大。
  五条规律是这 18 个里数出来的，不是 151 个的统计。**别把它当成"商业游戏都这样"。**
- **R8（取舍已定，别反复）**：背景 `desat=0.50` / 左侧压暗 `0.24` 是实拍叠 UI 后定的。
  像素龟饱和度极高，满色会跟金色木框打架。参考里只有两条路——
  Absolum/Black Jacket 压暗插画配**无框文字**，Fuga/Zombie Rollerz 满色配**白底实条菜单**。
  本项目选了前者；想让龟满色，左栏就得改回色块条，二者只能选一个。

## 验收清单

版式这轮做完，下面每条都要能指着实拍说"是/否"，不许"大致上"：

- [ ] ⏳ 中间区域能看出**空间关系**（有前后遮挡 + 有地面/看台 + 龟有朝向差异），不是正面排开
- [ ] ⏳ 货币区**不含任何按钮材质**（`frame-coin.png` / `btn-frame.png` 零引用）
- [ ] ⏳ 全屏**只有一个**元素用了主 CTA 的材质/颜色
- [ ] ⏳ 商店被锁时，**屏幕上直接写着**锁的理由（不点不弹 toast 也看得见）
- [ ] ⏳ 1280×720 与 1560×720 两个比例各实拍一张，无越界、无重叠、无压字
- [ ] ⏳ 所有可点元素短边 ≥81 视口像素（44pt）
- [ ] ⏳ `verify_mainmenu_layout` 换判据后全绿，且**每条都反向验证过会红**
- [ ] ⏳ `bash run-tests.sh` 只认 `GATE_RC=0` 与 `ALL PASS (N/N)`
- [ ] ⏳ 版本号五处 + tag（玩家可感知的改动）
