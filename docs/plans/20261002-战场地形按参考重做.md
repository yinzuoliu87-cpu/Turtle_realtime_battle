## 2. 调查：先回答他问的三个问题

### 2.1 那一圈水学的谁的 —— **没学谁，是我们自己迭代的**

2026-07-31「沉岛斗场」那版（v0.17.30）的 commit 写得很清楚：**三轮自己迭代、自己评**。

做成外圈是**量出来的**：改前水池铺满中央 ⇒ 所有战斗都发生在全场最亮的地方
（实测 水 98 vs 淤泥 32），深色龟压在最亮处最难读 ⇒ 把水赶出战斗区。

★但同一条 commit 里还写着：**「完整可见的闭合水环做不出来」**——
战场宽 ±798、可见窗口只到 ±673，岛还必须装下最外单位（±555），
留给环左右两臂只有 1.1 格。定稿是**梭形岛**。
⇒ **屏幕上那个「一大圈」是梭形在透视下的样子，不是设计出来的环。**

### 2.2 边界 —— 视觉层级是**反的**

实测 `ARENA = Rect2(70,110,1596,728)`，投到 1280×720 屏上是个梯形：
上边 y=205 / 下边 y=596 / 左 x=11~179 / 右 x=1101~1269。

| 玩家看到的 | 它实际是什么 |
|---|---|
| **水**（最强的视觉分界） | **纯视觉、能走**（`battle_world_builder.gd:180` 注释原文「纯视觉不改玩法」）。而 ARENA 内 779 格里 **240 格是水（31%）** |
| **边界墙**（岛外沿） | 画在**岛边**，比 ARENA 外扩 左298 / 右334 / 上192 / 下194 px —— 不是玩法边界 |
| **玩法边界 ARENA** | **什么都没画** |
| 真正挡路的 | 另一套 `_obstacles`，3 个椭圆（1 大礁 + 2 礁墙），与地面美术完全无关 |

⇒ 「模糊」是准确的：**不是画得糊，是画的东西和规则对不上。**

### 2.3 装饰物为什么「不像游戏」—— 它是一张写死的坐标表

`_build_decorations()` 里 16 件、**4 种素材**、沿上下两条线一字排开。
实测 **Clark-Evans R = 1.13**（比随机还均匀），**y 坐标只有 11 个不同值**，
中间 **642px 完全没有装饰**。

## 4. 方案

### 4.1 三条改动（一刀做完，不分批）

| # | 改什么 | 依据 |
|---|---|---|
| **A** | **水退出战斗区** | 两个参考的战斗场都没有水；而我们的水**纯视觉却占 ARENA 内 31%**，是画面上最强却最没有意义的分界 |
| **B** | **边界改成「地块硬边断进虚空」**，撤掉岛边那道墙 | 两个参考一致；咩咩的竖面还**刻意留空** |
| **C** | **装饰物换陆地系 + 成组摆放** | 用户点名「珊瑚海草不适合」；R 从 1.13 往 0.66 走；件数 16 → 往 79 走 |

### 4.3 已知风险与未决点

1. 🔲 **碎料层留多少 —— 两份实测打架，必须拍板。**
   2026-09-20 **照 Brotato** 加的 820 件（「参考 296 件/Mpx、覆盖 2.20%，我们 0 件」）；
   2026-09-30 **照 Botworld** 量，同一层是空地噪声**第一大来源（37%）**。
   咩咩实测是 **178 件/Mpx（人工计数）**，介于两者之间。
   ⇒ 两份都是真实测，**参考对象不同**。不是谁错，是**没定过我们要像哪个**。

2. ⚠ **水退出战斗区会不会让画面变单调** —— 没实拍过。水是现在画面上唯一的亮色面积
   （实测 水 98 vs 淤泥 32）。撤掉之后中间调占比/亮坡比会怎么动，要拍了才知道。

3. ⚠ **「边界有可见表达」具体画什么还没定** —— 两个参考都是「外面什么都没有」来读边界，
   但我们的 ARENA 是**岛内部的一个矩形**，不是岛的外沿。
   照搬「硬边断进虚空」要求 ARENA ≈ 岛边 —— 那是**改地图轮廓**，不只是改画法。

4. ⚠ **素材复用需要点名**（memory `fb-no-asset-reuse-unless-told`）。陆地系素材库里有，
   但按铁律要先问。

5. ⚠ **信息密度那把尺子有工作区间**：咩咩 agent 标定出 `_edge_mid_pct` 在 1920×1080 下
   **1px 棋盘读 0.00（瞎）、2px 顶到 100（饱和）**，工作区间只有源图 3~32px。
   验收前要先确认我们的改动落在它看得见的尺度上。
