## 2. 调查结论

- 像素感的来源：`tools/assetgen/sfx_prompts.json`（已删）的 `style` = `cartoon pixel-art mobile game sound effect…`，`tools/assetgen/gen_sfx_elevenlabs.py:99` 拼到全部 161 条前面；挑选尺子 `tools/sfx_clap.py:29` `REF_DIR = .out/blackbox/sfx`（黑箱像素原声）。
- 量出来（`tools/sfx_measure.py`，中位）：旧音效 154 条 150 Hz 以下低频占比 0.01、有声段 RMS −18.8 dB、平坦度 0.05；Riot 普攻命中 430 条 0.35 / −13.5 / 0.27，技能命中 354 条 0.46 / −14.6 / 0.21。
- 云顶 / LoL 的拆法（本机游戏文件，`tools/oneoff/riot_audio_extract.py`）：普攻 `BasicAttack_OnCast` + `OnHit` 各 4 变体、暴击另一套；技能按时刻拆 `OnCast` / `cast2` / `OnHitLocation`；科加斯 Q 声轨与画面逐帧对齐见 `docs/studies/20261105-云顶音效拆解-科加斯Q声轨逐帧.md`。
- 改前游戏只有：普攻命中 `atk_<龟>` 1 条、技能放出 `cast_<技能>` 1 条；技能命中 / 装备 / 护盾 / 治疗全是 PoC 通用声（`autoload/Audio.gd` 旧 `SFX_PATHS`）。
- 竹刺阵改前（`scripts/systems/skills/bamboo_system.gd` `_sk_bamboo_spikes`）：共享技能环一闪就淡；0.6 秒时圈内随机 14 根冰刺贴图（`ice-spike-vfx.png`）染绿；无爆点、无裂地。

## 3. 需求 ↔ 代码的出入

- 「旧的那个普攻、伤害音效、盾音效」：命中 / 护盾 / 治疗用的是 PoC 七条（`hit-physical` 等），11-04 / 11-05 两轮都没换过 —— 我 11-05 夜里只换了技能放出那层就报了「音效做完」。
- 「每个技能怎么做的音效」：云顶一个技能至少放出 + 命中两条，我们只有放出一条，命中全走通用声。

## 4. 方案（已实施）

1. 参考：解 58 个英雄原皮 + 云顶公共包，按类别量（时长 / 低频 / 质心 / 平坦度 / RMS），CLAP 嵌入做「像不像云顶」的尺子。
2. 描述表 `tools/assetgen/sfx_v2_table.py`：28 龟 × 出手 / 命中 / 暴击 + 87 技能放出 + 60 技能命中 + 84 件装备 + 21 条公共 / 界面，每条写材质与对应的 LoL 技能；三轮生成（v2 / v2r2 去低频字眼 / v2r3 补 7 条）。
3. 定选 `tools/sfx_pick_v2.py`：CLAP 对描述 + 对 Riot 同类中心 + 对参考英雄 + 形状罚分；否决质心 < 180 Hz（手机放不出）与像素感。
4. 成品 `tools/assetgen/build_sfx_v2.py`：母带均衡往 Riot 频谱形状拉（±6 dB 内）、按类响度、峰值 −1 dBFS；事件表 `scripts/gamedata/sfx_events.gd`（EVENTS + VARIANTS）。
5. 接线：`AudioSystem` 普攻出手 / 命中 / 暴击、技能放出后 6 秒内的非普攻伤害 = 该技能命中、装备上下文里的伤害 / 治疗 / 护盾 = 该装备；12 件无伤害触发点显式 `sfx_equip`；持续回复类不出声；`Audio` 变体随机不连重、旧名映射给旧录像。
6. 删除：`assets/audio/sfx/ev/` 154 条、PoC 七条、方波合成的 `queue_found.wav` / `studio_intro.wav`，以及旧工具 `build_sfx.py` / `sfx_pick.py` / `sfx_rank.py` / `sfx_bar.py` / `sfx_picks.json` / `sfx_prompts.json` / `build_queue_found_sfx.py`。
7. 特效：竹刺阵 `BambooSpikesVfx`（新素材 `tools/assetgen/build_bamboo_spikes.py`）；糖衣炮弹落区细环保持 + 落点影子；星波细波前 + 两道余波。

## 5. 已知风险与未决点

- [未验] 好不好听只有用户耳朵能判；我只能量（CLAP 与 Riot 同类中心的余弦、频谱形状）。成品选中中位：普攻命中 0.65（Riot 留出 0.79）、技能放出 0.51（0.68）—— 还有差距，技能放出偏薄（低频 0.12 vs Riot 0.41）。
- [已堵] 生成器遇到「deep / sub-bass」会出一团低频轰鸣：第二轮去掉这些字眼 + 否决质心 < 180 Hz。
- [已堵] 持续回复 / 每攻叠盾的装备每跳出声会刷屏：`QUIET_AUX` 六件只在触发那一刻出声。
- [未决] 技能命中的来源认法是「放技能后 6 秒内该龟的非普攻伤害」，被动 / 羁绊伤害在窗口内会被认成技能命中（近似）。
- ElevenLabs 本期已用约 28.2k / 40k（12-04 重置；自动续费已取消，再订先问）。
