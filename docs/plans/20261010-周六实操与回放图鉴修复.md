## 2. 调查

- 周六 18 个晋级号分两批实打：修复前 0/45 场真人对手，修复后 35/35（拉取晚一格，见台账 G1）。
- 赛况板 / 观赛：子任务只读审计 + 实机窗口（台账 G2~G5）。
- 回放：`tests/_probe_replay_sweep.gd` 把赛况板 92 场录像下载到本地逐场重放；录制时代码上 88 场同版本里 55 场分叉（台账 G15）。
- 换行：导出 WinVerify 包实测，关 / 开 `include_text_server_data` 两版对比，与用户截图逐字一致。
- 图鉴：子任务逐页截图 216 张 + 手机比例 21 张，归成 13 类问题。

## 3. 出入（需求与代码事实不一致处）

- 「没处花钱」是我误判：模拟脚本满装备时不买同款升星，不是游戏的问题（用户纠正「装备不知道升星吗」）。
- 「积分赛终榜」周六还在变：根因在闯关赛快照也写进了积分赛 `ghosts` 表，不在榜单代码。
- 回放分叉不是今天改动造成的：用录制时的代码重放照样分叉。

## 4. 方案

见 0.19.563 的 CHANGELOG 与台账 G1~G17，各条修复都写明了根因与判据。

## 5. 已知风险

- 真人手机 / PC 录的 8 场回放仍在开打后不久分叉，原因未定位（推测 ARM / x86 浮点末位）；录像已开始记录平台与架构，等下一批对号。
- 手机杀进程仍能逃掉一场负（只堵了电脑上的 ESC / R），是否「开打先记负」待用户定。
- 选龟界面仍读 `passiveSkill` 标记，命运之轮 / 海盗船 / 水晶球可能仍标「被动」；删标记会让精英开始偷这三招，待用户定。
