### 装备小卡版式（从图 4 读出来的，逐条）

1. **头部**：左侧装备图标（方形，带细边），右侧第一行**名字**（较大、白）
2. 名字下一行：**属性行 = 小图标 + 数字**，多项横排（例 ❤+250 ⚔+25%），**无文字标签**
3. **一条细分隔线**
4. **效果说明**正文（浅灰白，多行自动换行）
5. **特殊规则**用**青绿色高亮**单独成段（例「The holder's attack speed is locked at 0.5」「cannot cast their ability」）
6. **脚注**用**灰色斜体**另起一段：限制（[Unique - only 1 per champion]）、关键词释义（Chill: reduce Attack Speed）、成长说明（Damage increases based on Stage）
7. 底：深藏青近黑、**细黄铜/金色描边**、直角或极小圆角；卡片高度随内容

### 技能小卡版式（从图 6、7 读出来的，逐条）

1. **头部**：左侧技能图标（方形），右侧技能名（白）——只有一行，没有属性行
2. **细分隔线**
3. **说明正文**：数值**已按当前状态算好**直接写进句子里，数字**着色**（物理=橙、法术=蓝），后面跟一个小属性图标表示它吃哪项属性（例「造成 365 (⚔) 物理伤害」）
4. 条件加成另起一段（例「Ionia Bonus: +15% Omnivamp」——对应我们可以是装备羁绊/星级加成）
5. **细分隔线**
6. **数值拆解表**：每行左边「项目名: 当前值 = 系数% 图标 + 系数% 图标」，右边方括号里是 **1★/2★/3★ 三档**，**当前档加粗**、其余灰
7. 底与装备卡同一套：深藏青近黑、细金边

⇒ 与装备卡的区别：技能卡**没有属性行**，多了**底部的数值拆解表**；正文里的数字是**算好的**。

## 三、已定下的决定

**面板（右侧检视面板）**
- 没有出售按钮
- ~~不单列「普攻」；只放天生 + 技能~~ → **被动 / 普攻 / 技能 三格**（用户 10-06 更正）；小弟额外标 **前排/后排**
- **19 项属性全上**：攻击、攻速、暴击、暴伤、增伤、护甲、魔抗、减伤、射程、移速、吸血、闪避、治疗强度、护盾强度、龟能充能、护甲穿透、魔法穿透、反伤、韧性
  - 版式：图标在上、数字在下，**一行 7 个、共 3 行**（用户 10-06 改；面板宽 400），**不写文字标签**，**没有「更多属性」入口**
  - 韧性要**新画图标**
- 龟身上**不列羁绊**（我们的羁绊来自装备类型，不来自龟）
- 整个框 + 里面每个小框**全部换掉**：新画像素素材，深色半透明底 + 细黄铜边（与主菜单暖黄铜一致），格子是素色暗底

**点击弹出小卡（面板左侧独立弹出，面板本身不变）**
- 点 **装备 / 技能·天生 / 属性图标** → 面板**左边**弹出一张独立小卡；点空白或再点一次关闭
- 三种卡共用同一个模板（上面「装备小卡版式」那 7 条）

## 四、我们和云顶不一样的地方（要塞进卡里）

| 点什么 | 头部 | 属性行 | 正文 | 我们独有 |
|---|---|---|---|---|
| 装备 | 图标 + 名字 + **品质色边**（SSS–C） | 加的属性（图标+数字） | 效果说明；特殊规则青绿；脚注灰斜体 | **本局统计**（造成伤害/治疗/触发次数）——云顶没有 |
| 天生 / 技能 | 图标 + 名字 + 「天生」/「技能」小标签 + 龟能消耗 | 无（照图 6、7） | 正文数值按当前状态算好并着色；底部拆解表「当前值 = 系数×属性」 | 拆解表右侧三档换成我们的**等级/星级**档位（待核实我们按什么分档） |
| 属性图标 | 图标 + 属性名 | 当前数值 | 一句话解释 | 云顶检视面板属性无释义弹窗，这是我们加的 |

其他我们独有、面板上要有位置的：龟能条、稀有度 SSS–C、等级、状态效果（增减益）、射程数值、首领/小弟。

- 特殊规则「青绿高亮」要从现有装备文案里区分出来——现有 `data/phase2-equipment.json` 文案没有这类标记，可能需要加字段或按句式拆，未定。
