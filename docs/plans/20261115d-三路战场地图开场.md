# 三路开场改成「战场地图」+ 对阵 / 开战 / 换路演出重做

日期：2026-11-15　|　状态：**实施中**

## 1. 需求原文

用户 2026-11-15：

> 「嗯，接下来要搞的是，就每次对局进去有个什么，呃，三路开战这些东西。你说三路开战这个，这个这种描述其实不符合一种商业游戏啊。你想想这个怎么怎么展示？你说上路战场、下路战场、中级战场，是否可以通过一个那个？地图一样的形式去展现出来，就是做多做点动画啥的，看这个该怎么优化，你可以设计一下。」

### 2.2 时长与输入（改动不能碰的部分）

- 每块幕布 5 秒，计时在 sim 步里：`RealtimeBattle3DScene.gd:573` `DL_PRESENT_SEC := 5.0`，`:2216-2219` 每步 `_dl_present_t += dt`，到点 `_dl_present_advance()`。裁判机、回放、直播都按这个步数对齐（`scripts/systems/stream/stream_player.gd:36-45` 开场跳过段 = 2 × `DL_PRESENT_SEC`）。
- 点幕布 = **改结果的输入**（决定下一路在第几步建场），回放只认录像里那一下：`dual_lane_flow.gd:97-103`。
- 流程：开局 overview → preview → 建场开打（`battle_spawn.gd:242-246`）；一路打完 eggwindow 到点 → `lane_settle`（`dual_lane_flow.gd:944-947`）→ 5 秒后 `_dl_lane_over` 记结果、清场、下一路 `preview`（`:951-968`、`:1196-1202`）；2:0 横扫或碎蛋直接结束（`:962-967`、`:906-922`）。
- 一局只有一张地图：`ArenaTheme.choose_for_battle` 开局按种子选一次（`battle_world_builder.gd:1576`），三路都在同一张图上打。
- 直播（手机）：幕布不是传画面，是手机收到 `curtain_in` 事件按同一份阵容自己建（`stream_player.gd:646-649`），跳进中间按全局状态补（`:904-907`）。开战那一下的屏震 / 定格 / 闪屏各自有事件（`:629-641`）。
- 周日决赛另有一层 6.2 秒「对手入场」盖在开场幕布上面（`scripts/scenes/battle/finals_vs_intro.gd:1-12`），收掉后底下的本路对阵还剩约 4 秒。它用 `pose(t)` 按时刻摆全部节点，不用 tween（无头 CI 下 tween 推进不稳，CLAUDE.md §4.5）。
- 守着幕布的门禁（会跟着改）：`verify_present_click_anywhere`、`verify_reserve_minion_ui`、`verify_stream_curtain_stats`、`verify_stream_hud_parity`、`verify_first_battle_tips`、`verify_tutorial_battle_tips`、`verify_tutorial_flow_v3`、`verify_referee_live_own`、`verify_gauntlet_online_queue`（按节点名 `PresentTitle` / `PresentHint` / `LaneSettle*` 找）。

### 2.4 商业参考（11-15 实机视频逐帧，`.out/lane_map_ref/*_sheet.png`）

| 游戏 | 看到的做法 | 拿来做什么 |
|---|---|---|
| 荒野乱斗（对局开场） | ①地图全景上打模式名；②双方角色**全身立绘斜切对峙** + VS + 倒计时；③开打时地图上砸「BRAWL」大字，底部挂地图名横幅 | 对阵屏、开战横幅 |
| 魔兽弧光大作战（关卡开场） | 镜头从敌方大本营一路摇到我方，整张图过一遍，可点跳过，再出「开始」 | 开场地图的「先看全图」 |
| 陷阵之志（岛屿地图） | 岛按区块分，当前要打的区染红、旁边挂名字标签；打完的区变绿；进战斗后横贯屏幕的「PLAYER TURN」带子 | 地图上的进度状态、开战横带 |
| Wargroove（像素战役） | 「TURN 1」标题卡：压暗地图 + 指挥官大立绘 + 队伍色大字 + 横向扫光线 | 横幅的像素做法 |

共同点：**先给全图 → 双方大立绘对峙 → 横贯屏幕的大字开打 → 角落常驻「现在在哪」→ 打完的地方在地图上留标记**。我们现在差在：全图是一张表格、对峙是小卡片、开打是一个飘字。

## 3. 需求 ↔ 代码的出入

- 「三路开战」这四个字只出现在 overview 标题一处（`dual_lane_flow.gd:203`）。用户说的「描述不符合商业游戏」不只是这四个字：整块是**一张表格 + 一行说明文字**，商业游戏这一拍是地图 / 立绘 / 动画，不写说明句。改标题字解决不了，要换整个呈现。
- 「通过地图的形式展现」：三路其实在**同一张场地**上依次打（§2.2），地图上画成三个战场是呈现上的说法，不改规则。
- 「多做点动画」：时长不能加（§2.2 的步数对齐），动画要在现有 5 秒一块里做完，点击跳过照旧。

## 4. 方案

### 4.1 版面（设计画布 1200×720，按屏幕等比缩放居中；背景铺满全屏）

```
   ┌─────────────────────────── 海图(深海 + 网格 + 浪花点) ───────────────────────────┐
   │ [暗林]                              ⚔上路战场⚔                                  │
   │                          [我方3头像] ( 场地圆章 ) [对方3头像]                     │
   │        ╲                              ┆                             ╱           │
   │ [我方龟蛋巢]                    ( 终极战场 大圆章 )                [对方龟蛋巢]     │
   │  名字 / 蛋血    ╱                     ┆                       ╲   名字 / 蛋血     │
   │                          [我方3头像] ( 场地圆章 ) [对方3头像]                     │
   │                                     下路战场                                    │
   └─────────────────────────────────────────────────────────────────────────────┘
```

- 左右两端是双方**龟蛋巢**（蛋 = 这一局真正要守的东西），上下两条路从蛋巢出发通到上路 / 下路战场，两路战场再各有一条虚线通到中间的终极战场 —— MOBA 小地图那套读法。
- 三个战场是**圆章**：里面是本局这张场地的真实画面（开局建好场地后用一个只渲染一次的 SubViewport 拍一张，三章共用；终极战场那章大一号、金框）。底下压一条路名金字（`bt-lane-*.png`）。
- 左上常驻一枚小牌：本局场地名（暗林 / 深礁 / 紫墟 / 赤林）。
