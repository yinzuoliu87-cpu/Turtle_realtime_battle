## 2. 调查结论（现状）

**结算**（不动）：`scripts/systems/equip/equip_system.gd` `_eq_water_wave`
- 起浪点 = 携带者身后 `WAVE_BACK` 1200 码，朝敌人质心方向推进 `WAVE_DIST` 3000 码；蓄浪 `windup` 0.5 秒 + 推进 `travel` 2.0 秒（线性）。
- 每个友军 / 敌人的结算时刻 = `windup + fwd / tdist * travel`（线性口径），挂 `_pending_shots`（sim 钟）。
- 宽度 `WAVE_HALF_W` 900 码（盖满全场，09-14「宽度固定」）。

**推进**：`scripts/systems/equip/equip_tick_system.gd` `_tick_tide_walls`（游戏钟，蓄浪→推进(线性，注释写明不许加缓动，否则伤害先落浪后到)→退去 0.35 秒）。

**画面**：`scripts/scenes/battle/battle_vfx.gd` 浪墙段（`TIDE_*` 常量、`_tide_profile`、`gen_tide_wall`、`_tide_vert`、`_tide_quad`、`tide_wall_spawn`）
- 一张 33×19 的生成网格，`StandardMaterial3D` 不透明、无光照、顶点色；按面片平均高度量化成 5 档平涂（深水 / 水体 / 浪面 / 浪唇 / 白沫）。
- `gen_tide_wall` 是纯函数 + `VfxTex.tag` 出处键：手机直播按 9 个参数调同一个函数重画（S3 逐帧直播）。
- 打中：`wave_splash(at2d, ally)`（友 / 敌两种水花）。

**实拍（2026-11-14，实验台 `staff_043`，原速录像 `.out/wave_study/wave_now.mp4`）**：读成一条**平的、阶梯锯齿边的青白色带**斜着扫过场地 —— 没有浪头的体积感、没有透明度、没有起手、没有水沫水雾、退场是整条落下。俯视镜头下 1.95 米的浪高几乎读不出来。

**参考（外部商业游戏 / 公开视频，`.out/wave_ref/`，不进仓库）**
- 河灵娜美（LoL 2020 皮肤展示 `xpjkn9C94UM` 84–90 秒，每 0.2 秒一帧拆过）：① 起手 = 施法者脚下一大团白 / 青水花往上喷；② 浪身 = **半透明**青绿水体，前沿隆起成浪头，浪头亮；身后拖白色水雾慢慢散；③ 打中 = 被打者身上一团很亮的白色水花 + 掀起；④ 走到头变淡散开。整段约 2.5 秒。
- 风格化浪潮样片（`mBj1_Y8fjCU`）：浪身是半透明水体厚板、前沿圆润隆起、**浪头一圈亮白泡沫**、浪身里有流动水纹、身后水雾与水滴、最后散成雾。

## 3. 需求 ↔ 代码的出入

用户这次没说具体哪里不对。按参考逐项对出来的差距（这就是本次要补的）：

| 参考有 | 我们现在 |
|---|---|
| 起手水花（施法者处） | 没有（只有 `_anticipate` 前摇） |
| 浪身半透明、看得到后面的单位 | 不透明平涂（09-14 为了排序问题关掉了透明，见 `TIDE_RAMP` 上方注释） |
| 浪头一条有碎边的亮白泡沫、会动 | 固定位置的一条白色面片带 |
| 浪身里流动的水纹 | 无（平涂色块） |
| 浪头往上溅的水沫、身后的水雾 | 无 |
| 打中一团亮白水花 | 有 `wave_splash`，偏弱 |
| 退场散成雾 / 地面留湿痕 | 整条落回去 |

## 4. 方案

**不动结算**：`_eq_water_wave` 的时刻、位置、宽度、线性推进口径一律不动 ⇒ 不改对局结果、不升规则版本；推进仍走 sim 钟。

**画面分层（全部新做，不复用别的装备素材）**

| 层 | 做法 | 落点 |
|---|---|---|
| ① 起手 | 携带者脚下：一圈往外扩的水波纹 + 往上喷的水柱水沫（蓄浪 0.5 秒内） | `battle_vfx.gd` 新函数，`_eq_water_wave` 调 |
| ② 浪身 | 网格不变拓扑（仍是纯函数 `gen_tide_wall` 生成，带出处键），顶点加 UV（沿墙 u / 横截面 t）；材质换成新着色器 `assets/shaders/tide_wall.gdshader`：半透明（深度照写，避开 09-14 那个排序坑）、按横截面与高度着色（深 → 浅青）、浪头泡沫带用噪声碎边并随时间流动、浪身水纹条沿推进反方向流、顶部亮边；最终颜色分档量化，保住像素游戏的平涂味 | `battle_vfx.gd` 浪墙段 + 新着色器 |
| ③ 浪头水沫 | 沿浪脊一排往上 / 往前飞溅的白色水沫小片，随浪走 | 同上 |
| ④ 身后水雾 | 浪身后方一片白雾，跟着浪、慢慢淡 | 同上 |
| ⑤ 打中 | 加强 `wave_splash`：被打者身上一团亮白水花 + 水滴 | `battle_vfx.gd` |
| ⑥ 退场 | 浪落下时泡沫与水雾留一会儿再散 | 同上 |

**直播**：着色器参数走现成的 `stream_shader_params` 跟踪（触手同一条路）；新生成的网格 / 贴图一律纯函数 + `VfxTex.tag`。

## 6. 验收标准

1. 实验台 `staff_043` + 真对局各录一段**原速**视频，逐帧自查：起手、浪身半透明可见后方单位、浪头泡沫、水沫、水雾、打中水花、退场。

3. 时刻对齐：浪体推进位置与伤害结算时刻仍一致（现有判据 + 实测）。
4. 门禁：浪墙相关测试、`verify_stream_parity` / `verify_stream_coverage` 绿。每条新判据先改坏一处证明会红，再逐字节还原。
