## 需求原文

用户 2026-09-10：「做完这个后你先继续处理 011，我回来一起验收两个」。
010 那一轮定死的做事口径（用户同日原话），011 逐字继承：

- 「**不应该有预警啊**」—— 文案没写的东西不许加。
- 「我实际的效果就是**波在移动，碰到人造成伤害**，你这样没有遵从装备效果啊」
  ⇒ **演出必须就是效果本身**，不是把效果换个说法重新编码一遍。
- 「不要拿图片贴图敷衍我，我要动画像素特效」；图标 **32×32**。
- 素材不复用（2026-08-03 铁律）。

装备文案（`data/phase2-equipment.json` · `p2eq_011`）：

> 该法器法力条集满时**连斩 5/6/8 次随机敌人**，每次造成（40/50/70+0.5/0.7/1.0×攻击力）物理伤害
> （**后续每发逐渐衰减**）；携带者的**溢出治疗转化为血护盾**（上限 200/350/500）。

⇒ 画面上必须能读出的三件事：①一刀接一刀（连）②每刀落在**不同的**敌人身上（随机敌）
③**一刀比一刀弱**（逐渐衰减）。文案没提预警、没提蓄力 ⇒ **不许加**。

## 方案

### 1. 素材：`tools/gen_bloodslash.py`（新）

| 产物 | 规格 | 说明 |
|---|---|---|
| `assets/sprites/vfx/eq011-slash.png` | 4 变体 × 5 帧 · 格 64 · 表 256×320 | 锁定 `blood` 调色板（6 色）· 0 半透 · Bayer 4×4 有序抖动按**最终像素**算 |
| `assets/sprites/equip/eq011-icon.png` | 32×32 | 血滴吊坠，同一块板 |

五帧（**帧帧不同**，A3）：
0 刃尖切入（弧的前 35%）→ 1 弧拉到 65% → 2 满弧 + 白热芯最厚 →
3 弧被抖动咬出缺口（**亮度不降**）→ 4 只剩几块碎片。
消散**靠碎不靠淡**（A2）：不透明像素的平均亮度全程 ≥ 最满帧的 70%。

四个变体 = 四个不同走向的刀路（右下斜 / 左下斜 / 近水平 / 陡斜），
连斩时**按刀序轮换** ⇒ 读起来是「一刀接一刀」而不是同一张图闪八次。

### 2. 演出：`_eq_blood_combo`（`equip_system.gd`，从上帝文件搬出来）

- 每一刀：`battle._anticipate(u)`（携带者自己的出手动作，**不是预警**）+ 斩痕落在目标身上。
- 斩痕**尺寸 ∝ 衰减系数**：`size = BLOOD_SLASH_W × pow(0.85, k)`
  ⇒ **画多大就是打多重**，「逐渐衰减」在画面上读得出来（门禁量这条）。
- 斩痕**偏向携带者那一侧**：落点 = 目标位置 + （携带者→目标方向的反向）× 偏移
  ⇒ 刀是从携带者那边切进来的，`from2d` 变成**真的被读的参数**（A8）。
- 五帧逐帧走 **`_wait_sim`**，与连斩节拍**同一条钟**（A5）；`create_tween` 整个删掉。
- `_blood_slash` / `VfxTex._make_slash_sheet` 从上帝文件与工具层删除（零调用者后）。

### 3. 数值

**一个不动。** A7 / A9 只报告不改（同 010「3 星就是这个强度」的口径）。

## 已知风险与未决点

1. **变体轮换会不会让人以为是不同的技能** —— 四个变体同色同板同节奏，只有刀路不同；
   风险是"看起来乱"。做完拿 100 帧自己看，读不出「连」就退回单一变体。
2. **`size ∝ decay` 到第 8 刀只剩 32%**（0.85⁷）—— 3★ 最后一刀会很小。
   这是效果本身（伤害也只剩 32%），但如果实拍读不出来，考虑把基准放大而不是加下限
   （加下限 = 画的和打的又不是一回事）。
3. **`extra_ls = 0.33` 不随星级变（A9）** 是数值决策，等用户拍板；本轮不动。
4. **护盾上限第 6 刀封顶（A7）** 同上。
5. 011 的 emoji 是 🌙（月亮），与刚改名的 009「月之刃」撞主题，且与"饮血"无关。
   属于展示层小事，**列出来等用户拍板**，本轮不动。

### 平台纪律（010 那一轮踩到的，011 直接继承）

- **`crit = 0.0`**：`_resolve_dmg` 会掷暴击（×1.5）。011 的判据里有「第 k 刀 / 第 0 刀 == 0.85^k」
  这种**比值**，只要有一刀暴击整条就成了掷骰子。010 的 ⑩c 就是这么单跑三次全绿、
  进并行门禁当场红的。⇒ 关掉暴击，判据从「大概」收紧成「正好」。
- **`active_skills = []` + `no_basic` + `no_move`**：只有被测那件装备能打出伤害；
  另配**对照组**（不带 011 推同样长的窗口，承伤必须 = 0），否则量到的是「有东西打了它」
  而不是「011 打的」。
- 等游戏内效果一律用**墙钟**当上限、**游戏钟**当尺子（CLAUDE.md §3.5）。
- 台子里最前面置 `GameState.test_mode = true`，绝不写玩家存档。

### 反向验证抓到我自己两个假判据

1. **⑧ 原本是恒真式**：写成「间隔 == `BLOOD_BEAT`」，而两边都来自同一个常量 ——
   把常量从 0.3 改成 0.25 **照样绿**。文案只说「连斩 N 次」、没说间隔多少，
   所以 0.3 是可调的设计数、不是它必须满足的声称。
   ⇒ 判据改成量【七个间隔彼此一致】（守得住「节拍乱了」），常量值本身交给 ④ 守。
2. **⑫ 量的不是被测那件事**：平台上我摆了 `carrier["lifesteal"] = 0.33`，
   于是把 `_eq_bloodletting` 里每刀自带的 `extra_ls = 0.33` 拿掉、⑫ **照样绿**
   —— 盾是我喂的吸血转的，不是 011 转的。⇒ 平台基础吸血归零，只留 011 自己的账。

### 一个留给用户拍板的观感项

末两刀只有 49 / 42 码，读成一道细红弧。这是忠实的（伤害也只剩 38% / 32%）。
要更醒目就**把基准 `BLOOD_SLASH_W` 调大**（比值不变），
**不是**给尺寸加下限 —— 那样「画的和打的」又不是一回事了。
