# 排行榜上点玩家可以切磋

日期：2026-10-30　|　状态：**已完成**（未发版，随下一版）

## 1. 需求原文

- 用户 10-30：「然后排行榜里面需要做一个这个切磋功能，也就是点击这个这个玩家之后，除了加好友选项，那还应该有这个切磋选项。」

## 2. 调查结论

- 排行榜点别人那一行 ⇒ `PlayerMenu.hotspot`（`scripts/scenes/LeaderboardScene.gd:1073-1076`），弹 `scripts/scenes/social/player_menu.gd` 的小卡：标题 + 玩家 ID + 状态行 + 2×2 四颗键（加好友 / 举报昵称 / 拉黑 / 关闭，`player_menu.gd:128-131`，盒子 480×284）。同一个菜单还被周日对阵图、周六赛况板、对局顶栏共用（`BracketMapScene.gd:1859`、`GauntletBoardScene.gd:376`、`battle/topbar_status.gd:97`）。
- 好友页切磋：`FriendsScene._spar`（`FriendsScene.gd:344-368`）→ `Spar.my_side_check()`（教程 / 闯关排队中 / 统领没选满就不开）→ `FriendsNet.fetch_lineup(账号)`（RPC `friend_lineup`）→ `Spar.start`。
- **服务端 `friend_lineup` 先验双方是好友**，非好友回 `not_friends`（`server/supabase/migrations/20261024_friends.sql:269-271`）；`lineups` 表客户端不能直读。
- 排行榜每一行背后是 `ghosts` 表里这个人**那一周最新的积分赛快照**（`20261024b_leaderboard_lead.sql` `latest`：同周、去机器人、`gl_w = gl_l = 0`、按场次 / 上传时刻倒序取第一行）；`ghosts` 对所有登录玩家可读（`schema.sql:67-70`，匹配就是这么拉对手的），带 `rules_ver` 列。榜单行已带 `account_id`（`supabase.gd _week_lb_row`）。
- 切磋结算屏「返回好友」写死回好友页（`scripts/scenes/battle/battle_hud.gd:1240`，`Spar.FRIENDS_SCENE`）。

## 3. 需求 ↔ 代码的出入

- 需求是「点玩家 → 有切磋」，而排行榜上绝大多数人不是好友，服务端不让读非好友的「最新背包阵容」。
- 但排行榜本身展示的就是每个人那一周的积分赛阵容，这份快照现成可读 ⇒ 非好友切磋打的是**他在榜上的那份阵容**，不用改服务器。

## 4. 方案

1. `player_menu.gd`：宿主给了 `spar_week`（且有账号）才多一颗「切磋」（第一颗、金色），菜单变三行：切磋 | 加好友 / 举报昵称 | 拉黑 / 关闭。其余三处入口不给 `spar_week` ⇒ 菜单不变（对局顶栏里切磋没有意义）。
2. 按下：`Spar.my_side_check()` 不过 ⇒ 状态行说原因；过了 ⇒ 状态行「正在读取对方阵容」→ `FriendsNet.fetch_for_spar(账号, 周)`：
   - 先 `friend_lineup`：是好友 ⇒ 打他的最新背包阵容（与好友页一致）；
   - 回 `not_friends` ⇒ 读 `ghosts` 这个人这一周的积分赛快照（与排行榜同一套筛选：去 `seed_` / 机器人 / 闯关行，按场次 / 上传时刻倒序取第一行），照样过 `lineup_check`（规则版本 / 结构版本 / 统领 / 分路）。
   - 成 ⇒ `Spar.start`（隔离与好友切磋完全同一套：不进战绩、不叠任何常规赛累积）；败 ⇒ 状态行说原因，键恢复可点。
3. `Spar`：对方信息里可带 `back`（回哪一页）；结算屏那颗键按它显示「返回排行榜」/「返回好友」并回对应页（`battle_hud.gd`）。
4. `LeaderboardScene`：服务端榜的行给 `spar_week`（这张榜的周号）与 `lead`（头像）。

## 5. 已知风险与未决点

| # | 风险 | 状态 |
|---|---|---|
| R1 | 非好友打的是「他这周积分赛结算那一刻的阵容」，不是他此刻背包里的；周一看上周榜时打的是上周的阵容 | 已知、接受：排行榜上显示的成绩就是这份阵容打出来的。若要「任何人都打最新背包阵容」需要服务端新函数 + 正式服迁移，要用户点头 |
| R2 | 对方用的是旧版本（规则版本不同）⇒ 打不了，提示「对方版本较旧」 | 已知：与好友切磋同一条规矩 |
| R3 | 本机榜（没连服务器时）的行没有账号 ⇒ 不给切磋键 | 已知、接受 |
| R4 | 每周二 00:00 UTC 清旧周快照 ⇒ 理论上看旧榜时快照已没了 ⇒ 提示「对方尚未配置阵容」 | 已知：排行榜只看本周 / 上周，上周的在周二才清 |

## 7. 决策记录

- 非好友用「榜上那份积分赛快照」：不改服务器、不放开「好友阵容只对好友可读」那条；好友照旧打最新背包阵容。按 memory「待拍板项按我的建议自定」先这样做，向用户说明 R1。
