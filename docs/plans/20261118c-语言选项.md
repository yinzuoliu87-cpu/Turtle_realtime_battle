日期：2026-11-18　|　状态：**草稿**

- 用户 11-07：「对了，我们游戏也要有语言选项，先支持中英等基本的语言」；同日「语言可以慢慢排期」。

⇒ 用户没定截止日期，也没说「基本的语言」具体是哪几种。下面按**第一期 = 中文 + 英文**写，其余语言放第 4.6 节，等第一期跑通再加。

## 2. 调查结论

**现在是零机制**（11-07 实查，11-18 复核）：
- `scripts/`、`autoload/` 里没有 `TranslationServer`、`tr(`、语言设置；`project.godot:89-91` 的 `[internationalization]` 只有 `locale/include_text_server_data=true`。
- 设置页（`scripts/scenes/SettingsScene.gd`）分「账号」（:257）「音乐 / 音效」（:392 / :398）「画面」（:408）「支持」（:419）几组，没有语言一行。存档里的设置字段在 `autoload/GameState.gd:996-997` 一带（`sfx_volume`、`fullscreen`），没有语言字段。

**要翻的量**（11-18 用 `python tools/oneoff/i18n_count.py <仓库根>` 只读统计：只数代码里的字符串字面量与 data 文件，注释不算）：

| 来源 | 汉字 | 条数 | 说明 |
|---|---|---|---|
| `scripts/` + `autoload/` 字符串字面量 | 约 2.2 万 | 约 3600 条 | 已扣掉开发用的特效实验台 `scripts/gamedata/vfxlab_cases.gd`（1.05 万字，不给玩家看） |
| `data/pets.json` | 1.9 万 | 28 只龟的名字 / 技能 / 被动模板 | 技能说明是模板（`{N:expr}` 之类），渲染在 `scripts/util/skill_text.gd` |
| `data/phase2-equipment.json` | 1.2 万 | 装备说明 | 装备数值事实源是 `EquipStats.STATS`，json 里的说明是展示用 |
| `data/tutorial-steps.json`、`status.json` 等 | 约 0.3 万 | | |
| `data/nickname-words.json`、`ghost_seed.json` | 约 0.25 万 | | **默认昵称词表与陪练号昵称，不翻**（见 §4.5） |

**会挡路的写法**（11-07 实查留档）：
- 用 `%` 拼中文 527 处、`+` 拼接 86 处：英文语序不同，要整句换成带占位的模板。
- **拿中文当逻辑判断**约 50 处（装备类型 `phase2_types`、羁绊、状态 match），中文当字典键 154 处：翻译后这些判断会坏，必须先拆成 id。
- `scripts/util/skill_text.gd:55` 的 `KEYWORD_RULES` 用中文正则（含前后断言）给「物理伤害 / 眩晕 /【专名】」上色：英文要另一套规则表。
- 文案门禁全是中文口径：`tools/text_golden.py`（快照 2773 段）、`copy_lol_style_lint`、`tooltip_number_audit`。

**字体**（11-11 用 fontTools 量过）：像素字 `assets/fonts/fusion-pixel-12px-zh_hans.otf` 拉丁字母、假名、韩文全有，繁中 / 西 / 葡 / 印尼 / 越南抽样全覆盖；**泰文 0/50**。⇒ 中英两种语言不用换字体。

**主站**（turtlepoll.com）已有 10 种语言（简中、en、es、id、ja、ko、pt、th、vi、zh-TW），界面默认英文；主站来的玩家不一定读中文 —— 这是做英文的直接理由。

## 3. 需求 ↔ 代码的出入

- 「先支持中英等基本的语言」：中文之外，代码里**没有任何一处**可以换语言。不是「加一份译文」，而是先把约 50 处中文判断拆成 id、把 600 多处拼句改成模板，再谈译文。
- 用户说的是「语言选项」，没说要不要跟着系统语言自动选。§5 U2。

## 4. 方案

### 4.1 机制：Godot 自带的翻译（不自己造）

- 译文表用 `.po`（gettext）：`locale/en.po`，msgid = 现在的中文原文。好处：**不用给 3600 条字符串起 key**；控件的 `text` 是字面量中文时，Godot 4 默认自动翻译（`auto_translate_mode` 继承根节点），不改代码就生效。
- 运行时拼出来的字（`"%d 胜" % n` 这类）改成 `tr("%d 胜") % n`；`+` 拼接改成整句模板。
- 切换：`TranslationServer.set_locale()`，存档加一个 `lang` 字段；设置页加一行「语言」（简体中文 / English）。切换后重进当前页（`SceneNav.go` 当前场景）。
- **测试默认语言钉成中文**：不然 CI 机器是英文系统，几百条门禁跟着变英文全红。

### 4.2 先拆逻辑（不动玩家看到的字，可以单独先上）

- 约 50 处「中文当判断」、154 处「中文当键」逐处改成 id（装备类型 / 羁绊 / 状态）。这一步不改任何显示，门禁照旧全绿 = 证明没改坏。
- 600 多处拼句改模板。同样不改显示（中文模板 = 原句）。

### 4.3 抽取与门禁

- 写 `tools/i18n_extract.py`：扫 `.gd` 字面量 + data json 的文案字段 → 生成 / 更新 `locale/zh.pot`；与 `en.po` 对账，列出**没译的**与**译文里占位符对不上的**（`%d` / `{N:expr}` 数目或种类不同）。进门禁：缺译文只报数（第一期允许逐批补），占位符对不上直接红。
- 英文版全屏截图走一遍（现成的 `_shot_screens` 两个比例）：英文通常比中文长 30%~60%，按钮 / 卡片会溢出，逐屏修版式。

### 4.4 译文体例

- 装备照云顶之弈英文版写法，龟技能照 LoL 英文官方写法（memory 里定过的体例）；自定属性名用我们自己的叫法。
- 先出一份**术语表**（龟名、技能名、装备名、属性、状态、赛制名词：积分赛 / 闯关赛 / 决赛 / 偷袭 / 援军小将…）给用户过目，再批量译正文。术语一旦定了，正文按术语表译。

### 4.5 不翻的

- 玩家昵称、默认昵称词表、陪练号昵称（昵称是玩家身份，不该随看的人语言变）。
- 服务器下发的维护公告（`service_status.notice`）：第一期只出中文；要双语就加一列，另议。
- 开发用的实验台、调试场、日志。

### 4.6 以后加语言

第一期把机制、门禁、版式问题全过一遍；之后加一种语言 = 加一份 `.po` + 截图走查。泰文要补一个后备字体（像素字没有泰文）。

### 4.7 分期

| 期 | 内容 | 玩家能看到吗 |
|---|---|---|
| P0 | 拆逻辑（§4.2）+ 抽取工具与门禁（§4.3）+ 测试钉中文 | 看不到，中文一字不变 |
| P1 | 设置页语言一行 + 界面文字（菜单 / 按钮 / 弹框 / 结算 / 设置）英文 | 能切英文，龟 / 装备说明仍中文 |
| P2 | 龟技能 / 装备 / 图鉴 / 教程英文 | 全英文 |
| P3 | App Store / TestFlight 英文说明、截图 | 商店页 |

## 5. 已知风险与未决点

- **U1（未决）第一期做哪几种语言？** 我的建议：只做英文，其余等第一期跑通再加（主站另外 8 种语言的玩家量现在看不出来）。
- **U2【已答 11-18】第一次打开**：用户「第一次进入应该是英文去显示，或者是跟随你的机子的那个系统语言。然后在设置里面应该是有语言的切换按钮，点击一下游戏的整个语言都会被切换。」⇒ 跟系统语言，系统不是中文（简 / 繁）一律英文；设置页一个切换按钮，点一下整个游戏换语言。
- **U3（未决）龟名 / 装备名翻不翻？** 我的建议：翻（英文玩家看不懂汉字名就记不住龟）；术语表先给你过目。
- **U4（未决）译文谁来把关？** 我先按 LoL / 云顶英文体例译；有没有英文母语的人（Tom 那边？）能抽查。
- 风险（未验）：英文变长导致的溢出，要等 P1 截图走查才知道多少屏要改版式。
- 风险（已堵，靠门禁）：拆逻辑时改坏判断 —— P0 不改显示，现有约 700 项门禁全绿才算过。
