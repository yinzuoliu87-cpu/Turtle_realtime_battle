## 调查

- **现状**：双头龟只有一张静态立绘，没有任何动作帧（`ANIM_*` 表里没有 two_head）；战斗靠 idle + 形变「演」动作。
- **有真动作帧的单位**：basic / ghost / ninja / 三种小将 / 训龟大师。帧格 64×64 横条（例 `ninja/slash.png` 192×64 = 3 帧）。
- **形态字段**：`u["two_form"]` = `"ranged"` / `"melee"`（`two_head_system.gd:364` 切换；开局远程，`battle_spawn.gd:718`）。
- **技能（`data/pets.json` two_head）**：
  - 被动 双生：技能一 / 技能二放完自动切形态；射程 400 ↔ 70。
  - 普攻 双头攻击：远程=灵能弹；近战=挥砍。
  - 技能一：远程=灵能冲击（大紫炮弹 → 爆炸）；近战=锤击（跳起落地砸）。
  - 技能二：远程=精神干扰（真伤 + 治疗削减 + 破盾）；近战=吸收（打 + 回血）。
  - 技能三 融合：锁定当前形态，「近战合体」属性 + 主动魔法波（物理/真实交替 + 击飞）。
- **生成流程**：沿用 memory `project-pixellab-sprite-workflow`：参考图 44×44 / 20 色；方向 south-west；循环动作 v3 + 10 帧；招式 pro（固定 4 帧）；装进游戏查归一（ANIM_NORM）与朝向（原图朝左，逐帧镜像）。

## 方案

**（10-07 第一版「两个头并排」被用户否：「这个双头形象我不喜欢，近战是举锤的战士，远程应该是术士法师」「你其实可以搞成双面龟那种变脸龟一样」「变脸龟好了，近战一个头一个形象，远程另一个」；近战姿势「举锤」；「名字到时候改，先把东西做出来」。）**

**变脸龟：一个身体、一个头，两种形象，靠「变脸」切换。**
- 远程·术士（开局）：灰紫冷静脸、额头发光符文眼、紫色兜帽斗篷、锤柄当法杖、符文石浮起当法球。
- 近战·战士：红色怒脸带战纹、红斗篷系一侧肩露铁护肩、扛/举符文石锤。
- 切换：斗篷一甩挡脸，甩过去就换好（川剧变脸）。融合＝两张脸同时露出那一刻。
- 已入游戏：`pets/two_head.png`(术士) / `pets/two_head_melee.png`(战士) / `avatars/two_head.png`；切形态由 `two_head_system._two_head_form_art` 换 idle 源头，门禁 verify_two_head_form_art。

**动作清单（每套形态各一份）**：待机、走路、普攻（远程灵能弹 / 近战挥锤）、技能一（远程法球胀大推出 / 近战双手举锤跳起落地砸，可拆起跳+落地两段）、技能二（远程符文眼放精神波 / 近战抓取回吸）、受击、死亡；共用「斗篷甩过挡脸」切换（分两段生成，在斗篷遮满脸那帧接）；融合魔法波一条。

**接线**：动画表按 `two_form` 取；伤害结算时刻对齐命中帧；锤击位移（0.42 秒弧线跳到目标前 52 码）按跳跃进度切帧；切远程时 0.32 秒滑退期间播换脸。

## 已知风险与未决点

- 两套形态要**看得出是同一只龟**：PixelLab 分开生成两次容易长成两只不同的龟。办法：先做远程形态定稿，再拿它当参考图生成近战形态（同一 character 换装/换姿势）。
- pro 招式只有 4 帧，跳起落地砸这种大动作可能不够 —— 先出一版看，不够再拆成「起跳」「落地」两段（近战小将的人体浪板就是拆成 5 段）。
- 形态切换现在是瞬切；加切换动作后，切换那一瞬间的普攻时机要确认不被动画卡住。
- 额度：两套 × 约 8 个动作，pro 每个约 20 次额度，总计约 300 次以上。
