## 2. 调查结论

- **为什么建议下一个做匕首**：属性「暴击伤害」是现成的（`critDmg`，`scripts/gamedata/equip_stats.gd:45`，单位基础暴伤 1.5 = `battle_spawn.gd:459`），不用新加战斗属性；双生匕首改类一直挂着等它。筹码要做消耗品 + 背包 + 经济流水（手机与服务器重放），系统改动最大，放后面；魔法书（增伤）/ 乐器（龟能回复）要新加属性。
- 现有刀类装备（避开撞题）：剑【剑士】追打；双生匕首 = 命中后 50/75/100% 追加一刺；月之刃 = 充能斩弧形刀光；暴君之牙 / 弓箭羁绊 = **处决**；056 **飞镖** = 击飞打靶子标记；100 烟雾弹 = 潜行。
- 机制挂在**携带者**身上（与剑 / 炸弹同口径）。流血、中毒走现成的叠层 `battle._damage._apply_dot_stacks(目标, "bleed"/"poison", 层数, 来源)`；百分比破甲有现成 `armor_pen_pct`。
- 炸弹的经验：用户要求羁绊机制**直观、三档只加强度**（「三档的话，只递增伤害就可以了，不需要加其他花里胡哨的东西」）、范围画多大判定就多大。

## 3. 需求 ↔ 代码的出入

## 4. 方案

### 4.1 羁绊：匕首（3 / 6 / 10 件三档，同炸弹）

- **属性**：每件匕首为携带者提供暴击伤害 **+6% / +12% / +20%**（对应 1 / 2 / 3 档；弓箭只给暴击率，匕首给暴伤，互补）。
- **【刺杀】**（全队，11-25 用户定）：每一路**开打时**，我方**所有友方单位**的下一次攻击**必定暴击**，这一击还额外获得**暴击伤害**与 **20% 生命偷取**；二档在开打第 **10** 秒再来一次，三档在第 **20** 秒再来一次（每次都是「所有友方单位的下一次攻击」）。

| 档 | 件数（不同匕首，按 id 去重） | 这一击额外暴击伤害 | 生命偷取 | 触发时刻（每路开打后） |
|---|---|---|---|---|
| 1 | 3 | +25% | 20% | 0 秒 |
| 2 | 6 | +55% | 20% | 0 秒、10 秒 |
| 3 | 10（集齐） | +80% | 20% | 0 秒、10 秒、20 秒 |

（我按的口径，待用户确认：「攻击」= 普攻；每路重新计时（同炸弹导弹）；额外暴击伤害三档随档位变、生命偷取固定 20%；某次触发时上一次还没打出去 ⇒ 不叠加，仍只强化下一击。原草稿「首击加伤 / 击杀闪身 / 必暴击」作废。）

### 4.2b 暗影忍者（11-25 用户改过）

- **属性**：生命 1500 / 3000 / 8000、攻击力 80 / 160 / 450、**护甲 / 魔抗 30 / 50 / 90、暴击率 25 / 35 / 50%**（双抗与暴击率是用户要的，数我定）、龟能上限 60；**登场隐身**（无法被选中，第一次攻击现形）。
- **普攻**：近战双刀快砍，100% 攻击力物理伤害。
- **技能【影袭】**（龟能满，**用户「没问题」**）：化成黑烟消失 0.3 秒，**瞬移到敌方当前生命值最低的单位身后**背刺，250% 攻击力物理伤害（必暴击），然后重新隐身 1.5 秒。
- **【影分身】（用户定，取代我提的「每第 3 次技能」）**：生命值**首次**降到 50% 时，分出一个**影子忍者，持续 20 秒**，拥有本体 **50% 最大生命值与 50% 攻击力**（同样的普攻与【影袭】）。
  - 分身存在期间，**本体或影子每释放一次【影袭】，两个忍者同时各掷出一枚手里剑，转向同一个目标**（影袭的那个目标），**沿直线飞向它，路径上的每个敌人**（逐步碰撞，每枚每人一次）受到（60 / 120 / 300 + 100% 攻击力）**魔法伤害**。
- 动作：走路 / 普攻双刀快砍 / 消失→出现背刺 / 掷手里剑 / 分身（照武士刀小将流程：先定关键姿势、逐帧标刀与手里剑路径再交）。
- 撞题：忍者龟本身有手里剑技能 ⇒ 暗影忍者的手里剑造型 / 特效另做（四角黑曜石色带紫光拖尾），不复用忍者龟的。

### 4.2c 专属羁绊「仪式」：仪式匕首在大轮里不断变强（用户 11-25「类似于香火石一样，针对在大轮里面，这个装备不断的增强」）

照 093 香火石 / 096 小木斧的先例（`GameState.incense_marks` / `axe_exp_*`，赛季级字段）：
- 仪式匕首 = **匕首 + 仪式**双类型；「仪式」羁绊**只有 1 档**：持有并装备 1 件即激活（同香火）。
- **【血契】**：仪式匕首的携带者每击杀一名敌人（龟或小将，斩杀也算）刻 1 道血契。血契存在**队伍级 + 大轮级**的池子里（存档新字段 `ritual_marks`），**整个大轮累计，换大轮（周一）清零**；卖掉匕首不退已刻的血契（同香火刻痕），再装上接着用。上限 **150** 道。
- 每道血契：
  - **装备那一份**（只给携带者，按星）：攻击力 +0.6 / 1.2 / 2.5、护甲穿透 +0.2 / 0.35 / 0.6（满 150 道 ⇒ 3★ 攻击 +375、护穿 +90）。
  - **羁绊那一份**（全队，含携带者）：攻击力 +0.1%（满 150 道 ⇒ 全队 +15% 攻击力）。
- **对手**：血契从对手快照读（快照带 `ritual_marks`，机器人 / 旧快照没有 ⇒ 0），局内新刻的不写对手存档（同香火 D3）。
- 界面：装备卡与羁绊面板显示「血契 N / 150」；刻一道时携带者身上冒一个小血滴字。
- 要动的链路（同香火石，全链路门禁照 `tests/verify_incense_stone.gd` 写一份）：存档读写 · 换大轮清零 · 快照上传 · 对手读快照 · 经济流水（血契是战斗副本，不进 econ_ops，同香火）· 服务器重放一致。

## 6. 验收标准

- 10 件、1–5 费各两件；名字全表不重名、过去 AI 味标准（脚本自查）。
- 门禁：每件效果按公式逐星对账；【刺杀】三档首击伤害、每路重置、每个敌人只吃一次；双生匕首算匕首不算剑（剑羁绊件数对账）；**先证明门禁会 FAIL**（改坏一个数确认红）。
- 跨进程确定性（`verify_rules_fingerprint` 覆盖到新装备）。
- 用户看每件的录像认可后才放出。
