范围：`scripts/systems/equip/tentacle_vfx.gd`、`tentacle_mesh_vfx.gd`、`assets/shaders/tentacle.gdshader`（附带 `tentacle_shadow.gdshader`、`tentacle_smear.gdshader`）、`tentacle_idle_keys.gd`、`tentacle_slam_fx.gd`，以及 7 条触手门禁与 `tests/_tentacle_geo.gd`。行号 = 当前工作区（含 11-13 未提交改动）。
标记：**【今天】** = 11-13 加的或改的；**【死】** = 代码还在但执行不到、或算出来没人读；**（推算）** = 只读代码推出，未实跑。

## 一、十条最大的限制

1. **平面锁（最大）**：每一节方向只由「前」和「上」两个分量合成（`tentacle_vfx.gd:1645 / 1654 / 1694`）。侧向只有一个正弦侧摆：出手各状态 ±3.5°，待机稳定后严格为 0（【今天】的待机关键帧只有平面内角度）。这个竖直平面只在出手瞬间按目标定一次，待机期间不转。来历：08-04 建模「固定弧长 + 沿切角积分 p += (cosθ·前 + sinθ·上)·ds」（:168-173）。
2. **物理整段是死代码**：`var calm := true`（:1724）让每个子步都走「临界阻尼弹簧跟随」后 `continue`，Verlet 惯性、重力 26、肌肉、距离约束、弯曲刚度（:1782-1849）一次都跑不到；`_inertia_step` 算出的 `lag` 没人读；收回期余振行波条件 `wc < 1.35` 永远不成立。现在的动作 = 姿态表 → 不过冲的弹簧 → 段长约束 → 地面硬钳，没有任何惯性、甩尾、过冲。
3. **整套拍击是写死的逐节单调旋转**（:1677-1694）：从前摇末形状出发，每节转向「根 20° → 梢 −2°」，梢晚起步 0.10 s、根早落地 0.06 s、按 pow 2.6 加速、到 `T_TOUCH` 钳死；不过冲不回弹，落地永远是一条贴地直线。
4. **第 3 条盖掉了整套拍击的参数姿势**（推算）：`_phase_at(ST_SLAM)` 那一整套（`ANG_SLAM`、`SNAP_T`、settle、comp、−10/−8、【今天】的 `ANT_A0/A1`、`_slam_curl`、`SLAM_FRONT_*`、拍击期侧摆和 7° 波纹）只对点刺生效。【今天】把 `SLAM_SPEED` 改 1.6、`SLAM_HOLD` 改非零，实际只改了甩长时机。
5. **长度按状态写死**：出土 / 待机 / 撤场 / 预警 / 前摇都是 5.76 米（【今天】`IDLE_ARC_K` = `REAR_ARC_K` = 0.60），拍下约 0.15 s 甩到 9.6 米，收回 0.4 s 缩回；每个子步 6 次段长约束把每节拉回固定长度；点刺第一帧弧长 5.76 → 9.6 直接跳。
6. **地面硬钳**：所有点不许低于根部（:1737 / 1759 / 1779），直接把高度抬上来；注释（:1620-1629）写的「沿地面摊开」已不在代码里。
7. **时间焊死**：伤害时刻 = `T_WARN` 1.00 + `T_REAR` 0.13 + `T_TOUCH` 0.35；拖尾公式落地时刻按 `T_TOUCH` 倒推；门禁要求梢端落地与伤害差 ≤ 0.05 s。
8. **不许回抬、不许拍两次**：`verify_tentacle_soft` ① 下砸过半程后梢端回抬 1 毫米都算红；`_slam_curl`「只准变直」、拍击期关掉行波、`comp` 下压补偿都为这一条加。
9. **过渡补丁叠了四层**：状态切换 0.15 s 方向混合（离开待机 0.35 s【今天】）、进待机 0.9 s 渐入【今天】、预警开头 0.35 s 侧摆渐出【今天】、预警从「此刻的参数姿势」起抬【今天】（稳定待机里这个参数姿势玩家看不见，全靠混合遮住）。
10. **外形锁**：截面宽窄和背鳍长哪一侧由固定的平面法线 `lat` 决定，不看实际往哪边卷（推算：反卷时鳍长到钩的内侧）；鳍间距按归一化身长排，传进去的 `arc_len` 没被用；身长短时整根 ×0.72 变细【今天】；「下透上实」与按 `TIME` 流动的体内纹【今天】。

## 二、是不是锁在一个竖直平面（前 + 上）里？—— 是

平面由 `_basis_of`（:1858-1867）决定：前 = 根部→目标水平单位向量，侧 = 水平法线，上 = 世界竖直写死。根部钉死（:1740 / 1762 / 1777 / 1840）；`aim` 只在 `strike()` 写一次（:702），两次出手之间平面不转；没有目标时朝正前方 400 码（:666-667）。

| 位置 | 式子 | 侧向分量 |
|---|---|---|
| :1645 | `fwd·cos(ar)·cos(yw) + lat·sin(yw)·cos(ar) + up·sin(ar)` | 只来自侧摆 yw |
| :1654【今天】 | 待机关键帧 `fwd·cos + up·sin` | **0** |
| :1655【今天】 | `slerp(rd, wr)`，0.9 s 渐入 | 0.9 s 后 = 0 |
| :1666-1671 | 状态切换混合 | 只有换目标时带旧平面残留 |
| :1684-1686 | 拍下：把前摇末方向投影回平面，< −90° 加 360° | 只取平面内角度 |
| :1693-1694 | `lat·lk`，lk 随下落线性归零 | 落地瞬间 = 0 |
| shader:125-127 | 截面坐标系挂在 `lat` 上 | 外形朝向锁在平面法线 |

侧向幅度：`S_AMP` 3.5°（:343，注释「实机摆得很轻，原画那种 S 形是艺术加工」）；`S_AMP_IDLE` 14°【今天】只在 0.9 s 渐入期和预警开头看得到；`yaw` 沿身长 0.6 个波写死（:1565）；拍击期降到 22%（`SLAM_WAVY_MIN` :550，只对点刺）；`SWAY_AMP` 0.30【死】。
**没有任何门禁断言「必须在平面内」** —— 平面是代码自己锁的。
