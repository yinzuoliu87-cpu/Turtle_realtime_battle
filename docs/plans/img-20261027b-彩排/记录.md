## 彩排查出的问题（都已修复，提交 1c521ea0）

1. **调度器停号 / `reap_overdue` 杀不掉 godot**：`timeout` 会自己另开一个进程组。改成 `kill_tree`，按会话杀。实测三条路径下 godot 都在 0.0~0.2 秒内消失。
2. **陪练号第 2 局误报「格子对不上」**：入队那一刻就配上的一方从没进过「排队中」状态。改成第一次进匹配屏就算格子已查过。
3. **号少时补格子推不动**：见上表第 3 条。
4. **登录令牌被轮换**：副本里跑的号的登录令牌换新了，原存档的令牌已经失效。已把新令牌补回原存档，只改了 `auth_refresh` 这一个字段。
