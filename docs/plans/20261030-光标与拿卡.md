# 光标点击点与拿起卡片（照商业游戏做法）

日期：2026-10-30　|　状态：**已完成**（未发版，随下一版）

## 1. 需求原文

- 用户 10-29：「拖不起来，你看这鼠标是不是有问题」
- 用户 10-29：「然后是这个鼠标，到底什么是鼠标的中心？到底怎么做鼠标？我抓起卡片这个中心怎么搞」
- 用户 10-29：「人家商业游戏呢」
- 用户 10-30：「商业游戏做法呢」
- 用户 10-30：「改这个代码肯定要改，但是还有个问题，就在这个背包里面，我把一个卡片，一个龟的卡片就拿起来，然后拖动到另外一个地，那卡片怎么放了半天都放不下来？这是为什么？你到底怎么判定的？」

## 2. 调查结论

**光标**（实测放大图：`C:\tmp\cursor_grab\paw_zoom.png`）
- 旧爪子三根爪一样长、朝正上，点击点 `HOT = (11,1)` 在中爪尖（旧 `autoload/CursorTheme.gd:64`）；圆团身子的中心比点击点低 11.6 设计 px（爪子才 24 高）⇒ 三个「尖」，看不出点在哪。
- 卷爪（握拳）那张画好了，但拖动时从没出现：状态只看「悬停控件的光标形状」，没有任何可拖控件设成 `CURSOR_DRAG`（旧 `CursorTheme.gd:192-200`）；实拍四处拖动都是「指着的爪子缩到 0.8」。
- 旧握拳贴图 24×22、点击点在拳头**外面**上方 1px。

**拿起卡片**（实拍：`C:\tmp\cursor_grab\sheet.png`）四处三种摆法，且都是瞬间跳：
- 背包装备：整张悬在鼠标上方，卡底离鼠标 18px（旧 `inv_drag.gd:103`），拿起瞬间往上跳约 70px。
- 背包单位卡：鼠标在卡的 50% / 60%（旧 `inv_drag.gd:133`），按在卡角拿起时竖着跳约 80px。
- 选统领龟卡 / 编队槽：只跟一个 56px 头像，原点无偏移 ⇒ Godot 默认把预览**左上角**钉在鼠标上，头像挂在右下（`TeamSelectScene.gd _make_drag_preview`；Godot 4.6.3 `viewport.cpp:2494-2495`）。

**商业游戏怎么做**（两个调研 agent，只认源码 / 官方资料；全文与图在 `C:\tmp\cursor_ref\`）
- 光标点击点都在唯一的那个尖上：英雄联盟护手、Dota 2（官方规范：自制光标点击点必须与默认箭头尖相同）、星露谷（反编译：贴图左上角画在鼠标坐标）、暗黑都斜指左上；系统手形是竖直但只伸一根食指（Windows / Chrome / Apple）。拖东西时 Chrome 换握拳，点击点在顶部指节。
- 拿起卡片：杀戮尖塔 2（反编译 `NMouseCardPlay.LerpToMouse`）卡中心平滑追到鼠标、0.8→1.0 放大、摆正；小丑牌（Lua 源码）按哪拿哪、放大 10%、投影加深。两家都不瞬间跳。手机上 Backpack Battles 加了「拾取偏移」把物品抬离手指。

**放不下来**（用户 10-30 那条）：落下由**鼠标那一个点**判定 —— 引擎从点下的控件往上逐层问「收不收」，碰到 `MOUSE_FILTER_STOP` 就停。修复前普通小将卡中间那块「前排/后排」热区是 STOP（旧 `InventoryScene.gd:692`）。探针（用户新号原样阵容，每张卡当落点逐点拖）：修复前下路 1 号、2 号普通小将 **20/35** 个点接得住、卡片中间那条全接不住；修复后 35/35。这与「拖不起来」是同一个 bug 的两头，已在 3ef7e709 修掉；用户 10-30 用的是修复前的桌面包（`user://logs` 显示修复版没开过）。

## 3. 需求 ↔ 代码的出入

- 「鼠标是不是有问题」：鼠标本身没问题（光标不吃点击，`mouse_filter = IGNORE`）；「拖不起来 / 放不下来」是热区 STOP + 按下就切（已修）。光标的问题是**图案让人看不出点击点在哪**，不是点击点算错。
- 「这个中心怎么搞」：代码里根本没有统一规则，三处各写各的，没有一处是「不跳」的。

## 4. 方案

1. **光标**（`autoload/CursorTheme.gd`）
   - 新图案：斜指左上，中趾最长、奶白爪尖 = 点击点 `HOT = (2,2)`；两侧短趾；画法沿用原来 2×2 大块与配色，外描边加深为 `#0e2c1b`。
   - 新握拳：24×24，三趾收短只露爪尖，点击点 `HOT_FIST = (6,6)`（最前那颗）。
   - 正在拖东西（`gui_is_dragging()`）⇒ 握拳；缩放锚 = 当前点击点（按下缩小 / 悬停放大时爪尖不离开鼠标点）；`hot_for()` 给实拍与门禁读。
   - Mac 系统光标同步换图，握拳用 `HOT_FIST`。
2. **拿起卡片**：新建 `scripts/util/drag_lift.gd`（`DragLift`），四处共用：
   - 拿起那一刻按下点正好在鼠标下（不跳）；随后卡中心按 `exp(-12·t)` 滑到鼠标下（电脑）/ 卡底抬到手指上方 18px（手机）。
   - 放大 1.08、摆正、投影；原位虚影 0.35，拖动结束（引擎删预览）时复原。
   - 接入点（穷举）：`inv_drag.gd _begin`（背包装备 / 单位卡 / 卡上装备三种）、`pet_grid.gd` 龟卡、`roster_slots.gd _slot_drag` 编队槽。`inv_drag._preview` 只剩「装备小卡的样子」，`_card_preview` 删除。
   - 选统领龟卡：`TeamSelectScene._card_drag` 在积分赛逐字节守卫里，**一字不动**；`pet_grid.gd` 照旧调它拿数据，再用 `DragLift` 替掉它设的小头像（引擎设第二张预览时先删第一张，`viewport.cpp:2490-2493`）。
