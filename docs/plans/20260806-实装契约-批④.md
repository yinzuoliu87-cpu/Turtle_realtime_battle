## 2. 已经给你接好的十个钩子

`EquipSystem` 里有一张 `B4_OWNER` 表把 17 个 id 路由到 6 个系统，然后调统一钩子。

| 钩子 | 何时调 | 备注 |
|---|---|---|
| `tick(delta)` | 每帧一次（**全局**，已用帧号去重） | 召唤物自走 / 区域结算 / 在途弹道 / 演出 |

| `on_hit(src, tgt, dmg, eid, si)` | 携带者命中结算后 | |
| `on_damaged(u, src, dmg, eid, si)` | 携带者受到伤害后 | ★**两条伤害路径都会调** |

## 3. ★三条焊死的口径（逐条对应踩过的坑）

### ① 随机一律走 `battle._battle_rng`
裸 `randi()` / `randf()` / `randfn()` 会破坏确定性。`tools/rng_discipline.py` 冻结了裸调用数、
`verify_battle_determinism` 同种子比指纹 —— 加一个裸随机**两处一起红，而且看着像别的问题**。

### ② 你打出的每一段伤害都 `from_equip = true`
`battle_damage.gd` 里 `if not from_equip` 才回钩 on-hit / 弓箭处决 / 冰封 / 僵硬。
不焊会自激 —— 080 的 3★ 一轮扫射 10 发 + 地毯轰炸连续投弹、086 的 6 条终极射线，都是自激放大器。

### ③ `_t` 跨路累加、永不重置（CLAUDE.md §3.4）
所有"持续 N 秒 / 每 N 秒"存**到期时刻**或**自管累加器**，**不许**拿 `_t` 直接和常数比 ——
否则下路一开场就触发。

## 6. 数值必须能被文案审计器锚到

`tools/tooltip_number_audit.py` 会 glob 到你的文件（`scripts/systems/**/*.gd` + `scripts/scenes/battle/*.gd`），
但它靠**锚点**判断"这个数组是不是这件装备的"：锚点 = 代码里的 `"p2eq_0XX"` 字符串字面量，窗口 ±2500 字符。

⇒ **规则：每件装备的三元数组必须写在离它自己的 `"p2eq_0XX"` 字面量 2500 字符以内。**
最省事的写法是每件一个 `match eid:` 分支，数组就近声明：

```gdscript
match eid:
    "p2eq_077":
        var hp := [30.0, 60.0, 100.0][si]      # 就近, 锚得到
        var atk := [10.0, 20.0, 30.0][si]
```

**不要**把所有数值提到文件顶部的常量区 —— 会被判"远处命中"，门禁红。

## 7. 特效标准

- **零素材优先**：能用 `VfxTex` 程序化纹理 / 现成 vfx 图集 / 几何原语做出来的，不要新建资源
- **要新素材就说**：用户铁律是「新内容一律新素材，只有背包/商店装备图标可复用」——
  你判断需要新美术时**写进交付报告**，不要拿别的素材顶替
- **数值测试不许依赖 tween 跑完**（CLAUDE.md §3.5）：把结算从演出里抽出来成独立函数，
  演出末尾调它、测试也直接调它。无头 CI 下 `create_tween()` 推进不稳，本地永远复现不出来
- 演出层的每个入口都要能被**单独调用**（供 VFXPREVIEW 与门禁用）

## 8. 交付要求

1. **门禁自己跑绿**：
   `godot --headless --path . res://tests/verify_eq_<你的>.tscn --quit-after 3000`
   判据不只看退出码，还要打出 `ALL PASS` 且**没有** `SCRIPT ERROR` / `Max recursion` / `freed instance`。
2. **反向验证**：挑你自己最关键的 **≥5 条**断言，逐条**改坏产品代码**确认那条**具名断言**变红，
   然后**逐字节还原**（`cp` 备份 + `md5sum` 对比，[[fb-restore-mutations-after-reverse-verify]]）。
   报告里贴出"改了什么 → 哪条红了 → 已还原"的证据。
3. **不许有恒真断言**：期望值**不许**读被测的那个常量；门禁**不许**重新实现一遍公式再跟自己比。
   打印分母 —— `N=0` 是空检查不是通过。
4. **诚实记录**：规格没写死、由你定的地方，在文件头列出来，写清**你选了哪一侧、为什么、另一侧是什么**。
   发现自己的门禁是假绿灯 —— **主动报**，上一批五个 agent 都报了，这是加分不是扣分。
5. **不要 commit**。改完把结论报回来。
