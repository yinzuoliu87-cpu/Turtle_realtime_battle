## 4. 方案

### A. 图鉴战利品

- `detail_views.gd` `_render_right`：宝箱龟（`pet.id == "chest"`）在被动条下面加一节「战利品」：三个池子并排，每个池子一行抬头「基础池 · 第 1-2 箱」（池名 = 藏宝图说明里的词，第几箱从 `ChestLoot.OPEN_ORDER` 推，战斗开箱也改读这张表），下面图标每排 3 个，图标框按池子上色（基础银 / 进阶蓝 / 传说金）；后面的普攻条 / 技能卡整体下移。
- 点任一图标 ⇒ 这一节底下就地展开：名字（池子色）+ 池名 · 第几箱 + 说明（`ChestLoot.desc_bb`，与背包 / 对局面板同一条上色管线）；选中的格子铺池子色暗调；再点同一个收起。（原写弹 `InspectCard` 小卡：图鉴里点被动 / 技能都是就地展开，小卡要宿主提供挂载层与定位，图鉴没有 ⇒ 跟图鉴自己的做法走。）
- 门禁：新 `tests/verify_codex_chest_loot.gd` —— 宝箱龟页有 15 个图标（分母）、三档各 6 / 6 / 3、点一个弹出的卡名字与说明对得上、整排在右栏内不出界；非宝箱龟页没有这一排。

### B. 普攻特效重做（只换画面）

- 打谁、范围（前方 170 × 124 码直线）、按波头扫到的时刻结算 **都不动** ⇒ 对局结果不变、不升 `RULES_VER`（规则指纹门禁核）。
- 先找商业游戏同类「重物砸地 → 冲击沿直线推出去」的普攻 / 技能当尺子（逐帧看：砸点、推进、命中、收尾各几帧），再按宝箱主题重做专属素材（箱子砸地的冲击、金币 / 宝石飞溅、沿地面推进的金色冲击、命中点的专属爆闪），不再用通用的火焰光晕 / 能量光束。
- 做完录游戏实速视频给用户看；**用户认可前不提交、不跑预检 / CI**（美术规矩）。
