## 4. 方案

### A. 图鉴战利品

- （11-20 用户改：「十几件装备其实可以放在装备那一栏不用塞到龟里面吧」）图鉴「装备」栏末尾加一组「宝箱龟战利品」：件数 / 顺序读 `ChestLoot.POOL`（基础 → 进阶 → 传说），行描边按池子上色（基础银 / 进阶蓝 / 传说金），图标 32 像素原尺寸画（`list_builder._add_equip_rows`）。
- 点开 = 战利品详情页，版式照装备页（`CodexDetail._show_loot`）：头图 + 名字 + 副标「宝箱龟战利品 · 基础池 · 第 1-2 箱」（池名 = 藏宝图说明里的词，第几箱从 `ChestLoot.OPEN_ORDER` 推，战斗开箱也改读这张表）→ 效果（`ChestLoot.desc_bb`，与背包 / 对局面板同一条上色管线）→ 获得方式（`ChestLoot.source_text`）。
- 龟页不放（第一版放在宝箱龟页被动条下面，用户看了改到装备栏）。
- 门禁：`tests/verify_codex_chest_loot.gd` —— 装备栏战利品条目 = POOL 全部、顺序对、排在所有装备后面；逐件点开名字 / 效果 / 池名 · 第几箱 / 获得方式对得上；手机 / iPad 两种比例字都在详情框内；龟页没有这一节。`verify_codex_browse` 的「装备栏行数 = 数据条数」改为「装备 + 战利品」，行框色契约补「战利品 = 池子色」。
- 顺手修（实拍发现）：王者之冠 / 星际龟的星辉 / 坚固木盾 3 张图标带着生成时的深色底，抠掉；王者之冠 / 木盾补 1 像素深色描边（`tools/oneoff/chest_loot_icon_bg_fix.py`，`icon_art_audit` 过）。
