## 0. 一句话结论

**批 3 加的 35 件新装备只有属性、没有效果。**（实跑核实：`p2eq_060`~`p2eq_094` 在
`equip_system.gd` / `equip_tick_system.gd` / `RealtimeBattle3DScene.gd` /
`battle_damage.gd` / `battle_ballistics.gd` 五个效果层文件里**零出现**。）

**这不是遗漏，是方案书 `20260802-装备扩充.md` §7 的有意切分** ——
批 3 定义为「内容层」，门禁只守「件数 59→94 / 类型计数 / 费用分布 / 每件三星属性非空」。
当时羁绊还没实装，效果无从贴合。**现在羁绊全部定稿了（v0.19.2~v0.19.11），这批就该做了。**

### 一个好消息与一个坏消息

- ✅ **文案没有骗人**：35 件的 `effectDesc1/3` 全是**风味文本**（"深海里飘着的一顶伞，看得见摸不着"），
  一句效果都没承诺。所以现状是"纯属性装"，不是"说了做不到"。
- ⚠ **但它们现在与旧装备不是一个物种**：旧 59 件里 55 件有触发效果，新 35 件一件都没有。
  玩家买到 5 费的「万潮法典」和 5 费的旧装，体验完全不同档次。

## 1. 调查结论（全部带实跑证据）

### 1.1 现成的效果钩子（**方案书里每条效果必须落在这些钩子上**）

| 钩子 | 调用点数 | 目前挂了几件 | 时机 |
|---|---|---|---|
| `_eq_on_hit` | 2 | 13 | 每次攻击命中后 |
| `_eq_on_basic_attack` | 3 | 9 | 普攻发出时 |
| `_eq_on_cast` | 2 | 19 | 放技能时 |
| `_eq_on_target` | 1 | 5 | 选中目标时 |
| `_eq_on_kill` | 1 | 1 | 击杀时 |
| `_eq_on_death` | 1 | 5 | 自己阵亡时 |
| `_eq_on_dodge` | 1 | 2 | 闪避成功时 |
| `_tick_eq_intervals` | 6 | 1 | **每 2.5 秒**（`EQ_TICK`） |
| `fire_equip_effect` | 2 | — | 周期效果的**统一入口**（法器法力条满也走它） |

★ `fire_equip_effect(u, iid, star, stt)` 是 2026-08-03 抽出来的 ——
「周期到点」与「法器法力条满」必须走**同一条路**，否则同一件装备会长出两套行为。
**新装备的周期效果一律挂进它的 `match`，不要另起分发。**

### 1.2 属性字段的真实通道（写效果时会用到）

| 字段 | 单位上的落点 | 消费点 |
|---|---|---|
| `atk` / `hp` / `def` / `mr` | `base_atk` / `maxHp` / `base_def` / `base_mr` | `_recalc_stats` |
| `crit` / `critDmg` | `crit` / `crit_dmg` | `DamageMath.crit_multiplier` |
| `armorPen` / `magicPen` | `armor_pen` / `magic_pen` | `_mitigate_incoming` |
| `armor_pen_pct` / `magic_pen_pct` | 同名 | `battle_damage.gd:505,507` |
| `_lifestealPct` | `lifesteal` | `battle_damage.gd:226`（= `lifesteal + ls_bonus`）|
| `_maxEnergy` | `init_energy_bonus` | **只减开局冷却**（`龟能 × 0.075` 秒），一次性 |
| `_echargePct` | 充能速率 | — |
| `_aspdPct` | `aspd_perm`（**加算**通道） | `atk_cd` |
| `_mspdPct` / `_rangePct` | 移速 / `atk_range` | `_eff_range` |
| `healAmp` / `shieldAmp` | `heal_amp` / `shield_amp` | `_heal` / `_grant_shield` |
| `dodgePct` | `dodge` | `_recalc_stats`（**硬上限 75%**）|
| `damage_amp` | 同名 | `battle_damage.gd:546` + `RB:4243`（**乘所有伤害**）|

### 1.3 三条设计约束（从已有 55 件与羁绊定稿里读出来的）

1. **效果要贴该件的类型羁绊主题** —— 这是方案书 `20260802` §7 解耦批 3 与批 4 的前提。
   例：弓箭件的效果应该围绕**处决 / 腐蚀**，不该是"回血"。
2. **1 费件的效果要简单**（一个触发一个结果），**5 费件才配复合机制**。
   费用分布见 §2 各表。
3. **不许再造"周期分发"** —— 周期效果进 `fire_equip_effect` 的 `match`。

## 4. 已知风险与未决点

### 未决点（**写成选择题，一句话可拍**）

**U1｜35 件一次做完，还是按类型分批？**
- **A. 一次做完**（一个版本号）。代价：改动面大，出问题难归因。
- **B. 按类型分 10 批**（每批 2~5 件）。代价：10 个版本号 + 10 轮门禁。
- **C. 按"钩子"分 3 批**：①周期类（12 件，全进 `fire_equip_effect`）②命中/普攻类（10 件）③其余（13 件，含 2 个新钩子）。
→ **建议 C** —— 同一钩子的件放一起做，门禁能共用，且新钩子（风险最高）单独一批。

**U2｜076 腐蚀重弩叠的层，`corrode_tier` 取什么？**
带弓箭羁绊时用羁绊档位；**不带羁绊时**呢？
- **A. 按 1 档算**（每层 +2%，满层转 10% 真伤）。最保守。
- **B. 按装备星级算**（1★→1 档 / 2★→2 档 / 3★→3 档）。让装备独立成立。
- **C. 不带羁绊就不能叠**。代价：这件在无羁绊阵容里废掉。
→ **建议 B**。

**U3｜083 潮汐细剑的层数，要不要被【剑士】的追打喂？**
剑士追打**会触发 on-hit**（这是它的设计），所以默认会喂。
- **A. 会喂**（追打每次都加层）⇒ 剑阵容里 083 层数涨得飞快。
- **B. 不喂**（追打打的那几下不加层）。代价：要在追打路径上打标记。
→ **建议 A**（这正是"剑 + 剑"的协同），但**需要 §4 R1 的量级复核**。

**U4｜087 深渊铸币机在没有奇械羁绊时，铸币上限是多少？**
羁绊铸币的上限是 `5/9/14/20`（按档），装备侧共用。
- **A. 无羁绊时上限 = `6/10/15`（按星级）**，有羁绊时取两者较大值。
- **B. 无羁绊时不能铸**。代价：这件 5 费装在无奇械阵容里只剩属性。
- **C. 无羁绊时单独上限 8 枚**（固定）。
→ **建议 A**。

**U5｜068 万灵龟血的"击杀猎物双倍"，与羁绊【战利品】叠加后总量?**
战利品是 +5/8 攻/猎物（全队），068 是 +4/7/12（本体，猎物双倍 → 最高 +24/次）。
一场杀 4 只猎物 ⇒ 068 本体最多 +96，加战利品 +32 = **+128 攻**（龟基础攻中位 40）。
- **A. 照上表**（上限 60/110/180 兜底）。
- **B. 把 068 的猎物双倍去掉**，只留基础值。
- **C. 上限砍半**。
→ **建议 A**（上限已经兜住），但**要跑 §4 R1 的量级检查**。

**U6｜新钩子「受到致命伤害时」（063 幽影墨囊）的判定位置？**
- **A. 挂 `_mitigate_incoming` 之后、扣血之前**（两条伤害路径都要，CLAUDE.md §3.3）。
- **B. 挂 `_kill` 入口，死了再救回来**。代价：`_kill` 里已有一串效果（收殓/猎获/亡灵），插进去顺序难定。
→ **建议 A**。

**U7｜版本号粒度？**
按 U1 的分批走：C 方案 = 3 批 = 3 个版本号 + 3 个 tag。

### 风险

**R1｜量级失控（最高风险）**
这批里有 **6 件"本场永久累积"**（068/070/091/092 + 羁绊的战利品/远古之力/成长）。
它们**互相叠加且都没有统一账本**。
⇒ 必须建一条 `verify_equip_growth_magnitude` 门禁：满配阵容跑满一场，
**算总增益倍率**，卡在设计带内。（羁绊那边已有 `verify_synergy_magnitude` 可照抄口径。）

**R2｜两个新钩子会波及所有装备**
「受到致命伤害」与「受到治疗」是**中央管线上的新分支**，加错会影响全部 95 件。
⇒ 两条都要**反向验证**：把钩子改成空转，确认对应门禁会红。

**R3｜`fire_equip_effect` 的 `match` 会膨胀到 13 件**
现在只有几条。加完之后这个函数会很长。
⇒ 按类型分组加注释分隔；**不要拆成多个分发函数**（那正是 2026-08-03 抽出它要解决的问题）。

**R4｜078 追加射击的"不触发 on-hit"必须焊死**
不焊的话与剑士追打 / 冰封掷骰 / 僵硬叠层形成连锁，可能自激。
⇒ 门禁：造一个带 078 + 剑士羁绊的单位，断言追加那发**不产生**剑士追打。

**R5｜082 / 084 是常驻修正，换路会丢**
换路重建单位字典（`_dl_clear_units` → `_make_unit`），常驻字段必须由
`_eq_apply_all_stats` 重写。⇒ 门禁：模拟换路后断言字段还在（照 `verify_synergy_rest5` 的做法）。

**R6｜文案要同步写**
35 件现在的 `effectDesc1/3` 是纯风味文本。加效果后**必须把效果写进文案**，
且要过 `tooltip_number_audit`（装备文案数值 ↔ 代码，进门禁）。
⇒ 这条**不是可选项** —— 不写文案 = 玩家买了不知道买了什么。
