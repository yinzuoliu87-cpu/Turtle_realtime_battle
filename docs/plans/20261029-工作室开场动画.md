# 工作室开场动画「灯鱼 Lampfish」（启动 → 开场标 → 主菜单）

日期：2026-10-29　|　状态：**草稿**（规格已按参考量出；素材在出，代码未动）

## 1. 需求原文（逐字）

- 用户 10-28：「然后现在开始游戏的时候，不是它会弹那个 g o d o t 引擎吗？把这个东西去掉，然后来做一个相当于只有我们工作室的一个，呃，开场动画，然后就调到那个小游戏的主界面，来想办法怎么做。」
- 用户 10-28：「我们现在也没有做工作室的名字，所以这些都可能要你来定一个。」→ 第一批（壳格 / 慢壳…）被否：「你为什么一定要限制在这种壳和这种格子之类的呢？」→ 第二批里用户选「灯鱼」。
- 用户 10-28 看代码手画的分镜：「质量不行。现在大模型不是能做非常质量高的视频吗？」
- 用户 10-29 看「整屏插画 + 光圈照开」预览：「不太行，跟别的游戏差太多」。
- 用户 10-29：「一定要用 Wave 吗？有其他软件吗？」→ 查实用户的 Gemini 是 Plus 档，有「制作视频」。
- 用户 10-29：「我们整个工作室的这个动画是占屏幕这么大吗？也没有这么大吧？到到底大小怎么样？到底怎么设计？你提前搞清楚了呀？」→ 用户「行」同意按下面 §4.1 的规格重做。

## 2. 调查

- 去 Godot 标已在 0.22.4 完成（见 [20261028-手机打字输入条.md](20261028-手机打字输入条.md) §4 最后一段，`tests/verify_boot_splash.gd`）。iPhone 启动屏 = 纯色 #0a0e18。
- 逐帧研究 10 家商业开场（会话 scratchpad `studio_intro/frames/研究.md`，每家一张接触印相）：
  1. 0.23~0.7 秒内标志就看得清（Supercell 0.23 秒满亮；Riot 第一帧就在）。
  2. 到场那一下有高峰再回落（Supercell 光晕 0.8 秒退、亮度回落 28%；Riot 整屏反色白闪约 0.2 秒；天美外扩光环）。
  3. 动的标志都配一个短声音记号，对准高峰（Supercell 0.35 秒 5 个上行音；Riot 上扬 + 重击）。
  4. 文字晚一拍「弹」出，不淡入（Riot「RIOT」→ 0.23 秒后「GAMES」）。
  5. 快进慢出（Riot 拳头每 1/30 秒位移 13/39/18/8/5/3 像素）。
  6. 停留段不完全冻结。
  7. 手游开场 1.5~3.6 秒，0.17~0.6 秒快速收尾，接整屏插画的加载画面。
  8. **标志小、平、高对比、纯色底**：Supercell 字只占画宽约 21%；整屏插画式只有天美 6 秒电影版。

## 3. 需求 ↔ 现状的出入

- 我第一版（会话 scratchpad `lampfish/logo_v1.png`）是整屏插画（深海场景 + 光线 + 粒子 + 字），与参考第 8 条相反；预览 `preview_b.mp4` 又违反第 1~4、6 条。**规格没先定就出了图**，本篇从规格开始。

## 4. 方案

### 4.1 规格（用户 10-29「行」）

| 项 | 规格 | 依据 |
|---|---|---|
| 底 | 纯色 #0a0e18，与 iPhone 启动屏同色（启动屏 → 开场不闪） | 参考 8；`project.godot` boot_splash/bg_color |
| 标志 | 小鱼 + 灯做成独立标志（不带场景背景），连同字整组宽约屏宽 25~30%，居中略偏上 | 参考 8（Supercell 21%） |
| 字 | LAMPFISH + 灯鱼，**游戏里叠**（视频模型写字不可靠），对准声音弹出，略过冲 | 参考 4、5 |
| 0~0.25 秒 | 灯「啪」亮起 + 闪光 + 「叮」；0.3 秒内看清小鱼 | 参考 1、2、3 |
| 0.25~0.8 秒 | 光晕回落；小鱼眨眼、扭一下 | 参考 2、6 |
| ≈0.6 秒 | LAMPFISH 弹出；+0.2 秒「灯鱼」弹出 | 参考 4 |
| 停留 ≈1 秒 | 灯火微闪，不全冻结 | 参考 6 |
| 收尾 | 0.3 秒淡出 → 主菜单 | 参考 7 |
| 总长 | ≈2.5 秒；0.3 秒后点任意处跳过 | 参考 7 |

### 4.2 素材路线

- 标志（纯色底小鱼 + 灯）与视频：用户的 Gemini Plus「制作图片」「制作视频」（不另花钱）。视频只出小鱼的动作；字、闪光时机、声音在游戏里对齐。
- 声音：Gemini「制作音乐」试一个 0.3~0.6 秒的记号音；不行再找可商用音效。

### 4.3 接入（待素材定稿后展开穷举）

新场景当 `run/main_scene`，播完 `SceneNav.go` 主菜单；陪练号 / 无头首帧直通主菜单。会碰：`verify_account_delete` ⑦、存档闸（`GameState.gd`）、`smoke_scenes`、`_play_driver`。
