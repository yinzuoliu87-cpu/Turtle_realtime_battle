## 2. 调查结论

现状（`scripts/scenes/SettingsScene.gd` 改前版本，截图 `C:/tmp/np2/set.png`）：

- 整页一列居中：账号四行（`_account_row`）→ 两条音量（`_slider_row`）→ 四块 260×50 木牌（`_text_button`）。左右各空约 400px。
- 木牌是**循环按钮**：「画面「窗口」」「画质「高」」点一下换字（`_fullscreen_label` / `_perf_label`），不点看不出有几个值。
- 「🛠 调试场」「⚠ 重置所有存档」带 emoji；重置与普通选项同一列同一种牌。
- 画质底层只有一个布尔 `GameState.perf_lite`（`_toggle_perf`），没有「中」档；显示模式是 `GameState.fullscreen` + `DisplayServer.window_set_mode`。
- 调试场 gate：`OS.is_debug_build() or OS.has_environment("DEVTOOLS")`；测试时间 gate：`phase2_config.time_travel_allowed()`。正式包不显示 —— 已经是对的，只是门禁只查源码。
- 重置已有二次确认（`_ask_reset` → `_do_reset`），`verify_settings` 4/5/6 守着。

参考：`docs/plans/ref/20261007-设置页参考/`（README 写了每张取什么）—— Brawl Stars（分组 ON/OFF 分段钮）、Angry Birds Journey（版本号 + 玩家 ID 底部小字）、Disney Mirrorverse（金属框 + SOUND/OPTIONS 小标题、ACCOUNT 页签的登录块）、Adorable Home（滑条 + ID + 云存档提示框）、Amazing Bomberman（左名 · 滑条 · 右值）。

## 3. 需求 ↔ 代码的出入

- 派活说明里写「画质 = 低/中/高（以现有值为准）」：**现有只有两档**（`perf_lite` 布尔）⇒ 分段钮做成「低 / 高」两段，不凭空造「中」档。
- 说明写「已绑定 · 邮箱 a***@x.com」（打码）：`verify_account` ④ 断言绑定态屏幕上显示完整邮箱（玩家要知道自己绑的是哪个）⇒ 保留完整邮箱，打码列为未决点。
- 说明写「显示 = 窗口/全屏（只在适用平台）」：改前所有平台都显示，手机上切了没反应 ⇒ 新增 `_display_row_on()`：`OS.has_feature("mobile")` 时不建。
- 说明写「重置存档 = 小号红描边文字键」：仓库里的像素按钮只有实心红/金/石板三种 ⇒ 用石板底 + 红字（实心红留给弹框里「确认重置」那一下）。

## 4. 方案

全部在 `scripts/scenes/SettingsScene.gd`，不新增素材：

| 位置 | 改法 |
|---|---|
| `_ready` | 左框 `_account_panel`（仅后端开着）+ 右框 `_settings_panel` + 底部 `_footer`；没配后端时右框居中 |
| `_account_panel`（替换 `_account_row`） | 状态分支逐条照搬（连接中/登录失效/存档冲突/已绑定/未绑定）；名字 26px → 玩家 ID → 状态卡（压暗底 + 状态色竖条）→ 按钮钉框底、满宽 56 高，主操作金色（未绑定=绑定邮箱，登录失效=邮箱登录，冲突=处理存档冲突）；节点名 `AcctRow*` 不变，新增 `AcctRowPanel`/`AcctRowCard` |
| `_settings_panel` | 「声音」音乐/音效（左名 · 406 宽槽 · 右 %）；「画面」显示（桌面端）/ 画质，`_segmented` 分段钮（`UISkin.pixel_tab`）；常驻小字「低画质更流畅 · 下场战斗生效」 |
| `_footer` | 左：版本 v（ProjectSettings）· 玩家 ID；右：调试场 / 测试时间（gate 原样）+ 最右「重置存档」 |
| 框 / 按钮 | 框 = `SettleScreen.frame_style()`（panel-frame 九宫格，mouse_filter=IGNORE）；按钮 = `UISkin.pixel_button` |
| 删除 | `_small_button` `_text_button` `_place_flow` `_slider_row` `_fullscreen_label` `_perf_label` `_toggle_perf` `_toggle_fullscreen` 及流水常量 |
| 新增 | `_set_fullscreen` `_set_perf_lite` `_segmented` `_frame_panel` `_heading` `_row_label` `_place_left` `_pix_button` `_display_row_on` `_is_full`；常量 `SEG_DISPLAY` `SEG_QUALITY` `RESET_BTN` `DEV_ARENA_BTN` `FOOT_LABEL`；测试缝 `release_override` |
| 重置弹框 | 标题去 ⚠；两颗键换 `pixel_button`（取消石板 / 确认红） |
| 音量槽 | 不再染青铜（槽现在坐在同族深蓝框里），槽底改深海军蓝 |

## 5. 已知风险与未决点

- 🔲 **邮箱打码**：派活说明举例「a***@x.com」；现在显示完整邮箱（`verify_account` ④ 守着）。要打码需用户拍板，并同步改那条断言。——未决
- 🔲 **画质三档**：只有低/高两档（底层是布尔）。要加「中」需要先定义中档具体关什么。——未决
- ⚠ 手机安全区：设计框 1280×720 由 `UIFrame` 居中，两侧刘海区只有背景；已在 2532×1061 实拍确认无内容进刘海。真机未验。——未验
- ⚠ `release_override` 是新测试缝（产品只读、只有 tests 写），已在 `write_orphan_audit` WHY 登记理由。——已堵
- ⚠ 「显示」行在 Web 端仍显示（浏览器全屏需要用户手势，Godot 在按钮回调里调用属于手势内）。——未验
- ⚠ toast 浮在底部条上方（y≈638），与底部小字可能短暂重叠 2 秒；节点名带 Toast，一致性门禁按名字豁免。——已知接受
