# 运维：数据库每周备份

线上数据库（Supabase 免费档）**不带自动备份**，所以仓库里有一个自动任务 `.github/workflows/db-backup.yml`：
**每周一北京时间 11:00** 自动把整个数据库导出一份，加密后存在 GitHub 上，保留 **90 天**（约 13 份）。

第一次用之前，要在 GitHub 网页上填**两个密钥**。全程只用浏览器，不用写代码。

---

## 第一步：从 Supabase 拿到「数据库连接串」

1. 打开 <https://supabase.com/dashboard>，登录，点进本游戏的项目。
2. 点页面顶部的 **Connect（连接）** 按钮（老版界面在 **Project Settings → Database → Connection string**）。
3. 选 **Connection string** 页签，类型选 **URI**。
4. 往下找到 **Session pooler** 那一栏（⚠ **不要用 Direct connection** —— 那个地址 GitHub 连不上），复制那一串，长得像：
   ```
   postgresql://postgres.xxxxxxxx:[YOUR-PASSWORD]@aws-0-xx-xxxx-1.pooler.supabase.com:5432/postgres
   ```
5. 把里面的 `[YOUR-PASSWORD]`（**连方括号一起**）换成你的**数据库密码**。
   - 忘了密码：同一页（或 Project Settings → Database）有 **Reset database password**，重置后用新密码。
   - 密码里如果有 `@ # / ? : %` 这类符号，重置一个**只含字母和数字**的密码最省事。
6. 这一整串先粘到记事本里备用。**不要发给任何人、不要贴进聊天或代码里。**

## 第二步：在 GitHub 上添加两个密钥（Secret）

1. 打开仓库页面 → 顶部 **Settings（设置）** → 左栏 **Secrets and variables** → **Actions**。
2. 点绿色按钮 **New repository secret**：
   - **Name** 填：`SUPABASE_DB_URL`
   - **Secret** 填：第一步记事本里那一整串
   - 点 **Add secret**。
3. 再点一次 **New repository secret**：
   - **Name** 填：`BACKUP_PASSWORD`
   - **Secret** 填：**你自己想一个长密码**（比如 20 位以上字母数字）。这是给备份文件加密用的。
   - 点 **Add secret**。
4. ⚠ **`BACKUP_PASSWORD` 一定要另外抄一份存好**（密码管理器 / 纸上）。GitHub 存进去后**再也看不到原文**，忘了就**打不开任何备份**。

> 为什么要加密：仓库是公开的，而公开仓库里的备份文件**任何登录 GitHub 的人都能下载**。备份里有玩家数据，所以必须加密。

## 第三步：手动跑一次，确认能用

1. 仓库页面顶部 → **Actions**。
2. 左栏点 **Weekly DB backup**。
3. 右侧点 **Run workflow** → 再点绿色的 **Run workflow**。
4. 等一两分钟刷新，出现**绿色对勾**就是成功。
   - **红叉**：点进去看红色报错。写着「缺少 SUPABASE_DB_URL / BACKUP_PASSWORD」就是第二步没填好；
     写着连接失败，多半是连接串用成了 Direct connection，或密码没替换对。
   - 另外：Supabase 免费项目**一周没人访问会自动暂停**，暂停时备份也会失败 —— 去 Supabase 后台点恢复即可。

## 第四步：下载备份

1. **Actions** → 左栏 **Weekly DB backup** → 点某一次**绿色对勾**的运行记录。
2. 页面最下面 **Artifacts** 区域，点 `db-backup-日期` 下载（是一个 zip）。
3. 解开 zip 得到 `db-backup-日期.7z`，用 **7-Zip**（<https://www.7-zip.org>，免费）打开，输入 `BACKUP_PASSWORD` 的密码。
4. 里面三个文件：`roles.sql`（角色）、`schema.sql`（表结构）、`data.sql`（数据）。
   需要还原时把这三个文件交给开发者（按 roles → schema → data 的顺序导入新项目）。

备份每份保留 90 天后自动删除；想长期保存某一份，下载下来自己存好即可。
