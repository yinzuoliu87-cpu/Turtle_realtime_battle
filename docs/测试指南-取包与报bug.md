# 测试指南 · 怎么拿包 + 怎么报 bug

> 给测试人员的一页纸。目标:**每次都从一个固定地方拿最新包**,报 bug **说得清是哪个版本**。

---

## 一、拿最新测试包(iOS)

**永远从这一个地方拿**:
👉 **Release「ios-latest」** — https://github.com/yinzuoliu87-cpu/Turtle_realtime_battle/releases/tag/ios-latest
下载里面的 `turtle-ios-unsigned.ipa`。

- **它是自动更新的**:开发每次 push 到 main,几分钟后这个包就换成最新的(同一个链接,不用找)。
- 想确认拿到的是不是最新:进游戏看**主菜单右下角的版本号**,和 Release 页最近更新时间对一下。

## 二、装到 iPhone(Sideloadly)

`.ipa` 是**未签名**包,不能直接装,得用 **Sideloadly** 签名安装:

1. 电脑(Windows/Mac)装 **Sideloadly**(sideloadly.io)。
2. iPhone **USB 连电脑**,信任这台电脑。
3. Sideloadly 里**拖入** `turtle-ios-unsigned.ipa`,填你的 **Apple ID**(用免费个人 ID 就行)。
4. 点 Start,签名 + 安装。
5. 手机上:**设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID 证书**,才能打开。

> ⚠ 免费证书 **7 天过期**,过期后 app 打不开——**重新 Sideloadly 签一次**即可,**存档不丢**。

## 三、报 bug(三样必带)

报 bug 请一定带上这三样,否则很难定位:

1. **版本号** —— 主菜单**右下角**那个 `v0.x.y`。(这是最重要的一条:说不清版本,开发就没法查是哪次改动引入的。)
2. **复现步骤** —— 什么操作 → 出了什么问题。越具体越好(哪只龟、哪个技能、哪一步)。
3. **截图 / 录屏** —— 视觉/手感类问题**必须**配图,文字描述不出来。

**bug 模板(复制着填):**
```
版本:v0.__.__
问题:一句话说清
复现:① … ② … ③ …
期望:本该怎样
截图/录屏:(附上)
```

## 四、调试场(开发工具·测试可用)

主菜单右下角 **🛠 调试场**(debug 包才有):
- **底部笔刷栏**点一只龟/小将/精英/大师 → 点战场**连点连摆**。
- **点已摆的龟** → 右边配置:技能 / 装备 / 星级 / **血量** / **无敌** / **满龟能**(逐只)。
- **⊟ 折叠**收起设置面板,释放整个战场。
- 训龟大师:摆下后**按 Q** 放主动技(在配置里选钩锁/怒火药水/口哨/冰川)。

拿它复现/隔离问题最快:摆一只有问题的龟 + 一个假人,开满龟能秒放技看效果。
